CharacterSet‑enumerationen definierar de möjliga uppsättningarna av teckenglyfer som är definierade i<br/>                teckensnitt för grafikoutput.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfCharacterSet

## **Members**
| **Member name** | **Description** |
| :- | :- |
| ANSI | Anger den engelska teckenuppsättningen. |
| ARABIC | Anger den arabiska teckenuppsättningen |
| BALTIC | Anger den baltiska (nordöstra europeiska) teckenuppsättningen |
| CHINESEBIG5 | Anger den "traditionella" kinesiska teckenuppsättningen, som främst används i<br/>                Taiwan samt i Hongkong och Macao särskilda administrativa regioner. |
| DEFAULT | Anger en teckenuppsättning baserad på det aktuella systemets språk; för<br/>                exempel, när systemets språk är amerikansk engelska, är standardteckenuppsättningen<br/>                ANSI_CHARSET. |
| EASTEUROPE | Anger en östeuropeisk teckenuppsättning. |
| GB2312 | Anger den "förenklade" kinesiska teckenuppsättningen för Folkrepubliken Kina. |
| GREEK | Anger den grekiska teckenuppsättningen. |
| HANGUL | Även stavat "Hangeul". Anger den Hangul koreanska teckenuppsättningen. |
| HEBREW | Anger den vietnamesiska teckenuppsättningen. |
| JOHAB | Även stavat "Johap". Anger den Johab koreanska teckenuppsättningen. |
| MAC | Anger Apple Macintosh-teckenuppsättningen. |
| OEM | Anger en mappning till en av OEM:s kodsidor, enligt den aktuella<br/>                systemlokalinställningen. |
| RUSSK | Anger den ryska kyrilliska teckenuppsättningen. |
| SHIFTJIS | Anger den japanska teckenuppsättningen. |
| SYMBOL | Anger en teckenuppsättning av symboler. |
| THAI | Anger den thailändska teckenuppsättningen. |
| TURKISK | Anger den turkiska teckenuppsättningen. |
| VIETNAMSISK | Anger den vietnamesiska teckenuppsättningen. |
