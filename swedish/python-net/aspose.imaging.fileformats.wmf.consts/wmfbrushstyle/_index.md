BrushStyle‑enumerationen specificerar de olika möjliga penseltyperna<br/>                som kan användas i grafikoperationer. För mer information, se<br/>                specifikationen av Brush‑objektet (avsnitt 2.2.1.1).

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfBrushStyle

## **Members**
| **Member name** | **Description** |
| :- | :- |
| DIBPATTERN | En mönsterpensel specificerad av en DIB. |
| DIBPATTERNPT | En mönsterpensel specificerad av en DIB. |
| DIBPATTERN_8X8 | Stöds inte. |
| GRADIENT | Gradienten<br/>            Stöds inte i wmf, stöd i odg. |
| HATCHED | En pensel som målar ett fördefinierat enkelt mönster, eller "hatch", på en solid bakgrund |
| INDEXED | Stöds inte. |
| MONOPATTERN | Stöds inte. |
| NULL | En pensel som inte gör någonting. Att använda en NULL-pensel i en grafikoperation<br/>                MÅSTE ha samma effekt som att inte använda någon pensel alls |
| PATTERN | En pensel som målar ett mönster definierat av en bitmap, som KAN vara ett Bitmap16-objekt<br/>                eller ett DeviceIndependentBitmap (DIB)-objekt. |
| PATTERN_8X8 | Stöds inte. |
| SOLID | En pensel som målar en enda, konstant färg, antingen solid eller ditherad. |
