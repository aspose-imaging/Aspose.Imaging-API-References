16‑bitars PenStyle‑enumerationen används för att specificera olika typer av pennor som kan användas i grafikoperationer.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfPenStyle

## **Members**
| **Member name** | **Description** |
| :- | :- |
| ALTERNATE | Pennan sätter varannan pixel (denna stil är endast tillämplig för kosmetiska pennor). |
| COSMETIC | Den kosmetiska |
| DASH | Pennan är streckad. |
| DASHDOT | Pennan har alternerande streck och punkter. |
| DASHDOTDOT | Pennan har streck och dubbla punkter. |
| DOT | Pennan är prickad. |
| ENDCAP_FLAT | Linjeändspetsar är platta. |
| ENDCAP_ROUND | Linjeändkaparna är runda. |
| ENDCAP_SQUARE | Linjeändkaparna är fyrkantiga. |
| INSIDEFRAME | Pennan är solid. När denna penna används i någon ritningspost som tar en avgränsande rektangel, krymper figurens dimensioner<br/>                så att den passar helt inom den avgränsande rektangeln, med hänsyn till pennans bredd. |
| JOIN_BEVEL | Linjekopplingarna är avfasade. |
| JOIN_MITER | Linjekopplingarna är snedställda när de ligger inom den aktuella<br/>                gränsen som sätts av SETMITERLIMIT META_ESCAPE-posten. En koppling avfasas när den skulle överskrida gränsen. |
| JOIN_ROUND | Linjekopplingarna är runda. |
| NULL | Pennan är osynlig. |
| SOLID | Pennan är solid. |
| USERSTYLE | Pennan använder en stilarray som tillhandahålls av användaren. |
