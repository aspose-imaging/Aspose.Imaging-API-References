PostScriptClipping‑enumerationen definierar funktioner som kan tillämpas på klippningsvägen<br/>                som används för PostScript‑utdata.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfPostScriptClipping

## **Members**
| **Member name** | **Description** |
| :- | :- |
| CLIP_INCLUSIVE | Skär den aktuella PostScript-klippvägen med den aktuella klippvägen<br/>                och sparar resultatet som den nya PostScript-klippvägen. |
| CLIP_RESTORE | Återställer PostScript-klippvägen till den senaste klippvägen som sparades<br/>                av en tidigare CLIP_SAVE-funktion som tillämpades av en CLIP_TO_PATH-post (avsnitt 2.3.6.6). |
| CLIP_SAVE | Sparar den aktuella PostScript-klippvägen. |
