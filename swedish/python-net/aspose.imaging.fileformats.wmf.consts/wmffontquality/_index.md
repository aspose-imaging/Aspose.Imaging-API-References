FontQuality‑enumerationen specificerar hur nära attributen för det logiska teckensnittet bör matcha<br/>                de för det fysiska teckensnittet vid rendering av text.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfFontQuality

## **Members**
| **Member name** | **Description** |
| :- | :- |
| ANTIALIASED | Anger att anti-aliasing SKALL användas när text renderas, if<br/>                the font supports it. |
| CLEARTYPE | Anger att ClearType anti-aliasing SKALL användas när<br/>                text renderas, if the font supports it. |
| DEFAULT | Anger att teckensnittets teckenkvalitet inte spelar någon roll, så<br/>                DRAFT kan användas. |
| DRAFT | Anger att teckensnittets teckenkvalitet är mindre viktig än den<br/>                logiska attributens matchning. För rasteriserade teckensnitt bör skalning SKALL vara aktiverad, vilket<br/>                betyder att fler teckensnittsstorlekar är tillgängliga. |
| NONANTIALIASED | Anger att anti-aliasing INTE SKALL användas när<br/>                text renderas |
| PROOF | Anger att teckensnittets teckenkvalitet är viktigare än den<br/>                logiska attributens matchning. För rasteriserade teckensnitt bör skalning SKALL vara inaktiverad, och det teckensnitt<br/>                som är närmast i storlek SKALL väljas. |
