PaletteStyle‑flaggorna specificerar egenskaper för grafikpaletter. Dessa flaggor kan kombineras för att ange flera alternativ.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusPaletteStyleFlags

## **Members**
| **Member name** | **Description** |
| :- | :- |
| PALETTE_STYLE_GRAY_SCALE | Om den är inställd måste paletten endast innehålla gråskaleposter. |
| PALETTE_STYLE_HALFTONE | Om den är inställd måste paletten innehålla diskreta färgvärden som kan användas för halvtoning. |
| PALETTE_STYLE_HAS_ALPHA | Om den är inställd måste en eller flera av palettposterna innehålla alfa-genomskinlighetsinformation. |
