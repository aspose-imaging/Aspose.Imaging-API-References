CompositingQuality‑enumerationen definierar kvalitetsnivåer för att skapa sammansatta bilder.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusCompositingQuality

## **Members**
| **Member name** | **Description** |
| :- | :- |
| COMPOSITING_QUALITY_ASSUME_LINEAR | Ingen gamma‑korrektion utförs; dock ger användning av linjära värden bättre kvalitet än standardvärdet med en något lägre hastighet. |
| COMPOSITING_QUALITY_DEFAULT | Ingen gamma‑korrektion utförs. Gamma‑korrektion styr bildens totala ljusstyrka och kontrast. Utan gamma‑korrektion kan sammansatta bilder framstå som för ljusa eller för mörka. |
| COMPOSITING_QUALITY_GAMMA_CORRECTED | Aktivera gamma‑korrektion för sammansättning av högre kvalitet med lägre hastighet. När det gäller resultatet finns ingen skillnad mellan detta värde och CompositingQualityHighQuality. |
| COMPOSITING_QUALITY_HIGH_QUALITY | Gamma‑korrektion utförs. Sammansättningskvalitet prioriteras på bekostnad av hastigheten. |
| COMPOSITING_QUALITY_HIGH_SPEED | Ingen gamma‑korrektion utförs. Sammansättningshastigheten prioriteras på bekostnad av kvalitet. När det gäller resultatet finns ingen skillnad mellan detta värde och CompositingQualityDefault. |
