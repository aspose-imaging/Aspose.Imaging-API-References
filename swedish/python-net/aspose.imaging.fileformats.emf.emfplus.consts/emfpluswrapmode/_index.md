WrapMode‑enumerationen definierar hur mönstret från en textur‑ eller gradientpensel tileläggs över en form eller vid formens kanter när det är mindre än det område som fylls.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusWrapMode

## **Members**
| **Member name** | **Description** |
| :- | :- |
| WRAP_MODE_CLAMP | Fixerar texturen eller gradienten till objektets gräns. |
| WRAP_MODE_TILE | Upprepar gradienten eller texturen. |
| WRAP_MODE_TILE_FLIP_X | Vänder texturen eller gradienten horisontellt, och därefter upprepar texturen eller gradienten. |
| WRAP_MODE_TILE_FLIP_XY | Vänder texturen eller gradienten horisontellt och vertikalt, och därefter upprepar texturen eller gradienten. |
| WRAP_MODE_TILE_FLIP_Y | Vänder texturen eller gradienten vertikalt, och därefter upprepar texturen eller gradienten. |
