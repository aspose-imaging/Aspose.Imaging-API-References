StringTrimming‑enumerationen definierar hur man trimmar tecken från en sträng som är för stor för textrutans layoutrektangel.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusStringTrimming

## **Members**
| **Member name** | **Description** |
| :- | :- |
| STRING_TRIMMING_CHARACTER | Anger att strängen bryts vid gränsen för det sista tecknet som ligger inom layoutrektangeln. Detta är standard. |
| STRING_TRIMMING_ELLIPSIS_CHARACTER | Anger att strängen bryts vid gränsen för det sista tecknet som ligger inom layoutrektangeln, och en ellips (...) infogas efter tecknet. |
| STRING_TRIMMING_ELLIPSIS_PATH | Anger att mitten tas bort från strängen och ersätts av en ellips. Algoritmen behåller så mycket som möjligt av den sista delen av strängen. |
| STRING_TRIMMING_ELLIPSIS_WORD | Anger att strängen bryts vid gränsen för det sista ordet som ligger inom layoutrektangeln, och en ellips (...) infogas efter ordet. |
| STRING_TRIMMING_NONE | Anger att ingen trimning utförs. |
| STRING_TRIMMING_WORD | Anger att strängen bryts vid gränsen för det sista ordet som ligger inom layoutrektangeln. |
