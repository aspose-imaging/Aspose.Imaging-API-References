StringDigitSubstitution‑enumerationen definierar sätt att ersätta siffror i en sträng enligt en användares språk eller lokala inställningar.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusStringDigitSubstitution

## **Members**
| **Member name** | **Description** |
| :- | :- |
| STRING_DIGIT_SUBSTITUTION_NATIONAL | Anger substitutionssiffror som motsvarar det officiella nationella språket för användarens lokala inställning. |
| STRING_DIGIT_SUBSTITUTION_NONE | Anger att inaktivera substitutioner. |
| STRING_DIGIT_SUBSTITUTION_TRADITIONAL | Anger ersättningssiffror som motsvarar användarens inhemska skript eller språk, vilket kan skilja sig från det officiella nationella språket för användarens lokala inställning. |
| STRING_DIGIT_SUBSTITUTION_USER | Anger ett implementationsdefinierat ersättningsschema. |
