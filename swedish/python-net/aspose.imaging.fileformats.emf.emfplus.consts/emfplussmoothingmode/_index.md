SmoothingMode‑uppräkningen definierar utjämningslägen som tillämpas på linjer, kurvor och kanterna på fyllda områden för att få dem att framstå som mer kontinuerliga eller skarpt definierade.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusSmoothingMode

## **Members**
| **Member name** | **Description** |
| :- | :- |
| SMOOTHING_MODE_ANTI_ALIAS_8X4 | Anger god kvalitet med ett 8x4‑boxfilter. |
| SMOOTHING_MODE_ANTI_ALIAS_8X8 | Anger bättre kvalitet med ett 8x8‑boxfilter. |
| SMOOTHING_MODE_DEFAULT | Anger standardkurvutjämning utan kantutjämning. |
| SMOOTHING_MODE_HIGH_QUALITY | Anger bästa kvalitet med kantutjämning. |
| SMOOTHING_MODE_HIGH_SPEED | Anger bästa prestanda utan kantutjämning. |
| SMOOTHING_MODE_NONE | Utför ingen kurvutjämning och ingen kantutjämning. |
