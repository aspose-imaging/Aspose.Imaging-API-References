Den PolygonFillMode enumeration definierar värden som specificerar hur man beräknar området för en polygon som ska fyllas.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfPolygonFillMode

## **Members**
| **Member name** | **Description** |
| :- | :- |
| ALTERNATE | Väljer alternativt läge (fyller området mellan udda och jämna polygon-sidor på varje avläsningslinje). |
| WINDING | Väljer lindningsläge (fyller alla regioner med ett icke‑noll lindningsvärde). |
