**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

## **Members**
| **Member name** | **Description** |
| :- | :- |
| CONSISTENT_RECOVER | Det konsekventa återställningsläget försöker återställa all data så länge korruption inte bryter filformatet och möjliggör korrekt vidare bearbetning. |
| MAXIMAL_RECOVER | Det maximala återställningsläget återställer all data även om filformatet har en korrupt struktur och vidare bearbetning kan ge oönskade effekter. |
| NONE | Ingen dataåterställning är underförstådd. När filformatet har korrupt data kastas ett lämpligt undantag. |
