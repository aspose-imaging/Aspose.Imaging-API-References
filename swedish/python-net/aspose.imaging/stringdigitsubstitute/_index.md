Enumen anger hur man ersätter siffror i en sträng enligt en användares landsinställning eller språk.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.StringDigitSubstitute

## **Members**
| **Member name** | **Description** |
| :- | :- |
| NATIONAL | Anger substitutionssiffror som motsvarar det officiella nationella språket för användarens lokala inställning. |
| NONE | Anger att inaktivera substitutioner. |
| TRADITIONAL | Anger substitutionssiffror som motsvarar användarens inhemska skriftsystem eller språk, vilket kan skilja sig från det officiella nationella språket för användarens lokala inställning. |
| USER | Anger ett användardefinierat substitutionsschema. |
