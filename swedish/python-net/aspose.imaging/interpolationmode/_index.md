Enumen [InterpolationMode](/imaging/python-net/aspose.imaging/interpolationmode/) anger den algoritm som används när bilder skalas eller roteras.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.InterpolationMode

## **Members**
| **Member name** | **Description** |
| :- | :- |
| BICUBIC | Anger bikubisk interpolation. Ingen förfiltrering utförs. Detta läge är inte lämpligt för att krympa en bild under 25 procent av dess originalstorlek. |
| BILINEAR | Anger bilinjär interpolation. Ingen förfiltrering utförs. Detta läge är inte lämpligt för att krympa en bild under 50 procent av dess originalstorlek. |
| DEFAULT | Anger standardläge. |
| HIGH | Anger interpolation av hög kvalitet. |
| HIGH_QUALITY_BICUBIC | Anger högkvalitativ, bikubisk interpolation. Förfiltrering utförs för att säkerställa högkvalitativ krympning. Detta läge ger de högsta kvaliteten på transformerade bilder. |
| HIGH_QUALITY_BILINEAR | Anger högkvalitativ, bilinjär interpolation. Förfiltrering utförs för att säkerställa högkvalitativ krympning. |
| INVALID | Ogiltigt interpolationsläge. |
| LOW | Anger interpolering med låg kvalitet. |
| NEAREST_NEIGHBOR | Anger närmaste-granne interpolering. |
