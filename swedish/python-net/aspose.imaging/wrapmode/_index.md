Anger hur en textur eller gradient tileas när den är mindre än det område som fylls.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.WrapMode

## **Members**
| **Member name** | **Description** |
| :- | :- |
| CLAMP | Texturen eller gradienten är inte upprepad. |
| TILE | Upprepar gradienten eller texturen. |
| TILE_FLIP_X | Vänder texturen eller gradienten horisontellt och upprepar sedan texturen eller gradienten. |
| TILE_FLIP_XY | Vänder texturen eller gradienten horisontellt och vertikalt och sedan lägger den i mosaik. |
| TILE_FLIP_Y | Vänder texturen eller gradienten vertikalt och sedan lägger den i mosaik. |
