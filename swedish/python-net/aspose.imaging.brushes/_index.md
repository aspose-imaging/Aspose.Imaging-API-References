Modulen tillhandahåller hjälparklasser och metoder för att arbeta med olika penseltyper.

| **Klass** | **Description** |
| :- | :- |
| [HatchBrush](/imaging/python-net/aspose.imaging.brushes/hatchbrush/) | Definierar en rektangulär pensel med ett rutmönster, en förgrundsfärg och en bakgrundsfärg. Denna klass kan inte ärvas. |
| [LinearGradientBrush](/imaging/python-net/aspose.imaging.brushes/lineargradientbrush/) | Inkapslar en [Brush](/imaging/python-net/aspose.imaging/brush/) med en linjär gradient. Denna klass kan inte ärvas. |
| [LinearGradientBrushBase](/imaging/python-net/aspose.imaging.brushes/lineargradientbrushbase/) | Representerar en [Brush](/imaging/python-net/aspose.imaging/brush/) med gradientfunktioner och lämpliga egenskaper. |
| [LinearMulticolorGradientBrush](/imaging/python-net/aspose.imaging.brushes/linearmulticolorgradientbrush/) | Representerar en [Brush](/imaging/python-net/aspose.imaging/brush/) med linjär gradient definierad av flera färger och lämpliga positioner. Denna klass kan inte ärvas. |
| [PathGradientBrush](/imaging/python-net/aspose.imaging.brushes/pathgradientbrush/) | Inkapslar ett [Brush](/imaging/python-net/aspose.imaging/brush/)‑objekt med en gradient. Denna klass kan inte ärvas. |
| [PathGradientBrushBase](/imaging/python-net/aspose.imaging.brushes/pathgradientbrushbase/) | Representerar en [Brush](/imaging/python-net/aspose.imaging/brush/) med basvägsgradientfunktion. |

| [SolidBrush](/imaging/python-net/aspose.imaging.brushes/solidbrush/) | Solid brush är avsedd för kontinuerlig ritning med en specifik färg. Denna klass kan inte ärvas. |

Denna klass kan inte ärvas. |
| [TransformBrush](/imaging/python-net/aspose.imaging.brushes/transformbrush/) | En [Brush](/imaging/python-net/aspose.imaging/brush/) med transformfunktioner. |
