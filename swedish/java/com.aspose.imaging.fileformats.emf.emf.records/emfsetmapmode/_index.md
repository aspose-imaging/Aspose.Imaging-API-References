EMR\_SETMAPMODE‑posten specificerar kartläggningsläget för uppspelningsenhetens kontext. Kartläggningsläget anger måttenheten som används för att omvandla enheter i sidutrymme till enheter i enhetens utrymme, och specificerar också orienteringen av enhetens x‑axel och y‑axel.
