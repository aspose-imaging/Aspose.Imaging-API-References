EMR\_POLYPOLYGON‑posten specificerar en serie av slutna polygoner.

Varje polygon SKALL kontureras med den aktuella pennan och fyllas med den aktuella penseln samt polygonfyllningsläget som definieras i uppspelningsenhetens kontext. Polygonerna som definieras av denna post kan överlappa.
