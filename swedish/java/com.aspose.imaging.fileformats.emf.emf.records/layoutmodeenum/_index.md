### LAYOUT_LTR {#LAYOUT-LTR}
```
public static final int LAYOUT_LTR
```


Ställer in standard horisontell layout till vänster-till-höger. Detta är standardläget för engelska och europeiska språk.

### LAYOUT_RTL {#LAYOUT-RTL}
```
public static final int LAYOUT_RTL
```


Ställer in standard horisontell layout till höger-till-vänster. Detta läge krävs för vissa språk, inklusive arabiska och hebreiska.

### LAYOUT_BITMAPORIENTATIONPRESERVED {#LAYOUT-BITMAPORIENTATIONPRESERVED}
```
public static final int LAYOUT_BITMAPORIENTATIONPRESERVED
```


Inaktiverar spegling av bitmapar som ritas av Bitmap Record Types (avsnitt 2.3.1) när layoutläget är höger-till-vänster.
