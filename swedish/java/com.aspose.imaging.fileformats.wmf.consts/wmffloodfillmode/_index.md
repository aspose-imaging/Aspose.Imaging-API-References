### FloodFillBorder {#FloodFillBorder}
```
public static final int FloodFillBorder
```


Fyllningsområdet begränsas av färgen som anges av Color‑medlemmen. Denna stil är identisk med fyllningen som utförs av META\_FLOODFILL‑posten.

### FloodFillSurface {#FloodFillSurface}
```
public static final int FloodFillSurface
```


Fyllningsområdet begränsas av färgen som anges av Color‑medlemmen. Fyllningen fortsätter utåt i alla riktningar så länge färgen påträffas. Denna stil är användbar för att fylla områden med flerfärgade gränser.
