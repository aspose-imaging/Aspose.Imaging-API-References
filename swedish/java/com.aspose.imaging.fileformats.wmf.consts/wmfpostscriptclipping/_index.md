PostScriptClipping‑enumerationen definierar funktioner som kan tillämpas på klippningsvägen som används för PostScript‑utdata.
## Fält

| Fält | Beskrivning |
| --- | --- |
| [CLIP_SAVE](#CLIP-SAVE) | Sparar den aktuella PostScript-klippningsvägen. |
| [CLIP_RESTORE](#CLIP-RESTORE) | Återställer PostScript-klippningsvägen till den senaste klippningsvägen som sparades av en tidigare CLIP\_SAVE-funktion som tillämpades av ett CLIP\_TO\_PATH‑record (avsnitt 2.3.6.6). |
| [CLIP_INCLUSIVE](#CLIP-INCLUSIVE) | Korsar den aktuella PostScript-klippvägen med den aktuella klippvägen och sparar resultatet som den nya PostScript-klippvägen. |
