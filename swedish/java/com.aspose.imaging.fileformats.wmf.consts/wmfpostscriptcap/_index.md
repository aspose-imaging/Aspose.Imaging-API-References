PostScriptCap‑enumerationen definierar linjeavslutningstyper för användning med en PostScript‑skrivardrivrutin.
## Fält

| Fält | Beskrivning |
| --- | --- |
| [PostScriptNotSet](#PostScriptNotSet) | Anger att radslutstilen inte har satts, och att en standardstil KAN [24] användas. |
| [PostScriptFlatCap](#PostScriptFlatCap) | Anger att linjen slutar vid den sista punkten. |
| [PostScriptRoundCap](#PostScriptRoundCap) | Anger en cirkulär avslutning. |
| [PostScriptSquareCap](#PostScriptSquareCap) | Anger en fyrkantig avslutning. |
### PostScriptNotSet {#PostScriptNotSet}
```
public static final int PostScriptNotSet
```


Anger att radslutstilen inte har satts, och att en standardstil KAN [24] användas.

### PostScriptFlatCap {#PostScriptFlatCap}
```
public static final int PostScriptFlatCap
```


Anger att linjen slutar vid den sista punkten. Slutet är fyrkantigt.

### PostScriptRoundCap {#PostScriptRoundCap}
```
public static final int PostScriptRoundCap
```


Anger en cirkulär avslutning. Centrum av cirkeln är den sista punkten i linjen. Diametern på cirkeln är densamma som linjebredden; det vill säga linjens tjocklek.

### PostScriptSquareCap {#PostScriptSquareCap}
```
public static final int PostScriptSquareCap
```


Anger en fyrkantig avslutning. Centrum av fyrkanten är den sista punkten i linjen. Höjden och bredden på fyrkanten är densamma som linjebredden; det vill säga linjens tjocklek.
