FamilyFont-uppräkningen specificerar teckensnittsfamiljen. Teckensnittsfamiljer beskriver hur ett teckensnitt ser ut på ett generellt sätt. De är avsedda för att specificera teckensnitt när den exakta önskade teckensnittsstilen inte är tillgänglig.

### Roman {#Roman}
```
public static final byte Roman
```


Teckensnitt med variabel linjebredd, som är proportionella mot de faktiska breddarna på glyferna, och som har seriffer. "MS Serif" är ett exempel.

### Swiss {#Swiss}
```
public static final byte Swiss
```


Typsnitt med variabel linjebredd, som är proportionella mot de faktiska breddarna på glyferna, och som inte har seriffer. "MS Sans Serif" är ett exempel.

### Modern {#Modern}
```
public static final byte Modern
```


Typsnitt med konstant linjebredd, med eller utan seriffer. Typsnitt med fast bredd är vanligtvis moderna. "Pica", "Elite" och "Courier New" är exempel.

### Script {#Script}
```
public static final byte Script
```


Typsnitt utformade för att se ut som handskrift. "Script" och "Cursive" är exempel.

### Decorative {#Decorative}
```
public static final byte Decorative
```


Nyskapande typsnitt. "Old English" är ett exempel.
