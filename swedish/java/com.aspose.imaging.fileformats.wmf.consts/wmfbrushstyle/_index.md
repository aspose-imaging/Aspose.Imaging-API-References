BrushStyle‑enumerationen specificerar de olika möjliga borsttyperna som kan användas i grafikoperationer. För mer information, se specifikationen av Brush Object (avsnitt 2.2.1.1).
## Fält

| Fält | Beskrivning |
| --- | --- |
| [Solid](#Solid) | En pensel som målar en enda, konstant färg, antingen solid eller dithrad. |
| [Null](#Null) | En pensel som gör ingenting. |
| [Hatched](#Hatched) | En pensel som målar ett fördefinierat enkelt mönster, eller "hatch", på en solid bakgrund |
| [Pattern](#Pattern) | En pensel som målar ett mönster definierat av en bitmap, som KAN vara ett Bitmap16‑objekt eller ett DeviceIndependentBitmap (DIB)‑objekt. |
| [Indexed](#Indexed) | Stöds inte. |
| [Dibpattern](#Dibpattern) | En mönsterpensel specificerad av en DIB. |
| [Dibpatternpt](#Dibpatternpt) | En mönsterpensel specificerad av en DIB. |
| [Pattern8X8](#Pattern8X8) | Stöds inte. |
| [Dibpattern8X8](#Dibpattern8X8) | Stöds inte. |
| [Monopattern](#Monopattern) | Stöds inte. |
| [Gradient](#Gradient) | Gradienten stöds inte i wmf, stöd i odg. |
