Med förmågan att utföra CDR-bildrasterisering och sätta skalningsfaktorer för både X- och Y-dimensioner ger detta API exakt kontroll över transformationsprocessen. Oavsett om du skalar för specifika utdata krav eller konverterar vektorgrafik till rasterformat, kan du utnyttja detta API för effektiv och anpassningsbar CDR-vektor‑till‑raster‑bildkonvertering.
