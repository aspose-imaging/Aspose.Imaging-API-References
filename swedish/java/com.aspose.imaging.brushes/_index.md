Paketet tillhandahåller hjälparklasser och metoder för att arbeta med olika penseltyper.


## Klasser

| Klass | Beskrivning |
| --- | --- |
| [HatchBrush](../com.aspose.imaging.brushes/hatchbrush) | Definierar en rektangulär pensel med ett korsningsmönster, en förgrundsfärg och en bakgrundsfärg. |
| [LinearGradientBrush](../com.aspose.imaging.brushes/lineargradientbrush) | Inkapslar en `Aspose.Imaging.Brush` med en linjär gradient. |
| [LinearGradientBrushBase](../com.aspose.imaging.brushes/lineargradientbrushbase) | Representerar en `Brush` med gradientfunktioner och lämpliga egenskaper. |
| [LinearMulticolorGradientBrush](../com.aspose.imaging.brushes/linearmulticolorgradientbrush) | Representerar en `Brush` med linjär gradient definierad av flera färger och lämpliga positioner. |
| [PathGradientBrush](../com.aspose.imaging.brushes/pathgradientbrush) | Inkapslar ett `Aspose.Imaging.Brush`-objekt med en gradient. |
| [PathGradientBrushBase](../com.aspose.imaging.brushes/pathgradientbrushbase) | Representerar en `Brush` med basvägsgradientfunktion. |
| [PathMulticolorGradientBrush](../com.aspose.imaging.brushes/pathmulticolorgradientbrush) | Inkapslar ett `Aspose.Imaging.Brush`-objekt med en gradient. |
| [SolidBrush](../com.aspose.imaging.brushes/solidbrush) | Solid pensel är avsedd för kontinuerlig ritning med en specifik färg. |
| [TextureBrush](../com.aspose.imaging.brushes/texturebrush) | Varje egenskap i klassen `Aspose.Imaging.Brushes.TextureBrush` är ett `Aspose.Imaging.Brush`-objekt som använder en bild för att fylla insidan av en form. |
| [TransformBrush](../com.aspose.imaging.brushes/transformbrush) | En `Brush` med transformfunktioner. |
