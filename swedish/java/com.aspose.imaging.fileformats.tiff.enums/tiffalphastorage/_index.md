### Associated {#Associated}
```
public static final int Associated
```


Alfavärdet lagras i förmultiplicerad form. När alfan återställs kan det uppstå avrundningseffekter och det återställda värdet kan skilja sig från originalet.

### Unassociated {#Unassociated}
```
public static final int Unassociated
```


Alfavärdet lagras i oassocierad form. Det betyder att den återställda alfan är exakt densamma som den lagrades i tiff-filen.
