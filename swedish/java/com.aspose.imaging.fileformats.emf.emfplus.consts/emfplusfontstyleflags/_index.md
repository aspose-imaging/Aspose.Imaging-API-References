### FontStyleBold {#FontStyleBold}
```
public static final int FontStyleBold
```


Om den är satt måste typsnittet renderas med en tyngre vikt eller tjocklek. Om den är avmarkerad måste typsnittet renderas med normal tjocklek.

### FontStyleItalic {#FontStyleItalic}
```
public static final int FontStyleItalic
```


Om den är satt måste typsnittet renderas med de vertikala stjälkarna i tecknen i en ökad vinkel eller lutning i förhållande till baslinjen. Om den är avmarkerad måste typsnittet renderas med de vertikala stjälkarna i tecknen i en normal vinkel.

### FontStyleUnderline {#FontStyleUnderline}
```
public static final int FontStyleUnderline
```


Om den är satt måste typsnittet renderas med en linje under baslinjen för tecknen. Om den är avmarkerad måste typsnittet renderas utan en linje under baslinjen.

### FontStyleStrikeout {#FontStyleStrikeout}
```
public static final int FontStyleStrikeout
```


Om den är satt, MUST renderas med en linje parallell med baslinjen som dras genom mitten av tecknen. Om den är rensad, MUST renderas utan en linje genom tecknen.
