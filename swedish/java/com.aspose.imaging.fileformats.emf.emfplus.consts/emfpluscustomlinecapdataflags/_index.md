CustomLineCapData-flaggorna specificerar data för anpassade linjekapper. Dessa flaggor kan kombineras för att specificera flera alternativ.

--------------------

Anpassade grafiklinjekapper specificeras av [EmfPlusCustomLineCap](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecap) objekt.
## Fält

| Fält | Beskrivning |
| --- | --- |
| [CustomLineCapDataFillPath](#CustomLineCapDataFillPath) | Om den är angiven, ett [EmfPlusFillPath](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfplusfillpath) objekt MUST specificeras i OptionalData-fältet för [EmfPlusCustomLineCapData](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecapdata) objektet för att fylla den anpassade linjekappen. |
| [CustomLineCapDataLinePath](#CustomLineCapDataLinePath) | Om den är angiven, ett [EmfPlusLinePath](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluslinepath) objekt MUST specificeras i OptionalData-fältet för EmfPlusCustomLineCapData objektet för att konturera den anpassade linjekappen. |
### CustomLineCapDataFillPath {#CustomLineCapDataFillPath}
```
public static final int CustomLineCapDataFillPath
```
