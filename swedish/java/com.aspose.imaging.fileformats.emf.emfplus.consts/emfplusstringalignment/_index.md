StringAlignment‑enumerationen definierar sätt att justera strängar i förhållande till en textrutningsrektangel.
## Fält

| Fält | Beskrivning |
| --- | --- |
| [StringAlignmentNear](#StringAlignmentNear) | Anger att strängjusteringen är mot ursprunget för layoutrektangeln. |
| [StringAlignmentCenter](#StringAlignmentCenter) | Anger att justeringen är centrerad mellan ursprunget och omfattningen av layoutrektangeln. |
| [StringAlignmentFar](#StringAlignmentFar) | Anger att justeringen är till höger sida av layoutrektangeln. |
### StringAlignmentNear {#StringAlignmentNear}
```
public static final int StringAlignmentNear
```


Anger att strängjusteringen är mot ursprunget för layoutrektangeln. Detta kan användas för att justera tecken längs en linje eller för att justera text inom en rektangel. För en layoutrektangel från höger till vänster SKA ursprunget vara uppe till höger.

### StringAlignmentCenter {#StringAlignmentCenter}
```
public static final int StringAlignmentCenter
```


Anger att justeringen är centrerad mellan ursprunget och omfattningen av layoutrektangeln.

### StringAlignmentFar {#StringAlignmentFar}
```
public static final int StringAlignmentFar
```


Anger att justeringen är till höger sida av layoutrektangeln.
