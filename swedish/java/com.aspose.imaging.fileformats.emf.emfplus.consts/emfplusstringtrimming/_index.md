StringTrimming‑enumerationen definierar hur man trimmar tecken från en sträng som är för stor för textrutningsrektangeln.
## Fält

| Fält | Beskrivning |
| --- | --- |
| [StringTrimmingNone](#StringTrimmingNone) | Anger att ingen trimning utförs. |
| [StringTrimmingCharacter](#StringTrimmingCharacter) | Anger att strängen bryts vid gränsen för det sista tecknet som ligger inom layoutrektangeln. |
| [StringTrimmingWord](#StringTrimmingWord) | Anger att strängen bryts vid gränsen för det sista ordet som ligger inom layoutrektangeln. |
| [StringTrimmingEllipsisCharacter](#StringTrimmingEllipsisCharacter) | Anger att strängen bryts vid gränsen för det sista tecknet som ligger inom layoutrektangeln, och en ellips (...) infogas efter tecknet. |
| [StringTrimmingEllipsisWord](#StringTrimmingEllipsisWord) | Anger att strängen bryts vid gränsen för det sista ordet som ligger inom layoutrektangeln, och en ellips (...) infogas efter ordet. |
| [StringTrimmingEllipsisPath](#StringTrimmingEllipsisPath) | Anger att mitten tas bort från strängen och ersätts av en ellips. |
