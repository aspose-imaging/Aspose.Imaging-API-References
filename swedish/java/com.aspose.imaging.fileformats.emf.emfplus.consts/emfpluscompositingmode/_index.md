CompositingMode‑enumerationen definierar lägen för att kombinera källfärger med bakgrundsfärger. Kompositläge representerar aktiveringsstatusen för alfa‑blandning.
## Fält

| [CompositingModeSourceCopy](#CompositingModeSourceCopy) | Inaktiverar alfa‑blandning, vilket betyder att när en källfärg renderas, skrivs den över bakgrundsfärgen. |
### CompositingModeSourceOver {#CompositingModeSourceOver}
```
public static final byte CompositingModeSourceOver
```


Aktiverar alfa‑blandning, vilket specificerar att när en färg renderas, blandas den med bakgrundsfärgen. Blandningsgraden bestäms av värdet på alfakomponenten i den renderade färgen.

### CompositingModeSourceCopy {#CompositingModeSourceCopy}
```
public static final byte CompositingModeSourceCopy
```


Inaktiverar alfa‑blandning, vilket betyder att när en källfärg renderas, skrivs den över bakgrundsfärgen.
