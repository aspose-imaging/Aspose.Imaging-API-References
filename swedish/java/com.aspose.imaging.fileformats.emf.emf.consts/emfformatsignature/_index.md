FormatSignature-enumerationen definierar värden som används för att identifiera formatet på inbäddade data i EMF-poster.
## Fält

| Fält | Beskrivning |
| --- | --- |
| [ENHMETA_SIGNATURE](#ENHMETA-SIGNATURE) | Värdet för den här medlemmen är sekvensen av ASCII-tecken "FME ", som råkar vara omvända av strängen "EMF", och den betecknar EMF‑postdata. |
| [EPS_SIGNATURE](#EPS-SIGNATURE) | Värdet för den här medlemmen är sekvensen av ASCII-tecken "FSPE", som råkar vara omvända av strängen "EPSF", och den betecknar kapslad PostScript (EPS)-formatdata. |
### ENHMETA_SIGNATURE {#ENHMETA-SIGNATURE}
```
public static final int ENHMETA_SIGNATURE
```


Värdet för den här medlemmen är sekvensen av ASCII-tecken "FME ", som råkar vara omvända av strängen "EMF", och den betecknar EMF‑postdata. Obs! Blanktecknet i strängen är betydelsefullt och MÅSTE vara närvarande.

### EPS_SIGNATURE {#EPS-SIGNATURE}
```
public static final int EPS_SIGNATURE
```


Värdet för den här medlemmen är sekvensen av ASCII-tecken "FSPE", som råkar vara omvända av strängen "EPSF", och den betecknar kapslad PostScript (EPS)-formatdata.
