### CA_LOG_FILTER {#CA-LOG-FILTER}
```
public static final int CA_LOG_FILTER
```


Det specificerar att en logaritmisk process SKALL tillämpas på den slutliga densiteten för utdatafärgerna. Detta kommer att öka färgkontrasten när luminansen är låg.
