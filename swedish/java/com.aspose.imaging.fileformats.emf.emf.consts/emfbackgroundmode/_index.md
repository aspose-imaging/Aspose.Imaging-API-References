BackgroundMode-enumerationen används för att ange bakgrundsläget som ska användas med text, skuggade penslar och pennstilar som inte är solida. Bakgrundsläget bestämmer hur bakgrunden kombineras med förgrundstext, skuggade penslar och pennstilar som inte är solida linjer.
