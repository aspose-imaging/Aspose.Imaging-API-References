Definierar en karta för att konvertera färger. Flera metoder i klassen [ImageAttributes](../../com.aspose.imaging/imageattributes) justerar bildfärger genom att använda en färg‑omkartningstabell, som är en array av `com.aspose.imaging.ColorMap`-strukturer. Ej ärftlig.
