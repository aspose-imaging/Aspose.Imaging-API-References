### Near {#Near}
```
public static final int Near
```


Anger att texten ska justeras nära layouten. I en layout från vänster till höger är den nära positionen vänster. I en layout från höger till vänster är den nära positionen höger.

### Center {#Center}
```
public static final int Center
```


Anger att texten är justerad i mitten av layoutrektangeln.

### Far {#Far}
```
public static final int Far
```


Anger att texten är justerad långt från ursprungspositionen för layoutrektangeln. I en layout från vänster till höger är den avlägsna positionen höger. I en layout från höger till vänster är den avlägsna positionen vänster.
