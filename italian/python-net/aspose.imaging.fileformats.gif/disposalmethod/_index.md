Indica il modo in cui la grafica deve essere trattata dopo essere stata visualizzata.

**Module:** [aspose.imaging.fileformats.gif](/imaging/python-net/aspose.imaging.fileformats.gif/)

**Full Name:** aspose.imaging.fileformats.gif.DisposalMethod

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| NONE | Nessuna eliminazione specificata. |
| PRESERVE | Non eliminare. La grafica deve rimanere al suo posto. |
| PREVIUOS | Ripristina al precedente. Il decoder è necessario per ripristinare l'area sovrascritta dalla grafica con ciò che era presente prima del rendering della grafica. |
| RESTORE | Ripristina al colore di sfondo. L'area utilizzata dalla grafica deve essere ripristinata al colore di sfondo. |
| UNDEFINED | Valore non definito. |
