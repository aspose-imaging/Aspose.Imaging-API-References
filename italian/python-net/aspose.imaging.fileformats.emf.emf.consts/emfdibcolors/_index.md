L'enumerazione DIBColors definisce come interpretare i valori nella tavola dei colori di un DIB.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfDibColors

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| DIB_PAL_COLORS | La tavola dei colori è composta da un array di indici a 16 bit nell'oggetto LogPalette (sezione 2.2.17) attualmente definito nel contesto del dispositivo di riproduzione. |
| DIB_PAL_INDICES | Non esiste una tavola dei colori. I pixel nel DIB sono indici nella palette logica corrente nel contesto del dispositivo di riproduzione. |
| DIB_RGB_COLORS | La tavola dei colori contiene valori RGB letterali |
