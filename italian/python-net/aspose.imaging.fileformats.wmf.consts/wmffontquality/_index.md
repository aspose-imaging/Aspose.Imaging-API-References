L'Enumerazione FontQuality specifica quanto da vicino gli attributi del carattere logico debbano corrispondere<br/>                a quelli del carattere fisico durante il rendering del testo.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfFontQuality

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| ANTIALIASED | Specifica che l'anti-aliasing DEVE essere usato durante il rendering del testo, se<br/>                il font lo supporta. |
| CLEARTYPE | Specifica che l'anti-aliasing ClearType DEVE essere usato quando<br/>                si rende il testo, se il font lo supporta. |
| DEFAULT | Specifica che la qualità dei caratteri del font non è importante, quindi<br/>                si può usare DRAFT. |
| DRAFT | Specifica che la qualità dei caratteri del font è meno importante rispetto al<br/>                corrispondenza degli attributi logici. Per i font rasterizzati, la scalatura DEVE essere abilitata, il che<br/>                significa che sono disponibili più dimensioni del font. |
| NONANTIALIASED | Specifica che l'anti-aliasing NON DEVE essere usato quando<br/>                si rende il testo |
| PROOF | Specifica che la qualità dei caratteri del font è più importante rispetto al<br/>                corrispondenza degli attributi logici. Per i font rasterizzati, la scalatura DEVE essere disabilitata, e il font<br/>                più vicino in dimensione DEVE essere scelto. |
