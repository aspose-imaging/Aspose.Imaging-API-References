L'enumerazione PenStyle a 16 bit è usata per specificare diversi tipi di penne che possono essere utilizzati nelle operazioni grafiche.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfPenStyle

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| ALTERNATE | La penna imposta ogni altro pixel (questo stile è applicabile solo alle penne cosmetiche). |
| COSMETIC | Il cosmetico |
| DASH | La penna è tratteggiata. |
| DASHDOT | La penna ha trattini e punti alternati. |
| DASHDOTDOT | La penna ha trattini e doppi punti. |
| DOT | La penna è puntinata. |
| ENDCAP_FLAT | Le estremità delle linee sono piatte. |
| ENDCAP_ROUND | Le estremità delle linee sono arrotondate. |
| ENDCAP_SQUARE | Le estremità delle linee sono quadrate. |
| INSIDEFRAME | La penna è solida. Quando questa penna viene usata in qualsiasi record di disegno che richiede un rettangolo di delimitazione, le dimensioni della<br/>                figura vengono ridotte in modo che si adattino interamente al rettangolo di delimitazione, tenendo conto della larghezza della penna. |
| JOIN_BEVEL | Le giunzioni delle linee sono smussate. |
| JOIN_MITER | Le giunzioni delle linee sono a spigolo quando sono entro il limite corrente<br/>                impostato dal record SETMITERLIMIT META_ESCAPE. Una giunzione è smussata quando supererebbe il limite. |
| JOIN_ROUND | Le giunzioni delle linee sono arrotondate. |
| NULL | La penna è invisibile. |
| SOLID | La penna è solida. |
| USERSTYLE | La penna utilizza un array di stile fornito dall'utente. |
