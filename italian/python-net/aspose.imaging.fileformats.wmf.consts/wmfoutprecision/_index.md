L'enumerazione OutPrecision definisce i valori per la precisione di output, che è il requisito per<br/>                il mapper dei caratteri di corrispondere a parametri specifici del font, inclusi altezza, larghezza, orientamento dei caratteri,<br/>                escapement, passo e tipo di font.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfOutPrecision

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| DEFAULT | Un valore che specifica il comportamento predefinito. |
| DEVICE | Un valore che specifica la scelta di un font del dispositivo quando il sistema<br/>                contiene più font con lo stesso nome. |
| OUTLINE | Un valore che specifica il requisito per i font TrueType e altri font outline. |
| PS_ONLY | Un valore che specifica un requisito per solo font PostScript. Se non<br/>                ci sono font PostScript installati nel sistema, viene specificato il comportamento predefinito. |
| RASTER | Un valore che specifica la scelta di un font rasterizzato quando il sistema<br/>                contiene più font con lo stesso nome. |
| SCREEN_OUTLINE | Un valore che specifica una preferenza per i font TrueType e altri<br/>                font outline. |
| STRING | Un valore restituito quando i font rasterizzati vengono enumerati. |
| STROKE | Un valore restituito quando i font TrueType e altri font outline, e<br/>                i font vettoriali vengono enumerati. |
| TT | Un valore che specifica la scelta di un font TrueType quando il sistema<br/>                contiene più font con lo stesso nome. |
| TT_ONLY | Un valore che specifica il requisito per solo font TrueType. Se<br/>                non ci sono font TrueType installati nel sistema, viene specificato il comportamento predefinito. |
