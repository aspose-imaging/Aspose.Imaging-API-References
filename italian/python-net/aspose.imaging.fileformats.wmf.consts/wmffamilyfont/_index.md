L'enumerazione FamilyFont specifica la famiglia di caratteri. Le famiglie di caratteri descrivono l'aspetto di un carattere in<br/>                modo generale. Sono destinate a specificare i caratteri quando il tipo esatto desiderato non è disponibile.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfFamilyFont

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| DECORATIVE | Font decorativi. "Old English" è un esempio. |
| DONTCARE | Il font predefinito è specificato, il che dipende dall'implementazione. |
| MODERN | Font con larghezza di tratto costante, con o senza grazie. I font a larghezza fissa sono<br/>                solitamente moderni. "Pica", "Elite" e "Courier New" sono esempi. |
| ROMAN | Font con larghezze di tratto variabili, proporzionali alle larghezze effettive dei<br/>                glifi, e che hanno grazie. "MS Serif" è un esempio. |
| SCRIPT | Font progettati per assomigliare alla scrittura a mano. "Script" e "Cursive" sono esempi. |
| SWISS | Font con larghezze di tratto variabili, proporzionali alle larghezze effettive dei<br/>                glifi, e che non hanno grazie. "MS Sans Serif" è un esempio. |
