L'Enumerazione BrushStyle specifica i diversi tipi di pennello possibili<br/>                che possono essere usati nelle operazioni grafiche. Per ulteriori informazioni, vedere la<br/>                specifica dell'oggetto Brush (sezione 2.2.1.1).

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfBrushStyle

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| DIBPATTERN | Un pennello a trama specificato da un DIB. |
| DIBPATTERNPT | Un pennello a trama specificato da un DIB. |
| DIBPATTERN_8X8 | Non supportato. |
| GRADIENT | Il gradiente<br/>            Non supportato in wmf, supportato in odg. |
| HATCHED | Un pennello che dipinge un modello semplice predefinito, o "hatch", su uno sfondo solido |
| INDEXED | Non supportato. |
| MONOPATTERN | Non supportato. |
| NULL | Un pennello che non fa nulla. L'uso di un pennello NULL in un'operazione grafica<br/>                DEVE avere lo stesso effetto di non usare alcun pennello. |
| PATTERN | Un pennello che dipinge un modello definito da una bitmap, che PUÒ essere un oggetto Bitmap16<br/>                o un oggetto DeviceIndependentBitmap (DIB). |
| PATTERN_8X8 | Non supportato. |
| SOLID | Un pennello che dipinge un unico colore costante, sia solido che a reticolo. |
