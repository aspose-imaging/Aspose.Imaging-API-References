Il tipo di filtro PNG.

**Module:** [aspose.imaging.fileformats.png](/imaging/python-net/aspose.imaging.fileformats.png/)

**Full Name:** aspose.imaging.fileformats.png.PngFilterType

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| ADAPTIVE | Filtraggio adattivo, significa che il processo di salvataggio sceglierà il filtro più adatto per ogni riga di dati. Migliore compressione, tempo di esecuzione più lento. |
| AVG | Il filtro avg, significa che il filtro medio verrà applicato ai dati dell'immagine. |
| NONE | Il filtro null, significa nessun filtraggio per le righe di dati dell'immagine. |
| PAETH | Il filtro predittore paeth. |
| SUB | Il filtro sub, significa che verrà applicato un filtraggio sottrattivo ai dati dell'immagine. |
| UP | Il filtro up, significa che verrà applicato un filtro di sottrazione riga per riga. |
