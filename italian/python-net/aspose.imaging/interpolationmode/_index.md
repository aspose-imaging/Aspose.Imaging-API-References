L'enumerazione [InterpolationMode](/imaging/python-net/aspose.imaging/interpolationmode/) specifica l'algoritmo utilizzato quando le immagini vengono scalate o ruotate.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.InterpolationMode

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| BICUBIC | Specifica l'interpolazione bicubica. Non viene eseguito alcun prefiltraggio. Questa modalità non è adatta per ridurre un'immagine al di sotto del 25 percento della sua dimensione originale. |
| BILINEAR | Specifica l'interpolazione bilineare. Non viene eseguito alcun prefiltraggio. Questa modalità non è adatta per ridurre un'immagine al di sotto del 50 percento della sua dimensione originale. |
| DEFAULT | Specifica la modalità predefinita. |
| HIGH | Specifica un'interpolazione ad alta qualità. |
| HIGH_QUALITY_BICUBIC | Specifica un'interpolazione bicubica ad alta qualità. Viene eseguito il prefiltraggio per garantire una riduzione di alta qualità. Questa modalità produce le immagini trasformate della massima qualità. |
| HIGH_QUALITY_BILINEAR | Specifica un'interpolazione bilineare ad alta qualità. Viene eseguito il prefiltraggio per garantire una riduzione di alta qualità. |
| INVALID | Modalità di interpolazione non valida. |
| LOW | Specifica l'interpolazione a bassa qualità. |
| NEAREST_NEIGHBOR | Specifica l'interpolazione nearest-neighbor. |
