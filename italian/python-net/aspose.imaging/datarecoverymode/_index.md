La modalità di recupero dati.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.DataRecoveryMode

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| CONSISTENT_RECOVER | La modalità di recupero coerente tenta di recuperare tutti i dati finché la corruzione non rompe il formato del file e consente un corretto ulteriore elaborazione. |
| MAXIMAL_RECOVER | La modalità di recupero massimale recupera tutti i dati anche se il formato del file presenta una struttura corrotta e l'elaborazione successiva può produrre effetti inattesi. |
| NONE | Non è previsto alcun recupero dati. Quando il formato del file contiene dati corrotti, viene sollevata l'eccezione appropriata. |
