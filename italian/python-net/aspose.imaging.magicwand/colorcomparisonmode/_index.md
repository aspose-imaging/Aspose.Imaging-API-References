Specifica come i colori vengono confrontati durante l'algoritmo Magic Wand.

**Module:** [aspose.imaging.magicwand](/imaging/python-net/aspose.imaging.magicwand/)

**Full Name:** aspose.imaging.magicwand.ColorComparisonMode

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| CUSTOM | L'algoritmo di confronto del colore è definito dall'utente. |
| RGB_DEFAULT | I colori sono confrontati nello spazio colore RGB.<br/>            Ogni differenza di colore deve soddisfare la soglia. |
| YUV_DEFAULT | I colori sono confrontati nello spazio colore YUV.<br/>            Ogni differenza di colore deve soddisfare la soglia. |
| YUV_LESS_LUMA_SENSITIVE | I colori sono confrontati nello spazio colore YUV.<br/>            Le differenze di informazioni sul colore devono soddisfare la soglia, la soglia per il componente di luminanza è raddoppiata. |
