**Full Name:** aspose.imaging.fileformats.tiff.enums.TiffAlphaStorage

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| ASSOCIATED | Il valore alfa è memorizzato in forma premoltiplicata. Quando l'alfa viene ripristinato potrebbero verificarsi alcuni effetti di arrotondamento e il valore ripristinato potrebbe differire da quello originale. |
| UNASSOCIATED | Il valore alfa è memorizzato in forma non associata. Ciò significa che l'alfa ripristinato è esattamente lo stesso di quello memorizzato nel tiff. |
| UNSPECIFIED | L'alfa non è specificato e viene memorizzato nel file tiff. |
