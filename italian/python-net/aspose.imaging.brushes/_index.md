Il modulo fornisce classi di supporto e metodi per lavorare con diversi tipi di pennello.

## **Classes**
| **Class** | **Descrizione** |
| :- | :- |
| [HatchBrush](/imaging/python-net/aspose.imaging.brushes/hatchbrush/) | Definisce un pennello rettangolare con uno stile a trama, un colore di primo piano e un colore di sfondo. Questa classe non può essere ereditata. |
| [LinearGradientBrush](/imaging/python-net/aspose.imaging.brushes/lineargradientbrush/) | Incapsula un [Brush](/imaging/python-net/aspose.imaging/brush/) con una sfumatura lineare. Questa classe non può essere ereditata. |
| [LinearGradientBrushBase](/imaging/python-net/aspose.imaging.brushes/lineargradientbrushbase/) | Rappresenta un [Brush](/imaging/python-net/aspose.imaging/brush/) con capacità di sfumatura e proprietà appropriate. |
| [LinearMulticolorGradientBrush](/imaging/python-net/aspose.imaging.brushes/linearmulticolorgradientbrush/) | Rappresenta un [Brush](/imaging/python-net/aspose.imaging/brush/) con sfumatura lineare definita da più colori e posizioni appropriate. Questa classe non può essere ereditata. |
| [PathGradientBrush](/imaging/python-net/aspose.imaging.brushes/pathgradientbrush/) | Incapsula un oggetto [Brush](/imaging/python-net/aspose.imaging/brush/) con una sfumatura. Questa classe non può essere ereditata. |
| [PathGradientBrushBase](/imaging/python-net/aspose.imaging.brushes/pathgradientbrushbase/) | Rappresenta un [Brush](/imaging/python-net/aspose.imaging/brush/) con funzionalità di sfumatura del percorso di base. |
| [PathMulticolorGradientBrush](/imaging/python-net/aspose.imaging.brushes/pathmulticolorgradientbrush/) | Incapsula un oggetto [Brush](/imaging/python-net/aspose.imaging/brush/) con una sfumatura. Questa classe non può essere ereditata. |
| [SolidBrush](/imaging/python-net/aspose.imaging.brushes/solidbrush/) | Il pennello solido è destinato al disegno continuo con un colore specifico. Questa classe non può essere ereditata. |
| [TextureBrush](/imaging/python-net/aspose.imaging.brushes/texturebrush/) | Ogni proprietà della classe [TextureBrush](/imaging/python-net/aspose.imaging.brushes/texturebrush/) è un oggetto [Brush](/imaging/python-net/aspose.imaging/brush/) che utilizza un'immagine per riempire l'interno di una forma. Questa classe non può essere ereditata. |
| [TransformBrush](/imaging/python-net/aspose.imaging.brushes/transformbrush/) | Un [Brush](/imaging/python-net/aspose.imaging/brush/) con capacità di trasformazione. |
