I flag della modalità di allineamento del testo del documento aperto

**Module:** [aspose.imaging.fileformats.opendocument.enums](/imaging/python-net/aspose.imaging.fileformats.opendocument.enums/)

**Full Name:** aspose.imaging.fileformats.opendocument.enums.OdTextAlignModeFlags

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| LINEA DI BASE | Il punto di riferimento DEVE trovarsi sulla linea di base del testo. |
| INFERIORE | Il punto di riferimento DEVE trovarsi sul bordo inferiore del rettangolo di delimitazione. |
| CENTRO | Il punto di riferimento DEVE essere allineato orizzontalmente con il centro del rettangolo di delimitazione. |
| HORIZONTAL | Rappresenta insiemi di allineamento del testo orizzontale (Sinistra | Destra | Centro) |
| GIUSTIFICA | Il testo deve essere allineato in modo che ogni riga di un paragrafo abbia la stessa lunghezza. |
| SINISTRA | Il punto di riferimento DEVE trovarsi sul bordo sinistro del rettangolo di delimitazione. |
| NOUPDATECP | La posizione di disegno nel contesto del dispositivo di riproduzione NON DEVE essere aggiornata dopo ogni<br/>                chiamata di output del testo. Il punto di riferimento DEVE essere passato alla funzione di output del testo. |
| DESTRA | Il punto di riferimento DEVE trovarsi sul bordo destro del rettangolo di delimitazione. |
| RTLREADING | Il testo DEVE essere disposto in ordine di lettura da destra a sinistra, invece dell'ordine predefinito da sinistra a destra. Questo DOVREBBE<br/>                essere applicato solo quando il font definito nel contesto del dispositivo di riproduzione è ebraico o arabo. |
| SUPERIORE | Il punto di riferimento DEVE trovarsi sul bordo superiore del rettangolo di delimitazione. |
| UPDATECP | La posizione di disegno nel contesto del dispositivo di riproduzione DEVE essere aggiornata dopo ogni<br/>                chiamata di output del testo. Essa DEVE essere usata come punto di riferimento. |
| VERTICAL | Rappresenta le impostazioni di allineamento del testo verticale (In alto | Inferiore | Linea di base) |
