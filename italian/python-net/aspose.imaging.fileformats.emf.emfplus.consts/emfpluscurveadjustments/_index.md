L'enumerazione CurveAdjustments definisce le regolazioni che possono essere applicate alla curva colore di un'immagine.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusCurveAdjustments

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| ADJUST_BLACK_SATURATION | Specifica una regolazione della saturazione nera di un'immagine, che è il valore minimo nell'intervallo di intensità per un dato canale colore, tipicamente da 0 a 255. |
| ADJUST_CONTRAST | Specifica un aumento o una diminuzione del contrasto di un'immagine. |
| ADJUST_DENSITY | Specifica la simulazione di un aumento o di una diminuzione della densità di un'immagine. |
| ADJUST_EXPOSURE | Specifica la simulazione di un aumento o di una diminuzione dell'esposizione di un'immagine. |
| ADJUST_HIGHLIGHT | Specifica un aumento o una diminuzione del valore di un canale colore di un'immagine, se quel canale ha già un valore superiore alla metà dell'intensità. Questa regolazione può essere usata per aumentare la definizione nelle aree chiare di un'immagine senza influire sulle aree scure. |
| ADJUST_MIDTONE | Specifica una regolazione che schiarisce o scurisce un'immagine. I valori dei canali colore al centro dell'intervallo di intensità vengono modificati più di quelli vicino agli estremi minimo o massimo dell'intensità. Questa regolazione può essere usata per schiarire o scurire un'immagine senza perdere il contrasto tra le parti più scure e più chiare dell'immagine. |
| ADJUST_SHADOW | Specifica un aumento o una diminuzione del valore di un canale colore di un'immagine, se quel canale ha già un valore inferiore alla metà dell'intensità. Questa regolazione può essere usata per aumentare la definizione nelle aree scure di un'immagine senza influire sulle aree chiare. |
| ADJUST_WHITE_SATURATION | Specifica una regolazione della saturazione bianca di un'immagine, definita come il valore massimo nell'intervallo di intensità per un dato canale colore, il cui intervallo è tipicamente da 0 a 255. |
