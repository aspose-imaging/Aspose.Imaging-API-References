L'enumerazione ObjectType definisce i tipi di oggetti grafici che possono essere creati e utilizzati nelle operazioni grafiche.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusObjectType

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| OBJECT_TYPE_BRUSH | Specifica un oggetto [EmfPlusBrush](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusbrush/) (sezione 2.2.1.1). Gli oggetti Brush riempiono le regioni grafiche. |
| OBJECT_TYPE_CUSTOM_LINE_CAP | Specifica un oggetto [EmfPlusCustomLineCap](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecap/) (sezione 2.2.1.2). Gli oggetti Custom line cap specificano forme da disegnare alle estremità di una linea grafica, includendo quadrati, cerchi e diamanti. |
| OBJECT_TYPE_FONT | Specifica un oggetto [EmfPlusFont](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusfont/) (sezione 2.2.1.3). Gli oggetti Font specificano le proprietà del carattere, includendo lo stile del tipo di carattere, la dimensione EM e la famiglia del carattere. |
| OBJECT_TYPE_IMAGE | Specifica un oggetto [EmfPlusImage](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusimage/) (sezione 2.2.1.4). Gli oggetti Image racchiudono bitmap e metafile. |
| OBJECT_TYPE_IMAGE_ATTRIBUTES | Specifica un oggetto [EmfPlusImageAttributes](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusimageattributes/) (sezione 2.2.1.5). | OBJECT_TYPE_PEN | Specifica un oggetto [EmfPlusPen](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfpluspen/) (sezione 2.2.1.7). Gli oggetti Pen disegnano linee grafiche. |
| OBJECT_TYPE_REGION | Specifica un oggetto [EmfPlusRegion](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusregion/) (sezione 2.2.1.8). Gli oggetti Region specificano le aree della superficie di output. |
| OBJECT_TYPE_STRING_FORMAT | Specifica un oggetto [EmfPlusStringFormat](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusstringformat/) (sezione 2.2.1.9).
