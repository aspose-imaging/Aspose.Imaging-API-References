L'enumerazione StringDigitSubstitution definisce i modi per sostituire le cifre in una stringa in base alla locale o alla lingua dell'utente.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusStringDigitSubstitution

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| STRING_DIGIT_SUBSTITUTION_NATIONAL | Specifica le cifre di sostituzione che corrispondono alla lingua nazionale ufficiale della locale dell'utente. |
| STRING_DIGIT_SUBSTITUTION_NONE | Specifica di disabilitare le sostituzioni. |
| STRING_DIGIT_SUBSTITUTION_TRADITIONAL | Specifica le cifre di sostituzione che corrispondono alla scrittura o lingua nativa dell'utente, che può differire dalla lingua nazionale ufficiale della località dell'utente. |
| STRING_DIGIT_SUBSTITUTION_USER | Specifica uno schema di sostituzione definito dall'implementazione. |
