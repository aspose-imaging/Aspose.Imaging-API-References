I flag CustomLineCapData specificano i dati per le estremità di linea personalizzate. Questi flag possono essere combinati per specificare più opzioni.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusCustomLineCapDataFlags

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| CUSTOM_LINE_CAP_DATA_FILL_PATH | Se impostato, un oggetto [EmfPlusFillPath](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusfillpath/) MUST essere specificato nel campo OptionalData dell'oggetto [EmfPlusCustomLineCapData](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecapdata/) per riempire il cappuccio di linea personalizzato. |
| CUSTOM_LINE_CAP_DATA_LINE_PATH | Se impostato, un oggetto [EmfPlusLinePath](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfpluslinepath/) MUST essere specificato nel campo OptionalData dell'oggetto EmfPlusCustomLineCapData per delineare il cappuccio di linea personalizzato. |
