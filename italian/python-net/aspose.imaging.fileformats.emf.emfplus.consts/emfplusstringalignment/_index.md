L'enumerazione StringAlignment definisce i modi per allineare le stringhe rispetto a un rettangolo di layout del testo.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusStringAlignment

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| STRING_ALIGNMENT_CENTER | Specifica che l'allineamento è centrato tra l'origine e l'estensione del rettangolo di layout. |
| STRING_ALIGNMENT_FAR | Specifica che l'allineamento è sul lato destro del rettangolo di layout. |
| STRING_ALIGNMENT_NEAR | Specifica che l'allineamento della stringa è verso l'origine del rettangolo di layout. Questo può essere usato per allineare i caratteri lungo una linea o per allineare il testo all'interno di un rettangolo. Per un rettangolo di layout da destra a sinistra, l'origine SHOULD trovarsi in alto a destra. |
