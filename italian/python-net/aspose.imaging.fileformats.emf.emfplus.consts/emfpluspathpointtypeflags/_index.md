I flag PathPointType specificano le proprietà di tipo dei punti sui percorsi grafici. Questi flag possono essere combinati per specificare più opzioni.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusPathPointTypeFlags

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| PATH_POINT_TYPE_CLOSE_SUBPATH | Specifica che il punto è il punto finale di un sotto-percorso. |
| PATH_POINT_TYPE_DASH_MODE | Specifica che un segmento di linea che passa attraverso il punto è tratteggiato. |
| PATH_POINT_TYPE_PATH_MARKER | Specifica che il punto è un marcatore di posizione. |
