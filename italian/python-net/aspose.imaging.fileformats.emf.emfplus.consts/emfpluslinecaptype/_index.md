L'enumerazione LineCapType definisce i tipi di estremità di linea da utilizzare alle estremità delle linee disegnate con pennelli grafici.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusLineCapType

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| LINE_CAP_TYPE_ANCHOR_MASK | Maschera usata per verificare se un cap di linea è un cap di ancoraggio. |
| LINE_CAP_TYPE_ARROW_ANCHOR | Specifica che l'estremità della linea è ancorata con una forma a punta di freccia. Il punto della punta DEVE trovarsi all'ultimo punto della linea. La punta DOVREBBE essere più larga della linea. |
| LINE_CAP_TYPE_CUSTOM | Specifica un cap di linea personalizzato. |
| LINE_CAP_TYPE_DIAMOND_ANCHOR | Specifica che l'estremità della linea è ancorata con un cap a forma di diamante, che è un quadrato ruotato di 45 gradi. Il centro del diamante DEVE trovarsi all'ultimo punto della linea. Il diamante DOVREBBE essere più largo della linea. |
| LINE_CAP_TYPE_FLAT | Specifica un cap di linea squadrato. L'estremità della linea DEVE essere l'ultimo punto della linea. |
| LINE_CAP_TYPE_NO_ANCHOR | Specifica che l'estremità della linea non è ancorata. |
| LINE_CAP_TYPE_ROUND | Specifica un cap di linea circolare. Il centro del cerchio DEVE trovarsi all'ultimo punto della linea. Il diametro del cerchio è la larghezza della linea. |
| LINE_CAP_TYPE_ROUND_ANCHOR | Specifica che l'estremità della linea è ancorata con un cap di linea circolare. Il centro del cerchio DEVE trovarsi all'ultimo punto della linea. Il cerchio DOVREBBE essere più largo della linea. |
| LINE_CAP_TYPE_SQUARE | Specifica un cappuccio di linea quadrato. Il centro del quadrato DEVE trovarsi all'ultimo punto della linea. La larghezza del quadrato è la larghezza della linea. |
| LINE_CAP_TYPE_SQUARE_ANCHOR | Specifica che l'estremità della linea è ancorata con un cappuccio di linea quadrato. Il centro del quadrato DEVE trovarsi all'ultimo punto della linea. L'altezza e la larghezza del quadrato sono la larghezza della linea. |
| LINE_CAP_TYPE_TRIANGLE | Specifica un cappuccio di linea triangolare. La base del triangolo DEVE trovarsi all'ultimo punto della linea. La base del triangolo è la larghezza della linea. |
