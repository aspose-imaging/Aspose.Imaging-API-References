I flag PaletteStyle specificano le proprietà delle palette grafiche. Questi flag possono essere combinati per specificare più opzioni.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusPaletteStyleFlags

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| PALETTE_STYLE_GRAY_SCALE | Se impostato, la tavolozza DEVE contenere solo voci in scala di grigi. |
| PALETTE_STYLE_HALFTONE | Se impostato, la tavolozza DEVE contenere valori di colore discreti che possono essere usati per l'halftone. |
| PALETTE_STYLE_HAS_ALPHA | Se impostato, una o più voci della tavolozza DEVE contenere informazioni di trasparenza alfa. |
