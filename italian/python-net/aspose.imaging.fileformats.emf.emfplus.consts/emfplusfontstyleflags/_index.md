I flag FontStyle specificano gli stili dei caratteri tipografici grafici. Questi flag possono essere combinati per specificare più opzioni.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusFontStyleFlags

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| FONT_STYLE_BOLD | Se impostato, il tipo di carattere DEVE essere renderizzato con un peso o spessore più pesante.<br/>            Se non impostato, il tipo di carattere DEVE essere renderizzato con uno spessore normale. |
| FONT_STYLE_ITALIC | Se impostato, il tipo di carattere DEVE essere renderizzato con gli steli verticali dei caratteri a un angolo aumentato o inclinato rispetto alla linea di base.<br/>            Se non impostato, il tipo di carattere DEVE essere renderizzato con gli steli verticali dei caratteri a un angolo normale. |
| FONT_STYLE_STRIKEOUT | Se impostato, il tipo di carattere DEVE essere renderizzato con una linea parallela alla linea di base tracciata attraverso il centro dei caratteri.<br/>            Se non impostato, il tipo di carattere DEVE essere renderizzato senza una linea attraverso i caratteri. |
| FONT_STYLE_UNDERLINE | Se impostato, il tipo di carattere DEVE essere renderizzato con una linea sotto la linea di base dei caratteri.<br/>            Se non impostato, il tipo di carattere DEVE essere renderizzato senza una linea sotto la linea di base. |
