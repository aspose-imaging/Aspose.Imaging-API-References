L'enumerazione UnitType definisce le unità di misura in diversi sistemi di coordinate.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusUnitType

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| UNIT_TYPE_DISPLAY | Specifica un'unità di distanza basata sulle caratteristiche del display fisico.<br/>            Ad esempio, se il dispositivo di visualizzazione è un monitor, l'unità è 1 pixel. |
| UNIT_TYPE_DOCUMENT | Specifica un'unità di 1/300 di pollice. |
| UNIT_TYPE_INCH | Specifica un'unità di 1 pollice. |
| UNIT_TYPE_MILLIMETER | Specifica un'unità di 1 millimetro. |
| UNIT_TYPE_PIXEL | Specifica un'unità di 1 pixel. |
| UNIT_TYPE_POINT | Specifica un'unità di 1 punto di stampa, o 1/72 di pollice. |
| UNIT_TYPE_WORLD | Specifica un'unità di distanza logica all'interno dello spazio mondiale. |
