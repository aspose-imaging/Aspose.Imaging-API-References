L'enumerazione SmoothingMode definisce le modalità di smussatura da applicare a linee, curve e ai bordi delle aree riempite per farle apparire più continue o nettamente definite.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusSmoothingMode

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| SMOOTHING_MODE_ANTI_ALIAS_8X4 | Specifica una buona qualità usando un filtro a blocchi 8x4. |
| SMOOTHING_MODE_ANTI_ALIAS_8X8 | Specifica una qualità migliore usando un filtro a blocchi 8x8. |
| SMOOTHING_MODE_DEFAULT | Specifica la smussatura predefinita della curva senza anti-aliasing. |
| SMOOTHING_MODE_HIGH_QUALITY | Specifica la migliore qualità con anti-aliasing. |
| SMOOTHING_MODE_HIGH_SPEED | Specifica le migliori prestazioni senza anti-aliasing. |
| SMOOTHING_MODE_NONE | Non esegue alcuna smussatura della curva né anti-aliasing. |
