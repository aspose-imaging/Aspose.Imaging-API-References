L'enumerazione PixelFormat definisce i formati pixel supportati nei bitmap EMF+.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusPixelFormat

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| PIXEL_FORMAT_16BPP_ARGB1555 | Il formato è di 16 bit per pixel; 1 bit è utilizzato per il componente alfa e 5 bit ciascuno sono utilizzati per i componenti rosso, verde e blu. |
| PIXEL_FORMAT_16BPP_GRAY_SCALE | Il formato è di 16 bit per pixel, in scala di grigi. |
| PIXEL_FORMAT_16BPP_RGB555 | Il formato è di 16 bit per pixel; 5 bit ciascuno sono utilizzati per i componenti rosso, verde e blu. Il bit rimanente non è utilizzato. |
| PIXEL_FORMAT_16BPP_RGB565 | Il formato è di 16 bit per pixel; 5 bit sono utilizzati per il componente rosso, 6 bit per il componente verde e 5 bit per il componente blu. |
| PIXEL_FORMAT_1BPP_INDEXED | Il formato è monocromatico e viene utilizzata una tabella di ricerca della palette dei colori. |
| PIXEL_FORMAT_24BPP_RGB | Il formato è di 24 bit per pixel; 8 bit per ciascuno dei componenti rosso, verde e blu. |
| PIXEL_FORMAT_32BPP_ARGB | Il formato è di 32 bit per pixel; 8 bit per ciascuno dei componenti alfa, rosso, verde e blu. |
| PIXEL_FORMAT_32BPP_PARGB | Il formato è di 32 bit per pixel; 8 bit per ciascuno dei componenti alfa, rosso, verde e blu. I componenti rosso, verde e blu sono premoltiplicati in base al componente alfa. |
| PIXEL_FORMAT_32BPP_RGB | Il formato è di 32 bit per pixel; 8 bit per ciascuno dei componenti rosso, verde e blu. Gli 8 bit rimanenti non sono utilizzati. |
| PIXEL_FORMAT_48BPP_RGB | Il formato è di 48 bit per pixel; 16 bit per ciascuno dei componenti rosso, verde e blu. |
| PIXEL_FORMAT_4BPP_INDEXED | Il formato è a 16 colori e viene utilizzata una tabella di ricerca della palette colori. |
| PIXEL_FORMAT_64BPP_ARGB | Il formato è di 64 bit per pixel; 16 bit per ciascuno dei componenti alfa, rosso, verde e blu. |
| PIXEL_FORMAT_64BPP_PARGB | Il formato è di 64 bit per pixel; 16 bit per ciascuno dei componenti alfa, rosso, verde e blu. I componenti rosso, verde e blu sono premoltiplicati in base al componente alfa. |
| PIXEL_FORMAT_8BPP_INDEXED | Il formato è a 256 colori e viene utilizzata una tabella di ricerca della palette colori. |
| PIXEL_FORMAT_UNDEFINED | Il formato non è specificato. |
