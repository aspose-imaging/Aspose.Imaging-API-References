Definisce la modalità di interlacciamento per dati pixel multicomponente (colore).

**Module:** [aspose.imaging.fileformats.jpeg](/imaging/python-net/aspose.imaging.fileformats.jpeg/)

**Full Name:** aspose.imaging.fileformats.jpeg.JpegLsInterleaveMode

## **Members**
| **Member name** | **Descrizione** |
| :- | :- |
| LINE | La modalità di interlacciamento è per riga. Una riga completa di ciascun componente è codificata prima di passare alla riga successiva. |
| NONE | I dati sono codificati e memorizzati componente per componente: RRRGGGBBB. |
| SAMPLE | I dati sono codificati e memorizzati per campione. Per le immagini a colori questo è il formato tipo RGBRGBRGB. |
