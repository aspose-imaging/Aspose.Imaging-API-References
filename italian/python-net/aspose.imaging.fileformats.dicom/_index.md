Il modulo gestisce l'elaborazione del formato file Dicom

## **Classes**
| **Class** | **Descrizione** |
| :- | :- |
| [Compression](/imaging/python-net/aspose.imaging.fileformats.dicom/compression/) | Contiene le impostazioni di compressione dell'immagine. |
| [DicomImage](/imaging/python-net/aspose.imaging.fileformats.dicom/dicomimage/) | Questa classe implementa il supporto del formato immagine raster Digital Imaging and Communications in Medicine<br/>            (DICOM) e offre una soluzione completa per<br/>            l'elaborazione delle immagini DICOM con precisione e flessibilità. È possibile manipolare senza problemi<br/>            le pagine dell'immagine, comprese le operazioni per ottenere, aggiungere o rimuovere pagine, e<br/>            controllare le pagine predefinite e attive. Con capacità di lavorare con canali alfa,<br/>            incorporare metadati XMP, ridimensionare, ruotare, ritagliare, binarizzare, regolare, applicare filtri,<br/>            e convertire in altri formati raster. Questa API consente agli sviluppatori di gestire<br/>            le immagini DICOM in modo efficace soddisfacendo i diversi requisiti applicativi in<br/>            contesti di imaging medico. |
| [DicomImageInfo](/imaging/python-net/aspose.imaging.fileformats.dicom/dicomimageinfo/) | Contiene tutte le meta-informazioni dall'intestazione del file Dicom |
| [DicomPage](/imaging/python-net/aspose.imaging.fileformats.dicom/dicompage/) | È una classe per lavorare con file DICOM di tipo multi frame |
