| [Triangle](#Triangle) | Specifica un cappuccio di linea triangolare. |

| [SquareAnchor](#SquareAnchor) | Specifica un cappuccio di linea con ancoraggio quadrato. |
| [RoundAnchor](#RoundAnchor) | Specifica un cappuccio di ancoraggio rotondo. |
| [DiamondAnchor](#DiamondAnchor) | Specifica un cappuccio di ancoraggio a diamante. |
| [ArrowAnchor](#ArrowAnchor) | Specifica un cappuccio di ancoraggio a forma di freccia. |
| [AnchorMask](#AnchorMask) | Specifica un cappuccio di linea personalizzato. |
