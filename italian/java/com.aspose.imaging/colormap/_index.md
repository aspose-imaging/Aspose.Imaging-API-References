public final class ColorMap

Definisce una mappa per la conversione dei colori. Diversi metodi della classe [ImageAttributes](../../com.aspose.imaging/imageattributes) regolano i colori dell'immagine utilizzando una tabella di rimappatura dei colori, che è un array di strutture `com.aspose.imaging.ColorMap`. Non ereditabile.
