Con la capacità di eseguire la rasterizzazione di immagini CDR e impostare i fattori di scala per entrambe le dimensioni X e Y, questa API fornisce un controllo preciso sul processo di trasformazione. Che si tratti di scalare per requisiti di output specifici o di convertire grafica vettoriale in formati raster, è possibile sfruttare questa API per una conversione efficiente e personalizzabile da vettoriale CDR a immagine raster.
