I tipi di record di stato specificano operazioni sullo stato del contesto del dispositivo di riproduzione.

Ogni contenitore di stato grafico DEVE essere aggiunto a un array di contenitori grafici salvati. Il contenitore di stato grafico non viene scritto nel metafile EMF+, quindi il suo formato può essere determinato dall'implementazione.
