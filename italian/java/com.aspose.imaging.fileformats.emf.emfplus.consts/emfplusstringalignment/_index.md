L'enumerazione StringAlignment definisce i modi per allineare le stringhe rispetto a un rettangolo di layout del testo.
## Campi

| Campo | Descrizione |
| --- | --- |
| [StringAlignmentNear](#StringAlignmentNear) | Specifica che l'allineamento della stringa è verso l'origine del rettangolo di layout. |
| [StringAlignmentCenter](#StringAlignmentCenter) | Specifica che l'allineamento è centrato tra l'origine e l'estensione del rettangolo di layout. |
| [StringAlignmentFar](#StringAlignmentFar) | Specifica che l'allineamento è sul lato destro del rettangolo di layout. |
### StringAlignmentNear {#StringAlignmentNear}
```
public static final int StringAlignmentNear
```


Specifica che l'allineamento della stringa è verso l'origine del rettangolo di layout. Questo può essere usato per allineare i caratteri lungo una linea o per allineare il testo all'interno di un rettangolo. Per un rettangolo di layout da destra a sinistra, l'origine SHOULD essere in alto a destra.

### StringAlignmentCenter {#StringAlignmentCenter}
```
public static final int StringAlignmentCenter
```


Specifica che l'allineamento è centrato tra l'origine e l'estensione del rettangolo di layout.

### StringAlignmentFar {#StringAlignmentFar}
```
public static final int StringAlignmentFar
```


Specifica che l'allineamento è sul lato destro del rettangolo di layout.
