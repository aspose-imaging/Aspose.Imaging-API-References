L'enumerazione StringDigitSubstitution definisce i modi per sostituire le cifre in una stringa in base alla locale o alla lingua dell'utente.
## Campi

| Campo | Descrizione |
| --- | --- |
| [StringDigitSubstitutionUser](#StringDigitSubstitutionUser) | Specifica uno schema di sostituzione definito dall'implementazione. |
| [StringDigitSubstitutionNone](#StringDigitSubstitutionNone) | Specifica di disabilitare le sostituzioni. |
| [StringDigitSubstitutionNational](#StringDigitSubstitutionNational) | Specifica le cifre di sostituzione che corrispondono alla lingua nazionale ufficiale della locale dell'utente. |
| [StringDigitSubstitutionTraditional](#StringDigitSubstitutionTraditional) | Specifica le cifre di sostituzione che corrispondono allo script o alla lingua nativa dell'utente, che può differire dalla lingua nazionale ufficiale della locale dell'utente. |
