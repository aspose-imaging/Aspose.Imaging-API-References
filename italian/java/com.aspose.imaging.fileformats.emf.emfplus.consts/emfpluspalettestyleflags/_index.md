I flag PaletteStyle specificano le proprietà delle palette grafiche. Questi flag possono essere combinati per specificare più opzioni.

--------------------

Le palette grafiche sono specificate da oggetti [EmfPlusPalette](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspalette).
## Campi

| Campo | Descrizione |
| --- | --- |
| [PaletteStyleHasAlpha](#PaletteStyleHasAlpha) | Se impostato, una o più voci della palette DEVONO contenere informazioni di trasparenza alfa. |
| [PaletteStyleGrayScale](#PaletteStyleGrayScale) | Se impostato, la palette DEVE contenere solo voci in scala di grigi. |
| [PaletteStyleHalftone](#PaletteStyleHalftone) | Se impostato, la palette DEVE contenere valori di colore discreti che possono essere usati per la mezzitonalità. |
