I flag CustomLineCapData specificano i dati per i cap di linea personalizzati. Questi flag possono essere combinati per specificare più opzioni.

--------------------

I cap di linea grafica personalizzati sono specificati da oggetti [EmfPlusCustomLineCap](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecap).
## Campi

| Campo | Descrizione |
| --- | --- |
| [CustomLineCapDataFillPath](#CustomLineCapDataFillPath) | Se impostato, un oggetto [EmfPlusFillPath](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfplusfillpath) DEVE essere specificato nel campo OptionalData dell'oggetto [EmfPlusCustomLineCapData](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecapdata) per riempire il cap di linea personalizzato. |
| [CustomLineCapDataLinePath](#CustomLineCapDataLinePath) | Se impostato, un oggetto [EmfPlusLinePath](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluslinepath) DEVE essere specificato nel campo OptionalData dell'oggetto EmfPlusCustomLineCapData per delineare il cap di linea personalizzato. |
### CustomLineCapDataFillPath {#CustomLineCapDataFillPath}
```
public static final int CustomLineCapDataFillPath
```
