L'enumerazione LineJoinType definisce i modi per unire due linee disegnate dalla stessa penna grafica e le cui estremità si incontrano.

--------------------

Le linee grafiche sono specificate da oggetti [EmfPlusPen](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspen) (sezione 2.2.1.7). Una giunzione di linea rende l'intersezione delle due estremità più continua.
## Campi

| Campo | Descrizione |
| --- | --- |
| [LineJoinTypeMiter](#LineJoinTypeMiter) | Specifica una giunzione di linea a spigolo. |
| [LineJoinTypeBevel](#LineJoinTypeBevel) | Specifica una giunzione di linea smussata. |
| [LineJoinTypeRound](#LineJoinTypeRound) | Specifica una giunzione di linea arrotondata. |
| [LineJoinTypeMiterClipped](#LineJoinTypeMiterClipped) | Specifica una giunzione di linea a spigolo ritagliata. |
