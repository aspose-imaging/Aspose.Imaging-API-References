I flag PathPointType specificano le proprietà di tipo dei punti nei percorsi grafici. Questi flag possono essere combinati per specificare più opzioni.

--------------------

I percorsi grafici sono specificati da oggetti [EmfPlusPath](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspath).
## Campi

| Campo | Descrizione |
| --- | --- |
| [PathPointTypeDashMode](#PathPointTypeDashMode) | Specifica che un segmento di linea che passa attraverso il punto è tratteggiato. |
| [PathPointTypePathMarker](#PathPointTypePathMarker) | Specifica che il punto è un indicatore di posizione. |
| [PathPointTypeCloseSubpath](#PathPointTypeCloseSubpath) | Specifica che il punto è il punto finale di un sotto-percorso. |
