I flag FontStyle specificano gli stili dei caratteri tipografici grafici. Questi flag possono essere combinati per specificare più opzioni.

--------------------

I caratteri tipografici grafici sono specificati dagli oggetti [EmfPlusFont](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfplusfont).
## Campi

| Campo | Descrizione |
| --- | --- |
| [FontStyleBold](#FontStyleBold) | Se impostato, il carattere tipografico DEVE essere renderizzato con un peso o spessore maggiore. |
| [FontStyleItalic](#FontStyleItalic) | Se impostato, il carattere tipografico DEVE essere renderizzato con gli steli verticali dei caratteri inclinati di un angolo maggiore rispetto alla linea di base. |
| [FontStyleUnderline](#FontStyleUnderline) | Se impostato, il carattere tipografico DEVE essere renderizzato con una linea sotto la linea di base dei caratteri. |
| [FontStyleStrikeout](#FontStyleStrikeout) | Se impostato, il carattere tipografico DEVE essere renderizzato con una linea parallela alla linea di base tracciata attraverso il centro dei caratteri. |
### FontStyleBold {#FontStyleBold}
```
public static final int FontStyleBold
```


Se impostato, il carattere tipografico DEVE essere renderizzato con un peso o spessore maggiore. Se non impostato, il carattere tipografico DEVE essere renderizzato con uno spessore normale.

### FontStyleItalic {#FontStyleItalic}
```
public static final int FontStyleItalic
```


Se impostato, il carattere tipografico DEVE essere renderizzato con gli steli verticali dei caratteri inclinati di un angolo maggiore rispetto alla linea di base. Se non impostato, il carattere tipografico DEVE essere renderizzato con gli steli verticali dei caratteri a un angolo normale.

### FontStyleUnderline {#FontStyleUnderline}
```
public static final int FontStyleUnderline
```


Se impostato, il carattere tipografico DEVE essere renderizzato con una linea sotto la linea di base dei caratteri. Se non impostato, il carattere tipografico DEVE essere renderizzato senza una linea sotto la linea di base.

### FontStyleStrikeout {#FontStyleStrikeout}
```
public static final int FontStyleStrikeout
```


Se impostato, il tipo di carattere DEVE essere renderizzato con una linea parallela alla linea di base disegnata attraverso il centro dei caratteri. Se non impostato, il tipo di carattere DEVE essere renderizzato senza una linea attraverso i caratteri.
