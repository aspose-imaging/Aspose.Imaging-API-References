L'enumerazione CompositingMode definisce i modi per combinare i colori di origine con i colori di sfondo. Il modo di composizione rappresenta lo stato abilitato del blending alfa.
## Campi

| Campo | Descrizione |
| --- | --- |
| [CompositingModeSourceOver](#CompositingModeSourceOver) | Abilita l'alpha blending, che specifica che quando un colore viene renderizzato, viene mescolato con il colore di sfondo. |
| [CompositingModeSourceCopy](#CompositingModeSourceCopy) | Disabilita l'alpha blending, il che significa che quando un colore sorgente viene renderizzato, sovrascrive il colore di sfondo. |
### CompositingModeSourceOver {#CompositingModeSourceOver}
```
public static final byte CompositingModeSourceOver
```


Abilita l'alpha blending, che specifica che quando un colore viene renderizzato, viene mescolato con il colore di sfondo. L'entità della miscelazione è determinata dal valore del componente alpha del colore renderizzato.

### CompositingModeSourceCopy {#CompositingModeSourceCopy}
```
public static final byte CompositingModeSourceCopy
```


Disabilita l'alpha blending, il che significa che quando un colore sorgente viene renderizzato, sovrascrive il colore di sfondo.
