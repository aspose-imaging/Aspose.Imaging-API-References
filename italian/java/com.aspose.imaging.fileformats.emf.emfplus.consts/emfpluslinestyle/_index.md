L'enumerazione LineStyle definisce gli stili delle linee disegnate con penne grafiche.

--------------------

Le linee grafiche sono specificate da oggetti [EmfPlusPen](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspen) (sezione 2.2.1.7).
