L'enumerazione UnitType definisce le unità di misura in diversi sistemi di coordinate.
## Campi

| Campo | Descrizione |
| --- | --- |
| [UnitTypeWorld](#UnitTypeWorld) | Specifica un'unità di distanza logica nello spazio mondiale. |
| [UnitTypeDisplay](#UnitTypeDisplay) | Specifica un'unità di distanza basata sulle caratteristiche del display fisico. |
| [UnitTypePixel](#UnitTypePixel) | Specifica un'unità di 1 pixel. |
| [UnitTypePoint](#UnitTypePoint) | Specifica un'unità di 1 punto della stampante, o 1/72 di pollice. |
| [UnitTypeInch](#UnitTypeInch) | Specifica un'unità di 1 pollice. |
| [UnitTypeDocument](#UnitTypeDocument) | Specifica un'unità di 1/300 di pollice. |
| [UnitTypeMillimeter](#UnitTypeMillimeter) | Specifica un'unità di 1 millimetro. |
