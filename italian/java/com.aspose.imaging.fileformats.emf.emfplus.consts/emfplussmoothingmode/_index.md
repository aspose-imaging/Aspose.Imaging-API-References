L'enumerazione SmoothingMode definisce le modalità di smussatura da applicare a linee, curve e ai bordi delle aree riempite per farle apparire più continue o nettamente definite.
## Campi

| Campo | Descrizione |
| --- | --- |
| [SmoothingModeDefault](#SmoothingModeDefault) | Specifica la smussatura predefinita delle curve senza anti-aliasing. |
| [SmoothingModeHighSpeed](#SmoothingModeHighSpeed) | Specifica le migliori prestazioni senza anti-aliasing. |
| [SmoothingModeHighQuality](#SmoothingModeHighQuality) | Specifica la migliore qualità con anti-aliasing. |
| [SmoothingModeNone](#SmoothingModeNone) | Non esegue alcuna smussatura delle curve né anti-aliasing. |
| [SmoothingModeAntiAlias8x4](#SmoothingModeAntiAlias8x4) | Specifica una buona qualità usando un filtro a scatola 8x4. |
| [SmoothingModeAntiAlias8x8](#SmoothingModeAntiAlias8x8) | Specifica una qualità migliore usando un filtro a scatola 8x8. |
