L'enumerazione PathPointType definisce i tipi di punti su un percorso grafico.

--------------------

## Campi

| [PathPointTypeBezier](#PathPointTypeBezier) | Specifica che il punto è un punto finale o un punto di controllo di una curva Bézier cubica. |
