I flag PenData specificano le proprietà delle penne grafiche, inclusa la presenza di campi dati opzionali. Questi flag possono essere combinati per specificare più opzioni.

--------------------

Le penne grafiche sono specificate da oggetti [EmfPlusPen](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspen).
