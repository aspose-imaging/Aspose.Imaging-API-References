Un intero senza segno a 32 bit che specifica la modalità di layout
## Campi

| Campo | Descrizione |
| --- | --- |
| [LAYOUT_LTR](#LAYOUT-LTR) | Imposta il layout orizzontale predefinito da sinistra a destra. |
| [LAYOUT_RTL](#LAYOUT-RTL) | Imposta il layout orizzontale predefinito da destra a sinistra. |
| [LAYOUT_BITMAPORIENTATIONPRESERVED](#LAYOUT-BITMAPORIENTATIONPRESERVED) | Disabilita la riflessione dei bitmap disegnati dai tipi di record Bitmap (sezione 2.3.1), quando la modalità di layout è da destra a sinistra. |
### LAYOUT_LTR {#LAYOUT-LTR}
```
public static final int LAYOUT_LTR
```


Imposta il layout orizzontale predefinito da sinistra a destra. Questa è la modalità predefinita per le impostazioni regionali inglesi ed europee.

### LAYOUT_RTL {#LAYOUT-RTL}
```
public static final int LAYOUT_RTL
```


Imposta il layout orizzontale predefinito da destra a sinistra. Questa modalità è necessaria per alcune lingue, tra cui arabo ed ebraico.

### LAYOUT_BITMAPORIENTATIONPRESERVED {#LAYOUT-BITMAPORIENTATIONPRESERVED}
```
public static final int LAYOUT_BITMAPORIENTATIONPRESERVED
```


Disabilita la riflessione dei bitmap disegnati dai tipi di record Bitmap (sezione 2.3.1), quando la modalità di layout è da destra a sinistra.
