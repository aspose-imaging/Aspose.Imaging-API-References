Il pacchetto fornisce classi e metodi di supporto per lavorare con diversi tipi di pennello.


## Classi

| Classe | Descrizione |
| --- | --- |
| [HatchBrush](../com.aspose.imaging.brushes/hatchbrush) | Definisce un pennello rettangolare con uno stile a trama, un colore di primo piano e un colore di sfondo. |
| [LinearGradientBrush](../com.aspose.imaging.brushes/lineargradientbrush) | Incapsula un `Aspose.Imaging.Brush` con un gradiente lineare. |
| [LinearGradientBrushBase](../com.aspose.imaging.brushes/lineargradientbrushbase) | Rappresenta un `Brush` con capacità di gradiente e proprietà appropriate. |
| [LinearMulticolorGradientBrush](../com.aspose.imaging.brushes/linearmulticolorgradientbrush) | Rappresenta un `Brush` con gradiente lineare definito da più colori e posizioni appropriate. |
| [PathGradientBrush](../com.aspose.imaging.brushes/pathgradientbrush) | Incapsula un oggetto `Aspose.Imaging.Brush` con un gradiente. |
| [PathGradientBrushBase](../com.aspose.imaging.brushes/pathgradientbrushbase) | Rappresenta un `Brush` con funzionalità di gradiente del percorso di base. |
| [PathMulticolorGradientBrush](../com.aspose.imaging.brushes/pathmulticolorgradientbrush) | Incapsula un oggetto `Aspose.Imaging.Brush` con un gradiente. |
| [SolidBrush](../com.aspose.imaging.brushes/solidbrush) | Il pennello solido è destinato al disegno continuo con un colore specifico. |
| [TextureBrush](../com.aspose.imaging.brushes/texturebrush) | Ogni proprietà della classe `Aspose.Imaging.Brushes.TextureBrush` è un oggetto `Aspose.Imaging.Brush` che utilizza un'immagine per riempire l'interno di una forma. |
| [TransformBrush](../com.aspose.imaging.brushes/transformbrush) | Un `Brush` con capacità di trasformazione. |
