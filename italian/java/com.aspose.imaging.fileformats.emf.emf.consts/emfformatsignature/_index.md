L'enumerazione FormatSignature definisce i valori usati per identificare il formato dei dati incorporati nei record EMF.
## Campi

| Campo | Descrizione |
| --- | --- |
| [ENHMETA_SIGNATURE](#ENHMETA-SIGNATURE) | Il valore di questo membro è la sequenza di caratteri ASCII \"FME \", che risulta essere l'inverso della stringa \"EMF\", e indica i dati del record EMF. |
| [EPS_SIGNATURE](#EPS-SIGNATURE) | Il valore di questo membro è la sequenza di caratteri ASCII \"FSPE\", che risulta essere l'inverso della stringa \"EPSF\", e indica i dati del formato PostScript incapsulato (EPS). |
### ENHMETA_SIGNATURE {#ENHMETA-SIGNATURE}
```
public static final int ENHMETA_SIGNATURE
```


Il valore di questo membro è la sequenza di caratteri ASCII \"FME \", che risulta essere l'inverso della stringa \"EMF\", e indica i dati del record EMF. Nota: il carattere spazio nella stringa è significativo e DEVE essere presente.

### EPS_SIGNATURE {#EPS-SIGNATURE}
```
public static final int EPS_SIGNATURE
```


Il valore di questo membro è la sequenza di caratteri ASCII \"FSPE\", che risulta essere l'inverso della stringa \"EPSF\", e indica i dati del formato PostScript incapsulato (EPS).
