| [ProjectLink](../com.aspose.imaging.xmp.schemas.xmpdm/projectlink) | Rappresenta il percorso del progetto. |

| [TimeFormat](../com.aspose.imaging.xmp.schemas.xmpdm/timeformat) | Rappresenta il formato temporale in `Timecode`. |
| [Timecode](../com.aspose.imaging.xmp.schemas.xmpdm/timecode) | Rappresenta il valore del timecode nel video. |
| [XmpDynamicMediaPackage](../com.aspose.imaging.xmp.schemas.xmpdm/xmpdynamicmediapackage) | Rappresenta lo spazio dei nomi XMP Dynamic Media. |
