L'enumerazione PenStyle a 16 bit è usata per specificare diversi tipi di penne che possono essere utilizzati nelle operazioni grafiche.
## Campi

| Campo | Descrizione |
| --- | --- |
| [Cosmetic](#Cosmetic) | Il cosmetico |
| [EndcapRound](#EndcapRound) | Le estremità delle linee sono arrotondate. |
| [JoinRound](#JoinRound) | Le giunzioni delle linee sono arrotondate. |
| [Solid](#Solid) | La penna è solida. |
| [Dash](#Dash) | La penna è tratteggiata. |
| [Dot](#Dot) | La penna è puntinata. |
| [Dashdot](#Dashdot) | La penna ha trattini e punti alternati. |
| [Dashdotdot](#Dashdotdot) | La penna ha trattini e doppi punti. |
| [Null](#Null) | La penna è invisibile. |
| [Insideframe](#Insideframe) | La penna è solida. |
| [Userstyle](#Userstyle) | La penna utilizza un array di stile fornito dall'utente. |
| [Alternate](#Alternate) | La penna imposta ogni altro pixel (questo stile è applicabile solo alle penne cosmetiche). |
| [EndcapSquare](#EndcapSquare) | Le estremità delle linee sono quadrate. |
| [EndcapFlat](#EndcapFlat) | Le estremità delle linee sono piatte. |
| [JoinBevel](#JoinBevel) | Le giunzioni delle linee sono smussate. |
| [JoinMiter](#JoinMiter) | Le giunzioni delle linee sono a spigolo quando sono entro il limite corrente impostato dal record SETMITERLIMIT META\_ESCAPE. |
