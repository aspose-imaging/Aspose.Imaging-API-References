L'enumerazione CharacterSet definisce i possibili insiemi di glifi di carattere definiti nei font per l'output grafico.
## Campi

| Campo | Descrizione |
| --- | --- |
| [Ansi](#Ansi) | Specifica il set di caratteri inglese. |
| [Default](#Default) | Specifica un set di caratteri basato sulla locale di sistema corrente; ad esempio, quando la locale di sistema è l'inglese degli Stati Uniti, il set di caratteri predefinito è ANSI\_CHARSET. |
| [Symbol](#Symbol) | Specifica un set di caratteri di simboli. |
| [Mac](#Mac) | Specifica il set di caratteri Apple Macintosh. |
| [Shiftjis](#Shiftjis) | Specifica il set di caratteri giapponese. |
| [Hangul](#Hangul) | Anche scritto "Hangeul". |
| [Johab](#Johab) | Anche scritto "Johap". |
| [Gb2312](#Gb2312) | Specifica il set di caratteri cinese "semplificato" per la Repubblica Popolare Cinese. |
| [Chinesebig5](#Chinesebig5) | Specifica il set di caratteri cinese "tradizionale", usato principalmente a Taiwan e nelle Regioni Amministrative Speciali di Hong Kong e Macao. |
| [Greek](#Greek) | Specifica il set di caratteri greco. |
| [Turkish](#Turkish) | Specifica il set di caratteri turco. |
| [Vietnamese](#Vietnamese) | Specifica il set di caratteri vietnamita. |
| [Hebrew](#Hebrew) | Specifica il set di caratteri vietnamita. |
| [Arabic](#Arabic) | Specifica il set di caratteri arabo |
| [Baltic](#Baltic) | Specifica il set di caratteri baltico (Europa nord-orientale) |
| [Russian](#Russian) | Specifica il set di caratteri cirillico russo. |
| [Thai](#Thai) | Specifica il set di caratteri tailandese. |
| [Easteurope](#Easteurope) | Specifica un set di caratteri dell'Europa orientale. |
| [Oem](#Oem) | Specifica una mappatura a una delle pagine di codice OEM, secondo l'impostazione della locale di sistema corrente. |
