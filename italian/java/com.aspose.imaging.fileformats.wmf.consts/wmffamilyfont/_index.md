L'enumerazione FamilyFont specifica la famiglia di caratteri. Le famiglie di caratteri descrivono l'aspetto di un carattere in modo generale. Sono destinate a specificare i caratteri quando il tipo di carattere esatto desiderato non è disponibile.
## Campi

| Campo | Descrizione |
| --- | --- |
| [Dontcare](#Dontcare) | Il carattere predefinito è specificato, il che dipende dall'implementazione. |
| [Roman](#Roman) | Caratteri con larghezze di tratto variabili, proporzionali alle larghezze effettive dei glifi, e che hanno grazie. |
| [Swiss](#Swiss) | Caratteri con larghezze di tratto variabili, proporzionali alle larghezze effettive dei glifi, e che non hanno grazie. |
| [Modern](#Modern) | Caratteri con larghezza di tratto costante, con o senza grazie. |
| [Script](#Script) | Caratteri progettati per assomigliare alla scrittura a mano. |
| [Decorative](#Decorative) | Caratteri di novità. |

### Roman {#Roman}
```

```


Caratteri con larghezze di tratto variabili, proporzionali alle larghezze effettive dei glifi, e che hanno grazie. "MS Serif" è un esempio.

### Swiss {#Swiss}
```

```


Caratteri con spessori di tratto variabili, proporzionali alle larghezze effettive dei glifi, e privi di grazie. "MS Sans Serif" è un esempio.

### Modern {#Modern}
```

```


Caratteri con spessore di tratto costante, con o senza grazie. I caratteri a larghezza fissa sono solitamente moderni. "Pica", "Elite" e "Courier New" sono esempi.
