Ogni codice di operazione raster ternaria rappresenta un'operazione booleana in cui i valori dei pixel nella sorgente, nel pennello selezionato e nella destinazione sono combinati. Di seguito i tre operandi utilizzati in queste operazioni.
## Campi

| Campo | Descrizione |
| --- | --- |
| [D](#D) | Bitmap di destinazione |
| [P](#P) | Pennello selezionato (chiamato anche pattern) |
| [S](#S) | Bitmap di sorgente |
| [a](#a) | AND bit a bit |
| [n](#n) | NOT bit a bit (inverso) |
| [o](#o) | OR bit a bit |
| [x](#x) | OR esclusivo bit a bit (XOR) |
