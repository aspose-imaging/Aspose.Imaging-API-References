L'enumerazione PostScriptCap definisce i tipi di terminazione di linea da usare con un driver di stampante PostScript.
## Campi

| Campo | Descrizione |
| --- | --- |
| [PostScriptNotSet](#PostScriptNotSet) | Specifica che lo stile di fine linea non è stato impostato e che uno stile predefinito MAY [24] può essere usato. |
| [PostScriptFlatCap](#PostScriptFlatCap) | Specifica che la linea termina all'ultimo punto. |
| [PostScriptRoundCap](#PostScriptRoundCap) | Specifica un cap circolare. |
| [PostScriptSquareCap](#PostScriptSquareCap) | Specifica un cap quadrato. |
### PostScriptNotSet {#PostScriptNotSet}
```
public static final int PostScriptNotSet
```


Specifica che lo stile di fine linea non è stato impostato e che uno stile predefinito MAY [24] può essere usato.

### PostScriptFlatCap {#PostScriptFlatCap}
```
public static final int PostScriptFlatCap
```


Specifica che la linea termina all'ultimo punto. L'estremità è squadrata.

### PostScriptRoundCap {#PostScriptRoundCap}
```
public static final int PostScriptRoundCap
```


Specifica un cappuccio circolare. Il centro del cerchio è l'ultimo punto della linea. Il diametro del cerchio è lo stesso della larghezza della linea; cioè lo spessore della linea.

### PostScriptSquareCap {#PostScriptSquareCap}
```
public static final int PostScriptSquareCap
```


Specifica un cappuccio quadrato. Il centro del quadrato è l'ultimo punto della linea. L'altezza e la larghezza del quadrato sono le stesse della larghezza della linea; cioè lo spessore della linea.
