L'enumerazione PostScriptClipping definisce le funzioni che possono essere applicate al percorso di ritaglio usato per l'output PostScript.
## Campi

| Campo | Descrizione |
| --- | --- |
| [CLIP_SAVE](#CLIP-SAVE) | Salva il percorso di ritaglio PostScript corrente. |
| [CLIP_RESTORE](#CLIP-RESTORE) | Ripristina il percorso di ritaglio PostScript all'ultimo percorso di ritaglio che è stato salvato da una precedente funzione CLIP\_SAVE applicata da un record CLIP\_TO\_PATH (sezione 2.3.6.6). |
| [CLIP_INCLUSIVE](#CLIP-INCLUSIVE) | Interseca il percorso di ritaglio PostScript corrente con il percorso di ritaglio corrente e salva il risultato come nuovo percorso di ritaglio PostScript. |
