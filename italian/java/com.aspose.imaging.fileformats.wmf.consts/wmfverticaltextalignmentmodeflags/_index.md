I flag VerticalTextAlignmentMode specificano la relazione tra un punto di riferimento e un rettangolo di delimitazione, per l'allineamento del testo. Questi flag possono essere combinati per specificare più opzioni, con la restrizione che solo un flag può essere scelto che altera la posizione di disegno nel contesto del dispositivo di riproduzione. L'allineamento verticale del testo viene eseguito quando il carattere ha una linea di base verticale predefinita, come nel Kanji.
## Campi

| Campo | Descrizione |
| --- | --- |
| [VTA_TOP](#VTA-TOP) | Il punto di riferimento DEVE trovarsi sul bordo superiore del rettangolo di delimitazione. |
| [VTA_RIGHT](#VTA-RIGHT) | Il punto di riferimento DEVE trovarsi sul bordo destro del rettangolo di delimitazione. |
| [VTA_BOTTOM](#VTA-BOTTOM) | Il punto di riferimento DEVE trovarsi sul bordo inferiore del rettangolo di delimitazione. |
| [VTA_CENTER](#VTA-CENTER) | Il punto di riferimento DEVE essere allineato verticalmente con il centro del rettangolo di delimitazione. |
| [VTA_LEFT](#VTA-LEFT) | Il punto di riferimento DEVE trovarsi sul bordo sinistro del rettangolo di delimitazione. |
| [VTA_BASELINE](#VTA-BASELINE) | Il punto di riferimento DEVE trovarsi sulla linea di base del testo. |
