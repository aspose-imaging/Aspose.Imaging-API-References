L'enumerazione OutPrecision definisce i valori per la precisione di output, che è il requisito per il mapper dei font per corrispondere a parametri specifici del font, inclusi altezza, larghezza, orientamento dei caratteri, escapement, passo e tipo di font.
## Campi

| Campo | Descrizione |
| --- | --- |
| [Default](#Default) | Un valore che specifica il comportamento predefinito. |
| [String](#String) | Un valore restituito quando i font rasterizzati vengono enumerati. |
| [Stroke](#Stroke) | Un valore restituito quando i font TrueType e altri font outline, e i font vettoriali vengono enumerati. |
| [Tt](#Tt) | Un valore che specifica la scelta di un font TrueType quando il sistema contiene più font con lo stesso nome. |
| [Device](#Device) | Un valore che specifica la scelta di un font di dispositivo quando il sistema contiene più font con lo stesso nome. |
| [Raster](#Raster) | Un valore che specifica la scelta di un font rasterizzato quando il sistema contiene più font con lo stesso nome. |
| [TtOnly](#TtOnly) | Un valore che specifica il requisito di utilizzare solo font TrueType. |
| [Outline](#Outline) | Un valore che specifica il requisito per font TrueType e altri font outline. |
| [ScreenOutline](#ScreenOutline) | Un valore che specifica una preferenza per i font TrueType e altri font outline. |
| [PsOnly](#PsOnly) | Un valore che specifica il requisito di utilizzare solo font PostScript. |
