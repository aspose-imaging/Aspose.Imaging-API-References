### Twips {#Twips}

Il twips Ogni unità logica è mappata a un ventesimo (1/20) di punto. Nella stampa, un punto è 1/72 di pollice; quindi, 1/20 di punto è 1/1440 di pollice. Questa unità è anche conosciuta come "twip".

### Isotropic {#Isotropic}
```
public static final short Isotropic
```


Le unità logiche isotrope sono mappate a unità di dispositivo arbitrarie con assi scalati in modo uguale; cioè, un'unità lungo l'asse x è uguale a un'unità lungo l'asse y. I record META\_SETWINDOWEXT e META\_SETVIEWPORTEXT specificano le unità e l'orientamento degli assi.
