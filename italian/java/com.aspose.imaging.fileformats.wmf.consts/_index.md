Il pacchetto contiene i tipi [MS-WMF]: Windows Metafile Format 2.1 Costanti WMF


## Classi

| Classe | Descrizione |
| --- | --- |
| [StretchMode](../com.aspose.imaging.fileformats.wmf.consts/stretchmode) | L'enumerazione [StretchMode](../com.aspose.imaging.fileformats.wmf.consts/stretchmode) specifica la modalità di stretching del bitmap, che definisce come il sistema combina righe o colonne di un bitmap con i pixel esistenti. |

| [WmfCharacterSet](../com.aspose.imaging.fileformats.wmf.consts/wmfcharacterset) | L'enumerazione CharacterSet definisce i possibili insiemi di glifi di carattere definiti nei font per l'output grafico. |
| [WmfClipPrecisionFlags](../com.aspose.imaging.fileformats.wmf.consts/wmfclipprecisionflags) | I flag ClipPrecision specificano la precisione del ritaglio, che definisce come ritagliare i caratteri parzialmente fuori da una regione di ritaglio. |
| [WmfColorUsageEnum](../com.aspose.imaging.fileformats.wmf.consts/wmfcolorusageenum) | L'enumerazione ColorUsage specifica se una tavola dei colori esiste in un bitmap indipendente dal dispositivo (DIB) e come interpretare i suoi valori. |
| [WmfCompression](../com.aspose.imaging.fileformats.wmf.consts/wmfcompression) | L'enumerazione Compression specifica il tipo di compressione per un'immagine bitmap. |

| [WmfFloodFillMode](../com.aspose.imaging.fileformats.wmf.consts/wmffloodfillmode) | L'enumerazione FloodFill specifica il tipo di operazione di riempimento da eseguire. |
| [WmfFontQuality](../com.aspose.imaging.fileformats.wmf.consts/wmffontquality) | L'enumerazione FontQuality specifica quanto strettamente gli attributi del font logico debbano corrispondere a quelli del font fisico durante il rendering del testo. |
| [WmfGamutMappingIntent](../com.aspose.imaging.fileformats.wmf.consts/wmfgamutmappingintent) | L'enumerazione GamutMappingIntent specifica la relazione tra i colori logici e fisici. |

| [WmfMapMode](../com.aspose.imaging.fileformats.wmf.consts/wmfmapmode) | Le modalità di mappa |
| [WmfMetafileEscapes](../com.aspose.imaging.fileformats.wmf.consts/wmfmetafileescapes) | L'enumerazione MetafileEscapes specifica la funzionalità del driver della stampante che potrebbe non essere direttamente accessibile tramite i record WMF definiti nell'enumerazione RecordType (sezione 2.1.1.1). |
| [WmfMetafileVersion](../com.aspose.imaging.fileformats.wmf.consts/wmfmetafileversion) | L'enumerazione MetafileVersion definisce i valori che specificano il supporto per bitmap indipendenti dal dispositivo (DIB) nei metafile. |
| [WmfMixMode](../com.aspose.imaging.fileformats.wmf.consts/wmfmixmode) | L'enumerazione MixMode specifica la modalità di miscelazione dello sfondo per il testo, i pennelli tratteggiati e altri stili di penna non solidi. |
| [WmfOutPrecision](../com.aspose.imaging.fileformats.wmf.consts/wmfoutprecision) | L'enumerazione OutPrecision definisce i valori per la precisione di output, che è il requisito per il mapper dei font per corrispondere a parametri specifici del font, inclusi altezza, larghezza, orientamento dei caratteri, escapement, passo e tipo di font. |
| [WmfPenStyle](../com.aspose.imaging.fileformats.wmf.consts/wmfpenstyle) | L'enumerazione PenStyle a 16 bit è usata per specificare diversi tipi di penne che possono essere utilizzati nelle operazioni grafiche. |

| [WmfPolyFillMode](../com.aspose.imaging.fileformats.wmf.consts/wmfpolyfillmode) | L'enumerazione PolyFillMode specifica il metodo usato per riempire un poligono. |
| [WmfPostScriptCap](../com.aspose.imaging.fileformats.wmf.consts/wmfpostscriptcap) | L'enumerazione PostScriptCap definisce i tipi di terminazione di linea da usare con un driver di stampante PostScript. |
| [WmfPostScriptClipping](../com.aspose.imaging.fileformats.wmf.consts/wmfpostscriptclipping) | L'enumerazione PostScriptClipping definisce le funzioni che possono essere applicate al percorso di ritaglio usato per l'output PostScript. |
| [WmfRecordType](../com.aspose.imaging.fileformats.wmf.consts/wmfrecordtype) | Tipo di record wmf |

| [WmfTextAlignmentModeFlags](../com.aspose.imaging.fileformats.wmf.consts/wmftextalignmentmodeflags) | I flag TextAlignmentMode specificano la relazione tra un punto di riferimento e un rettangolo di delimitazione, per l'allineamento del testo. |
| [WmfVerticalTextAlignmentModeFlags](../com.aspose.imaging.fileformats.wmf.consts/wmfverticaltextalignmentmodeflags) | I flag VerticalTextAlignmentMode specificano la relazione tra un punto di riferimento e un rettangolo di delimitazione, per l'allineamento del testo. |
