L'enumerazione BrushStyle specifica i diversi tipi di pennello possibili che possono essere usati nelle operazioni grafiche. Per ulteriori informazioni, vedere la specifica dell'oggetto Brush (sezione 2.2.1.1).
## Campi

| Campo | Descrizione |
| --- | --- |
| [Solid](#Solid) | Un pennello che dipinge un unico colore costante, sia solido che a reticolo. |
| [Null](#Null) | Un pennello che non fa nulla. |
| [Hatched](#Hatched) | Un pennello che dipinge un modello semplice predefinito, o "hatch", su uno sfondo solido |
| [Pattern](#Pattern) | Un pennello che dipinge un modello definito da una bitmap, che PUÒ essere un oggetto Bitmap16 o un oggetto DeviceIndependentBitmap (DIB). |
| [Indexed](#Indexed) | Non supportato. |
| [Dibpattern](#Dibpattern) | Un pennello a modello specificato da un DIB. |
| [Dibpatternpt](#Dibpatternpt) | Un pennello a modello specificato da un DIB. |
| [Pattern8X8](#Pattern8X8) | Non supportato. |
| [Dibpattern8X8](#Dibpattern8X8) | Non supportato. |
| [Monopattern](#Monopattern) | Non supportato. |
| [Gradient](#Gradient) | Il gradiente non è supportato in wmf, è supportato in odg. |
