### FloodFillBorder {#FloodFillBorder}
```
public static final int FloodFillBorder
```


L'area di riempimento è delimitata dal colore specificato dal membro Color. Questo stile è identico al riempimento eseguito dal record META\_FLOODFILL.

### FloodFillSurface {#FloodFillSurface}
```
public static final int FloodFillSurface
```


L'area di riempimento è delimitata dal colore che è specificato dal membro Color. Il riempimento continua verso l'esterno in tutte le direzioni finché il colore è incontrato. Questo stile è utile per riempire aree con confini multicolori.
