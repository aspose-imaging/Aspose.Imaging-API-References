Especifica cómo unir segmentos consecutivos de línea o curva en una figura (subruta) contenida en un objeto [GraphicsPath](/imaging/python-net/aspose.imaging/graphicspath/).

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.LineJoin

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| BEVEL | Especifica una unión biselada. Esto produce una esquina diagonal. |
| MITER | Especifica una unión en inglete. Esto produce una esquina aguda o una esquina recortada, dependiendo de si la longitud del inglete supera el límite del inglete. |
| MITER_CLIPPED | Especifica una unión en inglete. Esto produce una esquina aguda o una esquina biselada, dependiendo de si la longitud del inglete supera el límite del inglete. |
| ROUND | Especifica una unión circular. Esto produce un arco circular y suave entre las líneas. |
