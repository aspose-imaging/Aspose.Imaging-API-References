Especifica los tipos de imágenes y colores que se verán afectados por la configuración de ajuste de color y escala de grises de un [ImageAttributes](/imaging/python-net/aspose.imaging/imageattributes/).

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.ColorMatrixFlag

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| ALT_GRAYS | Solo se ajustan los tonos de gris. |
| DEFAULT | Todos los valores de color, incluidos los tonos de gris, se ajustan mediante la misma matriz de ajuste de color. |
| SKIP_GRAYS | Todos los colores se ajustan, pero los tonos de gris no se ajustan. Un tono de gris es cualquier color que tiene el mismo valor para sus componentes rojo, verde y azul. |
