Especifica canales individuales en el espacio de color CMYK (cian, magenta, amarillo, negro). Esta enumeración es usada por los métodos SetOutputChannel.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.ColorChannelFlag

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| COLOR_CHANNEL_C | El canal de color cian. |
| COLOR_CHANNEL_K | El canal de color negro. |
| COLOR_CHANNEL_LAST | Se debe usar el último canal seleccionado. |
| COLOR_CHANNEL_M | El canal de color magenta. |
| COLOR_CHANNEL_Y | El canal de color amarillo. |
