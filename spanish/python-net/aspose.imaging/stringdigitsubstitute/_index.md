La enumeración especifica cómo sustituir dígitos en una cadena según la configuración regional o el idioma del usuario.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.StringDigitSubstitute

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| NATIONAL | Especifica los dígitos de sustitución que corresponden con el idioma nacional oficial de la configuración regional del usuario. |
| NONE | Especifica desactivar las sustituciones. |
| TRADITIONAL | Especifica los dígitos de sustitución que corresponden con el guion o idioma nativo del usuario, que puede ser diferente del idioma nacional oficial de la configuración regional del usuario. |
| USER | Especifica un esquema de sustitución definido por el usuario. |
