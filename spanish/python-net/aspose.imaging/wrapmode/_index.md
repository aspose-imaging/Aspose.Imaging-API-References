Especifica cómo se repite una textura o degradado cuando es más pequeña que el área a rellenar.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.WrapMode

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| CLAMP | La textura o el degradado no se repite. |
| TILE | Repite el degradado o la textura. |
| TILE_FLIP_X | Invierte la textura o el degradado horizontalmente y luego repite la textura o el degradado. |
| TILE_FLIP_XY | Invierte la textura o degradado horizontal y verticalmente y luego repite la textura o degradado. |
| TILE_FLIP_Y | Invierte la textura o degradado verticalmente y luego repite la textura o degradado. |
