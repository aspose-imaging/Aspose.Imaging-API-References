Especifica cómo recortar caracteres de una cadena que no cabe completamente en una forma de diseño.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.StringTrimming

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| CHARACTER | Especifica que el texto se recorta al carácter más cercano. |
| ELLIPSIS_CHARACTER | Especifica que el texto se recorta al carácter más cercano y se inserta una elipsis al final de una línea recortada. |
| ELLIPSIS_PATH | El centro se elimina de las líneas recortadas y se reemplaza por una elipsis. El algoritmo conserva la mayor parte posible del último segmento delimitado por barras de la línea. |
| ELLIPSIS_WORD | Especifica que el texto se recorta a la palabra más cercana y se inserta una elipsis al final de una línea recortada. |
| NONE | Especifica que no hay recorte. |
| WORD | Especifica que el texto se recorta hasta la palabra más cercana. |
