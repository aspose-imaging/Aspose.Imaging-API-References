El módulo maneja el procesamiento del formato de archivo Jpeg.

## **Classes**
| **Clase** | **Descripción** |
| :- | :- |
| [JFIFData](/imaging/python-net/aspose.imaging.fileformats.jpeg/jfifdata/) | El segmento jfif. |
| [JpegImage](/imaging/python-net/aspose.imaging.fileformats.jpeg/jpegimage/) | Manipula eficientemente imágenes raster JPEG con nuestra API, ofreciendo soporte<br/>            para varios perfiles de color como RGB y CMYK, bits por píxel personalizables<br/>            resolución, y procesamiento de contenedores de metadatos EXIF, JFIF y XMP.<br/>            Disfruta de rotación automática basada en datos de orientación y elige entre diferentes<br/>            niveles de compresión, incluido JPEG sin pérdida, para lograr una calidad de imagen óptima<br/>            y un equilibrio entre el tamaño del archivo y tus proyectos. |
| [JpegLsPresetCodingParameters](/imaging/python-net/aspose.imaging.fileformats.jpeg/jpeglspresetcodingparameters/) | Define los parámetros de codificación preestablecidos JPEG-LS según lo definido en ISO/IEC 14495-1, C.2.4.1.1.<br/>            JPEG-LS define un conjunto predeterminado de parámetros, pero se pueden usar parámetros personalizados.<br/>            Cuando se usan, estos parámetros se escriben en el flujo de bits codificado según se necesiten para el proceso de decodificación. |
