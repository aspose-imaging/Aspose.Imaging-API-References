Define el modo de entrelazado para datos de píxeles multicomponente (color).

**Module:** [aspose.imaging.fileformats.jpeg](/imaging/python-net/aspose.imaging.fileformats.jpeg/)

**Full Name:** aspose.imaging.fileformats.jpeg.JpegLsInterleaveMode

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| LÍNEA | El modo de intercalado es por línea. Se codifica una línea completa de cada componente antes de pasar a la siguiente línea. |
| NONE | Los datos se codifican y almacenan componente por componente: RRRGGGBBB. |
| MUESTRA | Los datos se codifican y almacenan por muestra. Para imágenes en color, este es el formato como RGBRGBRGB. |
