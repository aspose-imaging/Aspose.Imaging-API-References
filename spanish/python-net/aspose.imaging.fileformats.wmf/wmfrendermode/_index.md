La enumeración de modo de renderizado.

**Module:** [aspose.imaging.fileformats.wmf](/imaging/python-net/aspose.imaging.fileformats.wmf/)

**Full Name:** aspose.imaging.fileformats.wmf.WmfRenderMode

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| AUTO | El renderizado automático. Si existe un emf incrustado, entonces renderiza el emf; de lo contrario, renderiza el wmf. |
| BOTH | Renderiza ambos en orden. |
| EMBEDDED_EMF_ONLY | Renderiza solo el emf incrustado. |
| WMF_RECORDS_ONLY | Renderiza solo los registros wmf sin emf incrustado. |
