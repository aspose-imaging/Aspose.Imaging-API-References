La enumeración MixMode especifica el modo de mezcla de fondo para texto, pinceles tramados,<br/>                y otros estilos de lápiz no sólidos.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfMixMode

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| OPAQUE | El fondo se rellena con el<br/>                color de fondo que está actualmente definido en el contexto del dispositivo de reproducción antes de que el texto, el pincel tramado o la pluma sean<br/>                dibujados. |
| TRANSPARENT | El fondo permanece sin tocar. |
