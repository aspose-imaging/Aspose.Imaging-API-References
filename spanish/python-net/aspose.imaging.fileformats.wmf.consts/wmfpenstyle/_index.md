La enumeración PenStyle de 16 bits se usa para especificar diferentes tipos de lápices que pueden usarse en operaciones gráficas.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfPenStyle

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| ALTERNATE | La pluma establece cada otro píxel (este estilo solo es aplicable a plumas cosméticas). |
| COSMETIC | El cosmético |
| DASH | La pluma está en guiones. |
| DASHDOT | La pluma tiene guiones y puntos alternados. |
| DASHDOTDOT | La pluma tiene guiones y puntos dobles. |
| DOT | La pluma está punteada. |
| ENDCAP_FLAT | Los extremos de línea son planos. |
| ENDCAP_ROUND | Los extremos de línea son redondos. |
| ENDCAP_SQUARE | Los extremos de línea son cuadrados. |
| INSIDEFRAME | El lápiz es sólido. Cuando este lápiz se usa en cualquier registro de dibujo que toma un rectángulo delimitador, las dimensiones de<br/>                la figura se reducen para que quepan completamente dentro del rectángulo delimitador, teniendo en cuenta el ancho del lápiz. |
| JOIN_BEVEL | Las uniones de línea están biseladas. |
| JOIN_MITER | Las uniones de línea están en inglete cuando están dentro del límite actual<br/>                establecido por el registro SETMITERLIMIT META_ESCAPE. Una unión está biselada cuando excedería el límite. |
| JOIN_ROUND | Las uniones de línea son redondas. |
| NULL | El lápiz es invisible. |
| SOLID | El lápiz es sólido. |
| USERSTYLE | El lápiz usa una matriz de estilo suministrada por el usuario. |
