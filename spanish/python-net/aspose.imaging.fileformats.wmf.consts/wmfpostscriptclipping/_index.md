La enumeración PostScriptClipping define funciones que pueden aplicarse a la ruta de recorte<br/>                utilizada para la salida PostScript.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfPostScriptClipping

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| CLIP_INCLUSIVE | Intersecta la ruta de recorte PostScript actual con la ruta de recorte actual<br/>                y guarda el resultado como la nueva ruta de recorte PostScript. |
| CLIP_RESTORE | Restaura la ruta de recorte PostScript a la última ruta de recorte que fue guardada<br/>                por una función CLIP_SAVE previa aplicada por un registro CLIP_TO_PATH (sección 2.3.6.6). |
| CLIP_SAVE | Guarda la ruta de recorte PostScript actual. |
