La enumeración OutPrecision define valores para la precisión de salida, que es el requisito para<br/>                que el asignador de fuentes coincida con parámetros de fuente específicos, incluyendo altura, anchura, orientación de caracteres,<br/>                escapamiento, paso y tipo de fuente.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfOutPrecision

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| DEFAULT | Un valor que especifica el comportamiento predeterminado. |
| DEVICE | Un valor que especifica la elección de una fuente de dispositivo cuando el sistema<br/>                contiene múltiples fuentes con el mismo nombre. |
| OUTLINE | Un valor que especifica el requisito para fuentes TrueType y otras fuentes de contorno. |
| PS_ONLY | Un valor que especifica un requisito solo para fuentes PostScript. Si no<br/>                hay fuentes PostScript instaladas en el sistema, se especifica el comportamiento predeterminado. |
| RASTER | Un valor que especifica la elección de una fuente rasterizada cuando el sistema<br/>                contiene múltiples fuentes con el mismo nombre. |
| SCREEN_OUTLINE | Un valor que especifica una preferencia por fuentes TrueType y otras<br/>                fuentes de contorno. |
| STRING | Un valor que se devuelve cuando se enumeran fuentes rasterizadas. |
| STROKE | Un valor que se devuelve cuando se enumeran fuentes TrueType y otras fuentes de contorno, y<br/>                fuentes vectoriales. |
| TT | Un valor que especifica la elección de una fuente TrueType cuando el sistema<br/>                contiene múltiples fuentes con el mismo nombre. |
| TT_ONLY | Un valor que especifica el requisito solo para fuentes TrueType. Si<br/>                no hay fuentes TrueType instaladas en el sistema, se especifica el comportamiento predeterminado. |
