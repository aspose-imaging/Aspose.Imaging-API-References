La enumeración FloodFill especifica el tipo de operación de relleno que se debe<br/>                realizar.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfFloodFillMode

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| FLOOD_FILL_BORDER | El área de relleno está delimitada por el color especificado por el miembro Color.<br/>                Este estilo es idéntico al relleno realizado por el<br/>                registro META_FLOODFILL. |
| FLOOD_FILL_SURFACE | El área de relleno está delimitada por el color que especifica el miembro Color<br/>                . El relleno continúa hacia afuera en todas las direcciones mientras se encuentre el<br/>                color. Este estilo es útil para rellenar áreas con<br/>                límites multicolores. |
