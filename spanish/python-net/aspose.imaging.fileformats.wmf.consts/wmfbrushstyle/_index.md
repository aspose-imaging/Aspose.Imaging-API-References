La enumeración BrushStyle especifica los diferentes tipos de pincel posibles<br/>                que pueden usarse en operaciones gráficas. Para más información, consulte la<br/>                especificación del objeto Brush (sección 2.2.1.1).

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfBrushStyle

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| DIBPATTERN | Un pincel de patrón especificado por un DIB. |
| DIBPATTERNPT | Un pincel de patrón especificado por un DIB. |
| DIBPATTERN_8X8 | No soportado. |
| GRADIENT | El gradiente<br/>            No compatible en wmf, compatible en odg. |
| HATCHED | Un pincel que pinta un patrón simple predefinido, o "hatch", sobre un fondo sólido |
| INDEXED | No soportado. |
| MONOPATTERN | No soportado. |
| NULL | Un pincel que no hace nada. Usar un pincel NULL en una operación gráfica<br/>                DEBE tener el mismo efecto que no usar ningún pincel. |
| PATTERN | Un pincel que pinta un patrón definido por un mapa de bits, que PUEDE ser un objeto Bitmap16<br/>                o un objeto DeviceIndependentBitmap (DIB). |
| PATTERN_8X8 | No soportado. |
| SOLID | Un pincel que pinta un color único y constante, ya sea sólido o tramado. |
