| [GifImage](/imaging/python-net/aspose.imaging.fileformats.gif/gifimage/) | La API para el Formato de Intercambio Gráfico (GIF) de archivos de imagen proporciona<br/>            a los desarrolladores herramientas versátiles para procesar imágenes raster comprimidas y<br/>            GIF animados. Ofrece funciones como manejo de metadatos XMP, configuración de paleta de colores<br/>            , control de color de fondo y transparente, ajustes de opacidad, redimensionado,<br/>            recorte, aplicación de filtros, correcciones gamma, ajuste de contraste, transformación en escala de grises<br/>            y conversión a otros formatos. Esta API permite una manipulación y mejora sin problemas<br/>            de imágenes GIF para una amplia gama de aplicaciones. |
