Indica la forma en que se debe tratar el gráfico después de ser mostrado.

**Module:** [aspose.imaging.fileformats.gif](/imaging/python-net/aspose.imaging.fileformats.gif/)

**Full Name:** aspose.imaging.fileformats.gif.DisposalMethod

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| NONE | No se especificó eliminación. |
| MANTENER | No desechar. El gráfico debe permanecer en su lugar. |
| ANTERIORES | Restaurar al anterior. Se requiere que el decodificador restaure el área sobrescrita por el gráfico con lo que había allí antes de renderizar el gráfico. |
| RESTAURAR | Restaurar al color de fondo. El área utilizada por el gráfico debe restaurarse al color de fondo. |
| INDIFINIDO | Valor indefinido. |
