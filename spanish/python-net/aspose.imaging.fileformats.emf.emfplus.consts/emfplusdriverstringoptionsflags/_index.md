Los indicadores DriverStringOptions especifican propiedades del posicionamiento y renderizado de texto gráfico. Estos indicadores pueden combinarse para especificar múltiples opciones.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusDriverStringOptionsFlags

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| DRIVER_STRING_OPTIONS_CMAP_LOOKUP | Si está establecido, las posiciones de los glifos de caracteres DEBERÍAN especificarse en una tabla de búsqueda de mapa de caracteres.<br/>            Si está despejado, las posiciones de los glifos DEBERÍAN obtenerse de una matriz de coordenadas. |
| DRIVER_STRING_OPTIONS_LIMIT_SUBPIXEL | Si está establecido, se DEBERÍA usar menos memoria para almacenar en caché glifos antialias, lo que produce una representación de texto de menor calidad.<br/>            Si está despejado, se DEBERÍA usar más memoria, lo que produce una representación de texto de mayor calidad. |
| DRIVER_STRING_OPTIONS_REALIZED_ADVANCE | Si está establecido, las posiciones de los glifos de caracteres DEBERÁN calcularse en relación con la posición del primer glifo.<br/>            Si está despejado, las posiciones de los glifos DEBERÁN obtenerse de una matriz de coordenadas. |
| DRIVER_STRING_OPTIONS_VERTICAL | Si está establecido, la cadena DEBERÁ renderizarse verticalmente.<br/>            Si está despejado, la cadena DEBERÁ renderizarse horizontalmente. |
