Los indicadores PaletteStyle especifican propiedades de paletas gráficas. Estos indicadores pueden combinarse para especificar múltiples opciones.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusPaletteStyleFlags

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| PALETTE_STYLE_GRAY_SCALE | Si está activado, la paleta DEBE contener solo entradas en escala de grises. |
| PALETTE_STYLE_HALFTONE | Si está activado, la paleta DEBE contener valores de color discretos que pueden usarse para semitonos. |
| PALETTE_STYLE_HAS_ALPHA | Si está activado, una o más entradas de la paleta DEBEN contener información de transparencia alfa. |
