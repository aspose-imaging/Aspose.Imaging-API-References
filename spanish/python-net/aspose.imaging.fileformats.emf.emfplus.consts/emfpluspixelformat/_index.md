La enumeración PixelFormat define formatos de píxel que son compatibles con los mapas de bits EMF+.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusPixelFormat

| PIXEL_FORMAT_16BPP_GRAY_SCALE | El formato es de 16 bits por píxel, en escala de grises. |

| PIXEL_FORMAT_1BPP_INDEXED | El formato es monocromo, y se usa una tabla de búsqueda de paleta de colores. |

| PIXEL_FORMAT_8BPP_INDEXED | El formato es de 256 colores, y se utiliza una tabla de búsqueda de paleta de colores. |
