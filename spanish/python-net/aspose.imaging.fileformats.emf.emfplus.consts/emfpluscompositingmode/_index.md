La enumeración CompositingMode define modos para combinar colores de origen con colores de fondo. El modo de composición representa el estado habilitado de la mezcla alfa.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusCompositingMode

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| COMPOSITING_MODE_SOURCE_COPY | Desactiva la fusión alfa, lo que significa que cuando se renderiza un color de origen, sobrescribe el color de fondo. |
| COMPOSITING_MODE_SOURCE_OVER | Activa la fusión alfa, lo que especifica que cuando se renderiza un color, se mezcla con el color de fondo. El grado de mezcla se determina por el valor del componente alfa del color que se está renderizando. |
