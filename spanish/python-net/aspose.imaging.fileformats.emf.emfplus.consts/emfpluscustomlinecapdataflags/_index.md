Los indicadores CustomLineCapData especifican datos para los extremos de línea personalizados. Estos indicadores pueden combinarse para especificar múltiples opciones.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusCustomLineCapDataFlags

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| CUSTOM_LINE_CAP_DATA_FILL_PATH | Si está establecido, se DEBE especificar un objeto [EmfPlusFillPath](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusfillpath/) en el campo OptionalData del objeto [EmfPlusCustomLineCapData](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecapdata/) para rellenar el capuchón de línea personalizado. |
| CUSTOM_LINE_CAP_DATA_LINE_PATH | Si está establecido, se DEBE especificar un objeto [EmfPlusLinePath](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfpluslinepath/) en el campo OptionalData del objeto EmfPlusCustomLineCapData para delinear el capuchón de línea personalizado. |
