La enumeración CurveChannel define canales de color que pueden verse afectados por un ajuste de efecto de curva de color en una imagen.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusCurveChannel

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| CURVE_CHANNEL_ALL | Especifica que un ajuste de curva de color se aplica a todos los canales de color. |
| CURVE_CHANNEL_BLUE | Especifica que un ajuste de curva de color se aplica solo al canal de color azul. |
| CURVE_CHANNEL_GREEN | Especifica que un ajuste de curva de color se aplica solo al canal de color verde. |
| CURVE_CHANNEL_RED | Especifica que un ajuste de curva de color se aplica solo al canal de color rojo. |
