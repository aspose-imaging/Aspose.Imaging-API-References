La enumeración MetafileDataType define tipos de datos de metarchivos que pueden incrustarse en un metarchivo EMF+.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusMetafileDataType

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| METAFILE_DATA_TYPE_EMF | Especifica que el metafichero es un metafichero EMF que especifica operaciones gráficas con registros EMF, como se indica en [MS-EMF]. |
| METAFILE_DATA_TYPE_EMF_PLUS_DUAL | Especifica que el metarchivo es un metarchivo EMF+ que especifica operaciones gráficas con registros tanto EMF como EMF+. |
| METAFILE_DATA_TYPE_EMF_PLUS_ONLY | Especifica que el metarchivo es un metarchivo EMF+ que especifica operaciones gráficas solo con registros EMF+. |
| METAFILE_DATA_TYPE_WMF | Especifica que el metarchivo es un metarchivo WMF que especifica operaciones gráficas con registros WMF, según lo especificado en [MS-WMF]. |
| METAFILE_DATA_TYPE_WMF_PLACEABLE | Especifica que el metarchivo es un metarchivo WMF que especifica operaciones gráficas con registros WMF, y que contiene información de encabezado adicional que hace que el metarchivo WMF sea independiente del dispositivo, según lo especificado en [MS-WMF]. |
