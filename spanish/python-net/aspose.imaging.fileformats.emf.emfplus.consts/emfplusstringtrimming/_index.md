La enumeración StringTrimming define cómo recortar caracteres de una cadena que es demasiado grande para el rectángulo de diseño de texto.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusStringTrimming

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| STRING_TRIMMING_CHARACTER | Especifica que la cadena se corta en el límite del último carácter que está dentro del rectángulo de diseño. Este es el valor predeterminado. |
| STRING_TRIMMING_ELLIPSIS_CHARACTER | Especifica que la cadena se corta en el límite del último carácter que está dentro del rectángulo de diseño, y se inserta una elipsis (...) después del carácter. |
| STRING_TRIMMING_ELLIPSIS_PATH | Especifica que el centro se elimina de la cadena y se reemplaza por una elipsis. El algoritmo conserva la mayor parte posible de la porción final de la cadena. |
| STRING_TRIMMING_ELLIPSIS_WORD | Especifica que la cadena se corta en el límite de la última palabra que está dentro del rectángulo de diseño, y se inserta una elipsis (...) después de la palabra. |
| STRING_TRIMMING_NONE | Especifica que no se realiza recorte. |
| STRING_TRIMMING_WORD | Especifica que la cadena se divide en el límite de la última palabra que está dentro del rectángulo de diseño. |
