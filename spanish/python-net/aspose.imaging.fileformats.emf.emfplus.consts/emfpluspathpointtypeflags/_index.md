Los indicadores PathPointType especifican propiedades de tipo de los puntos en rutas gráficas. Estos indicadores pueden combinarse para especificar múltiples opciones.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusPathPointTypeFlags

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| PATH_POINT_TYPE_CLOSE_SUBPATH | Especifica que el punto es el extremo de una subruta. |
| PATH_POINT_TYPE_DASH_MODE | Especifica que un segmento de línea que pasa por el punto está punteado. |
| PATH_POINT_TYPE_PATH_MARKER | Especifica que el punto es un marcador de posición. |
