La enumeración UnitType define unidades de medida en diferentes sistemas de coordenadas.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusUnitType

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| UNIT_TYPE_DISPLAY | Especifica una unidad de distancia basada en las características de la pantalla física.<br/>            Por ejemplo, si el dispositivo de pantalla es un monitor, entonces la unidad es 1 píxel. |
| UNIT_TYPE_DOCUMENT | Especifica una unidad de 1/300 de pulgada. |
| UNIT_TYPE_INCH | Especifica una unidad de 1 pulgada. |
| UNIT_TYPE_MILLIMETER | Especifica una unidad de 1 milímetro. |
| UNIT_TYPE_PIXEL | Especifica una unidad de 1 píxel. |
| UNIT_TYPE_POINT | Especifica una unidad de 1 punto de impresora, o 1/72 de pulgada. |
| UNIT_TYPE_WORLD | Especifica una unidad de distancia lógica dentro del espacio mundial. |
