La enumeración WrapMode define cómo el patrón de una textura o pincel de degradado se repite a lo largo de una forma o en los bordes de la forma, cuando es más pequeño que el área a rellenar.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusWrapMode

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| WRAP_MODE_CLAMP | Fija la textura o el degradado al contorno del objeto. |
| WRAP_MODE_TILE | Repite el degradado o la textura. |
| WRAP_MODE_TILE_FLIP_X | Invierte la textura o el degradado horizontalmente, y luego repite la textura o el degradado. |
| WRAP_MODE_TILE_FLIP_XY | Invierte la textura o el degradado horizontal y verticalmente, y luego repite la textura o el degradado. |
| WRAP_MODE_TILE_FLIP_Y | Invierte la textura o el degradado verticalmente, y luego repite la textura o el degradado. |
