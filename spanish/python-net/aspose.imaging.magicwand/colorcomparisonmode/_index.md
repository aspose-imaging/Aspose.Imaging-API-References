Especifica cómo se comparan los colores durante el algoritmo de Varita Mágica.

**Module:** [aspose.imaging.magicwand](/imaging/python-net/aspose.imaging.magicwand/)

**Full Name:** aspose.imaging.magicwand.ColorComparisonMode

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| CUSTOM | El algoritmo de comparación de colores es definido por el usuario. |
| RGB_DEFAULT | Los colores se comparan en el espacio de color RGB.<br/>            Cada diferencia de color debe cumplir con el umbral. |
| YUV_DEFAULT | Los colores se comparan en el espacio de color YUV.<br/>            Cada diferencia de color debe cumplir con el umbral. |
| YUV_LESS_LUMA_SENSITIVE | Los colores se comparan en el espacio de color YUV.<br/>            Las diferencias de información de color deben cumplir con el umbral, el umbral para el componente de luminancia se duplica. |
