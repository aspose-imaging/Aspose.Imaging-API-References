La enumeración FormatSignature define valores que se utilizan para identificar el formato de los datos incrustados en los registros EMF.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfFormatSignature

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| ENHMETA_SIGNATURE | El valor de este miembro es la secuencia de caracteres ASCII "FME ",<br/>            que resulta ser la inversa de la cadena "EMF", y denota datos de registro EMF.<br/>            Nota: el carácter de espacio en la cadena es significativo y DEBE estar presente. |
| EPS_SIGNATURE | El valor de este miembro es la secuencia de caracteres ASCII "FSPE",<br/>            que resulta ser la inversa de la cadena "EPSF", y denota datos del formato PostScript encapsulado (EPS). |
