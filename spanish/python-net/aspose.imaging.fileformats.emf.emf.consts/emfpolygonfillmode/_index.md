La enumeración PolygonFillMode define valores que especifican cómo calcular la región de un polígono que se debe rellenar.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfPolygonFillMode

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| ALTERNATE | Selecciona el modo alterno (rellena el área entre los lados impares y pares del polígono en cada línea de escaneo). |
| WINDING | Selecciona el modo de winding (rellena cualquier región con un valor de winding distinto de cero). |
