El módulo gestiona el procesamiento del formato de archivo Apng.

## **Classes**
| **Clase** | **Descripción** |
| :- | :- |
| [ApngFrame](/imaging/python-net/aspose.imaging.fileformats.apng/apngframe/) | Cree fotogramas de imagen PNG animado (APNG) a partir de imágenes rasterizadas de una sola página con nuestra API.<br/>            Establezca sin problemas la animación y la duración de los fotogramas, programe la cantidad de fotogramas y<br/>            ajuste los niveles de gamma y contraste, garantizando animaciones cautivadoras y personalizables<br/>            adaptadas a su visión. |
| [ApngImage](/imaging/python-net/aspose.imaging.fileformats.apng/apngimage/) | La API para el formato de archivo de imagen PNG animado (Animated Portable Network Graphics)<br/>            es una solución versátil para desarrolladores que buscan integrar<br/>            contenido animado en sus aplicaciones. Esta API ofrece un control amplio<br/>            sobre la configuración de los fotogramas, permitiendo a los usuarios definir<br/>            parámetros específicos de cada fotograma, incluyendo la duración del bucle y la configuración de archivos PNG. Con esta<br/>            herramienta rica en funciones, puede gestionar y optimizar sin esfuerzo la visualización<br/>            de imágenes APNG, importar y exportar imágenes, mejorando los aspectos dinámicos y<br/>            interactivos de sus aplicaciones. |
