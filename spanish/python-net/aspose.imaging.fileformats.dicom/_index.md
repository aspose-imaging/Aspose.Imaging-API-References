El módulo gestiona el procesamiento del formato de archivo Dicom

## **Classes**
| **Clase** | **Descripción** |
| :- | :- |
| [Compression](/imaging/python-net/aspose.imaging.fileformats.dicom/compression/) | Contiene la configuración de compresión de la imagen. |
| [DicomImage](/imaging/python-net/aspose.imaging.fileformats.dicom/dicomimage/) | Esta clase implementa el soporte del formato de imagen raster DICOM (Digital Imaging and Communications in Medicine)<br/>            y ofrece una solución integral para el procesamiento de imágenes DICOM con precisión y flexibilidad. Puedes manipular sin problemas<br/>            las páginas de la imagen, incluyendo operaciones para obtener, añadir o eliminar páginas, y<br/>            controlar las páginas predeterminadas y activas. Con capacidad para trabajar con canales alfa,<br/>            incrustar metadatos XMP, cambiar el tamaño, rotar, recortar, binarizar, ajustar, aplicar filtros,<br/>            y convertir a otros formatos raster. Esta API permite a los desarrolladores manejar<br/>            imágenes DICOM de manera eficaz mientras satisfacen diversos requisitos de aplicación en<br/>            contextos de imágenes médicas. |
| [DicomImageInfo](/imaging/python-net/aspose.imaging.fileformats.dicom/dicomimageinfo/) | Contiene toda la metainformación del encabezado del archivo DICOM |
