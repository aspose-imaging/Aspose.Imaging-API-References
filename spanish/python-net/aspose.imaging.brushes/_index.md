El módulo proporciona clases y métodos auxiliares para trabajar con diferentes tipos de pincel.

## **Classes**
| **Clase** | **Descripción** |
| :- | :- |
| [HatchBrush](/imaging/python-net/aspose.imaging.brushes/hatchbrush/) | Define un pincel rectangular con un estilo de trama, un color de primer plano y un color de fondo. Esta clase no puede heredarse. |
| [LinearGradientBrush](/imaging/python-net/aspose.imaging.brushes/lineargradientbrush/) | Encapsula un [Brush](/imaging/python-net/aspose.imaging/brush/) con un degradado lineal. Esta clase no puede heredarse. |
| [LinearGradientBrushBase](/imaging/python-net/aspose.imaging.brushes/lineargradientbrushbase/) | Representa un [Brush](/imaging/python-net/aspose.imaging/brush/) con capacidades de degradado y propiedades apropiadas. |
| [LinearMulticolorGradientBrush](/imaging/python-net/aspose.imaging.brushes/linearmulticolorgradientbrush/) | Representa un [Brush](/imaging/python-net/aspose.imaging/brush/) con degradado lineal definido por varios colores y posiciones apropiadas. Esta clase no puede heredarse. |
| [PathGradientBrush](/imaging/python-net/aspose.imaging.brushes/pathgradientbrush/) | Encapsula un objeto [Brush](/imaging/python-net/aspose.imaging/brush/) con un degradado. Esta clase no puede heredarse. |
| [PathGradientBrushBase](/imaging/python-net/aspose.imaging.brushes/pathgradientbrushbase/) | Representa un [Brush](/imaging/python-net/aspose.imaging/brush/) con funcionalidad de degradado de ruta base. |
| [PathMulticolorGradientBrush](/imaging/python-net/aspose.imaging.brushes/pathmulticolorgradientbrush/) | Encapsula un objeto [Brush](/imaging/python-net/aspose.imaging/brush/) con un degradado. Esta clase no puede heredarse. |
| [SolidBrush](/imaging/python-net/aspose.imaging.brushes/solidbrush/) | El pincel sólido está destinado a dibujar continuamente con un color específico. Esta clase no puede heredarse. |
| [TextureBrush](/imaging/python-net/aspose.imaging.brushes/texturebrush/) | Cada propiedad de la clase [TextureBrush](/imaging/python-net/aspose.imaging.brushes/texturebrush/) es un objeto [Brush](/imaging/python-net/aspose.imaging/brush/) que utiliza una imagen para rellenar el interior de una forma. Esta clase no puede heredarse. |
| [TransformBrush](/imaging/python-net/aspose.imaging.brushes/transformbrush/) | Un [Brush](/imaging/python-net/aspose.imaging/brush/) con capacidades de transformación. |
