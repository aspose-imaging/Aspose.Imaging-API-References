El estilo de degradado

**Module:** [aspose.imaging.fileformats.opendocument.enums](/imaging/python-net/aspose.imaging.fileformats.opendocument.enums/)

**Full Name:** aspose.imaging.fileformats.opendocument.enums.OdGradientStyle

## **Members**
| **Nombre del miembro** | **Descripción** |
| :- | :- |
| AXIAL | El axial<br/>                define un degradado bi-lineal que también se conoce como degradado reflejado o degradado lineal espejo.<br/>                Se crea como un degradado lineal que se refleja (o refleja) a lo largo de su eje. |
| ELLIPSOID | El elipsoide<br/>                define un degradado donde los colores se mezclan a lo largo del radio desde el centro de un<br/>                elipsoide según lo definido con los atributos draw:cx y draw:cy.<br/>                La longitud del semieje mayor es el ancho del área rellenada y la longitud del semieje menor |
| LINEAL | El lineal<br/>                define un degradado donde los colores se mezclan a lo largo del eje lineal del degradado.<br/>                El eje del degradado se especifica con el atributo draw:angle en sentido horario respecto al eje vertical. |
| NONE | El estilo de degradado es ninguno |
| RADIAL | El radial<br/>                define un degradado donde los colores se mezclan a lo largo del radio desde el centro<br/>                de un círculo según los atributos draw:cx y draw:cy.<br/>                El exterior del círculo se rellena con el color final. |
| RECTANGLE | El rectángulo<br/>                define un degradado que produce una mezcla rectangular desde el centro del rectángulo hasta el borde más corto<br/>                de los 4 bordes. El centro del rectángulo se define con los atributos draw:cx y draw:cy.<br/>                El ancho del rectángulo es el ancho del área rellenada,<br/>                la altura del rectángulo es la altura del área rellenada.<br/>                El exterior del cuadrado se rellena con el color final. |
| SQUARE | El cuadrado<br/>                define un degradado que produce una mezcla cuadrada, imitando la perspectiva visual en un corredor o la<br/>                vista aérea de una pirámide.<br/>                También conocido como "degradado de caja" y "degradado piramidal".<br/>                El centro del cuadrado se define con los atributos draw:cx y draw:cy.<br/>                El ancho y la altura del cuadrado son el valor mínimo entre el ancho o la altura del área rellenada.<br/>                El exterior del cuadrado se rellena con el color final. |
