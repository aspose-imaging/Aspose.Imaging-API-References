El módulo contiene diferentes formas combinadas a partir de segmentos de forma.

## **Classes**
| **Clase** | **Descripción** |
| :- | :- |
| [ArcShape](/imaging/python-net/aspose.imaging.shapes/arcshape/) | Representa una forma de arco. |
| [BezierShape](/imaging/python-net/aspose.imaging.shapes/beziershape/) | Representa una spline Bézier. |
| [CurveShape](/imaging/python-net/aspose.imaging.shapes/curveshape/) | Representa una forma de spline curvada. |
| [EllipseShape](/imaging/python-net/aspose.imaging.shapes/ellipseshape/) | Representa una forma de elipse. |
| [PieShape](/imaging/python-net/aspose.imaging.shapes/pieshape/) | Representa una forma de sector. |
| [PolygonShape](/imaging/python-net/aspose.imaging.shapes/polygonshape/) | Representa una forma de polígono. |
| [RectangleProjectedShape](/imaging/python-net/aspose.imaging.shapes/rectangleprojectedshape/) | Representa una forma que se proyecta sobre un rectángulo girado a una orientación particular.<br/>            Especificado por cuatro puntos que pueden rotarse en el espacio manteniendo la misma longitud de los bordes y 90 grados entre los bordes adyacentes. |
| [RectangleShape](/imaging/python-net/aspose.imaging.shapes/rectangleshape/) | Representa una forma rectangular. |
| [TextShape](/imaging/python-net/aspose.imaging.shapes/textshape/) | Representa una forma de texto. |
