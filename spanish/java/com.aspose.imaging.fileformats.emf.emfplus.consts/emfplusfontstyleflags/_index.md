Los indicadores FontStyle especifican estilos de tipografías de fuentes gráficas. Estos indicadores pueden combinarse para especificar múltiples opciones.

--------------------

Las tipografías de fuentes gráficas se especifican mediante objetos [EmfPlusFont](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfplusfont) objetos
## Campos

| Campo | Descripción |
| --- | --- |
| [FontStyleBold](#FontStyleBold) | Si está establecida, la tipografía DEBE renderizarse con un peso o grosor mayor. |
| [FontStyleItalic](#FontStyleItalic) | Si está establecida, la tipografía DEBE renderizarse con los tallos verticales de los caracteres en un ángulo o inclinación mayor respecto a la línea base. |
| [FontStyleUnderline](#FontStyleUnderline) | Si está establecida, la tipografía DEBE renderizarse con una línea bajo la línea base de los caracteres. |
| [FontStyleStrikeout](#FontStyleStrikeout) | Si está establecida, la tipografía DEBE renderizarse con una línea paralela a la línea base trazada a través del centro de los caracteres. |
### FontStyleBold {#FontStyleBold}
```
public static final int FontStyleBold
```


Si está establecida, la tipografía DEBE renderizarse con un peso o grosor mayor. Si no está establecida, la tipografía DEBE renderizarse con un grosor normal.

### FontStyleItalic {#FontStyleItalic}
```
public static final int FontStyleItalic
```


Si está establecida, la tipografía DEBE renderizarse con los tallos verticales de los caracteres en un ángulo o inclinación mayor respecto a la línea base. Si no está establecida, la tipografía DEBE renderizarse con los tallos verticales de los caracteres en un ángulo normal.

### FontStyleUnderline {#FontStyleUnderline}
```
public static final int FontStyleUnderline
```


Si está establecida, la tipografía DEBE renderizarse con una línea bajo la línea base de los caracteres. Si no está establecida, la tipografía DEBE renderizarse sin una línea bajo la línea base.

### FontStyleStrikeout {#FontStyleStrikeout}
```
public static final int FontStyleStrikeout
```


Si está activado, el tipo de letra DEBE renderizarse con una línea paralela a la línea base dibujada a través del medio de los caracteres. Si está desactivado, el tipo de letra DEBE renderizarse sin una línea a través de los caracteres.
