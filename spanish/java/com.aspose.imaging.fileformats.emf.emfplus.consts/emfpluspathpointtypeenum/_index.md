La enumeración PathPointType define tipos de puntos en una ruta gráfica.

--------------------

Los tipos de punto de la ruta gráfica se especifican mediante objetos [EmfPlusPathPointType](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspathpointtype) (sección 2.2.2.31).
## Campos

| Campo | Descripción |
| --- | --- |
| [PathPointTypeStart](#PathPointTypeStart) | Especifica que el punto es el punto de inicio de una ruta. |
| [PathPointTypeLine](#PathPointTypeLine) | Especifica que el punto es uno de los dos extremos de una línea. |
| [PathPointTypeBezier](#PathPointTypeBezier) | Especifica que el punto es un extremo o un punto de control de una curva cúbica de Bézier. |
