La enumeración LineStyle define estilos de líneas que se dibujan con lápices gráficos.

--------------------

Las líneas gráficas se especifican mediante objetos [EmfPlusPen](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspen) (sección 2.2.1.7).
