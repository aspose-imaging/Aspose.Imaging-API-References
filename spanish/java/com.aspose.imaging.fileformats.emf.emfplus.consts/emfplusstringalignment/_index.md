La enumeración StringAlignment define formas de alinear cadenas con respecto a un rectángulo de diseño de texto.
## Campos

| Campo | Descripción |
| --- | --- |
| [StringAlignmentNear](#StringAlignmentNear) | Especifica que la alineación de la cadena es hacia el origen del rectángulo de diseño. |
| [StringAlignmentCenter](#StringAlignmentCenter) | Especifica que la alineación está centrada entre el origen y la extensión del rectángulo de diseño. |
| [StringAlignmentFar](#StringAlignmentFar) | Especifica que la alineación está al lado derecho del rectángulo de diseño. |
### StringAlignmentNear {#StringAlignmentNear}
```
public static final int StringAlignmentNear
```


Especifica que la alineación de la cadena es hacia el origen del rectángulo de diseño. Esto puede usarse para alinear caracteres a lo largo de una línea o para alinear texto dentro de un rectángulo. Para un rectángulo de diseño de derecha a izquierda, el origen DEBERÍA estar en la esquina superior derecha.

### StringAlignmentCenter {#StringAlignmentCenter}
```
public static final int StringAlignmentCenter
```


Especifica que la alineación está centrada entre el origen y la extensión del rectángulo de diseño.

### StringAlignmentFar {#StringAlignmentFar}
```
public static final int StringAlignmentFar
```


Especifica que la alineación está al lado derecho del rectángulo de diseño.
