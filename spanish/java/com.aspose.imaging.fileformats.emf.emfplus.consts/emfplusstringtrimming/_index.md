La enumeración StringTrimming define cómo recortar caracteres de una cadena que es demasiado grande para el rectángulo de diseño de texto.
## Campos

| Campo | Descripción |
| --- | --- |
| [StringTrimmingNone](#StringTrimmingNone) | Especifica que no se realiza recorte. |
| [StringTrimmingCharacter](#StringTrimmingCharacter) | Especifica que la cadena se corta en el límite del último carácter que está dentro del rectángulo de diseño. |
| [StringTrimmingWord](#StringTrimmingWord) | Especifica que la cadena se corta en el límite de la última palabra que está dentro del rectángulo de diseño. |
| [StringTrimmingEllipsisCharacter](#StringTrimmingEllipsisCharacter) | Especifica que la cadena se corta en el límite del último carácter que está dentro del rectángulo de diseño, y se inserta una elipsis (...) después del carácter. |
| [StringTrimmingEllipsisWord](#StringTrimmingEllipsisWord) | Especifica que la cadena se corta en el límite de la última palabra que está dentro del rectángulo de diseño, y se inserta una elipsis (...) después de la palabra. |
| [StringTrimmingEllipsisPath](#StringTrimmingEllipsisPath) | Especifica que el centro se elimina de la cadena y se reemplaza por una elipsis. |
### StringTrimmingNone {#StringTrimmingNone}

### StringTrimmingWord {#StringTrimmingWord}

Especifica que la cadena se corta en el límite de la última palabra que está dentro del rectángulo de diseño.

Especifica que la cadena se corta en el límite del último carácter que está dentro del rectángulo de diseño, y se inserta una elipsis (...) después del carácter.

### StringTrimmingEllipsisWord {#StringTrimmingEllipsisWord}
```
public static final int StringTrimmingEllipsisWord
```


Especifica que la cadena se corta en el límite de la última palabra que está dentro del rectángulo de diseño, y se inserta una elipsis (...) después de la palabra.

### StringTrimmingEllipsisPath {#StringTrimmingEllipsisPath}
```
public static final int StringTrimmingEllipsisPath
```


Especifica que el centro se elimina de la cadena y se reemplaza por una elipsis. El algoritmo conserva la mayor parte posible de la última porción de la cadena.
