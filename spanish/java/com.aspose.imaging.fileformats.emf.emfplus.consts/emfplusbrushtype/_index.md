La enumeración BrushType define tipos de pinceles gráficos, que se utilizan para rellenar regiones gráficas.
## Campos

| Campo | Descripción |
| --- | --- |
| [BrushTypeSolidColor](#BrushTypeSolidColor) | Especifica un pincel de color sólido, que se caracteriza por un valor EmfPlusArgb. |
| [BrushTypeHatchFill](#BrushTypeHatchFill) | Especifica un pincel de trama, que se caracteriza por un patrón predefinido. |
| [BrushTypeTextureFill](#BrushTypeTextureFill) | Especifica un pincel de textura, que se caracteriza por una imagen. |
| [BrushTypePathGradient](#BrushTypePathGradient) | Especifica un pincel de degradado de ruta, que se caracteriza por datos de pincel de degradado de color de ruta. |
| [BrushTypeLinearGradient](#BrushTypeLinearGradient) | contiene datos de pincel de degradado lineal. |
