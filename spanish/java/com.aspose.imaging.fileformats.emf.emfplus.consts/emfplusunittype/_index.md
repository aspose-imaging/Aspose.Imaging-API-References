La enumeración UnitType define unidades de medida en diferentes sistemas de coordenadas.
## Campos

| Campo | Descripción |
| --- | --- |
| [UnitTypeWorld](#UnitTypeWorld) | Especifica una unidad de distancia lógica dentro del espacio mundial. |
| [UnitTypeDisplay](#UnitTypeDisplay) | Especifica una unidad de distancia basada en las características de la pantalla física. |
| [UnitTypePixel](#UnitTypePixel) | Especifica una unidad de 1 píxel. |
| [UnitTypePoint](#UnitTypePoint) | Especifica una unidad de 1 punto de impresora, o 1/72 de pulgada. |
| [UnitTypeInch](#UnitTypeInch) | Especifica una unidad de 1 pulgada. |
| [UnitTypeDocument](#UnitTypeDocument) | Especifica una unidad de 1/300 de pulgada. |
| [UnitTypeMillimeter](#UnitTypeMillimeter) | Especifica una unidad de 1 milímetro. |
