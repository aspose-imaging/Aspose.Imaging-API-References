Los indicadores PenData especifican propiedades de los lápices gráficos, incluida la presencia de campos de datos opcionales. Estos indicadores pueden combinarse para especificar múltiples opciones.

--------------------

Los lápices gráficos se especifican mediante objetos [EmfPlusPen](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspen) objetos.
