La enumeración CompositingMode define modos para combinar colores de origen con colores de fondo. El modo de composición representa el estado habilitado de la mezcla alfa.
## Campos

| Campo | Descripción |
| --- | --- |
| [CompositingModeSourceOver](#CompositingModeSourceOver) | Habilita la mezcla alfa, que especifica que cuando se renderiza un color, se combina con el color de fondo. |
| [CompositingModeSourceCopy](#CompositingModeSourceCopy) | Deshabilita la mezcla alfa, lo que significa que cuando se renderiza un color de origen, sobrescribe el color de fondo. |
### CompositingModeSourceOver {#CompositingModeSourceOver}
```
public static final byte CompositingModeSourceOver
```


Habilita la mezcla alfa, que especifica que cuando se renderiza un color, se combina con el color de fondo. El grado de mezcla está determinado por el valor del componente alfa del color que se está renderizando.

### CompositingModeSourceCopy {#CompositingModeSourceCopy}
```
public static final byte CompositingModeSourceCopy
```


Deshabilita la mezcla alfa, lo que significa que cuando se renderiza un color de origen, sobrescribe el color de fondo.
