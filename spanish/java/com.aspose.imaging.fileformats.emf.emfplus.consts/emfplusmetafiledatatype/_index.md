La enumeración MetafileDataType define tipos de datos de metarchivos que pueden incrustarse en un metarchivo EMF+.

--------------------

Los datos de metarchivo incrustados se especifican mediante objetos EmfPlusMetafileData (sección 2.2.2.27).
## Campos

| Campo | Descripción |
| --- | --- |
| [MetafileDataTypeWmf](#MetafileDataTypeWmf) | Especifica que el metarchivo es un metarchivo WMF que define operaciones gráficas con registros WMF, según lo especificado en [MS-WMF]. |
| [MetafileDataTypeWmfPlaceable](#MetafileDataTypeWmfPlaceable) | Especifica que el metarchivo es un metarchivo WMF que define operaciones gráficas con registros WMF, y que contiene información de encabezado adicional que hace que el metarchivo WMF sea independiente del dispositivo, según lo especificado en [MS-WMF]. |
| [MetafileDataTypeEmf](#MetafileDataTypeEmf) | Especifica que el metarchivo es un metarchivo EMF que define operaciones gráficas con registros EMF, según lo especificado en [MS-EMF]. |
| [MetafileDataTypeEmfPlusOnly](#MetafileDataTypeEmfPlusOnly) | Especifica que el metarchivo es un metarchivo EMF+ que define operaciones gráficas únicamente con registros EMF+. |
| [MetafileDataTypeEmfPlusDual](#MetafileDataTypeEmfPlusDual) | Especifica que el metarchivo es un metarchivo EMF+ que define operaciones gráficas con registros EMF y EMF+. |
### MetafileDataTypeWmf {#MetafileDataTypeWmf}
