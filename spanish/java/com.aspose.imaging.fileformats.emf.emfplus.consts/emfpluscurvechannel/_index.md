La enumeración CurveChannel define canales de color que pueden verse afectados por un ajuste de efecto de curva de color en una imagen.
## Campos

| Campo | Descripción |
| --- | --- |
| [CurveChannelAll](#CurveChannelAll) | Especifica que un ajuste de curva de color se aplica a todos los canales de color. |
| [CurveChannelRed](#CurveChannelRed) | Especifica que un ajuste de curva de color se aplica solo al canal de color rojo. |
| [CurveChannelGreen](#CurveChannelGreen) | Especifica que un ajuste de curva de color se aplica solo al canal de color verde. |
| [CurveChannelBlue](#CurveChannelBlue) | Especifica que un ajuste de curva de color se aplica solo al canal de color azul. |
