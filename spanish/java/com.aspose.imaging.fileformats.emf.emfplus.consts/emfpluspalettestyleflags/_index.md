Los indicadores PaletteStyle especifican propiedades de las paletas gráficas. Estos indicadores pueden combinarse para especificar múltiples opciones.

--------------------

Las paletas gráficas son especificadas por objetos [EmfPlusPalette](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspalette).
## Campos

| Campo | Descripción |
| --- | --- |
| [PaletteStyleHasAlpha](#PaletteStyleHasAlpha) | Si está establecido, una o más de las entradas de la paleta DEBEN contener información de transparencia alfa. |
| [PaletteStyleGrayScale](#PaletteStyleGrayScale) | Si está establecido, la paleta DEBE contener solo entradas en escala de grises. |
| [PaletteStyleHalftone](#PaletteStyleHalftone) | Si está establecido, la paleta DEBE contener valores de color discretos que pueden usarse para semitonos. |
