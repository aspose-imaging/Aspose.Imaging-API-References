Los indicadores CustomLineCapData especifican datos para los extremos de línea personalizados. Estos indicadores pueden combinarse para especificar múltiples opciones.

--------------------

Los extremos de línea personalizados de gráficos se especifican mediante objetos [EmfPlusCustomLineCap](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecap) objetos.
## Campos

| Campo | Descripción |
| --- | --- |
| [CustomLineCapDataFillPath](#CustomLineCapDataFillPath) | Si está establecido, se DEBE especificar un objeto [EmfPlusFillPath](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfplusfillpath) en el campo OptionalData del objeto [EmfPlusCustomLineCapData](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecapdata) para rellenar el extremo de línea personalizado. |
| [CustomLineCapDataLinePath](#CustomLineCapDataLinePath) | Si está establecido, se DEBE especificar un objeto [EmfPlusLinePath](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluslinepath) en el campo OptionalData del objeto EmfPlusCustomLineCapData para delinear el extremo de línea personalizado. |
