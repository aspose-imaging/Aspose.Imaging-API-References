Los indicadores PathPointType especifican propiedades de tipo de los puntos en rutas gráficas. Estos indicadores pueden combinarse para especificar múltiples opciones.

--------------------

Las rutas gráficas se especifican mediante objetos [EmfPlusPath](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspath).
## Campos

| Campo | Descripción |
| --- | --- |
| [PathPointTypeDashMode](#PathPointTypeDashMode) | Especifica que un segmento de línea que pasa por el punto es discontinuo. |
| [PathPointTypePathMarker](#PathPointTypePathMarker) | Especifica que el punto es un marcador de posición. |
| [PathPointTypeCloseSubpath](#PathPointTypeCloseSubpath) | Especifica que el punto es el extremo de una subruta. |
