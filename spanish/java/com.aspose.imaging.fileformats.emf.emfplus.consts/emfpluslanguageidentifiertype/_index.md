La enumeración LanguageIdentifier define identificadores para lenguas naturales en configuraciones regionales, incluyendo países, regiones geográficas y distritos administrativos.

--------------------

Los identificadores de idioma son especificados por objetos [EmfPlusLanguageIdentifierType](../../com.aspose.imaging.fileformats.emf.emfplus.consts/emfpluslanguageidentifiertype) (sección 2.2.2.23). Cada valor es una codificación de un identificador de idioma principal y un identificador de subidioma. Consulte `[MS-LCID]` para obtener información adicional sobre los identificadores de idioma, incluido el soporte de versiones de Windows.
