La enumeración WrapMode define cómo se repite el patrón de una brocha de textura o degradado sobre una forma o en los bordes de la forma, cuando es más pequeño que el área a rellenar.
## Campos

| Campo | Descripción |
| --- | --- |
| [WrapModeTile](#WrapModeTile) | Repite el degradado o la textura. |
| [WrapModeTileFlipX](#WrapModeTileFlipX) | Invierte la textura o el degradado horizontalmente, y luego repite la textura o el degradado. |
| [WrapModeTileFlipY](#WrapModeTileFlipY) | Invierte la textura o el degradado verticalmente, y luego repite la textura o el degradado. |
| [WrapModeTileFlipXY](#WrapModeTileFlipXY) | Invierte la textura o el degradado horizontal y verticalmente, y luego repite la textura o el degradado. |
| [WrapModeClamp](#WrapModeClamp) | Fija la textura o el degradado al borde del objeto. |
