public class WmfChord extends WmfRectangle

El registro META\_CHORD dibuja una cuerda, que está definida por una región delimitada por la intersección de una elipse con un segmento de línea. La cuerda se perfila usando la pluma y se rellena con el pincel que están definidos en el contexto del dispositivo de reproducción.
