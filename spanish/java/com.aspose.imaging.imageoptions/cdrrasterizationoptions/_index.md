Con la capacidad de realizar la rasterización de imágenes CDR y establecer factores de escala para ambas dimensiones X y Y, esta API proporciona un control preciso sobre el proceso de transformación. Ya sea escalando para requisitos de salida específicos o convirtiendo gráficos vectoriales a formatos raster, puede aprovechar esta API para una conversión eficiente y personalizable de vectores CDR a imágenes raster.
