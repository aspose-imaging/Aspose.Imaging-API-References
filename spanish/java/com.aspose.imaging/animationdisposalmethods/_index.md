Indica la forma en que se debe tratar el gráfico después de mostrarse.
## Campos

| Campo | Descripción |
| --- | --- |
| [PRESERVE](#PRESERVE) | No desechar. |
| [BACKGROUND](#BACKGROUND) | Restaurar al color de fondo. |
| [PREVIOUS](#PREVIOUS) | Restaurar al anterior. |
### PRESERVE {#PRESERVE}
```
public static final int PRESERVE
```


No desechar. El gráfico debe permanecer en su lugar.

### BACKGROUND {#BACKGROUND}
```
public static final int BACKGROUND
```


Restaurar al color de fondo. El área utilizada por el gráfico debe restaurarse al color de fondo.

### PREVIOUS {#PREVIOUS}
```
public static final int PREVIOUS
```


Restaurar al anterior. El decodificador debe restaurar el área sobrescrita por el gráfico con lo que había antes de renderizar el gráfico.
