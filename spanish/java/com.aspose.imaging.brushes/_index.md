El paquete proporciona clases y métodos auxiliares para trabajar con diferentes tipos de pincel.


## Clases

| Clase | Descripción |
| --- | --- |
| [HatchBrush](../com.aspose.imaging.brushes/hatchbrush) | Define un pincel rectangular con un estilo de trama, un color de primer plano y un color de fondo. |
| [LinearGradientBrush](../com.aspose.imaging.brushes/lineargradientbrush) | Encapsula un `Aspose.Imaging.Brush` con un degradado lineal. |
| [LinearGradientBrushBase](../com.aspose.imaging.brushes/lineargradientbrushbase) | Representa un `Brush` con capacidades de degradado y propiedades apropiadas. |
| [LinearMulticolorGradientBrush](../com.aspose.imaging.brushes/linearmulticolorgradientbrush) | Representa un `Brush` con degradado lineal definido por múltiples colores y posiciones apropiadas. |
| [PathGradientBrush](../com.aspose.imaging.brushes/pathgradientbrush) | Encapsula un objeto `Aspose.Imaging.Brush` con un degradado. |
| [PathGradientBrushBase](../com.aspose.imaging.brushes/pathgradientbrushbase) | Representa un `Brush` con funcionalidad de degradado de ruta base. |
| [PathMulticolorGradientBrush](../com.aspose.imaging.brushes/pathmulticolorgradientbrush) | Encapsula un objeto `Aspose.Imaging.Brush` con un degradado. |
| [SolidBrush](../com.aspose.imaging.brushes/solidbrush) | El pincel sólido está destinado a dibujar continuamente con un color específico. |
| [TextureBrush](../com.aspose.imaging.brushes/texturebrush) | Cada propiedad de la clase `Aspose.Imaging.Brushes.TextureBrush` es un objeto `Aspose.Imaging.Brush` que utiliza una imagen para rellenar el interior de una forma. |
| [TransformBrush](../com.aspose.imaging.brushes/transformbrush) | Un `Brush` con capacidades de transformación. |
