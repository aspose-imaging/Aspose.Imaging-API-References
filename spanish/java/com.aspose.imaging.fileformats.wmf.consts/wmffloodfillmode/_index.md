La enumeración FloodFill especifica el tipo de operación de relleno a realizar.
## Campos

| Campo | Descripción |
| --- | --- |
| [FloodFillBorder](#FloodFillBorder) | El área de relleno está delimitada por el color especificado por el miembro Color. |
| [FloodFillSurface](#FloodFillSurface) | El área de relleno está delimitada por el color que especifica el miembro Color. |
### FloodFillBorder {#FloodFillBorder}
```
public static final int FloodFillBorder
```


El área de relleno está delimitada por el color especificado por el miembro Color. Este estilo es idéntico al relleno realizado por el registro META\_FLOODFILL.

### FloodFillSurface {#FloodFillSurface}
```
public static final int FloodFillSurface
```


El área de relleno está delimitada por el color que especifica el miembro Color. El relleno continúa expandiéndose en todas las direcciones mientras se encuentre el color. Este estilo es útil para rellenar áreas con límites multicolores.
