La enumeración CharacterSet define los conjuntos posibles de glifos de caracteres que se definen en fuentes para la salida gráfica.
## Campos

| Campo | Descripción |
| --- | --- |
| [Ansi](#Ansi) | Especifica el conjunto de caracteres inglés. |
| [Default](#Default) | Especifica un conjunto de caracteres basado en la configuración regional del sistema; por ejemplo, cuando la configuración regional del sistema es Inglés de Estados Unidos, el conjunto de caracteres predeterminado es ANSI\_CHARSET. |
| [Symbol](#Symbol) | Especifica un conjunto de caracteres de símbolos. |
