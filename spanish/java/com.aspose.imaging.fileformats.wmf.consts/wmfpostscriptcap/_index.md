La enumeración PostScriptCap define los tipos de terminación de línea para su uso con un controlador de impresora PostScript.
## Campos

| Campo | Descripción |
| --- | --- |
| [PostScriptNotSet](#PostScriptNotSet) | Especifica que el estilo de terminación de línea no se ha establecido, y que se PUEDE usar un estilo predeterminado [24]. |
| [PostScriptFlatCap](#PostScriptFlatCap) | Especifica que la línea termina en el último punto. |
| [PostScriptRoundCap](#PostScriptRoundCap) | Especifica una tapa circular. |
| [PostScriptSquareCap](#PostScriptSquareCap) | Especifica una tapa cuadrada. |
### PostScriptNotSet {#PostScriptNotSet}
```
public static final int PostScriptNotSet
```


Especifica que el estilo de terminación de línea no se ha establecido, y que se PUEDE usar un estilo predeterminado [24].

### PostScriptFlatCap {#PostScriptFlatCap}
```
public static final int PostScriptFlatCap
```


Especifica que la línea termina en el último punto. El extremo está cuadrado.

### PostScriptRoundCap {#PostScriptRoundCap}
```
public static final int PostScriptRoundCap
```


Especifica una tapa circular. El centro del círculo es el último punto de la línea. El diámetro del círculo es el mismo que el ancho de la línea; es decir, el grosor de la línea.

### PostScriptSquareCap {#PostScriptSquareCap}
```
public static final int PostScriptSquareCap
```


Especifica una tapa cuadrada. El centro del cuadrado es el último punto de la línea. La altura y el ancho del cuadrado son los mismos que el ancho de la línea; es decir, el grosor de la línea.
