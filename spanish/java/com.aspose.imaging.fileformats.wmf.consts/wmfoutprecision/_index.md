La enumeración OutPrecision define valores para la precisión de salida, que es el requisito para que el asignador de fuentes coincida con parámetros de fuente específicos, incluidos altura, anchura, orientación de caracteres, escapamiento, paso y tipo de fuente.

| [String](#String) | Un valor que se devuelve cuando se enumeran fuentes rasterizadas. |
| [Stroke](#Stroke) | Un valor que se devuelve cuando se enumeran fuentes TrueType y otras fuentes de contorno, y fuentes vectoriales. |
| [Tt](#Tt) | Un valor que especifica la elección de una fuente TrueType cuando el sistema contiene varias fuentes con el mismo nombre. |

| [TtOnly](#TtOnly) | Un valor que especifica el requisito de solo fuentes TrueType. |
