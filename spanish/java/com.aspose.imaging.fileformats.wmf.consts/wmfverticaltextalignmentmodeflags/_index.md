Los indicadores VerticalTextAlignmentMode especifican la relación entre un punto de referencia y un rectángulo delimitador, para la alineación de texto. Estos indicadores pueden combinarse para especificar múltiples opciones, con la restricción de que solo se puede elegir un indicador que altere la posición de dibujo en el contexto del dispositivo de reproducción. La alineación vertical del texto se realiza cuando la fuente tiene una línea base vertical predeterminada, como en Kanji.
## Campos

| Campo | Descripción |
| --- | --- |
| [VTA_TOP](#VTA-TOP) | El punto de referencia DEBE estar en el borde superior del rectángulo delimitador. |
| [VTA_RIGHT](#VTA-RIGHT) | El punto de referencia DEBE estar en el borde derecho del rectángulo delimitador. |
| [VTA_BOTTOM](#VTA-BOTTOM) | El punto de referencia DEBE estar en el borde inferior del rectángulo delimitador. |
| [VTA_CENTER](#VTA-CENTER) | El punto de referencia DEBE estar alineado verticalmente con el centro del rectángulo delimitador. |
| [VTA_LEFT](#VTA-LEFT) | El punto de referencia DEBE estar en el borde izquierdo del rectángulo delimitador. |
| [VTA_BASELINE](#VTA-BASELINE) | El punto de referencia DEBE estar en la línea base del texto. |
