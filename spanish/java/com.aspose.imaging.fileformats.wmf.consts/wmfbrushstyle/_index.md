La enumeración BrushStyle especifica los diferentes tipos posibles de pincel que pueden usarse en operaciones gráficas. Para más información, consulte la especificación del objeto Brush (sección 2.2.1.1).
## Campos

| Campo | Descripción |
| --- | --- |
| [Solid](#Solid) | Un pincel que pinta un solo color constante, ya sea sólido o tramado. |
| [Null](#Null) | Un pincel que no hace nada. |
| [Hatched](#Hatched) | Un pincel que pinta un patrón simple predefinido, o "hatch", sobre un fondo sólido |
| [Pattern](#Pattern) | Un pincel que pinta un patrón definido por un mapa de bits, que PUEDE ser un objeto Bitmap16 o un objeto DeviceIndependentBitmap (DIB). |
| [Indexed](#Indexed) | No soportado. |
| [Dibpattern](#Dibpattern) | Un pincel de patrón especificado por un DIB. |
| [Dibpatternpt](#Dibpatternpt) | Un pincel de patrón especificado por un DIB. |
| [Pattern8X8](#Pattern8X8) | No soportado. |
| [Dibpattern8X8](#Dibpattern8X8) | No soportado. |
| [Monopattern](#Monopattern) | No soportado. |
| [Gradient](#Gradient) | El gradiente no es compatible en wmf, es compatible en odg. |
