La enumeración PenStyle de 16 bits se usa para especificar diferentes tipos de lápices que pueden utilizarse en operaciones gráficas.
## Campos

| Campo | Descripción |
| --- | --- |
| [Cosmetic](#Cosmetic) | El cosmético |
| [EndcapRound](#EndcapRound) | Los extremos de línea son redondos. |
| [JoinRound](#JoinRound) | Las uniones de línea son redondas. |
| [Solid](#Solid) | El lápiz es sólido. |
| [Dash](#Dash) | El lápiz es discontinuo. |
| [Dot](#Dot) | El lápiz es punteado. |
| [Dashdot](#Dashdot) | El lápiz tiene guiones y puntos alternados. |
| [Dashdotdot](#Dashdotdot) | El lápiz tiene guiones y puntos dobles. |
| [Null](#Null) | El lápiz es invisible. |
| [Insideframe](#Insideframe) | El lápiz es sólido. |
| [Userstyle](#Userstyle) | El lápiz utiliza una matriz de estilo proporcionada por el usuario. |
| [Alternate](#Alternate) | El lápiz establece cada otro píxel (este estilo solo es aplicable a lápices cosméticos). |
| [EndcapSquare](#EndcapSquare) | Los extremos de línea son cuadrados. |
| [EndcapFlat](#EndcapFlat) | Los extremos de línea son planos. |
| [JoinBevel](#JoinBevel) | Las uniones de línea son biseladas. |
| [JoinMiter](#JoinMiter) | Las uniones de línea son en ángulo cuando están dentro del límite actual establecido por el registro SETMITERLIMIT META\_ESCAPE. |
