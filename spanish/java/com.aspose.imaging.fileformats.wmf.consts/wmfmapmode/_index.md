### Text {#Text}
```
public static final short Text
```


El texto Cada unidad lógica se asigna a un píxel del dispositivo. El eje x positivo está a la derecha; el eje y positivo está hacia abajo.

### Hienglish {#Hienglish}

public static final short Hienglish

### Twips {#Twips}
```
public static final short Twips
```


El twips Cada unidad lógica se asigna a una vigésima (1/20) de un punto. En impresión, un punto es 1/72 de pulgada; por lo tanto, 1/20 de punto es 1/1440 de pulgada. Esta unidad también se conoce como "twip".

### Isotropic {#Isotropic}
```
public static final short Isotropic
```


El isotropic Las unidades lógicas se asignan a unidades de dispositivo arbitrarias con ejes escalados igualmente; es decir, una unidad a lo largo del eje x es igual a una unidad a lo largo del eje y. Los registros META\_SETWINDOWEXT y META\_SETVIEWPORTEXT especifican las unidades y la orientación de los ejes.

public static final short Anisotropic

El anisotrópico Las unidades lógicas se asignan a unidades arbitrarias con ejes escalados arbitrariamente.
