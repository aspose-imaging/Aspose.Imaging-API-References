La enumeración MixMode especifica el modo de mezcla de fondo para texto, pinceles tramados y otros estilos de lápiz no sólido.
## Campos

| Campo | Descripción |
| --- | --- |
| [Transparent](#Transparent) | El fondo permanece sin cambios. |
| [Opaque](#Opaque) | El fondo se rellena con el color de fondo que está actualmente definido en el contexto del dispositivo de reproducción antes de que se dibuje el texto, el pincel tramado o el lápiz. |
### Transparent {#Transparent}
```
public static final short Transparent
```


El fondo permanece sin cambios.

### Opaque {#Opaque}
```
public static final short Opaque
```


El fondo se rellena con el color de fondo que está actualmente definido en el contexto del dispositivo de reproducción antes de que se dibuje el texto, el pincel tramado o el lápiz.
