La enumeración PostScriptClipping define funciones que pueden aplicarse a la ruta de recorte utilizada para la salida PostScript.
## Campos

| Campo | Descripción |
| --- | --- |
| [CLIP_SAVE](#CLIP-SAVE) | Guarda la ruta de recorte PostScript actual. |
| [CLIP_RESTORE](#CLIP-RESTORE) | Restaura la ruta de recorte PostScript a la última ruta de recorte que fue guardada por una función CLIP\_SAVE previa aplicada por un registro CLIP\_TO\_PATH (sección 2.3.6.6). |
| [CLIP_INCLUSIVE](#CLIP-INCLUSIVE) | Interseca la ruta de recorte PostScript actual con la ruta de recorte actual y guarda el resultado como la nueva ruta de recorte PostScript. |
