public final class EmfStrokeAndFillPath extends EmfDrawingRecordType

El registro EMR\_STROKEANDFILLPATH cierra cualquier figura abierta en una ruta, traza el contorno de la ruta usando la pluma actual y rellena su interior usando el pincel actual.
