El registro EMR\_POLYPOLYGON especifica una serie de polígonos cerrados.

Cada polígono DEBERÍA estar delineado usando la pluma actual y rellenado usando el pincel actual y el modo de relleno de polígonos que están definidos en el contexto del dispositivo de reproducción. Los polígonos definidos por este registro pueden superponerse.
