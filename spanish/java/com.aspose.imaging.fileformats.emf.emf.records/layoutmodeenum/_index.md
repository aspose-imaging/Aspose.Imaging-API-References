Un entero sin signo de 32 bits que especifica el modo de disposición.
## Campos

| Campo | Descripción |
| --- | --- |
| [LAYOUT_LTR](#LAYOUT-LTR) | Establece el diseño horizontal predeterminado de izquierda a derecha. |
| [LAYOUT_RTL](#LAYOUT-RTL) | Establece el diseño horizontal predeterminado de derecha a izquierda. |
| [LAYOUT_BITMAPORIENTATIONPRESERVED](#LAYOUT-BITMAPORIENTATIONPRESERVED) | Desactiva la reflexión de los mapas de bits que son dibujados por los tipos de registro de mapa de bits (sección 2.3.1), cuando el modo de diseño es de derecha a izquierda. |
### LAYOUT_LTR {#LAYOUT-LTR}
```
public static final int LAYOUT_LTR
```


Establece el diseño horizontal predeterminado de izquierda a derecha. Este es el modo predeterminado para los locales de inglés y europeos.

### LAYOUT_RTL {#LAYOUT-RTL}
```
public static final int LAYOUT_RTL
```


Establece el diseño horizontal predeterminado de derecha a izquierda. Este modo es necesario para algunos idiomas, incluidos el árabe y el hebreo.

### LAYOUT_BITMAPORIENTATIONPRESERVED {#LAYOUT-BITMAPORIENTATIONPRESERVED}
```
public static final int LAYOUT_BITMAPORIENTATIONPRESERVED
```


Desactiva la reflexión de los mapas de bits que son dibujados por los tipos de registro de mapa de bits (sección 2.3.1), cuando el modo de diseño es de derecha a izquierda.
