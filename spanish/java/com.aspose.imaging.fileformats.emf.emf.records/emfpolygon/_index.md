El registro EMR\_POLYGON especifica un polígono compuesto por dos o más vértices conectados por líneas rectas.

El polígono DEBE delinearse usando la pluma actual y rellenarse usando el pincel actual y el modo de relleno de polígonos. El polígono DEBE cerrarse automáticamente dibujando una línea desde el último vértice hasta el primero.
