public final class EmfSetMapMode extends EmfRecord

El registro EMR\_SETMAPMODE especifica el modo de mapeo del contexto del dispositivo de reproducción. El modo de mapeo especifica la unidad de medida utilizada para transformar las unidades del espacio de página en unidades del espacio del dispositivo, y también especifica la orientación del eje x y del eje y del dispositivo.
