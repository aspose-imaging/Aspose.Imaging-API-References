public final class EmfPolylineTo16 extends EmfPolyShape

El registro EMR\_POLYLINETO16 especifica una o más líneas rectas basadas en la posición actual. Una línea se dibuja desde la posición actual hasta el primer punto especificado por el campo aPoints usando la pluma actual. Para cada línea adicional, el dibujo se realiza desde el punto final de la línea anterior hasta el siguiente punto especificado por aPoints.
