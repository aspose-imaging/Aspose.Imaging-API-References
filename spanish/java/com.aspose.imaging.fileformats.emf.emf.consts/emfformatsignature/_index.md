La enumeración FormatSignature define valores que se utilizan para identificar el formato de los datos incrustados en los registros EMF.
## Campos

| Campo | Descripción |
| --- | --- |
| [ENHMETA_SIGNATURE](#ENHMETA-SIGNATURE) | El valor de este miembro es la secuencia de caracteres ASCII "FME ", que resulta ser la inversa de la cadena "EMF", y denota datos de registro EMF. |
| [EPS_SIGNATURE](#EPS-SIGNATURE) | El valor de este miembro es la secuencia de caracteres ASCII "FSPE", que resulta ser la inversa de la cadena "EPSF", y denota datos en formato PostScript encapsulado (EPS). |
### ENHMETA_SIGNATURE {#ENHMETA-SIGNATURE}
```
public static final int ENHMETA_SIGNATURE
```


El valor de este miembro es la secuencia de caracteres ASCII "FME ", que resulta ser la inversa de la cadena "EMF", y denota datos de registro EMF. Nota: el carácter de espacio en la cadena es significativo y DEBE estar presente.

### EPS_SIGNATURE {#EPS-SIGNATURE}
```
public static final int EPS_SIGNATURE
```


El valor de este miembro es la secuencia de caracteres ASCII "FSPE", que resulta ser la inversa de la cadena "EPSF", y denota datos en formato PostScript encapsulado (EPS).
