La enumeración PolygonFillMode define valores que especifican cómo calcular la región de un polígono que se debe rellenar.
## Campos

| Campo | Descripción |
| --- | --- |
| [ALTERNATE](#ALTERNATE) | Selecciona el modo alternativo (rellena el área entre los lados impares y pares del polígono en cada línea de escaneo). |
| [WINDING](#WINDING) | Selecciona el modo de contorno (rellena cualquier región con un valor de contorno distinto de cero). |
