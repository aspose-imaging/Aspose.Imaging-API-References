La enumeración HatchStyle es una extensión de la enumeración WMF HatchStyle ([MS-WMF] sección 2.1.1.12).
## Campos

| Campo | Descripción |
| --- | --- |
| [HS_HORIZONTAL](#HS-HORIZONTAL) | Un tramado horizontal. |
| [HS_VERTICAL](#HS-VERTICAL) | Un tramado vertical. |
| [HS_FDIAGONAL](#HS-FDIAGONAL) | Un tramado de 45 grados descendente, de izquierda a derecha. |
| [HS_BDIAGONAL](#HS-BDIAGONAL) | Un tramado de 45 grados ascendente, de izquierda a derecha. |
| [HS_CROSS](#HS-CROSS) | Un tramado cruzado horizontal y vertical. |
| [HS_DIAGCROSS](#HS-DIAGCROSS) | Un tramado cruzado de 45 grados. |
| [HS_SOLIDCLR](#HS-SOLIDCLR) | El tramado no es un patrón, sino un color sólido. |
| [HS_DITHEREDCLR](#HS-DITHEREDCLR) | El tramado no es un patrón, sino un color sólido. |
| [HS_SOLIDTEXTCLR](#HS-SOLIDTEXTCLR) | El tramado no es un patrón, sino un color sólido, definido por el color de texto actual (primer plano). |
| [HS_DITHEREDTEXTCLR](#HS-DITHEREDTEXTCLR) | El tramado no es un patrón, sino un color difuminado, definido por el color de texto actual (primer plano). |
| [HS_SOLIDBKCLR](#HS-SOLIDBKCLR) | El tramado no es un patrón, sino un color sólido, definido por el color de fondo actual. |
| [HS_DITHEREDBKCLR](#HS-DITHEREDBKCLR) | El tramado no es un patrón, sino un color difuminado, definido por el color de fondo actual. |
