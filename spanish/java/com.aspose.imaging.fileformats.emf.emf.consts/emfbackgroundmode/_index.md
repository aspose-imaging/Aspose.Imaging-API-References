La enumeración BackgroundMode se usa para especificar el modo de fondo que se utilizará con texto, pinceles tramados y estilos de lápiz que no son sólidos. El modo de fondo determina cómo combinar el fondo con el texto en primer plano, los pinceles tramados y los estilos de lápiz que no son líneas sólidas.
## Campos

| Campo | Descripción |
| --- | --- |
| [TRANSPARENT](#TRANSPARENT) | El transparente - El fondo permanece sin cambios. |
| [OPAQUE](#OPAQUE) | El opaco - El fondo se llena con el color de fondo actual antes de que se dibuje el texto, el pincel de trama o el lápiz. |
