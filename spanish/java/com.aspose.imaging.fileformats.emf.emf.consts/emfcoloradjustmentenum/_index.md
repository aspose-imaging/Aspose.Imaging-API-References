La enumeración ColorAdjustment se usa para especificar cómo debe prepararse la imagen de salida cuando el modo de estiramiento es HALFTONE.
## Campos

| --- | --- |

```

```


El Especifica que se DEBE aplicar un proceso logarítmico a la densidad final de los colores de salida. Esto aumentará el contraste de color cuando la luminancia sea baja
