DriverStringOptions bayrakları, grafik metin konumlandırma ve oluşturma özelliklerini belirtir. Bu bayraklar birden fazla seçeneği belirtmek için birleştirilebilir.

--------------------

Grafik metin çıktısı, [EmfPlusDrawDriverString](../../com.aspose.imaging.fileformats.emf.emfplus.records/emfplusdrawdriverstring) kayıtlarında belirtilir.

### DriverStringOptionsCmapLookup {#DriverStringOptionsCmapLookup}
```
public static final int DriverStringOptionsCmapLookup
```


Ayarlanmışsa, karakter gliflerinin konumları bir karakter haritası arama tablosunda belirtilmelidir. Temizlenmişse, glif konumları bir koordinat dizisinden elde edilmelidir.

### DriverStringOptionsVertical {#DriverStringOptionsVertical}
```
public static final int DriverStringOptionsVertical
```


Ayarlanmışsa, dize dikey olarak oluşturulmalıdır. Temizlenmişse, dize yatay olarak oluşturulmalıdır.

### DriverStringOptionsRealizedAdvance {#DriverStringOptionsRealizedAdvance}
```
public static final int DriverStringOptionsRealizedAdvance
```


Ayarlanmışsa, karakter glif konumları ilk glifin konumuna göre hesaplanmalıdır. Temizlenmişse, glif konumları bir koordinat dizisinden elde edilmelidir.

### DriverStringOptionsLimitSubpixel {#DriverStringOptionsLimitSubpixel}
```
public static final int DriverStringOptionsLimitSubpixel
```


Ayarlanmışsa, anti-alias gliflerini önbelleğe almak için daha az bellek kullanılmalı, bu da daha düşük kalite metin oluşturmasına yol açar. Temizlenmişse, daha fazla bellek kullanılmalı, bu da daha yüksek kalite metin oluşturur.
