FontStyle bayrakları, grafik yazı tipi stillerini belirtir. Bu bayraklar birden fazla seçeneği belirtmek için birleştirilebilir.

--------------------

Grafik yazı tipleri, [EmfPlusFont](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfplusfont) nesneleri tarafından belirtilir.

### FontStyleBold {#FontStyleBold}
```
public static final int FontStyleBold
```


Ayarlanmışsa, yazı tipi daha ağır bir ağırlık veya kalınlıkla işlenmelidir. Temizlenmişse, yazı tipi normal kalınlıkta işlenmelidir.

### FontStyleItalic {#FontStyleItalic}
```
public static final int FontStyleItalic
```


Ayarlanmışsa, karakterlerin dikey sapları, temel çizgiye göre artırılmış bir açıyla işlenmelidir. Temizlenmişse, karakterlerin dikey sapları normal bir açıyla işlenmelidir.

### FontStyleUnderline {#FontStyleUnderline}
```
public static final int FontStyleUnderline
```


Ayarlanmışsa, karakterlerin temel çizgisinin altında bir çizgiyle işlenmelidir. Temizlenmişse, karakterlerin temel çizgisinin altında bir çizgi olmadan işlenmelidir.

### FontStyleStrikeout {#FontStyleStrikeout}
```
public static final int FontStyleStrikeout
```


Ayarlanmışsa, yazı tipi MUTLAKA karakterlerin ortasından geçen, temel çizgiye paralel bir çizgiyle render edilmelidir. Temizlenmişse, yazı tipi MUTLAKA karakterler üzerinden bir çizgi olmadan render edilmelidir.
