PitchFont enumarasyonu, bir yazı tipinin özelliklerini belirtmek için kullanılan değerleri tanımlar. Değerler, bir yazı tipindeki karakterlerin sabit mi yoksa değişken genişlikli mi olduğunu veya pitch (aralık) olduğunu göstermek için kullanılır.
## Alanlar

| Alan | Açıklama |
| --- | --- |
| [DEFAULT_PITCH](#DEFAULT-PITCH) | Varsayılan pitch, uygulamaya bağlıdır. |
| [FIXED_PITCH](#FIXED-PITCH) | Sabit pitch, yazı tipindeki tüm karakterlerin bir dize içinde çıktığında aynı genişliği kapladığı anlamına gelir. |
| [VARIABLE_PITCH](#VARIABLE-PITCH) | Değişken pitch, yazı tipindeki karakterlerin bir dize içinde çıktığında gliflerin gerçek genişliklerine orantılı genişlikler kapladığı anlamına gelir. |
### DEFAULT_PITCH {#DEFAULT-PITCH}
```
public static final byte DEFAULT_PITCH
```


Varsayılan pitch, uygulamaya bağlıdır.

### FIXED_PITCH {#FIXED-PITCH}
```
public static final byte FIXED_PITCH
```


Sabit pitch, yazı tipindeki tüm karakterlerin bir dize içinde çıktığında aynı genişliği kapladığı anlamına gelir.

### VARIABLE_PITCH {#VARIABLE-PITCH}
```
public static final byte VARIABLE_PITCH
```


Değişken pitch, yazı tipindeki karakterlerin bir dize içinde çıktığında gliflerin gerçek genişliklerine orantılı genişlikler kapladığı anlamına gelir. Örneğin, "i" ve boşluk karakterleri genellikle bir "W" veya "O" karakterinden çok daha küçük genişliklere sahiptir.
