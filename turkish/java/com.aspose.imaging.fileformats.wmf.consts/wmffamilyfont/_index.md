FamilyFont sayımı, yazı tipi ailesini belirtir. Yazı tipi aileleri, bir yazı tipinin görünümünü genel bir şekilde tanımlar. İstenen kesin yazı tipi mevcut olmadığında yazı tiplerini belirtmek için tasarlanmıştır.

### Roman {#Roman}



Değişken çizgi kalınlıklarına sahip yazı tipleri, gliflerin gerçek genişliklerine orantılıdır ve seriflidir. "MS Serif" bir örnektir.

### Swiss {#Swiss}
```
public static final byte Swiss
```


Değişken çizgi kalınlıklarına sahip yazı tipleri, gliflerin gerçek genişliklerine orantılıdır ve serif içermez. "MS Sans Serif" bir örnektir.

### Modern {#Modern}
```
public static final byte Modern
```


Sabit çizgi kalınlığına sahip yazı tipleri, serifli veya serifsiz olabilir. Sabit genişlikli yazı tipleri genellikle moderndir. "Pica", "Elite" ve "Courier New" örneklerdir.

El yazısı gibi görünmek üzere tasarlanmış yazı tipleri. "Script" ve "Cursive" örneklerdir.
