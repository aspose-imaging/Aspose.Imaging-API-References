DriverStringOptions bayrakları, grafik metin konumlandırma ve renderleme özelliklerini belirtir. Bu bayraklar birden fazla seçeneği belirtmek için birleştirilebilir.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusDriverStringOptionsFlags

## **Members**
| **Üye adı** | **Açıklama** |
| :- | :- |
| DRIVER_STRING_OPTIONS_CMAP_LOOKUP | Ayarlanırsa, karakter gliflerinin konumları bir karakter haritası arama tablosunda belirtilmelidir.<br/>            Ayarlanmamışsa, glif konumları bir koordinat dizisinden elde edilmelidir. |
| DRIVER_STRING_OPTIONS_LIMIT_SUBPIXEL | Ayarlanırsa, anti-alias gliflerini önbelleğe almak için daha az bellek kullanılmalıdır, bu daha düşük kalite metin render'ı üretir.<br/>            Ayarlanmamışsa, daha fazla bellek kullanılmalıdır, bu daha yüksek kalite metin render'ı üretir. |
| DRIVER_STRING_OPTIONS_REALIZED_ADVANCE | Ayarlanmışsa, karakter glif konumları SHOULD ilk glifin konumuna göre hesaplanmalıdır.<br/>            Temizlenmişse, glif konumları SHOULD bir koordinat dizisinden elde edilmelidir. |
| DRIVER_STRING_OPTIONS_VERTICAL | Ayarlanmışsa, dize SHOULD dikey olarak render edilmelidir.<br/>            Temizlenmişse, dize SHOULD yatay olarak render edilmelidir. |
