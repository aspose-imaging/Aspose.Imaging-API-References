Перечисление BitCount указывает количество бит, определяющих каждый пиксель, и максимальное количество цветов в device-independent bitmap (DIB).
## Поля

| Поле | Описание |
| --- | --- |
| [BIT_COUNT_0](#BIT-COUNT-0) | Количество бит на пиксель не определено. |
| [BIT_COUNT_1](#BIT-COUNT-1) | Изображение указано с двумя цветами.Каждый пиксель в растровом изображении представлен одним битом. |
| [BIT_COUNT_2](#BIT-COUNT-2) | Изображение указано с максимумом в 16 цветов. |
| [BIT_COUNT_3](#BIT-COUNT-3) | Изображение указано с максимумом в 256 цветов. |
| [BIT_COUNT_4](#BIT-COUNT-4) | Изображение указано с максимумом в 2^16 цветов. |
| [BIT_COUNT_5](#BIT-COUNT-5) | Растровое изображение имеет максимум в 2^24 цветов, а поле Colors в DIB равно NULL. |
| [BIT_COUNT_6](#BIT-COUNT-6) | Битовая карта имеет максимум 2^24 цветов |
### BIT_COUNT_0 {#BIT-COUNT-0}
```
public static final short BIT_COUNT_0
```


Количество бит на пиксель не определено. Изображение ДОЛЖНО быть в формате JPEG или PNG. Ни один из этих форматов не содержит таблицу цветов, поэтому это значение указывает, что таблица цветов отсутствует. См. [JFIF] и [RFC2083] для получения дополнительной информации о форматах сжатия JPEG и PNG.

### BIT_COUNT_1 {#BIT-COUNT-1}
```
public static final short BIT_COUNT_1
```


Изображение задано двумя цветами. Каждый пиксель в битовой карте представлен одним битом. Если бит сброшен, пиксель отображается цветом первой записи в таблице цветов; если бит установлен, пиксель имеет цвет второй записи в таблице.

### BIT_COUNT_2 {#BIT-COUNT-2}
```
public static final short BIT_COUNT_2
```


Изображение задано максимум 16 цветами. Каждый пиксель в битовой карте представлен 4‑битовым индексом в таблице цветов, и каждый байт содержит 2 пикселя.

### BIT_COUNT_3 {#BIT-COUNT-3}
```
public static final short BIT_COUNT_3
```


Изображение задано максимум 256 цветами. Каждый пиксель в битовой карте представлен 8‑битовым индексом в таблице цветов, и каждый байт содержит 1 пиксель.

### BIT_COUNT_4 {#BIT-COUNT-4}
```
public static final short BIT_COUNT_4
```


Изображение задано максимум 2^16 цветами. Каждый пиксель в битовой карте представлен 16‑битовым значением.

### BIT_COUNT_5 {#BIT-COUNT-5}
```
public static final short BIT_COUNT_5
```


Битовая карта имеет максимум 2^24 цветов, и поле Colors в DIB равно NULL. Каждая 3‑байтовая тройка в массиве битовой карты представляет относительные интенсивности синего, зелёного и красного цветов соответственно для пикселя. Таблица цветов Colors используется для оптимизации цветов на устройствах с палитрой, и ДОЛЖНА содержать количество записей, указанное в поле ColorUsed объекта BitmapInfoHeader.

### BIT_COUNT_6 {#BIT-COUNT-6}
```
public static final short BIT_COUNT_6
```


Битовая карта имеет максимум 2^24 цветов
