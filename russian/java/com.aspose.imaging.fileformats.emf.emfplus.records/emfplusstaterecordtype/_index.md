Типы записей состояния определяют операции над состоянием контекста устройства воспроизведения.

Каждый контейнер состояния графики ДОЛЖЕН быть добавлен в массив сохранённых контейнеров графики. Контейнер состояния графики не записывается в метафайл EMF+, поэтому его формат может быть определён реализацией.
