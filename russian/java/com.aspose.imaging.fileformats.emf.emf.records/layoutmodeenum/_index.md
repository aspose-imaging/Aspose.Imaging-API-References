32‑разрядное беззнаковое целое, указывающее режим компоновки
## Поля

| Поле | Описание |
| --- | --- |
| [LAYOUT_LTR](#LAYOUT-LTR) | Устанавливает горизонтальное расположение по умолчанию слева направо. |
| [LAYOUT_RTL](#LAYOUT-RTL) | Устанавливает горизонтальное расположение по умолчанию справа налево. |
| [LAYOUT_BITMAPORIENTATIONPRESERVED](#LAYOUT-BITMAPORIENTATIONPRESERVED) | Отключает зеркальное отображение битмапов, рисуемых типами записей Bitmap (раздел 2.3.1), когда режим расположения справа налево. |
### LAYOUT_LTR {#LAYOUT-LTR}
```
public static final int LAYOUT_LTR
```


Устанавливает горизонтальное расположение по умолчанию слева направо. Это режим по умолчанию для английского и европейских локалей.

### LAYOUT_RTL {#LAYOUT-RTL}
```
public static final int LAYOUT_RTL
```


Устанавливает горизонтальное расположение по умолчанию справа налево. Этот режим требуется для некоторых языков, включая арабский и иврит.

### LAYOUT_BITMAPORIENTATIONPRESERVED {#LAYOUT-BITMAPORIENTATIONPRESERVED}
```
public static final int LAYOUT_BITMAPORIENTATIONPRESERVED
```


Отключает зеркальное отображение битмапов, рисуемых типами записей Bitmap (раздел 2.3.1), когда режим расположения справа налево.
