### getCyanRed() {#getCyanRed--}
```
public int getCyanRed()
```


Получает или задает 32‑битное знаковое целое, которое указывает изменение количества красного в изображении. Это значение ДОЛЖНО находиться в диапазоне от -100 до 100, при этом эффекты следующие: -100 \u2264 value < 0 По мере уменьшения значения количество красного в изображении ДОЛЖНО уменьшаться, а количество циана ДОЛЖНО увеличиваться. 0 Значение 0 указывает, что количества красного и циана НЕ ДОЛЖНЫ изменяться. 0 < value \u2264 100 По мере увеличения значения количество красного в изображении ДОЛЖНО увеличиваться, а количество циана ДОЛЖНО уменьшаться.

**Returns:**
int
