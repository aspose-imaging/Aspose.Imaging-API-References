Получает или задает параметр, определяющий, насколько осветлять светлые участки изображения. Значения цветовых каналов в верхней части диапазона интенсивности изменяются сильнее, чем значения ближе к середине или нижнему концу, что позволяет осветлять изображение без потери контраста между более тёмными областями. 0 \\u2264 value < Указывает, что светлые участки с процентом интенсивности выше этого порога ДОЛЖНЫ быть увеличены на 100. 100 Указывает, что светлые участки НЕ ДОЛЖНЫ изменяться.

Значение: Светлые участки.

int
