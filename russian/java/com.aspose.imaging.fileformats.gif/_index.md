Пакет обрабатывает формат файлов Gif.


## Классы

| Класс | Описание |
| --- | --- |
| [DisposalMethod](../com.aspose.imaging.fileformats.gif/disposalmethod) | Указывает, как графика должна обрабатываться после отображения. |
| [GifBlock](../com.aspose.imaging.fileformats.gif/gifblock) | Реализация блока gif по умолчанию. |
| [GifBlocksRegistry](../com.aspose.imaging.fileformats.gif/gifblocksregistry) | Представляет реестр открывающих блоков gif. |
| [GifImage](../com.aspose.imaging.fileformats.gif/gifimage) | API для файлов изображений Graphical Interchange Format (GIF) предоставляет разработчикам универсальные инструменты для обработки сжатых растровых изображений и анимированных GIF. |
