Обладая возможностью выполнять растеризацию изображений CDR и задавать коэффициенты масштабирования для измерений X и Y, этот API предоставляет точный контроль над процессом преобразования. Будь то масштабирование для конкретных требований к выводу или преобразование векторной графики в растровые форматы, вы можете использовать этот API для эффективного и настраиваемого преобразования векторных изображений CDR в растровые.
