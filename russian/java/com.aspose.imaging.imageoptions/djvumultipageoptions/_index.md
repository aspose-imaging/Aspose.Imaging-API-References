API формата графических файлов DjVu предоставляет разработчикам бесшовный доступ к документам DjVu, идеальным для сканированных документов и книг. С параметрами загрузки изображений разработчики могут без усилий интегрировать файлы DjVu в свои приложения, раскрывая возможности работы с многостраничным контентом, включая текст, рисунки и изображения, для универсальных решений обработки документов.
