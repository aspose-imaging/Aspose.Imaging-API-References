Перечисление StringAlignment определяет способы выравнивания строк относительно прямоугольника размещения текста.
## Поля

| Поле | Описание |
| --- | --- |
| [StringAlignmentNear](#StringAlignmentNear) | Указывает, что выравнивание строки направлено к началу прямоугольника макета. |
| [StringAlignmentCenter](#StringAlignmentCenter) | Указывает, что выравнивание центрировано между началом и границами прямоугольника макета. |
| [StringAlignmentFar](#StringAlignmentFar) | Указывает, что выравнивание находится справа от прямоугольника макета. |
### StringAlignmentNear {#StringAlignmentNear}
```
public static final int StringAlignmentNear
```


Указывает, что выравнивание строки направлено к началу прямоугольника макета. Это можно использовать для выравнивания символов вдоль линии или для выравнивания текста внутри прямоугольника. Для прямоугольника макета справа налево начало ДОЛЖНО находиться в правом верхнем углу.

### StringAlignmentCenter {#StringAlignmentCenter}
```
public static final int StringAlignmentCenter
```


Указывает, что выравнивание центрировано между началом и границами прямоугольника макета.

### StringAlignmentFar {#StringAlignmentFar}
```
public static final int StringAlignmentFar
```


Указывает, что выравнивание находится справа от прямоугольника макета.
