Перечисление CombineMode определяет режимы объединения двух графических областей. В последующих описаниях области, которые объединяются, называют «существующей» и «новой» областями.
## Поля

| Поле | Описание |
| --- | --- |
| [CombineModeReplace](#CombineModeReplace) | Заменяет существующую область новой областью. |
| [CombineModeIntersect](#CombineModeIntersect) | Заменяет существующую область пересечением существующей и новой областей. |
| [CombineModeUnion](#CombineModeUnion) | Заменяет существующую область объединением существующей и новой областей. |
| [CombineModeXor](#CombineModeXor) | Заменяет существующую область операцией XOR над существующей и новой областями. |
| [CombineModeExclude](#CombineModeExclude) | Заменяет существующую область частью самой области, которая не находится в новой области. |
| [CombineModeComplement](#CombineModeComplement) | Заменяет существующую область частью новой области, которая не находится в существующей области. |
