Перечисление PenAlignment определяет распределение ширины пера относительно рисуемой линии.

--------------------

Графические перья задаются объектами [EmfPlusPen](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspen) (раздел 2.2.1.7). Выравнивание пера можно визуализировать, рассматривая теоретическую одномерную линию, проведённую между двумя заданными точками. Выравнивание пера определяет долю ширины пера, перпендикулярную теоретической линии.
## Поля

| Поле | Описание |
| --- | --- |
| [PenAlignmentCenter](#PenAlignmentCenter) | Указывает, что объект EmfPlusPen центрирован над теоретической линией. |
| [PenAlignmentInset](#PenAlignmentInset) | Указывает, что перо расположено внутри теоретической линии. |
| [PenAlignmentLeft](#PenAlignmentLeft) | Указывает, что перо расположено слева от теоретической линии. |
| [PenAlignmentOutset](#PenAlignmentOutset) | Указывает, что перо расположено снаружи теоретической линии. |
| [PenAlignmentRight](#PenAlignmentRight) | Указывает, что перо расположено справа от теоретической линии. |
