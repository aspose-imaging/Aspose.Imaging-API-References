Перечисление StringTrimming определяет, как обрезать символы в строке, которая слишком велика для прямоугольника размещения текста.
## Поля

| Поле | Описание |
| --- | --- |
| [StringTrimmingNone](#StringTrimmingNone) | Указывает, что обрезка не выполняется. |
| [StringTrimmingCharacter](#StringTrimmingCharacter) | Указывает, что строка разрывается на границе последнего символа, находящегося внутри прямоугольника размещения. |
| [StringTrimmingWord](#StringTrimmingWord) | Указывает, что строка разрывается на границе последнего слова, находящегося внутри прямоугольника размещения. |
| [StringTrimmingEllipsisCharacter](#StringTrimmingEllipsisCharacter) | Указывает, что строка разрывается на границе последнего символа, находящегося внутри прямоугольника размещения, и после символа вставляется многоточие (...). |
| [StringTrimmingEllipsisWord](#StringTrimmingEllipsisWord) | Указывает, что строка разрывается на границе последнего слова, находящегося внутри прямоугольника размещения, и после слова вставляется многоточие (...). |
| [StringTrimmingEllipsisPath](#StringTrimmingEllipsisPath) | Указывает, что центр удаляется из строки и заменяется многоточием. |
