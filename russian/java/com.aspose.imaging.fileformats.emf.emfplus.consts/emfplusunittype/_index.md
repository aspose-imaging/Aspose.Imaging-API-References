Перечисление UnitType определяет единицы измерения в разных системах координат.
## Поля

| Поле | Описание |
| --- | --- |
| [UnitTypeWorld](#UnitTypeWorld) | Указывает единицу логического расстояния в мировом пространстве. |
| [UnitTypeDisplay](#UnitTypeDisplay) | Указывает единицу расстояния, основанную на характеристиках физического дисплея. |
| [UnitTypePixel](#UnitTypePixel) | Указывает единицу, равную 1 пикселю. |
| [UnitTypePoint](#UnitTypePoint) | Указывает единицу, равную 1 точке принтера или 1/72 дюйма. |
| [UnitTypeInch](#UnitTypeInch) | Указывает единицу, равную 1 дюйму. |
| [UnitTypeDocument](#UnitTypeDocument) | Указывает единицу, равную 1/300 дюйма. |
| [UnitTypeMillimeter](#UnitTypeMillimeter) | Указывает единицу, равную 1 миллиметру. |
