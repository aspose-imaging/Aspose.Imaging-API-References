### AdjustMidtone {#AdjustMidtone}
```
public static final int AdjustMidtone
```


Указывает настройку, которая осветляет или затемняет изображение. Значения цветовых каналов в середине диапазона интенсивности изменяются сильнее, чем значения, близкие к минимальным или максимальным экстремумам интенсивности. Эта настройка может использоваться для осветления или затемнения изображения без потери контраста между самыми темными и самыми светлыми частями изображения.

### AdjustWhiteSaturation {#AdjustWhiteSaturation}
```
public static final int AdjustWhiteSaturation
```


Указывает настройку белой насыщенности изображения, определяемую как максимальное значение в диапазоне интенсивностей для данного цветового канала, диапазон которого обычно составляет от 0 до 255.

--------------------

Например, значение настройки белой насыщенности 240 указывает, что значения цветовых каналов в диапазоне от 0 до 240 корректируются так, чтобы они распределились по диапазону от 0 до 255, при этом значения выше 240 устанавливаются в 255.

### AdjustBlackSaturation {#AdjustBlackSaturation}
```
public static final int AdjustBlackSaturation
```


Указывает настройку черной насыщенности изображения, которая является минимальным значением в диапазоне интенсивностей для данного цветового канала, обычно от 0 до 255.

--------------------

Например, значение настройки черной насыщенности 15 указывает, что значения цветовых каналов в диапазоне от 15 до 255 корректируются так, чтобы они распределились по диапазону от 0 до 255, при этом значения ниже 15 устанавливаются в 0.
