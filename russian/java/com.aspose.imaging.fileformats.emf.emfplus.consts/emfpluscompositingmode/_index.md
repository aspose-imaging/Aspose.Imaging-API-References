Перечисление CompositingMode определяет режимы комбинирования исходных цветов с цветами фона. Режим композитинга представляет состояние включения альфа‑смешивания.
## Поля

| Поле | Описание |
| --- | --- |
| [CompositingModeSourceOver](#CompositingModeSourceOver) | Включает альфа‑смешивание, которое указывает, что при отрисовке цвета он смешивается с фоновым цветом. |
| [CompositingModeSourceCopy](#CompositingModeSourceCopy) | Отключает альфа‑смешивание, что означает, что при отрисовке исходного цвета он перезаписывает фоновый цвет. |
### CompositingModeSourceOver {#CompositingModeSourceOver}
```
public static final byte CompositingModeSourceOver
```


Включает альфа‑смешивание, которое указывает, что при отрисовке цвета он смешивается с фоновым цветом. Степень смешивания определяется значением альфа‑компоненты отрисовываемого цвета.

### CompositingModeSourceCopy {#CompositingModeSourceCopy}
```
public static final byte CompositingModeSourceCopy
```


Отключает альфа‑смешивание, что означает, что при отрисовке исходного цвета он перезаписывает фоновый цвет.
