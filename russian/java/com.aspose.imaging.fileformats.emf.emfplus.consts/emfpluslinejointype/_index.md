Перечисление LineJoinType определяет способы соединения двух линий, нарисованных одним графическим пером, и чьи концы соприкасаются.

--------------------

Графические линии задаются объектами [EmfPlusPen](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspen) (раздел 2.2.1.7). Соединение линий делает пересечение двух концов линии более непрерывным.
## Поля

| Поле | Описание |
| --- | --- |
| [LineJoinTypeMiter](#LineJoinTypeMiter) | Указывает соединение линий с срезом. |
| [LineJoinTypeBevel](#LineJoinTypeBevel) | Указывает соединение линий с фаской. |
| [LineJoinTypeRound](#LineJoinTypeRound) | Указывает соединение линий с закруглением. |
| [LineJoinTypeMiterClipped](#LineJoinTypeMiterClipped) | Указывает соединение линий с обрезанным срезом. |
