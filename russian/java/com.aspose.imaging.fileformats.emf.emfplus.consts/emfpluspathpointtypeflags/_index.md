Флаги PathPointType задают свойства типа точек на графических путях. Эти флаги можно комбинировать для указания нескольких вариантов.

--------------------

Графические пути задаются объектами [EmfPlusPath](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspath).
## Поля

| Поле | Описание |
| --- | --- |
| [PathPointTypeDashMode](#PathPointTypeDashMode) | Указывает, что отрезок, проходящий через точку, пунктирный. |
| [PathPointTypePathMarker](#PathPointTypePathMarker) | Указывает, что точка является маркером позиции. |
| [PathPointTypeCloseSubpath](#PathPointTypeCloseSubpath) | Указывает, что точка является конечной точкой подпути. |
