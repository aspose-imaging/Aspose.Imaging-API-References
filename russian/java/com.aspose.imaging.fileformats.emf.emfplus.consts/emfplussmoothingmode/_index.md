Перечисление SmoothingMode определяет режимы сглаживания, применяемые к линиям, кривым и краям заполненных областей, чтобы они выглядели более непрерывными или чётко определёнными.
## Поля

| Поле | Описание |
| --- | --- |
| [SmoothingModeDefault](#SmoothingModeDefault) | Указывает сглаживание кривой по умолчанию без антиалиасинга. |
| [SmoothingModeHighSpeed](#SmoothingModeHighSpeed) | Указывает наилучшую производительность без антиалиасинга. |
| [SmoothingModeHighQuality](#SmoothingModeHighQuality) | Указывает наилучшее качество с антиалиасингом. |
| [SmoothingModeNone](#SmoothingModeNone) | Не выполняет сглаживание кривой и не использует антиалиасинг. |
| [SmoothingModeAntiAlias8x4](#SmoothingModeAntiAlias8x4) | Указывает хорошее качество с использованием 8x4 коробочного фильтра. |
| [SmoothingModeAntiAlias8x8](#SmoothingModeAntiAlias8x8) | Указывает лучшее качество с использованием 8x8 коробочного фильтра. |
