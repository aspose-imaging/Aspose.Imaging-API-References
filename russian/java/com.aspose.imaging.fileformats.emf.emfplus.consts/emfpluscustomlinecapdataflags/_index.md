Флаги CustomLineCapData указывают данные для пользовательских окончаний линий. Эти флаги можно комбинировать, чтобы задать несколько вариантов.

--------------------

Пользовательские графические окончания линий задаются объектами [EmfPlusCustomLineCap](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecap).
## Поля

| Поле | Описание |
| --- | --- |
| [CustomLineCapDataFillPath](#CustomLineCapDataFillPath) | Если установлен, объект [EmfPlusFillPath](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfplusfillpath) ДОЛЖЕН быть указан в поле OptionalData объекта [EmfPlusCustomLineCapData](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecapdata) для заполнения пользовательского окончания линии. |
| [CustomLineCapDataLinePath](#CustomLineCapDataLinePath) | Если установлен, объект [EmfPlusLinePath](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluslinepath) ДОЛЖЕН быть указан в поле OptionalData объекта EmfPlusCustomLineCapData для обрисовки пользовательского окончания линии. |
### CustomLineCapDataFillPath {#CustomLineCapDataFillPath}
```
public static final int CustomLineCapDataFillPath
```

Если установлен, объект [EmfPlusFillPath](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfplusfillpath) ДОЛЖЕН быть указан в поле OptionalData объекта [EmfPlusCustomLineCapData](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecapdata) для заполнения пользовательского окончания линии.
