Флаги FontStyle определяют стили графических шрифтов. Эти флаги можно комбинировать для указания нескольких вариантов.

--------------------

Графические шрифты задаются объектами [EmfPlusFont](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfplusfont) objects
## Поля

| Поле | Описание |
| --- | --- |
| [FontStyleBold](#FontStyleBold) | Если установлен, шрифт ДОЛЖЕН отображаться с более тяжёлым весом или толщиной. |
| [FontStyleItalic](#FontStyleItalic) | Если установлен, шрифт ДОЛЖЕН отображаться с вертикальными штрихами символов под увеличенным углом или наклоном относительно базовой линии. |
| [FontStyleUnderline](#FontStyleUnderline) | Если установлен, шрифт ДОЛЖЕН отображаться с линией под базовой линией символов. |
| [FontStyleStrikeout](#FontStyleStrikeout) | Если установлен, шрифт ДОЛЖЕН отображаться с линией, параллельной базовой линии, проведённой через середину символов. |
### FontStyleBold {#FontStyleBold}
```
public static final int FontStyleBold
```


Если установлен, шрифт ДОЛЖЕН отображаться с более тяжёлым весом или толщиной. Если сброшен, шрифт ДОЛЖЕН отображаться с нормальной толщиной.

### FontStyleItalic {#FontStyleItalic}
```
public static final int FontStyleItalic
```


Если установлен, шрифт ДОЛЖЕН отображаться с вертикальными штрихами символов под увеличенным углом или наклоном относительно базовой линии. Если сброшен, шрифт ДОЛЖЕН отображаться с вертикальными штрихами символов под обычным углом.

### FontStyleUnderline {#FontStyleUnderline}
```
public static final int FontStyleUnderline
```


Если установлен, шрифт ДОЛЖЕН отображаться с линией под базовой линией символов. Если сброшен, шрифт ДОЛЖЕН отображаться без линии под базовой линией.

### FontStyleStrikeout {#FontStyleStrikeout}
```
public static final int FontStyleStrikeout
```


Если установлен, шрифт ДОЛЖЕН отображаться линией, параллельной базовой линии, проведённой через середину символов. Если сброшен, шрифт ДОЛЖЕН отображаться без линии, проходящей через символы.
