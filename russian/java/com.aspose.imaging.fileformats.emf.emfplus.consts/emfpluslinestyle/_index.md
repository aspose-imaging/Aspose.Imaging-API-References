Перечисление LineStyle определяет стили линий, рисуемых графическими перьями.

--------------------

Графические линии задаются объектами [EmfPlusPen](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspen) (раздел 2.2.1.7).
## Поля

| Поле | Описание |
| --- | --- |
| [LineStyleSolid](#LineStyleSolid) | Указывает сплошную линию. |
| [LineStyleDash](#LineStyleDash) | Указывает пунктирную линию. |
| [LineStyleDot](#LineStyleDot) | Указывает точечную линию. |
| [LineStyleDashDot](#LineStyleDashDot) | Указывает чередующуюся линию тире-точка. |
| [LineStyleDashDotDot](#LineStyleDashDotDot) | Указывает чередующуюся линию тире-точка-точка. |
