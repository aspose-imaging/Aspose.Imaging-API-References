Флаги PaletteStyle указывают свойства графических палитр. Эти флаги можно комбинировать для указания нескольких вариантов.

--------------------

Графические палитры задаются объектами [EmfPlusPalette](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspalette).
## Поля

| Поле | Описание |
| --- | --- |
| [PaletteStyleHasAlpha](#PaletteStyleHasAlpha) | Если установлен, один или несколько элементов палитры ДОЛЖНЫ содержать информацию об альфа‑прозрачности. |
| [PaletteStyleGrayScale](#PaletteStyleGrayScale) | Если установлен, палитра ДОЛЖНА содержать только оттенки серого. |
| [PaletteStyleHalftone](#PaletteStyleHalftone) | Если установлен, палитра ДОЛЖНА содержать дискретные цветовые значения, которые можно использовать для полутонов. |
