### Axial {#Axial}
```
public static final int Axial
```


Axial определяет би‑линейный градиент, который также известен как отражённый градиент или зеркальный линейный градиент. Он создаётся как линейный градиент, зеркально (или отражённо) отражённый вдоль своей оси.

### Ellipsoid {#Ellipsoid}
```
public static final int Ellipsoid
```


Эллипсоид определяет градиент, где цвета смешиваются вдоль радиуса от центра эллипсоида, как определено атрибутами draw:cx и draw:cy. Длина полу‑большой оси соответствует ширине заполненной области, а длина полу‑меньшей оси.

### Linear {#Linear}
```
public static final int Linear
```


Линейный определяет градиент, где цвета смешиваются вдоль линейной оси градиента. Ось градиента задаётся атрибутом draw:angle по часовой стрелке относительно вертикальной оси.

### Radial {#Radial}
```
public static final int Radial
```


Радиальный определяет градиент, где цвета смешиваются вдоль радиуса от центра круга, как определено атрибутами draw:cx и draw:cy. Внешняя часть круга заполняется конечным цветом.

### Rectangle {#Rectangle}
```
public static final int Rectangle
```


Прямоугольник определяет градиент, который создаёт прямоугольное смешивание от центра прямоугольника до ближайшей из четырёх границ. Центр прямоугольника задаётся атрибутами draw:cx и draw:cy. Ширина прямоугольника соответствует ширине заполненной области, высота прямоугольника — высоте заполненной области. Внешняя часть квадрата заполняется конечным цветом.

### Square {#Square}
```
public static final int Square
```


Квадрат определяет градиент, который создаёт квадратное смешивание, имитируя визуальную перспективу в коридоре или вид сверху на пирамиду. Также известен как "box gradient" и "pyramidal gradient". Центр квадрата задаётся атрибутами draw:cx и draw:cy. Ширина и высота квадрата равны минимальному значению из ширины или высоты заполненной области. Внешняя часть квадрата заполняется конечным цветом.

### None {#None}
```
public static final int None
```


Стиль градиента — отсутствует
