Пакет предоставляет вспомогательные классы и методы для работы с различными типами кистей.


## Классы

| Класс | Описание |
| --- | --- |
| [HatchBrush](../com.aspose.imaging.brushes/hatchbrush) | Определяет прямоугольную кисть с штриховкой, цветом переднего плана и цветом фона. |
| [LinearGradientBrush](../com.aspose.imaging.brushes/lineargradientbrush) | Инкапсулирует `Aspose.Imaging.Brush` с линейным градиентом. |
| [LinearGradientBrushBase](../com.aspose.imaging.brushes/lineargradientbrushbase) | Представляет `Brush` с возможностями градиента и соответствующими свойствами. |
| [LinearMulticolorGradientBrush](../com.aspose.imaging.brushes/linearmulticolorgradientbrush) | Представляет `Brush` с линейным градиентом, определённым несколькими цветами и соответствующими позициями. |
| [PathGradientBrush](../com.aspose.imaging.brushes/pathgradientbrush) | Инкапсулирует объект `Aspose.Imaging.Brush` с градиентом. |
| [PathGradientBrushBase](../com.aspose.imaging.brushes/pathgradientbrushbase) | Представляет `Brush` с функциональностью градиента базового пути. |
| [PathMulticolorGradientBrush](../com.aspose.imaging.brushes/pathmulticolorgradientbrush) | Инкапсулирует объект `Aspose.Imaging.Brush` с градиентом. |
| [SolidBrush](../com.aspose.imaging.brushes/solidbrush) | Сплошная кисть предназначена для непрерывного рисования определённым цветом. |
| [TextureBrush](../com.aspose.imaging.brushes/texturebrush) | Каждое свойство класса `Aspose.Imaging.Brushes.TextureBrush` является объектом `Aspose.Imaging.Brush`, который использует изображение для заполнения внутренней части формы. |
| [TransformBrush](../com.aspose.imaging.brushes/transformbrush) | `Brush` с возможностями трансформации. |
