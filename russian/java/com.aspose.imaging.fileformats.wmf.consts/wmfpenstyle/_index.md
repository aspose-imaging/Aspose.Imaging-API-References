Перечисление PenStyle 16‑бит используется для указания различных типов перьев, которые могут применяться в графических операциях.
## Поля

| Поле | Описание |
| --- | --- |
| [Cosmetic](#Cosmetic) | Косметический |
| [EndcapRound](#EndcapRound) | Концы линий закруглены. |
| [JoinRound](#JoinRound) | Стыки линий закруглены. |
| [Solid](#Solid) | Перо сплошное. |
| [Dash](#Dash) | Перо пунктирное. |
| [Dot](#Dot) | Перо точечное. |
| [Dashdot](#Dashdot) | Перо имеет чередующиеся тире и точки. |
| [Dashdotdot](#Dashdotdot) | Ручка имеет тире и двойные точки. |
| [Null](#Null) | Ручка невидима. |
| [Insideframe](#Insideframe) | Перо сплошное. |
| [Userstyle](#Userstyle) | Ручка использует массив стилей, предоставленный пользователем. |
| [Alternate](#Alternate) | Ручка устанавливает каждый второй пиксель (этот стиль применим только к косметическим ручкам). |
| [EndcapSquare](#EndcapSquare) | Концы линий квадратные. |
| [EndcapFlat](#EndcapFlat) | Концы линий плоские. |
