Флаги VerticalTextAlignmentMode определяют взаимосвязь между опорной точкой и ограничивающим прямоугольником для выравнивания текста. Эти флаги можно комбинировать, чтобы задать несколько вариантов, при этом допускается выбор только одного флага, изменяющего позицию отрисовки в контексте устройства воспроизведения. Вертикальное выравнивание текста выполняется, когда шрифт имеет вертикальную базовую линию по умолчанию, например, кандзи.

| Поле | Описание |
| --- | --- |
| [VTA_TOP](#VTA-TOP) | Опорная точка ДОЛЖНА находиться на верхнем крае ограничивающего прямоугольника. |
| [VTA_RIGHT](#VTA-RIGHT) | Опорная точка ДОЛЖНА находиться на правом крае ограничивающего прямоугольника. |
| [VTA_BOTTOM](#VTA-BOTTOM) | Опорная точка ДОЛЖНА находиться на нижнем крае ограничивающего прямоугольника. |
| [VTA_CENTER](#VTA-CENTER) | Опорная точка ДОЛЖНА быть выровнена по вертикали с центром ограничивающего прямоугольника. |
| [VTA_LEFT](#VTA-LEFT) | Опорная точка ДОЛЖНА находиться на левом крае ограничивающего прямоугольника. |
| [VTA_BASELINE](#VTA-BASELINE) | Опорная точка ДОЛЖНА находиться на базовой линии текста. |
