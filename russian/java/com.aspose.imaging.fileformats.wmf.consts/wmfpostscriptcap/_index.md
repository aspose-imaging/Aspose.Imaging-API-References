Перечисление PostScriptCap определяет типы окончаний линий для использования с драйвером принтера PostScript.
## Поля

| Поле | Описание |
| --- | --- |
| [PostScriptNotSet](#PostScriptNotSet) | Указывает, что стиль завершения линии не установлен, и что может быть использован стиль по умолчанию [24]. |
| [PostScriptFlatCap](#PostScriptFlatCap) | Указывает, что линия заканчивается в последней точке. |
| [PostScriptRoundCap](#PostScriptRoundCap) | Указывает круглую насадку. |
| [PostScriptSquareCap](#PostScriptSquareCap) | Указывает квадратную насадку. |
### PostScriptNotSet {#PostScriptNotSet}
```
public static final int PostScriptNotSet
```


Указывает, что стиль завершения линии не установлен, и что может быть использован стиль по умолчанию [24].

### PostScriptFlatCap {#PostScriptFlatCap}
```
public static final int PostScriptFlatCap
```


Указывает, что линия заканчивается в последней точке. Конец обрезан квадратом.

### PostScriptRoundCap {#PostScriptRoundCap}
```
public static final int PostScriptRoundCap
```


Указывает круглую головку. Центр круга является последней точкой линии. Диаметр круга совпадает с шириной линии; то есть с толщиной линии.

### PostScriptSquareCap {#PostScriptSquareCap}
```
public static final int PostScriptSquareCap
```


Указывает квадратную головку. Центр квадрата является последней точкой линии. Высота и ширина квадрата совпадают с шириной линии; то есть с толщиной линии.
