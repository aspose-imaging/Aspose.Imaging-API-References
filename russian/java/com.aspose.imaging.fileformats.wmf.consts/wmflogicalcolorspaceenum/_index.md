Перечисление LogicalColorSpace указывает тип цветового пространства.
## Поля

| Поле | Описание |
| --- | --- |
| [LCS_CALIBRATED_RGB](#LCS-CALIBRATED-RGB) | Значения цвета откалиброваны как значения красного, зелёного, синего (RGB). |
| [LCS_sRGB](#LCS-sRGB) | Значение представляет собой кодировку ASCII‑символов "sRGB" и указывает, что значения цвета являются значениями sRGB. |
| [LCS_WINDOWS_COLOR_SPACE](#LCS-WINDOWS-COLOR-SPACE) | Значение представляет собой кодировку ASCII‑символов "Win " (включая завершающий пробел) и указывает, что значения цвета являются значениями цветового пространства Windows по умолчанию. |

### LCS_sRGB {#LCS-sRGB}

Значение представляет собой кодировку ASCII‑символов "sRGB" и указывает, что значения цвета являются значениями sRGB.

### LCS_WINDOWS_COLOR_SPACE {#LCS-WINDOWS-COLOR-SPACE}
```
public static final int LCS_WINDOWS_COLOR_SPACE
```


Значение представляет собой кодировку ASCII‑символов "Win " (включая завершающий пробел) и указывает, что значения цвета являются значениями цветового пространства Windows по умолчанию.
