### Text {#Text}
```
public static final short Text
```


Текст: каждая логическая единица отображается в один пиксель устройства. Положительный x направлен вправо; положительный y направлен вниз.

### Lometric {#Lometric}
```
public static final short Lometric
```


Лометрический: каждый логический блок отображается в 0,1 миллиметра. Положительная ось x направлена вправо; положительная ось y — вверх.

### Himetric {#Himetric}
```
public static final short Himetric
```


Гиметрический: каждый логический блок отображается в 0,01 миллиметра. Положительная ось x направлена вправо; положительная ось y — вверх.

### Loenglish {#Loenglish}
```
public static final short Loenglish
```


Лоанглийский: каждый логический блок отображается в 0,01 дюйма. Положительная ось x направлена вправо; положительная ось y — вверх.

### Hienglish {#Hienglish}
```
public static final short Hienglish
```


Хианглийский: каждый логический блок отображается в 0,001 дюйма. Положительная ось x направлена вправо; положительная ось y — вверх.

### Twips {#Twips}
```
public static final short Twips
```


Твипсы: каждый логический блок отображается в одну двадцатую (1/20) части пункта. При печати пункт равен 1/72 дюйма; следовательно, 1/20 пункта — это 1/1440 дюйма. Эта единица также известна как "twip".

### Isotropic {#Isotropic}
```
public static final short Isotropic
```


Изотропный: логические единицы отображаются в произвольные единицы устройства с одинаковым масштабом осей; то есть один блок по оси x равен одному блоку по оси y. Записи META\_SETWINDOWEXT и META\_SETVIEWPORTEXT указывают единицы и ориентацию осей.

### Anisotropic {#Anisotropic}
```
public static final short Anisotropic
```


Анизотропный: логические единицы отображаются в произвольные единицы с произвольным масштабом по осям.
