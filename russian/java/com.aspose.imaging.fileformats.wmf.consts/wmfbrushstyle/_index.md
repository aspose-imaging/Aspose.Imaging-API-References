Перечисление BrushStyle определяет различные возможные типы кистей, которые могут использоваться в графических операциях. Для получения дополнительной информации см. спецификацию объекта Brush (раздел 2.2.1.1).
## Поля

| Поле | Описание |
| --- | --- |
| [Solid](#Solid) | Кисть, которая рисует один постоянный цвет, сплошной или с диффузией. |
| [Null](#Null) | Кисть, которая ничего не делает. |
| [Hatched](#Hatched) | Кисть, которая рисует предопределённый простой узор, или \"hatch\", на сплошном фоне. |
| [Pattern](#Pattern) | Кисть, которая рисует узор, определённый битмапом, который МОЖЕТ быть объектом Bitmap16 или объектом DeviceIndependentBitmap (DIB). |
| [Indexed](#Indexed) | Не поддерживается. |
| [Dibpattern](#Dibpattern) | Кисть‑узор, заданная DIB. |
| [Dibpatternpt](#Dibpatternpt) | Кисть‑узор, заданная DIB. |
| [Pattern8X8](#Pattern8X8) | Не поддерживается. |
| [Dibpattern8X8](#Dibpattern8X8) | Не поддерживается. |
| [Monopattern](#Monopattern) | Не поддерживается. |
| [Gradient](#Gradient) | Градиент не поддерживается в wmf, поддерживается в odg. |
