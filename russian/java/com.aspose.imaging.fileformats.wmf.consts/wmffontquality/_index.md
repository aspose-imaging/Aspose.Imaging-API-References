Перечисление FontQuality указывает, насколько точно атрибуты логического шрифта должны соответствовать атрибутам физического шрифта при отображении текста.
## Поля

| Поле | Описание |
| --- | --- |
| [Default](#Default) | Указывает, что качество символов шрифта не имеет значения, поэтому можно использовать DRAFT. |
| [Draft](#Draft) | Указывает, что качество символов шрифта менее важно, чем соответствие логическим атрибутам. |
| [Proof](#Proof) | Указывает, что качество символов шрифта важнее, чем соответствие логическим атрибутам. |
| [Nonantialiased](#Nonantialiased) | Указывает, что сглаживание НЕ ДОЛЖНО использоваться при рендеринге текста. |
| [Antialiased](#Antialiased) | Указывает, что сглаживание ДОЛЖНО использоваться при рендеринге текста, если шрифт это поддерживает. |
| [Cleartype](#Cleartype) | Указывает, что сглаживание ClearType ДОЛЖНО использоваться при рендеринге текста, если шрифт это поддерживает. |
### Default {#Default}
```
public static final byte Default
```


Указывает, что качество символов шрифта не имеет значения, поэтому можно использовать DRAFT.

### Draft {#Draft}
```
public static final byte Draft
```


Указывает, что качество символов шрифта менее важно, чем соответствие логическим атрибутам. Для растровых шрифтов масштабирование ДОЛЖНО быть включено, что означает доступность большего количества размеров шрифта.

### Proof {#Proof}
```
public static final byte Proof
```


Указывает, что качество символов шрифта важнее, чем соответствие логическим атрибутам. Для растровых шрифтов масштабирование ДОЛЖНО быть отключено, и следует выбирать шрифт ближайшего размера.

### Nonantialiased {#Nonantialiased}
```
public static final byte Nonantialiased
```


Указывает, что сглаживание НЕ ДОЛЖНО использоваться при рендеринге текста.

### Antialiased {#Antialiased}
```
public static final byte Antialiased
```


Указывает, что сглаживание ДОЛЖНО использоваться при рендеринге текста, если шрифт это поддерживает.

### Cleartype {#Cleartype}
```
public static final byte Cleartype
```


Указывает, что сглаживание ClearType ДОЛЖНО использоваться при рендеринге текста, если шрифт это поддерживает.
