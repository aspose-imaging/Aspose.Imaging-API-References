Перечисление FloodFill указывает тип операции заливки, которую следует выполнить.
## Поля

| Поле | Описание |
| --- | --- |
| [FloodFillBorder](#FloodFillBorder) | Область заполнения ограничена цветом, указанным членом Color. |
| [FloodFillSurface](#FloodFillSurface) | Область заполнения ограничена цветом, который указан членом Color. |
### FloodFillBorder {#FloodFillBorder}
```
public static final int FloodFillBorder
```


Область заполнения ограничена цветом, указанным членом Color. Этот стиль идентичен заполнению, выполняемому записью META\_FLOODFILL.

### FloodFillSurface {#FloodFillSurface}
```
public static final int FloodFillSurface
```


Область заполнения ограничена цветом, который указан членом Color. Заполнение продолжается наружу во всех направлениях, пока встречается этот цвет. Этот стиль полезен для заполнения областей с многоцветными границами.
