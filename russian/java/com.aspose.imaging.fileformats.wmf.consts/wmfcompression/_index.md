## Поля

### BI_RGB {#BI-RGB}
```
public static final int BI_RGB
```


Битовая карта находится в несжатом формате красный-зелёный-синий (RGB), который не сжат и не использует цветовые маски.

### BI_RLE8 {#BI-RLE8}
```
public static final int BI_RLE8
```


Формат RGB, использующий сжатие методом последовательного кодирования (RLE) для битмапов с 8 битами на пиксель. Сжатие использует 2‑байтовый формат, состоящий из байта счёта, за которым следует байт, содержащий индекс цвета.

### BI_RLE4 {#BI-RLE4}
```
public static final int BI_RLE4
```


Формат RGB, использующий RLE‑сжатие для битмапов с 4 битами на пиксель. Сжатие использует 2‑байтовый формат, состоящий из байта счёта, за которым следуют два индекса длиной в слово.

### BI_BITFIELDS {#BI-BITFIELDS}
```
public static final int BI_BITFIELDS
```


Битмап не сжат, и таблица цветов состоит из трёх DWORD масок цветов, которые соответственно задают красный, зелёный и синий компоненты каждого пикселя. Это допустимо при использовании с битмапами в 16 и 32 бита на пиксель.

### BI_JPEG {#BI-JPEG}
```
public static final int BI_JPEG
```


Изображение является JPEG‑изображением, как указано в [JFIF]. Это значение ДОЛЖНО использоваться только в определённых операциях с битмапами, таких как пропуск JPEG. Приложение ДОЛЖНО запрашивать поддержку пропуска, поскольку не все устройства поддерживают пропуск JPEG. Использование битмапов, не являющихся RGB, МОЖЕТ ограничить переносимость метафайла на другие устройства. Например, контексты отображения обычно не поддерживают такой пропуск.

### BI_PNG {#BI-PNG}
```
public static final int BI_PNG
```


Изображение является PNG‑изображением, как указано в [RFC2083]. Это значение ДОЛЖНО использоваться только в определённых операциях с битмапами, таких как пропуск JPEG/PNG. Приложение ДОЛЖНО запрашивать поддержку пропуска, потому что не все устройства поддерживают пропуск JPEG/PNG. Использование битмапов, не являющихся RGB, МОЖЕТ ограничить переносимость метафайла на другие устройства. Например, контексты отображения обычно не поддерживают такой пропуск.
