Перечисление CharacterSet определяет возможные наборы глифов символов, определённых в шрифтах для графического вывода.
## Поля

| Поле | Описание |
| --- | --- |
| [Ansi](#Ansi) | Указывает английский набор символов. |
| [Default](#Default) | Указывает набор символов, основанный на текущей системной локали; например, когда системная локаль — английский (США), набор символов по умолчанию — ANSI\_CHARSET. |
| [Symbol](#Symbol) | Указывает набор символов‑знаков. |
| [Mac](#Mac) | Указывает набор символов Apple Macintosh. |
| [Shiftjis](#Shiftjis) | Указывает японский набор символов. |
| [Hangul](#Hangul) | Также пишется "Hangeul". |
| [Johab](#Johab) | Также пишется "Johap". |
| [Gb2312](#Gb2312) | Указывает "упрощённый" китайский набор символов для Китайской Народной Республики. |
| [Chinesebig5](#Chinesebig5) | Указывает "традиционный" китайский набор символов, используемый в основном в Тайване и в специальных административных регионах Гонконга и Макао. |
| [Greek](#Greek) | Указывает греческий набор символов. |
| [Turkish](#Turkish) | Указывает турецкий набор символов. |
| [Vietnamese](#Vietnamese) | Указывает вьетнамский набор символов. |
| [Hebrew](#Hebrew) | Указывает вьетнамский набор символов. |
| [Arabic](#Arabic) | Указывает арабский набор символов |
| [Baltic](#Baltic) | Указывает балтийский (северо-восточно‑европейский) набор символов |
| [Russian](#Russian) | Указывает русский кириллический набор символов. |
| [Thai](#Thai) | Указывает тайский набор символов. |
| [Easteurope](#Easteurope) | Указывает восточно‑европейский набор символов. |
| [Oem](#Oem) | Указывает сопоставление с одной из OEM‑страниц кодов в соответствии с текущей настройкой системной локали. |
