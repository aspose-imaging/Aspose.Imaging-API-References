Перечисление FamilyFont указывает семейство шрифтов. Семейства шрифтов описывают внешний вид шрифта в общем виде. Они предназначены для указания шрифтов, когда требуемый конкретный тип шрифта недоступен.
## Поля

| Поле | Описание |
| --- | --- |
| [Dontcare](#Dontcare) | Указывается шрифт по умолчанию, который зависит от реализации. |
| [Roman](#Roman) | Шрифты с переменной толщиной штриха, пропорциональной фактической ширине глифов, и имеющие засечки. |
| [Swiss](#Swiss) | Шрифты с переменной толщиной штриха, пропорциональной фактической ширине глифов, и не имеющие засечек. |
| [Modern](#Modern) | Шрифты с постоянной толщиной штриха, с засечками или без них. |
| [Script](#Script) | Шрифты, имитирующие рукописный текст. |
| [Decorative](#Decorative) | Декоративные шрифты. |
### Dontcare {#Dontcare}
```
public static final byte Dontcare
```


Указывается шрифт по умолчанию, который зависит от реализации.

### Roman {#Roman}
```
public static final byte Roman
```


Шрифты с переменной толщиной штриха, пропорциональной фактической ширине глифов, и имеющие засечки. "MS Serif" — пример.

### Swiss {#Swiss}
```
public static final byte Swiss
```


Шрифты с переменной толщиной штриха, пропорциональной фактической ширине глифов, и без засечек. "MS Sans Serif" — пример.

### Modern {#Modern}
```
public static final byte Modern
```


Шрифты с постоянной толщиной штриха, с засечками или без них. Шрифты фиксированной ширины обычно современны. "Pica", "Elite" и "Courier New" — примеры.

### Script {#Script}
```
public static final byte Script
```


Шрифты, имитирующие рукописный текст. "Script" и "Cursive" — примеры.

### Decorative {#Decorative}
```
public static final byte Decorative
```


Новостные (декоративные) шрифты. "Old English" — пример.
