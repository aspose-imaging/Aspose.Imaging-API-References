Перечисление MixMode указывает режим смешивания фона для текста, штриховых кистей и других несолидных стилей пера.
## Поля

| Поле | Описание |
| --- | --- |
| [Transparent](#Transparent) | Фон остаётся нетронутым. |
| [Opaque](#Opaque) | Фон заполняется цветом фона, который в данный момент определён в контексте устройства воспроизведения перед отрисовкой текста, штриховой кисти или пера. |
