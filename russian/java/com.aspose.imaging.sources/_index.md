| [FileOpenSource](../com.aspose.imaging.sources/fileopensource) | Представляет файловый источник для открытия. |
| [FileSource](../com.aspose.imaging.sources/filesource) | Представляет файловый источник, способный к манипуляции файлами. |
| [StreamSource](../com.aspose.imaging.sources/streamsource) | Представляет потоковый источник. |
