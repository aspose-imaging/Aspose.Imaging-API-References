| [TimeFormat](../com.aspose.imaging.xmp.schemas.xmpdm/timeformat) | Представляет формат времени в `Timecode`. |
| [Timecode](../com.aspose.imaging.xmp.schemas.xmpdm/timecode) | Представляет значение таймкода в видео. |
| [XmpDynamicMediaPackage](../com.aspose.imaging.xmp.schemas.xmpdm/xmpdynamicmediapackage) | Представляет пространство имён XMP Dynamic Media. |
