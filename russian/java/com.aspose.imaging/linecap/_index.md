| [Round](#Round) | Указывает круглое окончание линии. |

| [NoAnchor](#NoAnchor) | Указывает отсутствие привязки. |

| [RoundAnchor](#RoundAnchor) | Указывает круглую заглушку якоря. |
| [DiamondAnchor](#DiamondAnchor) | Указывает ромбовидную заглушку якоря. |
| [ArrowAnchor](#ArrowAnchor) | Указывает стрелкообразную заглушку якоря. |
