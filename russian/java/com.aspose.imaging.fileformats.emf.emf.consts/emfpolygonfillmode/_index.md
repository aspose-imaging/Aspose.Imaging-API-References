Перечисление PolygonFillMode определяет значения, указывающие, как вычислять область полигона, подлежащую заполнению.
## Поля

| Поле | Описание |
| --- | --- |
| [ALTERNATE](#ALTERNATE) | Выбирает альтернативный режим (заполняет область между нечетными и четными сторонами полигона на каждой строке сканирования). |
| [WINDING](#WINDING) | Выбирает режим заполнения по правилу обхода (заполняет любую область с ненулевым значением обхода). |
