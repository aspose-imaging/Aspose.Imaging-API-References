Перечисление FormatSignature определяет значения, используемые для идентификации формата встроенных данных в записях EMF.
## Поля

| Поле | Описание |
| --- | --- |
| [ENHMETA_SIGNATURE](#ENHMETA-SIGNATURE) | Значение этого члена — последовательность символов ASCII "FME ", которая является обратной строке "EMF" и обозначает данные записи EMF. |
| [EPS_SIGNATURE](#EPS-SIGNATURE) | Значение этого члена — последовательность символов ASCII "FSPE", которая является обратной строке "EPSF" и обозначает данные формата инкапсулированного PostScript (EPS). |
### ENHMETA_SIGNATURE {#ENHMETA-SIGNATURE}
```
public static final int ENHMETA_SIGNATURE
```


Значение этого члена — последовательность символов ASCII "FME ", которая является обратной строке "EMF" и обозначает данные записи EMF. Примечание: символ пробела в строке имеет значение и ДОЛЖЕН присутствовать.

### EPS_SIGNATURE {#EPS-SIGNATURE}
```
public static final int EPS_SIGNATURE
```


Значение этого члена — последовательность символов ASCII "FSPE", которая является обратной строке "EPSF" и обозначает данные формата инкапсулированного PostScript (EPS).
