Перечисление RegionMode определяет значения, используемые с EMR\_SELECTCLIPPATH и EMR\_EXTSELECTCLIPRGN, указывающие текущий путь или новую область, которая комбинируется с текущей областью отсечения.
## Поля

| Поле | Описание |
| --- | --- |
| [RGN_AND](#RGN-AND) | Новая область отсечения включает пересечение (перекрывающиеся области) текущей области отсечения и текущего пути (или новой области). |
| [RGN_OR](#RGN-OR) | Новый регион отсечения включает объединение (совмещённые области) текущего региона отсечения и текущего пути (или нового региона). |
| [RGN_XOR](#RGN-XOR) | Новый регион отсечения включает объединение текущего региона отсечения и текущего пути (или нового региона), но без перекрывающихся областей |
| [RGN_DIFF](#RGN-DIFF) | Новый регион отсечения включает области текущего региона отсечения, исключая области текущего пути (или нового региона). |
| [RGN_COPY](#RGN-COPY) | Новый регион отсечения — это текущий путь (или новый регион). |
