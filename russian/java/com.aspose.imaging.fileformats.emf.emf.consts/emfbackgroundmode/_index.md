Перечисление BackgroundMode используется для указания режима фона, который применяется к тексту, штрихованным кистям и стилям пера, не являющимся сплошными. Режим фона определяет, как комбинировать фон с передним текстом, штрихованными кистями и стилями пера, не являющимися сплошными линиями.
## Поля

| Поле | Описание |
| --- | --- |
| [TRANSPARENT](#TRANSPARENT) | Прозрачный - фон остается нетронутым. |
| [OPAQUE](#OPAQUE) | Непрозрачный - фон заполняется текущим цветом фона перед отрисовкой текста, штриховой кисти или пера. |
