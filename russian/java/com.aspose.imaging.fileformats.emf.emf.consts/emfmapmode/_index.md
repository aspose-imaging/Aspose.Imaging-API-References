
Каждая логическая единица отображается в одну двадцатую часть точки принтера (1/1440 дюйма, также называемую "twip"). Положительная ось x направлена вправо; положительная ось y направлена вверх.

### MM_ISOTROPIC {#MM-ISOTROPIC}
```
public static final int MM_ISOTROPIC
```


Логические единицы отображаются в произвольные единицы с одинаково масштабированными осями; то есть одна единица вдоль оси x равна одной единице вдоль оси y. Записи EMR\_SETWINDOWEXTEX и EMR\_SETVIEWPORTEXTEX ДОЛЖНЫ использоваться для указания единиц и ориентации осей. Корректировки ДОЛЖНЫ быть выполнены по мере необходимости, чтобы гарантировать, что единицы по осям x и y остаются одинакового размера. Например, когда задаётся размер окна, область просмотра ДОЛЖНА быть скорректирована, чтобы сохранить изотропность единиц.

### MM_ANISOTROPIC {#MM-ANISOTROPIC}
```
public static final int MM_ANISOTROPIC
```


Логические единицы отображаются в произвольные единицы с произвольно масштабированными осями. Записи EMR\_SETWINDOWEXTEX и EMR\_SETVIEWPORTEXTEX ДОЛЖНЫ использоваться для указания единиц, ориентации и масштабирования.
