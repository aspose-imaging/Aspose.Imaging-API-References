Перечисление ColorAdjustment используется для указания того, как следует подготовить выходное изображение, когда режим растягивания установлен в HALFTONE.
## Поля

| Поле | Описание |
| --- | --- |
| [CA_NEGATIVE](#CA-NEGATIVE) | Указывает, что негатив оригинального изображения ДОЛЖЕН отображаться. |
| [CA_LOG_FILTER](#CA-LOG-FILTER) | Эта Указывает, что к конечной плотности выходных цветов ДОЛЖЕН применяться логарифмический процесс. |
### CA_NEGATIVE {#CA-NEGATIVE}
```
public static final int CA_NEGATIVE
```

### CA_LOG_FILTER {#CA-LOG-FILTER}
```
public static final int CA_LOG_FILTER
```


Эта Указывает, что к конечной плотности выходных цветов ДОЛЖЕН применяться логарифмический процесс. Это увеличит цветовой контраст при низкой яркости.
