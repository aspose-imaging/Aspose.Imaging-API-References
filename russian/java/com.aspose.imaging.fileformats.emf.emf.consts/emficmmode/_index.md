Перечисление ICMMode определяет значения, указывающие, когда включать и выключать ICM.
## Поля

| Поле | Описание |
| --- | --- |
| [ICM_OFF](#ICM-OFF) | Отключает управление цветом изображения (ICM) в контексте воспроизведения устройства. |
| [ICM_ON](#ICM-ON) | Включает ICM в контексте воспроизведения устройства. |
| [ICM_QUERY](#ICM-QUERY) | Запрашивает текущее состояние управления цветом в контексте воспроизведения устройства. |
| [ICM_DONE_OUTSIDEDC](#ICM-DONE-OUTSIDEDC) | Отключает ICM в контексте воспроизведения устройства и отключает старый способ коррекции цвета полутонов. |
### ICM_OFF {#ICM-OFF}
