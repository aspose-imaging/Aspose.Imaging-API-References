Перечисление BitCount указывает количество бит, определяющих каждый пиксель, и<br/>                максимальное число цветов в независимом от устройства битмапе (DIB).

**Module:** [aspose.imaging.apsbuilder.dib](/imaging/python-net/aspose.imaging.apsbuilder.dib/)

**Full Name:** aspose.imaging.apsbuilder.dib.DibBitCount

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| BITCOUNT0 | Количество бит на пиксель не определено.<br/>                Изображение ДОЛЖНО быть в формате JPEG или PNG.<br/>                Ни один из этих форматов не включает таблицу цветов, поэтому это значение<br/>                указывает, что таблица цветов отсутствует. См. [JFIF] и [RFC2083]<br/>                для получения дополнительной информации о форматах сжатия JPEG и PNG. |
| BITCOUNT1 | Изображение задано двумя цветами. Каждый пиксель в битмапе<br/>                представлен одним битом. Если бит сброшен, пиксель отображается<br/>                цветом первой записи в таблице цветов;<br/>                если бит установлен, пиксель имеет цвет второй записи в таблице. |
| BITCOUNT2 | Изображение задано максимум 16 цветами.<br/>                Каждый пиксель в битмапе представлен 4-битным индексом в<br/>                таблице цветов, и каждый байт содержит 2 пикселя. |
| BITCOUNT3 | Изображение задано максимум 256 цветами.<br/>                Каждый пиксель в битмапе представлен 8-битным индексом в<br/>                таблице цветов, и каждый байт содержит 1 пиксель. |
| BITCOUNT4 | Изображение задано максимум 2^16 цветами.<br/>                Каждый пиксель в битмапе представлен 16-битным значением. |
| BITCOUNT5 | Битмап поддерживает максимум 2^24 цветов, а поле Colors в DIB равно NULL.<br/>                Каждая 3-байтовая тройка в массиве битмапа представляет относительные интенсивности<br/>                синего, зелёного и красного цветов соответственно для пикселя. Таблица цветов Colors<br/>                используется для оптимизации цветов на устройствах с палитрой, и ДОЛЖНА содержать<br/>                количество записей, указанное в поле ColorUsed объекта BitmapInfoHeader. |
| BITCOUNT6 | Битмап поддерживает максимум 2^24 цветов. |
