Указывает, как сравниваются цвета во время работы алгоритма Magic Wand.

**Module:** [aspose.imaging.magicwand](/imaging/python-net/aspose.imaging.magicwand/)

**Full Name:** aspose.imaging.magicwand.ColorComparisonMode

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| CUSTOM | Алгоритм сравнения цветов определяется пользователем. |
| RGB_DEFAULT | Цвета сравниваются в цветовом пространстве RGB.<br/>            Каждое различие цветов должно удовлетворять порогу. |
| YUV_DEFAULT | Цвета сравниваются в цветовом пространстве YUV.<br/>            Каждое различие цветов должно удовлетворять порогу. |
| YUV_LESS_LUMA_SENSITIVE | Цвета сравниваются в цветовом пространстве YUV.<br/>            Различия цветовой информации должны удовлетворять порогу, порог для компоненты яркости удвоен. |
