Перечисление BackgroundMode используется для указания режима фона, применяемого к тексту,<br/>            штрихованным кистям и стилям пера, которые не являются сплошными. Режим фона определяет, как<br/>            комбинировать фон с передним текстом, штрихованными кистями и стилями пера, которые не являются сплошными линиями.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfBackgroundMode

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| OPAQUE | Непрозрачный - Фон заполняется текущим цветом фона перед тем, как будет нарисован текст, штриховка кисти или перо |
| TRANSPARENT | Прозрачный - Фон остаётся нетронутым. |
