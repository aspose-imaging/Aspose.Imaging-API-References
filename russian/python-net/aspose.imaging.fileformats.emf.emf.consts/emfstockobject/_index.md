Перечисление StockObject указывает индексы предопределённых логических графических объектов <br/>            которые могут использоваться в графических операциях. Конкретные структуры stock objects зависят от реализации; однако свойства stock objects ДОЛЖНЫ быть эквивалентны <br/>            свойствам явно созданных объектов того же типа. <br/>            Эти свойства указаны, где это возможно, для stock objects, определённых в этом перечислении.
