Перечисление ColorSpace используется для указания, когда включать и выключать цветовую проверку, а также когда удалять преобразования.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfColorSpace

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| CS_DELETE_TRANSFORM | Если управление цветом включено для целевого профиля, отключает его и удаляет объединённое преобразование. |
| CS_DISABLE | Отключает проверку цвета. |
| CS_ENABLE | Отображает цвета в цветовой gamut целевого устройства. Это включает проверку цвета. <br/>            Все последующие команды рисования в контексте устройства воспроизведения будут отображать цвета так, как они выглядели бы на целевом устройстве. |
