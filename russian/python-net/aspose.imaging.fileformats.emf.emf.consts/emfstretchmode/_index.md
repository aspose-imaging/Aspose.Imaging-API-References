Перечисление StretchMode используется для указания того, как цветовые данные добавляются или удаляются из растровых изображений, которые растягиваются или сжимаются.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfStretchMode

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| STRETCH_ANDSCANS | Выполняет логическую операцию И, используя значения цветов для удалённых и существующих пикселей.<br/>            Если растровое изображение монохромное, этот режим сохраняет чёрные пиксели за счёт белых пикселей |
| STRETCH_DELETESCANS | Удаляет пиксели. Этот режим удаляет все удалённые линии пикселей, не пытаясь сохранять их информацию. |
| STRETCH_HALFTONE | Отображает пиксели из исходного прямоугольника в блоки пикселей в целевом прямоугольнике. <br/>            Средний цвет блока целевых пикселей приближён к цвету исходных пикселей. |
| STRETCH_ORSCANS | Выполняет логическую операцию ИЛИ, используя значения цветов для удалённых и существующих пикселей. <br/>            Если растровое изображение монохромное, этот режим сохраняет белые пиксели за счёт чёрных пикселей. |
