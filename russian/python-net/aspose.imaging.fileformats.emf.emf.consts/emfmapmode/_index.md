Перечисление MapMode используется для определения единицы измерения при преобразовании единиц пространства страницы <br/>            в единицы пространства устройства и для задания ориентации осей рисования.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfMapMode

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| MM_ANISOTROPIC | Логические единицы отображаются в произвольные единицы с произвольно масштабированными осями. <br/>            Записи EMR_SETWINDOWEXTEX и EMR_SETVIEWPORTEXTEX SHOULD быть использованы для указания единиц, <br/>            ориентации и масштабирования. |
| MM_HIENGLISH | Каждая логическая единица отображается в 0.001 дюйма. Положительная x направлена вправо; положительная y направлена вверх. |
| MM_HIMETRIC | Каждая логическая единица отображается в 0.01 миллиметра. Положительная x направлена вправо; положительная y направлена вверх. |
| MM_ISOTROPIC | Логические единицы отображаются в произвольные единицы с одинаково масштабированными осями; то есть одна единица <br/>            вдоль оси x равна одной единице вдоль оси y. Записи EMR_SETWINDOWEXTEX и <br/>            EMR_SETVIEWPORTEXTEX SHOULD быть использованы для указания единиц и ориентации <br/>            осей.<br/>            Корректировки MUST быть выполнены по мере необходимости, чтобы обеспечить одинаковый размер единиц по осям x и y. <br/>            Например, когда задаётся размер окна, область просмотра MUST быть скорректирована, чтобы сохранить изотропность единиц. |
| MM_LOENGLISH | Каждая логическая единица отображается в 0.01 дюйма. Положительная x направлена вправо; положительная y направлена вверх |
| MM_LOMETRIC | Каждая логическая единица отображается в 0.1 миллиметра. Положительная x направлена вправо; положительная y направлена вверх. |
| MM_TEXT | Каждая логическая единица отображается в один пиксель устройства. Положительная x направлена вправо; положительная y направлена вниз. |
| MM_TWIPS | Каждая логическая единица отображается в одну двадцатую часть точки принтера <br/>            (1/1440 дюйма, также называемую "twip"). Положительная x направлена вправо; положительная y направлена вверх. |
