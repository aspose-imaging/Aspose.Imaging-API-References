Перечисление ExtTextOutOptions задает параметры, контролирующие различные аспекты<br/>            вывода текста записями EMR_SMALLTEXTOUT (раздел 2.3.5.37) и объектами EmrText.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfExtTextOutOptions

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| ETO_CLIPPED | Этот бит указывает, что текст ДОЛЖЕН быть обрезан до прямоугольника. |
| ETO_GLYPH_INDEX | Этот бит указывает, что коды символов в строке выводимого текста являются фактически <br/>            индексами глифов символов в шрифте TrueType. Индексы глифов зависят от шрифта, <br/>            поэтому для правильного отображения символов при воспроизведении используемый шрифт ДОЛЖЕН быть <br/>            идентичен шрифту, использованному для генерации индексов. |
| ETO_IGNORELANGUAGE | Этот бит указывает, что никакая специальная обработка операционной системы для размещения глифов не должна быть <br/>            выполнена для строк справа налево; то есть все позиционирование глифов ДОЛЖНО обрабатываться <br/>            отрисовкой и записями состояния в метафайле |
| ETO_NO_RECT | Этот бит указывает, что запись не определяет ограничивающий прямоугольник для вывода текста. |
| ETO_NUMERICSLATIN | Этот бит указывает, что для отображения чисел ДОЛЖНЫ использоваться европейские цифры. |
| ETO_NUMERICSLOCAL | Этот бит указывает, что для отображения чисел ДОЛЖНЫ использоваться цифры, соответствующие локали. |
| ETO_OPAQUE | Этот бит указывает, что текущий цвет фона ДОЛЖЕН использоваться для заполнения прямоугольника. |
| ETO_PDY | Этот бит указывает, что оба значения смещения символов по горизонтали и вертикали ДОЛЖНЫ быть предоставлены |
| ETO_REVERSE_INDEX_MAP | Этот бит зарезервирован и НЕ ДОЛЖЕН использоваться |
| ETO_RTLREADING | Этот бит указывает, что текст ДОЛЖЕН быть размещён в порядке чтения справа налево, <br/>            вместо стандартного порядка слева направо. Это ДОЛЖНО применяться только когда шрифт<br/>            выбранный в контекст устройства воспроизведения является либо еврейским, либо арабским |
| ETO_SMALL_CHARS | Этот бит указывает, что коды символов в выходной строке текста являются 8‑битными, <br/>            полученными из младших байтов 16‑битных кодов Unicode UTF16-LE, <br/>            при этом старший байт считается равным 0. |
