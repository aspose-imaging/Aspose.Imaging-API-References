Перечисление RegionMode определяет значения, которые используются с EMR_SELECTCLIPPATH и EMR_EXTSELECTCLIPRGN, <br/>            указывая текущий путь или новую область, которая комбинируется с текущей областью отсечения.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfRegionMode

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| RGN_AND | Новый регион отсечения включает пересечение (перекрывающиеся области) текущего региона отсечения и текущего пути (или нового региона). |
| RGN_COPY | Новый регион отсечения — это текущий путь (или новый регион). |
| RGN_DIFF | Новый регион отсечения включает области текущего региона отсечения, исключая области текущего пути (или нового региона). |
| RGN_OR | Новый регион отсечения включает объединение (совмещённые области) текущего региона отсечения и текущего пути (или нового региона). |
| RGN_XOR | Новый регион отсечения включает объединение текущего региона отсечения и текущего пути (или нового региона), но без перекрывающихся областей. |
