Модуль предоставляет вспомогательные классы и методы для работы с различными типами кистей.

## **Classes**
| **Class** | **Description** |
| :- | :- |
| [HatchBrush](/imaging/python-net/aspose.imaging.brushes/hatchbrush/) | Определяет прямоугольную кисть с штриховкой, цветом переднего плана и цветом фона. Этот класс не может быть унаследован. |
| [LinearGradientBrush](/imaging/python-net/aspose.imaging.brushes/lineargradientbrush/) | Инкапсулирует [Brush](/imaging/python-net/aspose.imaging/brush/) с линейным градиентом. Этот класс не может быть унаследован. |
| [LinearGradientBrushBase](/imaging/python-net/aspose.imaging.brushes/lineargradientbrushbase/) | Представляет [Brush](/imaging/python-net/aspose.imaging/brush/) с возможностями градиента и соответствующими свойствами. |
| [LinearMulticolorGradientBrush](/imaging/python-net/aspose.imaging.brushes/linearmulticolorgradientbrush/) | Представляет [Brush](/imaging/python-net/aspose.imaging/brush/) с линейным градиентом, определённым несколькими цветами и соответствующими позициями. Этот класс не может быть унаследован. |
| [PathGradientBrush](/imaging/python-net/aspose.imaging.brushes/pathgradientbrush/) | Инкапсулирует объект [Brush](/imaging/python-net/aspose.imaging/brush/) с градиентом. Этот класс не может быть унаследован. |
| [PathGradientBrushBase](/imaging/python-net/aspose.imaging.brushes/pathgradientbrushbase/) | Представляет [Brush](/imaging/python-net/aspose.imaging/brush/) с функцией градиента базового пути. |
| [PathMulticolorGradientBrush](/imaging/python-net/aspose.imaging.brushes/pathmulticolorgradientbrush/) | Инкапсулирует объект [Brush](/imaging/python-net/aspose.imaging/brush/) с градиентом. Этот класс не может быть унаследован. |
| [SolidBrush](/imaging/python-net/aspose.imaging.brushes/solidbrush/) | Твёрдая кисть предназначена для непрерывного рисования определённым цветом. Этот класс не может быть унаследован. |
| [TextureBrush](/imaging/python-net/aspose.imaging.brushes/texturebrush/) | Каждое свойство класса [TextureBrush](/imaging/python-net/aspose.imaging.brushes/texturebrush/) является объектом [Brush](/imaging/python-net/aspose.imaging/brush/), который использует изображение для заполнения внутренней части фигуры. Этот класс не может быть унаследован. |
| [TransformBrush](/imaging/python-net/aspose.imaging.brushes/transformbrush/) | Кисть [Brush](/imaging/python-net/aspose.imaging/brush/) с возможностями трансформации. |
