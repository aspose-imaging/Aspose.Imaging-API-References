Указывает, как графика должна обрабатываться после отображения.

**Module:** [aspose.imaging.fileformats.gif](/imaging/python-net/aspose.imaging.fileformats.gif/)

**Full Name:** aspose.imaging.fileformats.gif.DisposalMethod

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| NONE | Не указано удаление. |
| PRESERVE | Не удалять. Графика должна оставаться на месте. |
| PREVIUOS | Восстановить предыдущее. Декодер должен восстановить область, перезаписанную графикой, тем, что было там до рендеринга графики. |
| RESTORE | Восстановить фон. Область, используемая графикой, должна быть восстановлена к цвету фона. |
| UNDEFINED | Неопределённое значение. |
