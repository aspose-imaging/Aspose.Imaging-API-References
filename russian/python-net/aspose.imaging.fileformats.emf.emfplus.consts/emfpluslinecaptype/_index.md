Перечисление LineCapType определяет типы окончаний линий, используемых на концах линий, нарисованных графическими перьями.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusLineCapType

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| LINE_CAP_TYPE_ANCHOR_MASK | Маска, используемая для проверки, является ли окончание линии якорной крышкой. |
| LINE_CAP_TYPE_ARROW_ANCHOR | Указывает, что конец линии зафиксирован в виде стрелки. Кончик стрелки MUST быть расположен в последней точке линии. Стрелка SHOULD быть шире линии. |
| LINE_CAP_TYPE_CUSTOM | Указывает пользовательскую форму конца линии. |
| LINE_CAP_TYPE_DIAMOND_ANCHOR | Указывает, что конец линии зафиксирован в виде ромбовидной крышки, представляющей собой квадрат, повернутый на 45 градусов. Центр ромба MUST находиться в последней точке линии. Ромб SHOULD быть шире линии. |
| LINE_CAP_TYPE_FLAT | Указывает на квадратную крышку линии. Конец линии MUST быть последней точкой линии. |
| LINE_CAP_TYPE_NO_ANCHOR | Указывает, что конец линии не зафиксирован. |
| LINE_CAP_TYPE_ROUND | Указывает на круглую крышку линии. Центр круга MUST находиться в последней точке линии. Диаметр круга равен ширине линии. |
| LINE_CAP_TYPE_ROUND_ANCHOR | Указывает, что конец линии зафиксирован в виде круглой крышки. Центр круга MUST находиться в последней точке линии. Круг SHOULD быть шире линии. |
| LINE_CAP_TYPE_SQUARE | Указывает квадратную заглушку линии. Центр квадрата ДОЛЖЕН находиться в последней точке линии. Ширина квадрата равна ширине линии. |
| LINE_CAP_TYPE_SQUARE_ANCHOR | Указывает, что конец линии зафиксирован квадратной заглушкой. Центр квадрата ДОЛЖЕН находиться в последней точке линии. Высота и ширина квадрата равны ширине линии. |
| LINE_CAP_TYPE_TRIANGLE | Указывает треугольную заглушку линии. Основание треугольника ДОЛЖНО находиться в последней точке линии. Основание треугольника равно ширине линии. |
