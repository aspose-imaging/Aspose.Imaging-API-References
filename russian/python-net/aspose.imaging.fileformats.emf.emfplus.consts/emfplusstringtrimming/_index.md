Перечисление StringTrimming определяет, как обрезать символы в строке, которая слишком велика для прямоугольника размещения текста.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusStringTrimming

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| STRING_TRIMMING_CHARACTER | Указывает, что строка обрезается на границе последнего символа, находящегося внутри прямоугольника разметки. Это значение по умолчанию. |
| STRING_TRIMMING_ELLIPSIS_CHARACTER | Указывает, что строка обрезается на границе последнего символа, находящегося внутри прямоугольника разметки, и после символа вставляется многоточие (...). |
| STRING_TRIMMING_ELLIPSIS_PATH | Указывает, что центр удаляется из строки и заменяется многоточием. Алгоритм сохраняет как можно большую часть последней части строки. |
| STRING_TRIMMING_ELLIPSIS_WORD | Указывает, что строка обрезается на границе последнего слова, находящегося внутри прямоугольника разметки, и после слова вставляется многоточие (...). |
| STRING_TRIMMING_NONE | Указывает, что обрезка не выполняется. |
| STRING_TRIMMING_WORD | Указывает, что строка разрывается на границе последнего слова, находящегося внутри прямоугольника макета. |
