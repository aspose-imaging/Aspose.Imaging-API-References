Перечисление CurveAdjustments определяет коррекции, которые могут быть применены к цветовой кривой изображения.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusCurveAdjustments

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| ADJUST_BLACK_SATURATION | Указывает корректировку черной насыщенности изображения, которая представляет собой минимальное значение в диапазоне интенсивностей для данного цветового канала, обычно от 0 до 255. |
| ADJUST_CONTRAST | Указывает увеличение или уменьшение контраста изображения. |
| ADJUST_DENSITY | Указывает имитацию увеличения или уменьшения плотности изображения. |
| ADJUST_EXPOSURE | Указывает имитацию увеличения или уменьшения экспозиции изображения. |
| ADJUST_HIGHLIGHT | Указывает увеличение или уменьшение значения цветового канала изображения, если этот канал уже имеет значение выше половины интенсивности. Эта корректировка может использоваться для повышения детализации в светлых областях изображения без воздействия на темные области. |
| ADJUST_MIDTONE | Указывает корректировку, которая осветляет или затемняет изображение. Значения цветовых каналов в середине диапазона интенсивности изменяются сильнее, чем значения каналов, близкие к минимальным или максимальным экстремумам интенсивности. Эта корректировка может использоваться для осветления или затемнения изображения без потери контраста между самыми темными и самыми светлыми частями изображения. |
| ADJUST_SHADOW | Указывает увеличение или уменьшение значения цветового канала изображения, если этот канал уже имеет значение ниже половины интенсивности. Эта корректировка может использоваться для повышения детализации в темных областях изображения без воздействия на светлые области. |
| ADJUST_WHITE_SATURATION | Указывает корректировку белой насыщенности изображения, определяемую как максимальное значение в диапазоне интенсивностей для данного цветового канала, обычно от 0 до 255. |
