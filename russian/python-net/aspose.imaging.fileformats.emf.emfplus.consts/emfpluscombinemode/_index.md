Перечисление CombineMode определяет режимы объединения двух графических областей. <br/>            В последующих описаниях объединяемые области называют «существующей» и «новой» областями.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusCombineMode

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| COMBINE_MODE_COMPLEMENT | Заменяет существующий регион частью нового региона, которой нет в существующем регионе. |
| COMBINE_MODE_EXCLUDE | Заменяет существующий регион частью самого себя, которой нет в новом регионе. |
| COMBINE_MODE_INTERSECT | Заменяет существующий регион пересечением существующего региона и нового региона. |
| COMBINE_MODE_REPLACE | Заменяет существующий регион новым регионом. |
| COMBINE_MODE_UNION | Заменяет существующий регион объединением существующего и нового регионов. |
| COMBINE_MODE_XOR | Заменяет существующий регион операцией XOR между существующим и новым регионами. |
