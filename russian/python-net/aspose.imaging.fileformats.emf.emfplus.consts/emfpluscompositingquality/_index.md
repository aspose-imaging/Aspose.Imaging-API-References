Перечисление CompositingQuality определяет уровни качества при создании композитных изображений

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusCompositingQuality

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| COMPOSITING_QUALITY_ASSUME_LINEAR | Гамма‑коррекция не применяется; однако использование линейных значений дает лучшее качество, чем значение по умолчанию, при слегка более низкой скорости. |
| COMPOSITING_QUALITY_DEFAULT | Гамма‑коррекция не применяется. Гамма‑коррекция управляет общей яркостью и контрастностью изображения. Без гамма‑коррекции составные изображения могут выглядеть слишком светлыми или слишком тёмными. |
| COMPOSITING_QUALITY_GAMMA_CORRECTED | Включите гамма‑коррекцию для более качественного составления при более низкой скорости. По результату нет различий между этим значением и CompositingQualityHighQuality. |
| COMPOSITING_QUALITY_HIGH_QUALITY | Гамма‑коррекция применяется. Качество составления предпочтительно за счёт скорости. |
| COMPOSITING_QUALITY_HIGH_SPEED | Гамма‑коррекция не применяется. Скорость составления предпочтительна за счёт качества. По результату нет различий между этим значением и CompositingQualityDefault. |
