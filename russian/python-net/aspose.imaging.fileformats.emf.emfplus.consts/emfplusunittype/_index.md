Перечисление UnitType определяет единицы измерения в различных системах координат.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusUnitType

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| UNIT_TYPE_DISPLAY | Указывает единицу измерения расстояния, основанную на характеристиках физического дисплея.<br/>            Например, если устройство отображения — монитор, то единица равна 1 пикселю. |
| UNIT_TYPE_DOCUMENT | Указывает единицу измерения 1/300 дюйма. |
| UNIT_TYPE_INCH | Указывает единицу измерения 1 дюйм. |
| UNIT_TYPE_MILLIMETER | Указывает единицу измерения 1 миллиметр. |
| UNIT_TYPE_PIXEL | Указывает единицу измерения 1 пиксель. |
| UNIT_TYPE_POINT | Указывает единицу измерения 1 пункт принтера, или 1/72 дюйма. |
| UNIT_TYPE_WORLD | Указывает единицу логического расстояния внутри мирового пространства. |
