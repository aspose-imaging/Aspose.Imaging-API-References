Флаги DriverStringOptions указывают свойства позиционирования и рендеринга графического текста. Эти флаги могут комбинироваться для указания нескольких вариантов.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusDriverStringOptionsFlags

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| DRIVER_STRING_OPTIONS_CMAP_LOOKUP | Если установлен, позиции глифов символов SHOULD быть указаны в таблице поиска карты символов.<br/>            Если сброшен, позиции глифов SHOULD быть получены из массива координат. |
| DRIVER_STRING_OPTIONS_LIMIT_SUBPIXEL | Если установлен, меньше памяти SHOULD использоваться для кэширования сглаженных глифов, что приводит к более низкому качеству отображения текста.<br/>            Если сброшен, больше памяти SHOULD использоваться, что приводит к более высокому качеству отображения текста. |
| DRIVER_STRING_OPTIONS_REALIZED_ADVANCE | Если установлен, позиции глифов символов ДОЛЖНЫ рассчитываться относительно позиции первого глифа.<br/>            Если сброшен, позиции глифов ДОЛЖНЫ получаться из массива координат. |
| DRIVER_STRING_OPTIONS_VERTICAL | Если установлен, строка ДОЛЖНА отображаться вертикально.<br/>            Если сброшен, строка ДОЛЖНА отображаться горизонтально. |
