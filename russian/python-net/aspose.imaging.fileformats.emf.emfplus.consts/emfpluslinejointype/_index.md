Перечисление LineJoinType определяет способы соединения двух линий, нарисованных одним и тем же графическим пером, и чьи концы соприкасаются.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusLineJoinType

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| LINE_JOIN_TYPE_BEVEL | Указывает скосное соединение линий. |
| LINE_JOIN_TYPE_MITER | Указывает соединение линий в виде острого угла. |
| LINE_JOIN_TYPE_MITER_CLIPPED | Указывает обрезанное соединение линий в виде острого угла. |
| LINE_JOIN_TYPE_ROUND | Указывает скругленное соединение линий. |
