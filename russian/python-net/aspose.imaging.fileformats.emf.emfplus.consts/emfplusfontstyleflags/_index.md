Флаги FontStyle указывают стили графических шрифтов. Эти флаги можно комбинировать для указания нескольких вариантов.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusFontStyleFlags

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| FONT_STYLE_BOLD | Если установлен, гарнитура шрифта ДОЛЖНА отображаться с более тяжелым весом или толщиной.<br/>
            Если сброшен, гарнитура шрифта ДОЛЖНА отображаться с обычной толщиной. |
| FONT_STYLE_ITALIC | Если установлен, шрифт MUST отображаться с вертикальными штрихами символов под увеличенным углом или наклоном относительно базовой линии.<br/>Если сброшен, шрифт MUST отображаться с вертикальными штрихами символов под обычным углом. |
| FONT_STYLE_STRIKEOUT | Если установлен, шрифт MUST отображаться линией, параллельной базовой линии, проведённой через середину символов.<br/>Если сброшен, шрифт MUST отображаться без линии, проходящей через символы. |
| FONT_STYLE_UNDERLINE | Если установлен, шрифт MUST отображаться линией под базовой линией символов.<br/>Если сброшен, шрифт MUST отображаться без линии под базовой линией. |
