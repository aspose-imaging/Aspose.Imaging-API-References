Перечисление SmoothingMode определяет режимы сглаживания, применяемые к линиям, кривым и краям заполненных областей, чтобы они выглядели более непрерывными или чётко определёнными.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusSmoothingMode

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| SMOOTHING_MODE_ANTI_ALIAS_8X4 | Указывает хорошее качество с использованием 8x4 коробочного фильтра. |
| SMOOTHING_MODE_ANTI_ALIAS_8X8 | Указывает лучшее качество с использованием 8x8 коробочного фильтра. |
| SMOOTHING_MODE_DEFAULT | Указывает сглаживание кривой по умолчанию без антиалиасинга. |
| SMOOTHING_MODE_HIGH_QUALITY | Указывает наилучшее качество с антиалиасингом. |
| SMOOTHING_MODE_HIGH_SPEED | Указывает наилучшую производительность без антиалиасинга. |
| SMOOTHING_MODE_NONE | Не выполняет сглаживание кривой и не использует антиалиасинг. |
