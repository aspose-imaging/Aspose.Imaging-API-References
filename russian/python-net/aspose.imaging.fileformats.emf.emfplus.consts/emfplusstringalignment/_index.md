Перечисление StringAlignment определяет способы выравнивания строк относительно прямоугольника размещения текста.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusStringAlignment

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| STRING_ALIGNMENT_CENTER | Указывает, что выравнивание центрировано между началом и размером прямоугольника макета. |
| STRING_ALIGNMENT_FAR | Указывает, что выравнивание находится с правой стороны прямоугольника макета. |
| STRING_ALIGNMENT_NEAR | Указывает, что выравнивание строки направлено к началу координат прямоугольника макета. Это можно использовать для выравнивания символов вдоль линии или для выравнивания текста внутри прямоугольника. Для прямоугольника макета справа налево начало координат ДОЛЖНО находиться в верхнем правом углу. |
