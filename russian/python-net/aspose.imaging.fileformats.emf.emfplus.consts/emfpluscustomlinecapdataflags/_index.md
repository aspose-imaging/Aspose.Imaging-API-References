Флаги CustomLineCapData указывают данные для пользовательских окончаний линий. Эти флаги могут комбинироваться для указания нескольких вариантов.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusCustomLineCapDataFlags

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| CUSTOM_LINE_CAP_DATA_FILL_PATH | Если установлен, объект [EmfPlusFillPath](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusfillpath/) ДОЛЖЕН быть указан в поле OptionalData объекта [EmfPlusCustomLineCapData](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecapdata/) для заполнения пользовательской конечной линии. |
| CUSTOM_LINE_CAP_DATA_LINE_PATH | Если установлен, объект [EmfPlusLinePath](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfpluslinepath/) ДОЛЖЕН быть указан в поле OptionalData объекта EmfPlusCustomLineCapData для обрисовки пользовательской конечной линии. |
