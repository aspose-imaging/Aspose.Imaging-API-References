Модуль обрабатывает формат файлов Jpeg.

## **Classes**
| **Class** | **Description** |
| :- | :- |
| [JFIFData](/imaging/python-net/aspose.imaging.fileformats.jpeg/jfifdata/) | Этот jfif segment. |
| [JpegImage](/imaging/python-net/aspose.imaging.fileformats.jpeg/jpegimage/) | Эффективно манипулировать растровыми изображениями JPEG с помощью нашего API, предлагая поддержку<br/>            различных цветовых профилей, таких как RGB и CMYK, настраиваемое количество бит на пиксель<br/>            разрешения и обработку контейнеров метаданных EXIF, JFIF и XMP.<br/>            Наслаждайтесь автоматическим вращением на основе данных ориентации и выбирайте из разных<br/>            уровней сжатия, включая без потерь JPEG, чтобы достичь оптимального качества изображения<br/>            и баланса размера файла для ваших проектов. |
| [JpegLsPresetCodingParameters](/imaging/python-net/aspose.imaging.fileformats.jpeg/jpeglspresetcodingparameters/) | Определяет предустановленные параметры кодирования JPEG‑LS, как указано в ISO/IEC 14495-1, C.2.4.1.1.<br/>            JPEG‑LS определяет набор параметров по умолчанию, но могут использоваться пользовательские параметры.<br/>            При использовании эти параметры записываются в закодированный битовый поток, поскольку они необходимы для процесса декодирования. |
