Определяет режим чередования для многокомпонентных (цветных) пиксельных данных.

**Module:** [aspose.imaging.fileformats.jpeg](/imaging/python-net/aspose.imaging.fileformats.jpeg/)

**Full Name:** aspose.imaging.fileformats.jpeg.JpegLsInterleaveMode

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| LINE | Режим чередования — по строке. Полная строка каждого компонента кодируется перед переходом к следующей строке. |
| NONE | Данные кодируются и хранятся по компонентам: RRRGGGBBB. |
| SAMPLE | Данные кодируются и хранятся по образцам. Для цветных изображений это формат типа RGBRGBRGB. |
