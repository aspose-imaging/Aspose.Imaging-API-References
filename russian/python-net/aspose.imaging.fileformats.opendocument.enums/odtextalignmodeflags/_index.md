Флаги режима выравнивания текста открытого документа

**Module:** [aspose.imaging.fileformats.opendocument.enums](/imaging/python-net/aspose.imaging.fileformats.opendocument.enums/)

**Full Name:** aspose.imaging.fileformats.opendocument.enums.OdTextAlignModeFlags

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| BASELINE | Точка отсчёта ДОЛЖНА находиться на базовой линии текста. |
| BOTTOM | Точка отсчёта ДОЛЖНА находиться на нижнем крае ограничивающего прямоугольника. |
| CENTER | Точка отсчёта MUST быть выровнена горизонтально относительно центра ограничивающего прямоугольника. |
| HORIZONTAL | Представляет наборы горизонтального выравнивания текста (Left | Right | Center) |
| ВЫРАВНИТЬ | Текст должен быть выровнен так, чтобы каждая строка абзаца имела одинаковую длину. |
| LEFT | Точка отсчёта ДОЛЖНА находиться на левом крае ограничивающего прямоугольника. |
| NOUPDATECP | Позиция рисования в контексте устройства воспроизведения MUST NOT обновляться после каждого<br/>                вызова вывода текста. Точка отсчёта MUST быть передана функции вывода текста. |
| RIGHT | Точка отсчёта ДОЛЖНА находиться на правом крае ограничивающего прямоугольника. |

| TOP | Точка отсчёта ДОЛЖНА находиться на верхнем крае ограничивающего прямоугольника. |
| UPDATECP | Позиция рисования в контексте устройства воспроизведения MUST быть обновлена после каждого<br/>                вызова вывода текста. Она MUST использоваться в качестве точки отсчёта. |
| VERTICAL | Представляет наборы вертикального выравнивания текста (Верх | Bottom | Baseline) |
