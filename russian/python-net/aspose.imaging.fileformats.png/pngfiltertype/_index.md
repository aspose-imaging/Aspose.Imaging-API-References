**Module:** [aspose.imaging.fileformats.png](/imaging/python-net/aspose.imaging.fileformats.png/)

**Full Name:** aspose.imaging.fileformats.png.PngFilterType

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| ADAPTIVE | Адаптивная фильтрация, означает, что процесс сохранения выберет наиболее подходящий фильтр для каждой строки данных. Наилучшее сжатие, самая медленная скорость выполнения. |
| AVG | Фильтр avg, означает, что к данным изображения будет применён средний фильтр. |
| NONE | Фильтр null-filter, означает отсутствие фильтрации строк данных изображения. |
| PAETH | Фильтр предсказателя paeth. |
| SUB | Фильтр sub, означает, что к данным изображения будет применена субтрактивная фильтрация. |
| UP | Фильтр up, означает, что будет применён построчный фильтр вычитания. |
