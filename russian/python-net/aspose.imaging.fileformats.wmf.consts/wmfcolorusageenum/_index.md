Перечисление ColorUsage определяет, существует ли таблица цветов в независимом от устройства<br/>                растровом изображении (DIB) и как интерпретировать её значения.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfColorUsageEnum

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| DIB_PAL_COLORS | Таблица цветов содержит 16-битные индексы в текущую логическую палитру в контексте устройства воспроизведения. |
| DIB_PAL_INDICES | Таблица цветов не существует. Пиксели в DIB являются индексами в текущую<br/>                логическую палитру в контексте устройства воспроизведения. |
| DIB_RGB_COLORS | Таблица цветов содержит значения RGB, указанные объектами RGBQuad (раздел 2.2.2.20). |
