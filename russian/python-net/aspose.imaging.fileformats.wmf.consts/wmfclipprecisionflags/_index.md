Флаги ClipPrecision определяют точность обрезки, которая задаёт, как обрезать символы, находящиеся<br/>                частично за пределами области обрезки. Эти флаги можно комбинировать для указания нескольких вариантов.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfClipPrecisionFlags

| DFA_DISABLE | Это значение указывает, что ассоциация шрифтов ДОЛЖНА [35] быть отключена.<br/>                [35] Это значение не поддерживается в Windows 95, Windows 98 и Windows Millennium Edition.<br/>                Ассоциация шрифтов отключена в Windows 2000, Windows XP и Windows Server 2003.<br/>                Это значение игнорируется в следующих версиях Windows:<br/>                - Windows Vista<br/>                - Windows Server 2008<br/>                - Windows 7<br/>                - Windows Server 2008 R2<br/>                - Windows 8<br/>                - Windows Server 2012<br/>                - Windows 8.1<br/>                - Windows Server 2012 R2 |
