Перечисление BrushStyle определяет различные возможные типы кистей<br/>                которые могут использоваться в графических операциях. Для получения дополнительной информации см.<br/>                спецификацию объекта Brush (раздел 2.2.1.1).

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfBrushStyle

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| DIBPATTERN | Кисть с узором, заданная DIB. |
| DIBPATTERNPT | Кисть с узором, заданная DIB. |
| DIBPATTERN_8X8 | Не поддерживается. |
| GRADIENT | Градиент<br/>            Не поддерживается в wmf, поддерживается в odg. |
| HATCHED | Кисть, которая наносит предопределённый простой узор, или "штриховку", на сплошной фон |
| INDEXED | Не поддерживается. |
| MONOPATTERN | Не поддерживается. |
| NULL | Кисть, которая ничего не делает. Использование NULL‑кисти в графической операции<br/>                ДОЛЖНО иметь тот же эффект, что и отсутствие кисти вовсе |
| PATTERN | Кисть, которая наносит узор, определённый битмапом, который МОЖЕТ быть объектом Bitmap16<br/>                или объектом DeviceIndependentBitmap (DIB). |
| PATTERN_8X8 | Не поддерживается. |
| SOLID | Кисть, которая наносит один, постоянный цвет, либо сплошной, либо с диффузией. |
