Флаги VerticalTextAlignmentMode указывают взаимосвязь между опорной точкой и<br/>                ограничивающим прямоугольником для выравнивания текста. Эти флаги можно комбинировать для указания нескольких вариантов,<br/>                при этом ограничение состоит в том, что может быть выбран только один флаг, изменяющий позицию рисования в контексте устройства воспроизведения.<br/>                Вертикальное выравнивание текста выполняется, когда шрифт имеет вертикальную базовую линию по умолчанию, например, кандзи.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfVerticalTextAlignmentModeFlags

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| VTA_BASELINE | Точка отсчёта ДОЛЖНА находиться на базовой линии текста. |
| VTA_BOTTOM | Точка отсчёта ДОЛЖНА находиться на нижнем крае ограничивающего прямоугольника. |
| VTA_CENTER | Точка отсчёта ДОЛЖНА быть выровнена по вертикали с центром ограничивающего прямоугольника. |
| VTA_LEFT | Точка отсчёта ДОЛЖНА находиться на левом крае ограничивающего прямоугольника. |
| VTA_RIGHT | Точка отсчёта ДОЛЖНА находиться на правом крае ограничивающего прямоугольника. |
| VTA_TOP | Точка отсчёта ДОЛЖНА находиться на верхнем крае ограничивающего прямоугольника. |
