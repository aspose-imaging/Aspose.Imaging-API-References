Перечисление FamilyFont определяет семейство шрифтов. Семейства шрифтов описывают внешний вид шрифта в<br/>                общем виде. Они предназначены для указания шрифтов, когда требуемый точный тип шрифта недоступен.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfFamilyFont

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| DECORATIVE | Шрифты декоративного стиля. "Old English" является примером. |
| DONTCARE | Указывается шрифт по умолчанию, который зависит от реализации. |
| MODERN | Шрифты с постоянной толщиной штриха, с засечками или без. Шрифты фиксированной ширины обычно являются современными.<br/>                "Pica", "Elite" и "Courier New" являются примерами. |
| ROMAN | Шрифты с переменной толщиной штриха, которые пропорциональны фактической ширине глифов,<br/>                и имеют засечки. "MS Serif" является примером. |
| SCRIPT | Шрифты, имитирующие рукописный текст. "Script" и "Cursive" являются примерами. |
| SWISS | Шрифты с переменной толщиной штриха, которые пропорциональны фактической ширине глифов,<br/>                и не имеют засечек. "MS Sans Serif" является примером. |
