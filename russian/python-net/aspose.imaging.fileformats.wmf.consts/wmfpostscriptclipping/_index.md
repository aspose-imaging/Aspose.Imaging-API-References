Перечисление PostScriptClipping определяет функции, которые могут применяться к пути обрезки<br/>                используемого для вывода PostScript.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfPostScriptClipping

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| CLIP_INCLUSIVE | Пересекает текущий путь отсечения PostScript с текущим путем отсечения<br/>                и сохраняет результат как новый путь отсечения PostScript. |
| CLIP_RESTORE | Восстанавливает путь отсечения PostScript до последнего пути отсечения, который был сохранён<br/>                предыдущей функцией CLIP_SAVE, применённой записью CLIP_TO_PATH (раздел 2.3.6.6). |
| CLIP_SAVE | Сохраняет текущий путь отсечения PostScript. |
