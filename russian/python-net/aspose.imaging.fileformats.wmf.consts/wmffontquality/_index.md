Перечисление FontQuality определяет, насколько точно атрибуты логического шрифта должны соответствовать<br/>                атрибутам физического шрифта при отображении текста.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfFontQuality

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| ANTIALIASED | Указывает, что сглаживание ДОЛЖНО использоваться при рендеринге текста, если<br/>                шрифт поддерживает его. |
| CLEARTYPE | Указывает, что сглаживание ClearType ДОЛЖНО использоваться при<br/>                рендеринге текста, если шрифт его поддерживает. |
| ПО УМОЛЧАНИЮ | Указывает, что качество символов шрифта не имеет значения, поэтому<br/>                можно использовать DRAFT. |
| DRAFT | Указывает, что качество символов шрифта менее важно, чем<br/>                соответствие логических атрибутов. Для растровых шрифтов масштабирование ДОЛЖНО быть включено, что<br/>                означает, что доступно больше размеров шрифта. |
| NONANTIALIASED | Указывает, что сглаживание НЕ ДОЛЖНО использоваться при<br/>                рендеринге текста. |
| PROOF | Указывает, что качество символов шрифта важнее, чем<br/>                соответствие логических атрибутов. Для растровых шрифтов масштабирование ДОЛЖНО быть отключено, и шрифт<br/>                ближайшего размера ДОЛЖЕН быть выбран. |
