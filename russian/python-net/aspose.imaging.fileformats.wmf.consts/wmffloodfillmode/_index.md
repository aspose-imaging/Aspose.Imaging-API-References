Перечисление FloodFill определяет тип операции заливки, которая будет<br/>                выполнена.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfFloodFillMode

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| FLOOD_FILL_BORDER | Область заливки ограничена цветом, указанным в члене Color.<br/>                Этот стиль идентичен заливке, выполняемой записью<br/>                META_FLOODFILL. |
| FLOOD_FILL_SURFACE | Область заливки ограничена цветом, указанным в члене Color.<br/>                Заливка продолжается наружу во всех направлениях, пока встречается этот цвет. Этот стиль полезен для заливки областей с<br/>                многоцветными границами. |
