Перечисление [StretchMode](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/stretchmode/) определяет режим растягивания растрового изображения<br/>                , который определяет, как система объединяет строки или столбцы<br/>                растрового изображения с существующими пикселями.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.StretchMode

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| BLACK_ON_WHITE | Выполняет логическую операцию AND, используя значения цветов для<br/>                удалённых и существующих пикселей. Если bitmap является монохромным<br/>                bitmap, этот режим сохраняет чёрные пиксели за счёт белых<br/>                пикселей |
| COLOR_ON_COLOR | Удаляет пиксели. Этот режим удаляет все удалённые строки пикселей<br/>                без попытки сохранить их информацию. |
| HALF_TONE | Отображает пиксели из исходного прямоугольника в блоки пикселей в<br/>                целевом прямоугольнике. Средний цвет блока целевых<br/>                пикселей приближён к цвету исходных пикселей. |
| WHITE_ON_BLACK | Выполняет логическую операцию ИЛИ, используя значения цветов для<br/>                удалённых и существующих пикселей. Если bitmap монохромный<br/>                bitmap, этот режим сохраняет белые пиксели за счёт чёрных<br/>                пикселей |
