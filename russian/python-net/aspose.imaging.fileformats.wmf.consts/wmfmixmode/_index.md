Перечисление MixMode указывает режим смешивания фона для текста, штрихованных кистей,<br/>                а также других несолидных стилей пера.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfMixMode

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| OPAQUE | Фон заполняется<br/>                цветом фона, который в данный момент определён в контексте устройства воспроизведения, перед тем как будет нарисован текст, штриховая кисть или перо. |
| TRANSPARENT | Фон остаётся нетронутым. |
