Перечисление CharacterSet определяет возможные наборы глифов символов, которые определены в<br/>                шрифтах для графического вывода.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfCharacterSet

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| ANSI | Указывает набор символов английского языка. |
| ARABIC | Указывает набор символов арабского языка |
| BALTIC | Указывает балтийский (северо-восточноевропейский) набор символов |
| CHINESEBIG5 | Указывает "традиционный" набор китайских символов, используемый в основном в<br/>                Тайване и в Специальных административных районах Гонконга и Макао. |
| ПО УМОЛЧАНИЮ | Указывает набор символов, основанный на текущей системной локали; для<br/>                примера, когда системная локаль — английский (США), набор символов по умолчанию —<br/>                ANSI_CHARSET. |
| EASTEUROPE | Указывает восточноевропейский набор символов. |
| GB2312 | Указывает "упрощённый" набор китайских символов для Китайской Народной Республики. |
| GREEK | Указывает греческий набор символов. |
| HANGUL | Также пишется "Hangeul". Указывает набор символов Hangul корейского языка. |
| HEBREW | Указывает вьетнамский набор символов. |
| JOHAB | Также пишется "Johap". Указывает набор символов Johab корейского языка. |
| MAC | Указывает набор символов Apple Macintosh. |
| OEM | Указывает сопоставление с одной из OEM-страничных кодировок в соответствии с текущей<br/>                настройкой системной локали. |
| РУССКИЙ | Указывает набор символов русского кириллического алфавита. |
| SHIFTJIS | Указывает набор символов японского языка. |
| SYMBOL | Указывает набор символов, состоящий из знаков. |
| THAI | Указывает набор символов тайского языка. |
| TURKISH | Указывает набор символов турецкого языка. |
| VIETNAMESE | Указывает вьетнамский набор символов. |
