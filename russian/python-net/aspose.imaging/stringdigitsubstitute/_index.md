Перечисление указывает, как заменять цифры в строке в соответствии с локалью или языком пользователя.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.StringDigitSubstitute

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| NATIONAL | Указывает цифры‑заменители, соответствующие официальному национальному языку локали пользователя. |
| NONE | Указывает отключить замену. |
| TRADITIONAL | Указывает цифры‑заменители, соответствующие родному письму или языку пользователя, которые могут отличаться от официального национального языка локали пользователя. |
| USER | Указывает пользовательскую схему замены. |
