Указывает доступные стили окончаний, с помощью которых объект [Pen](/imaging/python-net/aspose.imaging/pen/) может завершать линию.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.LineCap

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| ANCHOR_MASK | Указывает пользовательскую форму конца линии. |
| ARROW_ANCHOR | Указывает якорный конец в виде стрелки. |
| CUSTOM | Указывает маску, используемую для проверки, является ли конец линии якорным. |
| DIAMOND_ANCHOR | Указывает ромбовидный якорный конец. |
| FLAT | Указывает плоский конец линии. |
| NO_ANCHOR | Указывает отсутствие привязки. |
| ROUND | Указывает круглое окончание линии. |
| ROUND_ANCHOR | Указывает круглое окончание привязки. |
| SQUARE | Указывает квадратное окончание линии. |
| SQUARE_ANCHOR | Указывает квадратное окончание линии привязки. |
| TRIANGLE | Указывает треугольное окончание линии. |
