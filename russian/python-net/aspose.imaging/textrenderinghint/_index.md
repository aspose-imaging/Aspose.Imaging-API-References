Указывает качество отображения текста.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.TextRenderingHint

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| ANTI_ALIAS | Каждый символ отрисовывается с использованием своего сглаженного растрового глифа без подсказок. Лучшее качество благодаря сглаживанию. Различия в толщине штрихов могут быть заметны, поскольку подсказки отключены. |
| ANTI_ALIAS_GRID_FIT | Каждый символ отрисовывается с использованием его сглаженного (антиалиасинг) растрового глифа с хинтингом. Качество значительно лучше благодаря антиалиасингу, но за счёт более высокой нагрузки на производительность. |
| CLEAR_TYPE_GRID_FIT | Каждый символ отрисовывается с использованием его глифового bitmap ClearType с хинтингом. Наивысшая настройка качества. Используется для получения преимуществ функций шрифта ClearType. |
| SINGLE_BIT_PER_PIXEL | Каждый символ отрисовывается с использованием его глифового bitmap. Хинтинг не используется. |
| SINGLE_BIT_PER_PIXEL_GRID_FIT | Каждый символ отрисовывается с использованием его глифового bitmap. Хинтинг используется для улучшения внешнего вида символов на штрихах и кривизне. |
| SYSTEM_DEFAULT | Каждый символ отрисовывается с использованием его глифового bitmap с системным режимом рендеринга по умолчанию. Текст будет отрисован с учётом настроек сглаживания шрифтов, выбранных пользователем в системе. |
