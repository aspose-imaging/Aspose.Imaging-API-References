Перечисление [InterpolationMode](/imaging/python-net/aspose.imaging/interpolationmode/) указывает алгоритм, используемый при масштабировании или вращении изображений.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.InterpolationMode

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| BICUBIC | Указывает бикубическую интерполяцию. Предфильтрация не выполняется. Этот режим не подходит для уменьшения изображения ниже 25 % от его исходного размера. |
| BILINEAR | Указывает билинейную интерполяцию. Предфильтрация не выполняется. Этот режим не подходит для уменьшения изображения ниже 50 % от его исходного размера. |
| ПО УМОЛЧАНИЮ | Указывает режим по умолчанию. |
| HIGH | Указывает интерполяцию высокого качества. |
| HIGH_QUALITY_BICUBIC | Указывает высококачественную бикубическую интерполяцию. Выполняется предфильтрация для обеспечения высокого качества уменьшения. Этот режим обеспечивает наивысшее качество преобразованных изображений. |
| HIGH_QUALITY_BILINEAR | Указывает высококачественную билинейную интерполяцию. Выполняется предфильтрация для обеспечения высокого качества уменьшения. |
| INVALID | Недопустимый режим интерполяции. |
| LOW | Указывает интерполяцию низкого качества. |
| NEAREST_NEIGHBOR | Указывает интерполяцию ближайшего соседа. |
