Режим восстановления данных.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.DataRecoveryMode

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| CONSISTENT_RECOVER | Последовательный режим восстановления пытается восстановить все данные, пока повреждение не нарушает структуру формата файла, и позволяет корректно продолжать обработку. |
| MAXIMAL_RECOVER | Максимальный режим восстановления восстанавливает все данные, даже если структура формата файла повреждена, и дальнейшая обработка может привести к непредвиденным эффектам. |
| NONE | Восстановление данных не предполагается. При наличии повреждённых данных в формате файла выбрасывается соответствующее исключение. |
