Указывает информацию об отображении и размещении текстовых строк.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.StringFormatFlags

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| DIRECTION_RIGHT_TO_LEFT | Текст отображается справа налево. |
| DIRECTION_VERTICAL | Текст выровнен вертикально. |
| DISPLAY_FORMAT_CONTROL | Управляющие символы, такие как маркер слева направо, отображаются в выводе с помощью представительного глифа. |
| EXACT_ALIGNMENT | Точное выравнивание, правильный отступ GDI+ |
| FIT_BLACK_BOX | Разрешено, чтобы части символов выступали за пределы прямоугольника размещения строки. По умолчанию символы перемещаются, чтобы избежать любого выступания. |
| LINE_LIMIT | Только полные строки размещаются в прямоугольнике форматирования. По умолчанию размещение продолжается до конца текста или пока видимы все строки в результате отсечения, в зависимости от того, что произойдёт первым.<br/>            Обратите внимание, что настройки по умолчанию позволяют последней строке быть частично скрытой прямоугольником форматирования, высота которого не является целым кратным высоте строки. Чтобы гарантировать отображение только полных строк,<br/>            укажите это значение и убедитесь, что прямоугольник форматирования имеет высоту не менее высоты одной строки. |
| MEASURE_TRAILING_SPACES | Включает завершающий пробел в конце каждой строки. По умолчанию ограничивающий прямоугольник, возвращаемый методом MeasureString, исключает пробел в конце каждой строки. Установите этот флаг, чтобы включить этот пробел в измерения. |
| NO_CLIP | Выступающие части глифов и не перенесённый текст, выходящие за пределы прямоугольника форматирования, разрешено отображать. По умолчанию весь текст и части глифов, выходящие за пределы прямоугольника форматирования, обрезаются. |
| NO_FONT_FALLBACK | Отключено использование альтернативных шрифтов для символов, не поддерживаемых запрошенным шрифтом. Любые отсутствующие символы отображаются с помощью отсутствующего глифа шрифта, обычно в виде открытого квадрата. |
| NO_WRAP | Перенос текста между строками при форматировании внутри прямоугольника отключён. Этот флаг подразумевается, когда вместо прямоугольника передаётся точка или когда указанный прямоугольник имеет нулевую длину строки. |
