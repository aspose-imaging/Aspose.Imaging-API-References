Указывает отдельные каналы в цветовом пространстве CMYK (циан, мажента, желтый, чёрный). Это перечисление используется методами SetOutputChannel.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.ColorChannelFlag

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| COLOR_CHANNEL_C | Циановый цветовой канал. |
| COLOR_CHANNEL_K | Черный цветовой канал. |
| COLOR_CHANNEL_LAST | Следует использовать последний выбранный канал. |
| COLOR_CHANNEL_M | Пурпурный цветовой канал. |
| COLOR_CHANNEL_Y | Желтый цветовой канал. |
