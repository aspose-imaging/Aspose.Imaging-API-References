Указывает, как обрезать символы в строке, которая не полностью помещается в форму размещения.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.StringTrimming

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| CHARACTER | Указывает, что текст обрезается до ближайшего символа. |
| ELLIPSIS_CHARACTER | Указывает, что текст обрезается до ближайшего символа, а в конце обрезанной строки вставляется многоточие. |
| ELLIPSIS_PATH | Центр удаляется из обрезанных строк и заменяется многоточием. Алгоритм сохраняет как можно большую часть последнего сегмента строки, разделённого слешем. |
| ELLIPSIS_WORD | Указывает, что текст обрезается до ближайшего слова, а в конце обрезанной строки вставляется многоточие. |
| NONE | Указывает отсутствие обрезки. |
| WORD | Указывает, что текст обрезается до ближайшего слова. |
