Указывает тип кэша, который следует использовать.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.CacheType

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| AUTO | Указывает тип автоматического кэширования. Схема автоматического кэширования будет сначала пытаться кэшировать в памяти, а затем на диске. |
| CACHE_IN_MEMORY_ONLY | Только кэш в памяти. |
| CACHE_ON_DISK_ONLY | Только кэш на диске. |
