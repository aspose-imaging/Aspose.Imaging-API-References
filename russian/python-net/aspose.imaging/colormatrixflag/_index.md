Указывает типы изображений и цветов, которые будут затронуты настройками коррекции цвета и градаций серого объекта [ImageAttributes](/imaging/python-net/aspose.imaging/imageattributes/).

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.ColorMatrixFlag

## **Members**
| **Имя члена** | **Description** |
| :- | :- |
| ALT_GRAYS | Только серые оттенки корректируются. |
| ПО УМОЛЧАНИЮ | Все цветовые значения, включая серые оттенки, корректируются одной и той же матрицей цветокоррекции. |
| SKIP_GRAYS | Все цвета корректируются, но серые оттенки не корректируются. Серый оттенок — любой цвет, у которого одинаковые значения красного, зелёного и синего компонентов. |
