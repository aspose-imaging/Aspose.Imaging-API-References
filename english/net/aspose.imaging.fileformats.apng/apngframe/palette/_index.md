## ApngFrame.Palette property

Gets or sets the color palette. [`ApngImage`](../../apngimage/) uses single palette, so [`ApngFrame`](../) effectively returns [`Container`](../../../aspose.imaging/image/container/) palette, when [`Container`](../../../aspose.imaging/image/container/) is set. Otherwise, returns own palette.

public override IColorPalette Palette { get; set; }
