## Image.AutoAdjustPalette property

Gets or sets a value indicating whether to re-generate the image palette after applying graphics effects or modifications like resizing, filtering etc. Applies only to the images supporting the color palette: Gif, Png, Apng, Tiff, BigTiff. Effectively returns `false`, if [`IsIndexed`](../isindexed/) is `false`.

public bool AutoAdjustPalette { get; set; }
