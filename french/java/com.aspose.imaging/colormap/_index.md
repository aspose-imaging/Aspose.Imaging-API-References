public final class ColorMap

Définit une carte pour la conversion des couleurs. Plusieurs méthodes de la classe [ImageAttributes](../../com.aspose.imaging/imageattributes) ajustent les couleurs d'image en utilisant une table de remappage des couleurs, qui est un tableau de structures `com.aspose.imaging.ColorMap`. Non héritable.
