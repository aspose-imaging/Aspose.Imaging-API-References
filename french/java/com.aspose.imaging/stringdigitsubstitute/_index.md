L'énumération spécifie comment substituer les chiffres dans une chaîne selon la locale ou la langue de l'utilisateur.
## Champs

| Champ | Description |
| --- | --- |
| [User](#User) | Spécifie un schéma de substitution défini par l'utilisateur. |
| [None](#None) | Spécifie de désactiver les substitutions. |
| [National](#National) | Spécifie les chiffres de substitution qui correspondent à la langue nationale officielle de la locale de l'utilisateur. |
| [Traditional](#Traditional) | Spécifie les chiffres de substitution qui correspondent à l'écriture ou à la langue native de l'utilisateur, qui peuvent différer de la langue nationale officielle de la locale de l'utilisateur. |
