Spécifie l'alignement d'une chaîne de texte par rapport à son rectangle de mise en page.
## Champs

| Champ | Description |
| --- | --- |
| [Near](#Near) | Spécifie que le texte soit aligné près de la mise en page. |
| [Center](#Center) | Spécifie que le texte soit aligné au centre du rectangle de mise en page. |
| [Far](#Far) | Spécifie que le texte soit aligné loin de la position d'origine du rectangle de mise en page. |
### Near {#Near}
```
public static final int Near
```


Spécifie que le texte soit aligné près de la mise en page. Dans une mise en page de gauche à droite, la position proche est à gauche. Dans une mise en page de droite à gauche, la position proche est à droite.

### Center {#Center}
```
public static final int Center
```


Spécifie que le texte soit aligné au centre du rectangle de mise en page.

### Far {#Far}
```
public static final int Far
```


Spécifie que le texte soit aligné loin de la position d'origine du rectangle de mise en page. Dans une mise en page de gauche à droite, la position éloignée est à droite. Dans une mise en page de droite à gauche, la position éloignée est à gauche.
