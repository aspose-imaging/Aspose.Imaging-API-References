L'enregistrement EMR\_SETMAPMODE spécifie le mode de mappage du contexte de périphérique de lecture. Le mode de mappage indique l'unité de mesure utilisée pour transformer les unités d'espace de page en unités d'espace de dispositif, et spécifie également l'orientation des axes x et y du dispositif.
