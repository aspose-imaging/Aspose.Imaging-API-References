```
public final class EmfEllipse extends EmfDrawingRecordType
```

L'enregistrement EMR\_ELLIPSE spécifie une ellipse. Le centre de l'ellipse est le centre du rectangle englobant spécifié. L'ellipse est contournée en utilisant le stylo actuel et remplie en utilisant le pinceau actuel.
