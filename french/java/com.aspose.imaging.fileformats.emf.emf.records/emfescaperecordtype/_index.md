public int getIEscape()

Obtient ou définit un entier non signé de 32 bits qui spécifie l'échappement du pilote d'imprimante à exécuter. Cette valeur DOIT être l'une des valeurs de l'énumération WMF MetafileEscapes ([MSWMF] section 2.1.1.17).
