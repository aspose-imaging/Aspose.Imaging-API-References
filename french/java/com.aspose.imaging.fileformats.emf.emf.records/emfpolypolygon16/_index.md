L'enregistrement EMR\_POLYPOLYGON16 spécifie une série de polygones fermés. Chaque polygone est contourné avec le crayon actuel et rempli avec le pinceau actuel et le mode de remplissage des polygones. Les polygones dessinés par cet enregistrement peuvent se chevaucher.

Chaque polygone DOIT être contourné à l’aide du crayon actuel, et rempli à l’aide du pinceau actuel et du mode de remplissage de polygone définis dans le contexte de dispositif de lecture. Les polygones définis par cet enregistrement peuvent se chevaucher.
