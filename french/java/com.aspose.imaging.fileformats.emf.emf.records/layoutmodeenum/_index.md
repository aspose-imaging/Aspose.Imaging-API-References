Un entier non signé de 32 bits qui spécifie le mode de mise en page
## Champs

| Champ | Description |
| --- | --- |
| [LAYOUT_LTR](#LAYOUT-LTR) | Définit la disposition horizontale par défaut comme de gauche à droite. |
| [LAYOUT_RTL](#LAYOUT-RTL) | Définit la disposition horizontale par défaut comme de droite à gauche. |
| [LAYOUT_BITMAPORIENTATIONPRESERVED](#LAYOUT-BITMAPORIENTATIONPRESERVED) | Désactive le miroir des images bitmap dessinées par les types d'enregistrements Bitmap (section 2.3.1), lorsque le mode de disposition est de droite à gauche. |
### LAYOUT_LTR {#LAYOUT-LTR}
```
public static final int LAYOUT_LTR
```


Définit la disposition horizontale par défaut comme de gauche à droite. C’est le mode par défaut pour les paramètres régionaux anglais et européens.

### LAYOUT_RTL {#LAYOUT-RTL}
```
public static final int LAYOUT_RTL
```


Définit la disposition horizontale par défaut comme de droite à gauche. Ce mode est requis pour certaines langues, dont l’arabe et l’hébreu.

### LAYOUT_BITMAPORIENTATIONPRESERVED {#LAYOUT-BITMAPORIENTATIONPRESERVED}
```
public static final int LAYOUT_BITMAPORIENTATIONPRESERVED
```


Désactive le miroir des images bitmap dessinées par les types d'enregistrements Bitmap (section 2.3.1), lorsque le mode de disposition est de droite à gauche.
