public class WmfSetLayout extends WmfObject

L'enregistrement META\_SETLAYOUT définit l'orientation de mise en page dans le contexte du dispositif de lecture. L'orientation de mise en page détermine la direction dans laquelle le texte et les graphiques sont dessinés.
