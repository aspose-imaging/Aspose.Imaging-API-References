L'enregistrement META\_ELLIPSE dessine une ellipse. Le centre de l'ellipse est le centre du rectangle englobant spécifié. L'ellipse est contournée en utilisant le crayon et remplie en utilisant le pinceau ; ceux-ci sont définis dans le contexte de l'appareil de lecture.
