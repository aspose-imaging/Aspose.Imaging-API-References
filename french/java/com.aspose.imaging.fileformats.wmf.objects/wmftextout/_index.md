L'enregistrement META\_EXTTEXTOUT génère du texte en utilisant la police, la couleur d'arrière-plan et la couleur du texte qui sont définies dans le contexte du dispositif de lecture. Optionnellement, des dimensions peuvent être fournies pour le rognage, l'opacification ou les deux.
