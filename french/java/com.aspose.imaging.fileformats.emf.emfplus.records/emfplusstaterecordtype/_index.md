Les types d'enregistrement d'état spécifient les opérations sur l'état du contexte du dispositif de lecture.

Chaque conteneur d'état graphique DOIT être ajouté à un tableau de conteneurs graphiques enregistrés. Le conteneur d'état graphique n'est pas écrit dans le métafichier EMF+, de sorte que son format peut être déterminé par l'implémentation.
