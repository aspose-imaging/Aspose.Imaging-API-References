Obtient ou définit le paramètre qui spécifie l'ajustement de la teinte. -180 \u2264 valeur < 0 Les valeurs négatives indiquent une rotation horaire sur le cercle chromatique. 0 Une valeur de 0 indique que la teinte NE DOIT PAS changer. 0 < valeur \u2264 180 Les valeurs positives indiquent une rotation anti-horaire sur le cercle chromatique.

Valeur : le niveau de teinte.
