Les objets Structure spécifient des conteneurs pour les structures de données intégrées dans les enregistrements de métafichier EMF+. Les objets Structure, contrairement aux objets graphiques, ne sont pas créés explicitement ; ils sont des composants qui composent des structures plus complexes.
