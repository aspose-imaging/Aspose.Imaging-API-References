L'énumération PostScriptCap définit les types de terminaison de ligne à utiliser avec un pilote d'imprimante PostScript.
## Champs

| Champ | Description |
| --- | --- |
| [PostScriptNotSet](#PostScriptNotSet) | Spécifie que le style de fin de ligne n'a pas été défini, et qu'un style par défaut MAY [24] être utilisé. |
| [PostScriptFlatCap](#PostScriptFlatCap) | Spécifie que la ligne se termine au dernier point. |
| [PostScriptRoundCap](#PostScriptRoundCap) | Spécifie une extrémité circulaire. |
| [PostScriptSquareCap](#PostScriptSquareCap) | Spécifie une extrémité carrée. |
### PostScriptNotSet {#PostScriptNotSet}
```
public static final int PostScriptNotSet
```


Spécifie que le style de fin de ligne n'a pas été défini, et qu'un style par défaut MAY [24] être utilisé.

### PostScriptFlatCap {#PostScriptFlatCap}
```
public static final int PostScriptFlatCap
```


Spécifie que la ligne se termine au dernier point. L'extrémité est carrée.

### PostScriptRoundCap {#PostScriptRoundCap}
```
public static final int PostScriptRoundCap
```


Spécifie un embout circulaire. Le centre du cercle est le dernier point de la ligne. Le diamètre du cercle est identique à la largeur de la ligne ; c’est‑à‑dire l’épaisseur de la ligne.

### PostScriptSquareCap {#PostScriptSquareCap}
```
public static final int PostScriptSquareCap
```


Spécifie un embout carré. Le centre du carré est le dernier point de la ligne. La hauteur et la largeur du carré sont identiques à la largeur de la ligne ; c’est‑à‑dire l’épaisseur de la ligne.
