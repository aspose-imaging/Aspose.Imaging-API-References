### Twips {#Twips}
```
public static final short Twips
```


Le twips Chaque unité logique est mappée à un vingtième (1/20) d'un point. En impression, un point vaut 1/72 de pouce ; ainsi, 1/20 d'un point vaut 1/1440 de pouce. Cette unité est également connue sous le nom de "twip".

### Isotropic {#Isotropic}
```
public static final short Isotropic
```


Le isotropic Les unités logiques sont mappées à des unités de dispositif arbitraires avec des axes à l'échelle égale ; c'est‑à‑dire qu'une unité le long de l'axe x est égale à une unité le long de l'axe y. Les enregistrements META\_SETWINDOWEXT et META\_SETVIEWPORTEXT spécifient les unités et l'orientation des axes.

public static final short Anisotropic

L'anisotropique Les unités logiques sont mappées à des unités arbitraires avec des axes à l'échelle arbitraire.
