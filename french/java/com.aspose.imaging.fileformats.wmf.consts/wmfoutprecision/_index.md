L'énumération OutPrecision définit des valeurs pour la précision de sortie, qui est l'exigence pour le mappeur de polices afin de correspondre à des paramètres de police spécifiques, y compris la hauteur, la largeur, l'orientation des caractères, l'échappement, le pas et le type de police.
## Champs

| Champ | Description |
| --- | --- |
| [Default](#Default) | Une valeur qui spécifie le comportement par défaut. |
| [String](#String) | Une valeur qui est renvoyée lorsque les polices rasterisées sont énumérées. |
| [Stroke](#Stroke) | Une valeur qui est renvoyée lorsque les polices TrueType et autres polices vectorielles, ainsi que les polices vecteur, sont énumérées. |
| [Tt](#Tt) | Une valeur qui spécifie le choix d'une police TrueType lorsque le système contient plusieurs polices portant le même nom. |
| [Device](#Device) | Une valeur qui spécifie le choix d'une police de dispositif lorsque le système contient plusieurs polices portant le même nom. |
| [Raster](#Raster) | Une valeur qui spécifie le choix d'une police rasterisée lorsque le système contient plusieurs polices portant le même nom. |
| [TtOnly](#TtOnly) | Une valeur qui spécifie l'exigence de n'utiliser que des polices TrueType. |
| [Outline](#Outline) | Une valeur qui spécifie l'exigence d'utiliser les polices TrueType et autres polices vectorielles. |
| [ScreenOutline](#ScreenOutline) | Une valeur qui spécifie une préférence pour les polices TrueType et autres polices vectorielles. |
| [PsOnly](#PsOnly) | Une valeur qui spécifie l'exigence de n'utiliser que des polices PostScript. |
