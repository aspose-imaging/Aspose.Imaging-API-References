L'énumération PitchFont définit des valeurs utilisées pour spécifier les caractéristiques d'une police. Les valeurs sont utilisées pour indiquer si les caractères d'une police ont une largeur fixe ou variable, ou une chasse.
## Champs

| Champ | Description |
| --- | --- |
| [DEFAULT_PITCH](#DEFAULT-PITCH) | La chasse par défaut, qui dépend de l'implémentation. |
| [FIXED_PITCH](#FIXED-PITCH) | Une chasse fixe, ce qui signifie que tous les caractères de la police occupent la même largeur lorsqu'ils sont affichés dans une chaîne. |
| [VARIABLE_PITCH](#VARIABLE-PITCH) | Une chasse variable, ce qui signifie que les caractères de la police occupent des largeurs proportionnelles aux largeurs réelles des glyphes lorsqu'ils sont affichés dans une chaîne. |

### FIXED_PITCH {#FIXED-PITCH}

### VARIABLE_PITCH {#VARIABLE-PITCH}
```
public static final byte VARIABLE_PITCH
```


Une chasse variable, ce qui signifie que les caractères de la police occupent des largeurs proportionnelles aux largeurs réelles des glyphes lorsqu'ils sont affichés dans une chaîne. Par exemple, les caractères "i" et l'espace ont généralement des largeurs beaucoup plus petites qu'un caractère "W" ou "O".
