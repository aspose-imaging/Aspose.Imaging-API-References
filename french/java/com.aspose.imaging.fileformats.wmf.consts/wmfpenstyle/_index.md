L'énumération PenStyle 16 bits est utilisée pour spécifier différents types de stylos qui peuvent être utilisés dans les opérations graphiques.
## Champs

| Champ | Description |
| --- | --- |
| [Cosmetic](#Cosmetic) | Le cosmétique |
| [EndcapRound](#EndcapRound) | Les extrémités de ligne sont rondes. |
| [JoinRound](#JoinRound) | Les jointures de ligne sont rondes. |
| [Solid](#Solid) | Le stylo est plein. |
| [Dash](#Dash) | Le stylo est en tirets. |
| [Dot](#Dot) | Le stylo est pointillé. |
| [Dashdot](#Dashdot) | Le stylo a des tirets et des points alternés. |
| [Dashdotdot](#Dashdotdot) | Le stylo possède des tirets et des points doubles. |
| [Null](#Null) | Le stylo est invisible. |
| [Insideframe](#Insideframe) | Le stylo est plein. |
| [Userstyle](#Userstyle) | Le stylo utilise un tableau de style fourni par l'utilisateur. |
| [Alternate](#Alternate) | Le stylo définit chaque pixel alternatif (ce style n'est applicable qu'aux stylos cosmétiques). |
| [EndcapSquare](#EndcapSquare) | Les extrémités de ligne sont carrées. |
| [EndcapFlat](#EndcapFlat) | Les extrémités de ligne sont plates. |
| [JoinBevel](#JoinBevel) | Les jointures de ligne sont biseautées. |
| [JoinMiter](#JoinMiter) | Les jointures de ligne sont en onglet lorsqu'elles sont dans la limite actuelle définie par l'enregistrement SETMITERLIMIT META\_ESCAPE. |
