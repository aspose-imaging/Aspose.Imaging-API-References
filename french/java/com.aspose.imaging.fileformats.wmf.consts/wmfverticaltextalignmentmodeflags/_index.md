Les indicateurs VerticalTextAlignmentMode spécifient la relation entre un point de référence et un rectangle englobant, pour l'alignement du texte. Ces indicateurs peuvent être combinés pour spécifier plusieurs options, avec la restriction qu'un seul indicateur peut être choisi et qu'il modifie la position du dessin dans le contexte du dispositif de lecture. L'alignement vertical du texte est effectué lorsque la police possède une ligne de base verticale par défaut, comme le Kanji.
