L'énumération MixMode spécifie le mode de mélange d'arrière-plan pour le texte, les brosses hachurées et les autres styles de stylo non plein.
## Champs

| Champ | Description |
| --- | --- |
| [Transparent](#Transparent) | L'arrière-plan reste intact. |
| [Opaque](#Opaque) | L'arrière-plan est rempli avec la couleur d'arrière-plan actuellement définie dans le contexte du dispositif de lecture avant que le texte, la brosse à hachures ou le stylo ne soient dessinés. |
### Transparent {#Transparent}
```
public static final short Transparent
```


L'arrière-plan reste intact.

### Opaque {#Opaque}
```
public static final short Opaque
```


L'arrière-plan est rempli avec la couleur d'arrière-plan actuellement définie dans le contexte du dispositif de lecture avant que le texte, la brosse à hachures ou le stylo ne soient dessinés.
