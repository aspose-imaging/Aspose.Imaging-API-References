L'énumération FloodFill spécifie le type d'opération de remplissage à effectuer.
## Champs

| Champ | Description |
| --- | --- |
| [FloodFillBorder](#FloodFillBorder) | La zone de remplissage est délimitée par la couleur spécifiée par le membre Color. |
| [FloodFillSurface](#FloodFillSurface) | La zone de remplissage est délimitée par la couleur qui est spécifiée par le membre Color. |
### FloodFillBorder {#FloodFillBorder}
```
public static final int FloodFillBorder
```


La zone de remplissage est délimitée par la couleur spécifiée par le membre Color. Ce style est identique au remplissage effectué par l'enregistrement META\_FLOODFILL.

### FloodFillSurface {#FloodFillSurface}
```
public static final int FloodFillSurface
```


La zone de remplissage est délimitée par la couleur qui est spécifiée par le membre Color. Le remplissage continue vers l'extérieur dans toutes les directions tant que la couleur est rencontrée. Ce style est utile pour remplir des zones avec des bordures multicolores.
