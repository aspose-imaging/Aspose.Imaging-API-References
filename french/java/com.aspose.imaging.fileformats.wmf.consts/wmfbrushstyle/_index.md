L'énumération BrushStyle spécifie les différents types de brosse possibles pouvant être utilisés dans les opérations graphiques. Pour plus d'informations, voir la spécification de l'objet Brush (section 2.2.1.1).
## Champs

| Champ | Description |
| --- | --- |
| [Solid](#Solid) | Une brosse qui peint une couleur unique et constante, soit solide, soit tramage. |
| [Null](#Null) | Une brosse qui ne fait rien. |
| [Hatched](#Hatched) | Une brosse qui peint un motif simple prédéfini, ou "hatch", sur un arrière-plan solide |
| [Pattern](#Pattern) | Une brosse qui peint un motif défini par un bitmap, qui PEUT être un objet Bitmap16 ou un objet DeviceIndependentBitmap (DIB). |
| [Indexed](#Indexed) | Non pris en charge. |
| [Dibpattern](#Dibpattern) | Une brosse à motif spécifiée par un DIB. |
| [Dibpatternpt](#Dibpatternpt) | Une brosse à motif spécifiée par un DIB. |
| [Pattern8X8](#Pattern8X8) | Non pris en charge. |
| [Dibpattern8X8](#Dibpattern8X8) | Non pris en charge. |
| [Monopattern](#Monopattern) | Non pris en charge. |
| [Gradient](#Gradient) | Le dégradé n'est pas pris en charge dans wmf, prise en charge dans odg. |
