L'énumération ColorAdjustment est utilisée pour spécifier comment l'image de sortie doit être préparée lorsque le mode d'étirement est HALFTONE.
## Champs

| Champ | Description |
| --- | --- |
| [CA_NEGATIVE](#CA-NEGATIVE) | Spécifie que le négatif de l'image originale DOIT être affiché. |
| [CA_LOG_FILTER](#CA-LOG-FILTER) | Le Spécifie que un processus logarithmique DOIT être appliqué à la densité finale des couleurs de sortie. |
### CA_NEGATIVE {#CA-NEGATIVE}
```
public static final int CA_NEGATIVE
```


Spécifie que le négatif de l'image originale DOIT être affiché.

### CA_LOG_FILTER {#CA-LOG-FILTER}
```
public static final int CA_LOG_FILTER
```


Le Spécifie que un processus logarithmique DOIT être appliqué à la densité finale des couleurs de sortie. Cela augmentera le contraste des couleurs lorsque la luminance est faible.
