L'énumération FormatSignature définit des valeurs utilisées pour identifier le format des données intégrées dans les enregistrements EMF.
## Champs

| Champ | Description |
| --- | --- |
| [ENHMETA_SIGNATURE](#ENHMETA-SIGNATURE) | La valeur de ce membre est la séquence de caractères ASCII "FME ", qui se trouve être l'inverse de la chaîne "EMF", et elle désigne les données d'enregistrement EMF. |
| [EPS_SIGNATURE](#EPS-SIGNATURE) | La valeur de ce membre est la séquence de caractères ASCII "FSPE", qui se trouve être l'inverse de la chaîne "EPSF", et elle désigne les données au format encapsulated PostScript (EPS). |
