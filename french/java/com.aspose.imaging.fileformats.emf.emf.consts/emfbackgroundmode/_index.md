L'énumération BackgroundMode est utilisée pour spécifier le mode d'arrière-plan à utiliser avec le texte, les pinceaux hachurés et les styles de crayon qui ne sont pas solides. Le mode d'arrière-plan détermine comment combiner l'arrière-plan avec le texte au premier plan, les pinceaux hachurés et les styles de crayon qui ne sont pas des lignes solides.
## Champs

| Champ | Description |
| --- | --- |
| [TRANSPARENT](#TRANSPARENT) | Le transparent - L'arrière-plan reste inchangé. |
| [OPAQUE](#OPAQUE) | Le opaque - L'arrière-plan est rempli avec la couleur d'arrière-plan actuelle avant que le texte, la brosse hachurée ou le stylo ne soit dessiné. |
