L'énumération PolygonFillMode définit des valeurs qui spécifient comment calculer la région d'un polygone à remplir.
## Champs

| Champ | Description |
| --- | --- |
| [ALTERNATE](#ALTERNATE) | Sélectionne le mode alternatif (remplit la zone entre les côtés impairs et pairs du polygone à chaque ligne de balayage). |
| [WINDING](#WINDING) | Sélectionne le mode enroulement (remplit toute région avec une valeur d'enroulement non nulle). |
