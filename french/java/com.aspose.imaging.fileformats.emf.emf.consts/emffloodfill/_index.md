L'énumération FloodFill définit des valeurs qui spécifient comment déterminer la zone pour une opération de remplissage.
## Champs

| Champ | Description |
| --- | --- |
| [FLOODFILLBORDER](#FLOODFILLBORDER) | La zone de remplissage est limitée par une couleur spécifique |

### FLOODFILLSURFACE {#FLOODFILLSURFACE}
```
public static final int FLOODFILLSURFACE
```


La zone de remplissage est définie par une couleur spécifique. Le remplissage continue vers l'extérieur dans toutes les directions tant que la couleur est rencontrée. Ce style est utile pour remplir des zones avec des limites multicolores
