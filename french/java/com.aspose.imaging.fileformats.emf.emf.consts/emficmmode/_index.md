L'énumération ICMMode définit des valeurs qui spécifient quand activer ou désactiver l'ICM.
## Champs

| Champ | Description |
| --- | --- |
| [ICM_OFF](#ICM-OFF) | Désactive la gestion des couleurs d'image (ICM) dans le contexte du dispositif de lecture. |
| [ICM_ON](#ICM-ON) | Active ICM dans le contexte du dispositif de lecture. |
| [ICM_QUERY](#ICM-QUERY) | Interroge l'état actuel de la gestion des couleurs dans le contexte du dispositif de lecture. |
| [ICM_DONE_OUTSIDEDC](#ICM-DONE-OUTSIDEDC) | Désactive ICM dans le contexte du dispositif de lecture, et désactive la correction des couleurs de style ancien des demi-teintes |
### ICM_OFF {#ICM-OFF}
```
public static final int ICM_OFF
```


Désactive la gestion des couleurs d'image (ICM) dans le contexte du dispositif de lecture. Active la correction des couleurs de style ancien des demi-teintes

### ICM_ON {#ICM-ON}
```
public static final int ICM_ON
```

Active ICM dans le contexte du dispositif de lecture. Désactive la correction des couleurs de style ancien des demi-teintes.

### ICM_QUERY {#ICM-QUERY}
```
public static final int ICM_QUERY
```


Interroge l'état actuel de la gestion des couleurs dans le contexte du dispositif de lecture.

### ICM_DONE_OUTSIDEDC {#ICM-DONE-OUTSIDEDC}
```
public static final int ICM_DONE_OUTSIDEDC
```
