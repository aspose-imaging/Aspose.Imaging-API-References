L'énumération CurveChannel définit les canaux de couleur qui peuvent être affectés par un ajustement d'effet de courbe de couleur sur une image.
## Champs

| Champ | Description |
| --- | --- |
| [CurveChannelAll](#CurveChannelAll) | Spécifie qu'un ajustement de courbe de couleur s'applique à tous les canaux de couleur. |
| [CurveChannelRed](#CurveChannelRed) | Spécifie qu'un ajustement de courbe de couleur s'applique uniquement au canal de couleur rouge. |
| [CurveChannelGreen](#CurveChannelGreen) | Spécifie qu'un ajustement de courbe de couleur s'applique uniquement au canal de couleur vert. |
