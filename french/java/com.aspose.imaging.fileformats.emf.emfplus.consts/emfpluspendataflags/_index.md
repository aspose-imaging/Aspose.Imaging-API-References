Les indicateurs PenData spécifient les propriétés des stylos graphiques, y compris la présence de champs de données optionnels. Ces indicateurs peuvent être combinés pour spécifier plusieurs options.

--------------------

Les stylos graphiques sont spécifiés par des objets [EmfPlusPen](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspen).
