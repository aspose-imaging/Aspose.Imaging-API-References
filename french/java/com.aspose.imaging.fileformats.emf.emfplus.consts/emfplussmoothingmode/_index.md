L'énumération SmoothingMode définit les modes d'anticrénelage à appliquer aux lignes, courbes et aux bords des zones remplies afin de les rendre plus continues ou nettement définies.
## Champs

| Champ | Description |
| --- | --- |
| [SmoothingModeDefault](#SmoothingModeDefault) | Spécifie le lissage de courbe par défaut sans anti‑aliasing. |
| [SmoothingModeHighSpeed](#SmoothingModeHighSpeed) | Spécifie les meilleures performances sans anti‑aliasing. |
| [SmoothingModeHighQuality](#SmoothingModeHighQuality) | Spécifie la meilleure qualité avec anti‑aliasing. |
| [SmoothingModeNone](#SmoothingModeNone) | N'effectue aucun lissage de courbe et aucun anti‑aliasing. |
| [SmoothingModeAntiAlias8x4](#SmoothingModeAntiAlias8x4) | Spécifie une bonne qualité en utilisant un filtre à boîte 8x4. |
| [SmoothingModeAntiAlias8x8](#SmoothingModeAntiAlias8x8) | Spécifie une meilleure qualité en utilisant un filtre à boîte 8x8. |
