Les indicateurs PaletteStyle spécifient les propriétés des palettes graphiques. Ces indicateurs peuvent être combinés pour spécifier plusieurs options.

--------------------

Les palettes graphiques sont spécifiées par les objets [EmfPlusPalette](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspalette).
## Champs

| Champ | Description |
| --- | --- |
| [PaletteStyleHasAlpha](#PaletteStyleHasAlpha) | Si défini, une ou plusieurs entrées de la palette DOIVENT contenir des informations de transparence alpha. |
| [PaletteStyleGrayScale](#PaletteStyleGrayScale) | Si défini, la palette DOIT contenir uniquement des entrées en niveaux de gris. |
| [PaletteStyleHalftone](#PaletteStyleHalftone) | Si défini, la palette DOIT contenir des valeurs de couleur discrètes pouvant être utilisées pour le tramage. |
