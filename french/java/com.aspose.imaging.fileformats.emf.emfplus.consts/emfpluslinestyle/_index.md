L'énumération LineStyle définit les styles des lignes dessinées avec des stylos graphiques.

--------------------

Les lignes graphiques sont spécifiées par des objets [EmfPlusPen](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspen) (section 2.2.1.7).
