L'énumération LanguageIdentifier définit les identifiants des langues naturelles dans les paramètres régionaux, y compris les pays, les régions géographiques et les districts administratifs.

--------------------

Les identifiants de langue sont spécifiés par les objets [EmfPlusLanguageIdentifierType](../../com.aspose.imaging.fileformats.emf.emfplus.consts/emfpluslanguageidentifiertype) (section 2.2.2.23). Chaque valeur est un codage d'un identifiant de langue principal et d'un identifiant de sous‑langue. Voir `[MS-LCID]` pour des informations supplémentaires concernant les identifiants de langue, y compris la prise en charge des versions de Windows.
