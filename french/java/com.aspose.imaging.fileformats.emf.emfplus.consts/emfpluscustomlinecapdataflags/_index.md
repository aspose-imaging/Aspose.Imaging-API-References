Les indicateurs CustomLineCapData spécifient les données pour les caps de ligne personnalisés. Ces indicateurs peuvent être combinés pour spécifier plusieurs options.

--------------------

Les caps de ligne graphiques personnalisés sont spécifiés par des objets [EmfPlusCustomLineCap](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecap).
## Champs

| Champ | Description |
| --- | --- |
| [CustomLineCapDataFillPath](#CustomLineCapDataFillPath) | Si défini, un objet [EmfPlusFillPath](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfplusfillpath) DOIT être spécifié dans le champ OptionalData de l'objet [EmfPlusCustomLineCapData](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecapdata) pour remplir le cap de ligne personnalisé. |
| [CustomLineCapDataLinePath](#CustomLineCapDataLinePath) | Si défini, un objet [EmfPlusLinePath](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluslinepath) DOIT être spécifié dans le champ OptionalData de l'objet EmfPlusCustomLineCapData pour tracer le contour du cap de ligne personnalisé. |
### CustomLineCapDataFillPath {#CustomLineCapDataFillPath}
```
public static final int CustomLineCapDataFillPath
```


Si défini, un objet [EmfPlusFillPath](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfplusfillpath) DOIT être spécifié dans le champ OptionalData de l'objet [EmfPlusCustomLineCapData](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecapdata) pour remplir le cap de ligne personnalisé.
