L'énumération UnitType définit les unités de mesure dans différents systèmes de coordonnées.
## Champs

| Champ | Description |
| --- | --- |
| [UnitTypeWorld](#UnitTypeWorld) | Spécifie une unité de distance logique dans l'espace mondial. |
| [UnitTypeDisplay](#UnitTypeDisplay) | Spécifie une unité de distance basée sur les caractéristiques de l'affichage physique. |
| [UnitTypePixel](#UnitTypePixel) | Spécifie une unité de 1 pixel. |
| [UnitTypePoint](#UnitTypePoint) | Spécifie une unité de 1 point d'imprimante, ou 1/72 pouce. |
| [UnitTypeInch](#UnitTypeInch) | Spécifie une unité de 1 pouce. |
| [UnitTypeDocument](#UnitTypeDocument) | Spécifie une unité de 1/300 pouce. |
| [UnitTypeMillimeter](#UnitTypeMillimeter) | Spécifie une unité de 1 millimètre. |
