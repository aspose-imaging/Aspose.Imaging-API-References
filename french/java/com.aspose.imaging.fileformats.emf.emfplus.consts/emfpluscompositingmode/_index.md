L’énumération CompositingMode définit les modes de combinaison des couleurs source avec les couleurs d’arrière-plan. Le mode de composition représente l’état d’activation du mélange alpha.
## Champs

| Champ | Description |
| --- | --- |
| [CompositingModeSourceOver](#CompositingModeSourceOver) | Active le mélange alpha, qui spécifie que lorsqu'une couleur est rendue, elle est mélangée avec la couleur d'arrière-plan. |
| [CompositingModeSourceCopy](#CompositingModeSourceCopy) | Désactive le mélange alpha, ce qui signifie que lorsqu'une couleur source est rendue, elle écrase la couleur d'arrière-plan. |
### CompositingModeSourceOver {#CompositingModeSourceOver}
```
public static final byte CompositingModeSourceOver
```


Active le mélange alpha, qui spécifie que lorsqu'une couleur est rendue, elle est mélangée avec la couleur d'arrière-plan. L'ampleur du mélange est déterminée par la valeur du composant alpha de la couleur rendue.

### CompositingModeSourceCopy {#CompositingModeSourceCopy}
```
public static final byte CompositingModeSourceCopy
```


Désactive le mélange alpha, ce qui signifie que lorsqu'une couleur source est rendue, elle écrase la couleur d'arrière-plan.
