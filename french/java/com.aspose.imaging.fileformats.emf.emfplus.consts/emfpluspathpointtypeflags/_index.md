Les indicateurs PathPointType spécifient les propriétés de type des points sur les chemins graphiques. Ces indicateurs peuvent être combinés pour spécifier plusieurs options.

--------------------

Les chemins graphiques sont spécifiés par les objets [EmfPlusPath](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspath).
## Champs

| Champ | Description |
| --- | --- |
| [PathPointTypeDashMode](#PathPointTypeDashMode) | Spécifie qu'un segment de ligne qui passe par le point est en pointillés. |
| [PathPointTypePathMarker](#PathPointTypePathMarker) | Spécifie que le point est un marqueur de position. |
| [PathPointTypeCloseSubpath](#PathPointTypeCloseSubpath) | Spécifie que le point est le point final d'un sous-chemin. |
