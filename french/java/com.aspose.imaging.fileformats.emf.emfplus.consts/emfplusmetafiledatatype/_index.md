L'énumération MetafileDataType définit les types de données de métafichiers pouvant être incorporés dans un métafichier EMF+.

--------------------

Les données de métafichier incorporées sont spécifiées par des objets EmfPlusMetafileData (section 2.2.2.27).
## Champs

| Champ | Description |
| --- | --- |
| [MetafileDataTypeWmf](#MetafileDataTypeWmf) | Spécifie que le métafichier est un métafichier WMF qui définit des opérations graphiques avec des enregistrements WMF, comme indiqué dans [MS-WMF]. |
| [MetafileDataTypeWmfPlaceable](#MetafileDataTypeWmfPlaceable) | Spécifie que le métafichier est un métafichier WMF qui définit des opérations graphiques avec des enregistrements WMF, et qui contient des informations d'en-tête supplémentaires rendant le métafichier WMF indépendant du dispositif, comme indiqué dans [MS-WMF]. |
| [MetafileDataTypeEmf](#MetafileDataTypeEmf) | Spécifie que le métafichier est un métafichier EMF qui définit des opérations graphiques avec des enregistrements EMF, comme indiqué dans [MS-EMF]. |
| [MetafileDataTypeEmfPlusOnly](#MetafileDataTypeEmfPlusOnly) | Spécifie que le métafichier est un métafichier EMF+ qui définit des opérations graphiques uniquement avec des enregistrements EMF+. |
| [MetafileDataTypeEmfPlusDual](#MetafileDataTypeEmfPlusDual) | Spécifie que le métafichier est un métafichier EMF+ qui définit des opérations graphiques avec des enregistrements EMF et EMF+. |
### MetafileDataTypeWmf {#MetafileDataTypeWmf}
```
public static final int MetafileDataTypeWmf
```


Spécifie que le métafichier est un métafichier WMF qui définit des opérations graphiques avec des enregistrements WMF, comme indiqué dans [MS-WMF].

### MetafileDataTypeWmfPlaceable {#MetafileDataTypeWmfPlaceable}
