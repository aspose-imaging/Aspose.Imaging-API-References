Les indicateurs FontStyle spécifient les styles des polices graphiques. Ces indicateurs peuvent être combinés pour spécifier plusieurs options.

--------------------

Les polices graphiques sont spécifiées par les objets [EmfPlusFont](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfplusfont) objects
## Champs

| Champ | Description |
| --- | --- |
| [FontStyleBold](#FontStyleBold) | Si le drapeau est défini, la police doit être rendue avec un poids ou une épaisseur plus lourds. |
| [FontStyleItalic](#FontStyleItalic) | Si le drapeau est défini, la police doit être rendue avec les tiges verticales des caractères à un angle ou une inclinaison augmentés par rapport à la ligne de base. |
| [FontStyleUnderline](#FontStyleUnderline) | Si le drapeau est défini, la police doit être rendue avec une ligne sous la ligne de base des caractères. |
| [FontStyleStrikeout](#FontStyleStrikeout) | Si le drapeau est défini, la police doit être rendue avec une ligne parallèle à la ligne de base tracée au milieu des caractères. |
### FontStyleBold {#FontStyleBold}
```
public static final int FontStyleBold
```


Si le drapeau est défini, la police doit être rendue avec un poids ou une épaisseur plus lourds. Si le drapeau n'est pas défini, la police doit être rendue avec une épaisseur normale.

### FontStyleItalic {#FontStyleItalic}
```
public static final int FontStyleItalic
```


Si le drapeau est défini, la police doit être rendue avec les tiges verticales des caractères à un angle ou une inclinaison augmentés par rapport à la ligne de base. Si le drapeau n'est pas défini, la police doit être rendue avec les tiges verticales des caractères à un angle normal.

### FontStyleUnderline {#FontStyleUnderline}
```
public static final int FontStyleUnderline
```


Si le drapeau est défini, la police doit être rendue avec une ligne sous la ligne de base des caractères. Si le drapeau n'est pas défini, la police doit être rendue sans ligne sous la ligne de base.

### FontStyleStrikeout {#FontStyleStrikeout}
```
public static final int FontStyleStrikeout
```


Si le drapeau est activé, la police DOIT être rendue avec une ligne parallèle à la ligne de base tracée à travers le milieu des caractères. Si le drapeau est désactivé, la police DOIT être rendue sans ligne à travers les caractères.
