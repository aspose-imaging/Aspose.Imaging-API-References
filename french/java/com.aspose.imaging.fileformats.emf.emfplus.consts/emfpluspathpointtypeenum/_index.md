L'énumération PathPointType définit les types de points sur un chemin graphique.

--------------------

Les types de points de chemin graphique sont spécifiés par les objets [EmfPlusPathPointType](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspathpointtype) (section 2.2.2.31).
## Champs

| Champ | Description |
| --- | --- |
| [PathPointTypeStart](#PathPointTypeStart) | Spécifie que le point est le point de départ d'un chemin. |
| [PathPointTypeLine](#PathPointTypeLine) | Spécifie que le point est l'une des deux extrémités d'une ligne. |
| [PathPointTypeBezier](#PathPointTypeBezier) | Spécifie que le point est une extrémité ou un point de contrôle d'une courbe de Bézier cubique. |
