L'énumération StringAlignment définit les manières d'aligner les chaînes par rapport à un rectangle de mise en page du texte.
## Champs

| Champ | Description |
| --- | --- |
| [StringAlignmentNear](#StringAlignmentNear) | Spécifie que l'alignement de la chaîne est vers l'origine du rectangle de mise en page. |
| [StringAlignmentCenter](#StringAlignmentCenter) | Spécifie que l'alignement est centré entre l'origine et l'étendue du rectangle de mise en page. |
| [StringAlignmentFar](#StringAlignmentFar) | Spécifie que l'alignement est du côté droit du rectangle de mise en page. |
### StringAlignmentNear {#StringAlignmentNear}
```
public static final int StringAlignmentNear
```


Spécifie que l'alignement de la chaîne est vers l'origine du rectangle de mise en page. Cela peut être utilisé pour aligner les caractères le long d'une ligne ou pour aligner le texte à l'intérieur d'un rectangle. Pour un rectangle de mise en page de droite à gauche, l'origine DOIT être en haut à droite.

### StringAlignmentCenter {#StringAlignmentCenter}
```
public static final int StringAlignmentCenter
```


Spécifie que l'alignement est centré entre l'origine et l'étendue du rectangle de mise en page.

### StringAlignmentFar {#StringAlignmentFar}
```
public static final int StringAlignmentFar
```


Spécifie que l'alignement est du côté droit du rectangle de mise en page.
