L'énumération StringTrimming définit comment tronquer les caractères d'une chaîne trop grande pour le rectangle de mise en page du texte.
## Champs

| Champ | Description |
| --- | --- |
| [StringTrimmingNone](#StringTrimmingNone) | Spécifie qu'aucune coupe n'est effectuée. |
| [StringTrimmingCharacter](#StringTrimmingCharacter) | Spécifie que la chaîne est coupée à la limite du dernier caractère qui se trouve à l'intérieur du rectangle de mise en page. |
| [StringTrimmingWord](#StringTrimmingWord) | Spécifie que la chaîne est coupée à la limite du dernier mot qui se trouve à l'intérieur du rectangle de mise en page. |
| [StringTrimmingEllipsisCharacter](#StringTrimmingEllipsisCharacter) | Spécifie que la chaîne est coupée à la limite du dernier caractère qui se trouve à l'intérieur du rectangle de mise en page, et qu'une ellipse (...) est insérée après le caractère. |
| [StringTrimmingEllipsisWord](#StringTrimmingEllipsisWord) | Spécifie que la chaîne est coupée à la limite du dernier mot qui se trouve à l'intérieur du rectangle de mise en page, et qu'une ellipse (...) est insérée après le mot. |
| [StringTrimmingEllipsisPath](#StringTrimmingEllipsisPath) | Spécifie que le centre est supprimé de la chaîne et remplacé par une ellipse. |
### StringTrimmingNone {#StringTrimmingNone}
```
public static final int StringTrimmingNone
```


Spécifie qu'aucune coupe n'est effectuée.

### StringTrimmingCharacter {#StringTrimmingCharacter}
```
public static final int StringTrimmingCharacter
```


Spécifie que la chaîne est coupée à la limite du dernier caractère qui se trouve à l'intérieur du rectangle de mise en page. C'est la valeur par défaut.

### StringTrimmingWord {#StringTrimmingWord}
```
public static final int StringTrimmingWord
```


Spécifie que la chaîne est coupée à la limite du dernier mot qui se trouve à l'intérieur du rectangle de mise en page.

### StringTrimmingEllipsisCharacter {#StringTrimmingEllipsisCharacter}
```
public static final int StringTrimmingEllipsisCharacter
```


Spécifie que la chaîne est coupée à la limite du dernier caractère qui se trouve à l'intérieur du rectangle de mise en page, et qu'une ellipse (...) est insérée après le caractère.

### StringTrimmingEllipsisWord {#StringTrimmingEllipsisWord}
```
public static final int StringTrimmingEllipsisWord
```


Spécifie que la chaîne est coupée à la limite du dernier mot qui se trouve à l'intérieur du rectangle de mise en page, et qu'une ellipse (...) est insérée après le mot.

### StringTrimmingEllipsisPath {#StringTrimmingEllipsisPath}
```
public static final int StringTrimmingEllipsisPath
```


Spécifie que le centre est supprimé de la chaîne et remplacé par une ellipse. L'algorithme conserve autant que possible la dernière partie de la chaîne.
