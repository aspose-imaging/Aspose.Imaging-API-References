Avec la capacité d'effectuer la rasterisation d'images CDR et de définir les facteurs d'échelle pour les dimensions X et Y, cette API fournit un contrôle précis du processus de transformation. Que ce soit pour adapter l'échelle à des exigences de sortie spécifiques ou pour convertir des graphiques vectoriels en formats raster, vous pouvez exploiter cette API pour une conversion efficace et personnalisable d'images vectorielles CDR en images raster.
