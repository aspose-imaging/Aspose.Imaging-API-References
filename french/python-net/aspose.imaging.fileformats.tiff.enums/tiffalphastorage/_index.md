Spécifie le stockage alpha pour les documents TIFF.

**Module:** [aspose.imaging.fileformats.tiff.enums](/imaging/python-net/aspose.imaging.fileformats.tiff.enums/)

**Full Name:** aspose.imaging.fileformats.tiff.enums.TiffAlphaStorage

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| ASSOCIATED | La valeur alpha est stockée sous forme prémultipliée. Lors de la restauration de l'alpha, il peut y avoir des effets d'arrondi et la valeur restaurée peut différer de l'originale. |
| UNASSOCIATED | La valeur alpha est stockée sous forme non associée. Cela signifie que l'alpha restauré est exactement le même que celui stocké dans le TIFF. |
| UNSPECIFIED | L'alpha n'est pas spécifié et est stocké dans le fichier TIFF. |
