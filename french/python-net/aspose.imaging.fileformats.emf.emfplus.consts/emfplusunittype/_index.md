L'énumération UnitType définit les unités de mesure dans différents systèmes de coordonnées.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusUnitType

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| UNIT_TYPE_DISPLAY | Spécifie une unité de distance basée sur les caractéristiques de l'affichage physique.<br/>            Par exemple, si le dispositif d'affichage est un moniteur, alors l'unité est de 1 pixel. |
| UNIT_TYPE_DOCUMENT | Spécifie une unité de 1/300 de pouce. |
| UNIT_TYPE_INCH | Spécifie une unité de 1 pouce. |
| UNIT_TYPE_MILLIMETER | Spécifie une unité de 1 millimètre. |
| UNIT_TYPE_PIXEL | Spécifie une unité de 1 pixel. |
| UNIT_TYPE_POINT | Spécifie une unité de 1 point d'imprimante, ou 1/72 de pouce. |
| UNIT_TYPE_WORLD | Spécifie une unité de distance logique dans l'espace mondial. |
