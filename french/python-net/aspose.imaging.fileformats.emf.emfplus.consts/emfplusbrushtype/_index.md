L'énumération BrushType définit les types de pinceaux graphiques, qui sont utilisés pour remplir les régions graphiques.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusBrushType

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| BRUSH_TYPE_HATCH_FILL | Spécifie un pinceau à hachures, qui se caractérise par un motif prédéfini. |
| BRUSH_TYPE_LINEAR_GRADIENT | contient des données de pinceau à dégradé linéaire. |
| BRUSH_TYPE_PATH_GRADIENT | Spécifie un pinceau à dégradé de chemin, qui se caractérise par des données de pinceau à dégradé de couleur de chemin. |
| BRUSH_TYPE_SOLID_COLOR | Spécifie un pinceau à couleur unie, qui se caractérise par une valeur EmfPlusArgb. |
| BRUSH_TYPE_TEXTURE_FILL | Spécifie un pinceau à texture, qui se caractérise par une image. |
