Les indicateurs FontStyle spécifient les styles des polices graphiques. Ces indicateurs peuvent être combinés pour spécifier plusieurs options.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusFontStyleFlags

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| FONT_STYLE_BOLD | Si l'option est activée, la police DOIT être rendue avec un poids ou une épaisseur plus lourde.<br/>            Si l'option est désactivée, la police DOIT être rendue avec une épaisseur normale. |
| FONT_STYLE_ITALIC | Si défini, la police doit être rendue avec les tiges verticales des caractères à un angle accru ou incliné par rapport à la ligne de base.<br/>            Si non défini, la police doit être rendue avec les tiges verticales des caractères à un angle normal. |
| FONT_STYLE_STRIKEOUT | Si défini, la police doit être rendue avec une ligne parallèle à la ligne de base tracée à travers le milieu des caractères.<br/>            Si non défini, la police doit être rendue sans ligne à travers les caractères. |
| FONT_STYLE_UNDERLINE | Si défini, la police doit être rendue avec une ligne sous la ligne de base des caractères.<br/>            Si non défini, la police doit être rendue sans ligne sous la ligne de base. |
