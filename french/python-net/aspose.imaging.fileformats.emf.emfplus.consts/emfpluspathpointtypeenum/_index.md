## **Members**
| **Nom du membre** | **Description** |

| PATH_POINT_TYPE_BEZIER | Spécifie que le point est un point d'extrémité ou un point de contrôle d'une courbe de Bézier cubique. |
| PATH_POINT_TYPE_LINE | Spécifie que le point est l'un des deux points d'extrémité d'une ligne. |
