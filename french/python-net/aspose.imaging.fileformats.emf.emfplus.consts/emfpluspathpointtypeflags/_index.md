Les indicateurs PathPointType spécifient les propriétés de type des points sur les chemins graphiques. Ces indicateurs peuvent être combinés pour spécifier plusieurs options.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusPathPointTypeFlags

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| PATH_POINT_TYPE_CLOSE_SUBPATH | Spécifie que le point est le point final d'un sous‑chemin. |
| PATH_POINT_TYPE_DASH_MODE | Spécifie qu'un segment de ligne qui passe par le point est en pointillé. |
| PATH_POINT_TYPE_PATH_MARKER | Spécifie que le point est un marqueur de position. |
