L'énumération CurveAdjustments définit les ajustements pouvant être appliqués à la courbe de couleur d'une image.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusCurveAdjustments

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| ADJUST_BLACK_SATURATION | Spécifie un ajustement de la saturation noire d'une image, qui est la valeur minimale dans la plage d'intensités d'un canal couleur donné, généralement de 0 à 255. |
| ADJUST_CONTRAST | Spécifie une augmentation ou une diminution du contraste d'une image. |
| ADJUST_DENSITY | Spécifie la simulation d'une augmentation ou d'une diminution de la densité d'une image. |
| ADJUST_EXPOSURE | Spécifie la simulation d'une augmentation ou d'une diminution de l'exposition d'une image. |
| ADJUST_HIGHLIGHT | Spécifie une augmentation ou une diminution de la valeur d'un canal couleur d'une image, si ce canal possède déjà une valeur supérieure à la moitié de l'intensité. Cet ajustement peut être utilisé pour augmenter la définition dans les zones claires d'une image sans affecter les zones sombres. |
| ADJUST_MIDTONE | Spécifie un ajustement qui éclaircit ou assombrit une image. Les valeurs des canaux couleur au milieu de la plage d'intensité sont modifiées davantage que les valeurs des canaux couleur proches des extrêmes minimum ou maximum de l'intensité. Cet ajustement peut être utilisé pour éclaircir ou assombrir une image sans perdre le contraste entre les parties les plus sombres et les plus claires de l'image. |
| ADJUST_SHADOW | Spécifie une augmentation ou une diminution de la valeur d'un canal couleur d'une image, si ce canal possède déjà une valeur inférieure à la moitié de l'intensité. Cet ajustement peut être utilisé pour augmenter la définition dans les zones sombres d'une image sans affecter les zones claires. |
| ADJUST_WHITE_SATURATION | Spécifie un ajustement de la saturation blanche d'une image, définie comme la valeur maximale dans la plage d'intensités d'un canal couleur donné, dont la plage est généralement de 0 à 255. |
