L'énumération HotkeyPrefix définit les options de sortie pour les préfixes de raccourcis clavier dans le texte graphique.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusHotkeyPrefix

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| HOTKEY_PREFIX_HIDE | Spécifie que le préfixe du raccourci doit être affiché. |
| HOTKEY_PREFIX_NONE | Spécifie que le préfixe du raccourci ne doit PAS être affiché. |
| HOTKEY_PREFIX_SHOW | Spécifie qu'aucun préfixe de raccourci n'est défini. |
