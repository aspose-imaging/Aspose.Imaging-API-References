L'énumération MetafileDataType définit les types de données de métafichiers pouvant être incorporés dans un métafichier EMF+.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusMetafileDataType

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| METAFILE_DATA_TYPE_EMF | Spécifie que le métafichier est un métafichier EMF qui spécifie les opérations graphiques avec des enregistrements EMF, comme indiqué dans [MS-EMF]. |
| METAFILE_DATA_TYPE_EMF_PLUS_DUAL | Spécifie que le métafichier est un métafichier EMF+ qui spécifie des opérations graphiques avec à la fois des enregistrements EMF et EMF+. |
| METAFILE_DATA_TYPE_EMF_PLUS_ONLY | Spécifie que le métafichier est un métafichier EMF+ qui spécifie des opérations graphiques avec uniquement des enregistrements EMF+. |
| METAFILE_DATA_TYPE_WMF | Spécifie que le métafichier est un métafichier WMF qui spécifie des opérations graphiques avec des enregistrements WMF, comme indiqué dans [MS-WMF]. |
| METAFILE_DATA_TYPE_WMF_PLACEABLE | Spécifie que le métafichier est un métafichier WMF qui spécifie des opérations graphiques avec des enregistrements WMF, et qui contient des informations d’en-tête supplémentaires rendant le métafichier WMF indépendant du dispositif, comme indiqué dans [MS-WMF]. |
