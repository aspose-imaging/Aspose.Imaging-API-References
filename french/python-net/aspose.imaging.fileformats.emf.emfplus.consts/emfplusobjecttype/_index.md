L'énumération ObjectType définit les types d'objets graphiques qui peuvent être créés et utilisés dans les opérations graphiques.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusObjectType

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| OBJECT_TYPE_BRUSH | Spécifie un objet [EmfPlusBrush](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusbrush/) (section 2.2.1.1). Les objets pinceau remplissent les régions graphiques. |
| OBJECT_TYPE_CUSTOM_LINE_CAP | Spécifie un objet [EmfPlusCustomLineCap](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecap/) (section 2.2.1.2). Les objets de terminaison de ligne personnalisée spécifient les formes à dessiner aux extrémités d’une ligne graphique, y compris les carrés, les cercles et les diamants. |
| OBJECT_TYPE_FONT | Spécifie un objet [EmfPlusFont](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusfont/) (section 2.2.1.3). Les objets police spécifient les propriétés de police, y compris le style de la fonte, la taille EM et la famille de police. |
| OBJECT_TYPE_IMAGE | Spécifie un objet [EmfPlusImage](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusimage/) (section 2.2.1.4). Les objets image encapsulent les bitmap et les métafichiers. |
| OBJECT_TYPE_IMAGE_ATTRIBUTES | Spécifie un objet [EmfPlusImageAttributes](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusimageattributes/) (section 2.2.1.5). Les objets d’attributs d’image spécifient les opérations sur les pixels lors du rendu d’image, y compris le réglage des couleurs, le réglage du niveau de gris, la correction gamma et le mappage des couleurs. |
| OBJECT_TYPE_INVALID | L’objet n’est pas un objet valide. |
| OBJECT_TYPE_PATH | Spécifie un objet [EmfPlusPath](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfpluspath/) (section 2.2.1.6). Les objets chemin spécifient des séquences de lignes, de courbes et de formes. |
| OBJECT_TYPE_PEN | Spécifie un objet [EmfPlusPen](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfpluspen/) (section 2.2.1.7). Les objets stylo dessinent des lignes graphiques. |
| OBJECT_TYPE_REGION | Spécifie un objet [EmfPlusRegion](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusregion/) (section 2.2.1.8). Les objets région spécifient les zones de la surface de sortie. |
| OBJECT_TYPE_STRING_FORMAT | Spécifie un objet [EmfPlusStringFormat](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusstringformat/) (section 2.2.1.9). Les objets de format de chaîne spécifient la mise en page du texte, y compris l’alignement, l’orientation, les tabulations, le rognage et la substitution de chiffres pour les langues qui n’utilisent pas les chiffres occidentaux. |
