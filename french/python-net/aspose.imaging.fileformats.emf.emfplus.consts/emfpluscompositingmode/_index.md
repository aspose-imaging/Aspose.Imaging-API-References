L'énumération CompositingMode définit les modes de combinaison des couleurs source avec les couleurs d'arrière-plan. Le mode de composition représente l'état d'activation du mélange alpha.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusCompositingMode

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| COMPOSITING_MODE_SOURCE_COPY | Désactive le mélange alpha, ce qui signifie que lorsqu'une couleur source est rendue, elle écrase la couleur d'arrière-plan. |
| COMPOSITING_MODE_SOURCE_OVER | Active le mélange alpha, ce qui spécifie que lorsqu'une couleur est rendue, elle est mélangée avec la couleur d'arrière-plan. L'étendue du mélange est déterminée par la valeur du composant alpha de la couleur rendue. |
