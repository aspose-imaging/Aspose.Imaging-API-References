Les indicateurs CustomLineCapData spécifient les données pour les extrémités de ligne personnalisées. Ces indicateurs peuvent être combinés pour spécifier plusieurs options.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusCustomLineCapDataFlags

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| CUSTOM_LINE_CAP_DATA_FILL_PATH | Si défini, un objet [EmfPlusFillPath](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusfillpath/) DOIT être spécifié dans le champ OptionalData de l'objet [EmfPlusCustomLineCapData](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecapdata/) pour remplir le capuchon de ligne personnalisé. |
| CUSTOM_LINE_CAP_DATA_LINE_PATH | Si défini, un objet [EmfPlusLinePath](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfpluslinepath/) DOIT être spécifié dans le champ OptionalData de l'objet EmfPlusCustomLineCapData pour tracer le contour du capuchon de ligne personnalisé. |
