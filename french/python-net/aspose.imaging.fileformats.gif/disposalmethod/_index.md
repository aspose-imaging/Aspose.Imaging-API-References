Indique la manière dont le graphique doit être traité après son affichage.

**Module:** [aspose.imaging.fileformats.gif](/imaging/python-net/aspose.imaging.fileformats.gif/)

**Full Name:** aspose.imaging.fileformats.gif.DisposalMethod

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| NONE | Aucune élimination spécifiée. |
| CONSERVER | Ne pas disposer. Le graphique doit rester en place. |
| PREVIUOS | Restaurer à l'état précédent. Le décodeur doit restaurer la zone écrasée par le graphique avec ce qui était présent avant le rendu du graphique. |
| RESTORE | Restaurer à la couleur d'arrière-plan. La zone utilisée par le graphique doit être restaurée à la couleur d'arrière-plan. |
| UNDEFINED | Valeur indéfinie. |
