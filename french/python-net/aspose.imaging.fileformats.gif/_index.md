Le module gère le traitement du format de fichier Gif.

## **Classes**
| **Classe** | **Description** |
| :- | :- |
| [GifBlock](/imaging/python-net/aspose.imaging.fileformats.gif/gifblock/) | L'implémentation par défaut du bloc GIF. |
| [GifBlocksRegistry](/imaging/python-net/aspose.imaging.fileformats.gif/gifblocksregistry/) | Représente le registre des ouvreurs de blocs GIF. |
| [GifImage](/imaging/python-net/aspose.imaging.fileformats.gif/gifimage/) | L'API du format d'image Graphical Interchange Format (GIF) fournit<br/>            aux développeurs des outils polyvalents pour le traitement des images raster compressées et<br/>            des GIF animés. Offrant des fonctionnalités telles que la gestion des métadonnées XMP, les réglages de palette de couleurs<br/>            , le contrôle du fond et de la couleur transparente, les paramètres d'opacité, le redimensionnement,<br/>            le recadrage, l'application de filtres, les corrections gamma, l'ajustement du contraste, la transformation en niveaux de gris<br/>            , et la conversion vers d'autres formats. Cette API permet une manipulation fluide<br/>            et l'amélioration des images GIF pour un large éventail d'applications. |
| [IGifBlock](/imaging/python-net/aspose.imaging.fileformats.gif/igifblock/) | Représente l'interface du bloc GIF. |
| [IGifBlockLoaderDescriptor](/imaging/python-net/aspose.imaging.fileformats.gif/igifblockloaderdescriptor/) | Descripteur du chargeur de bloc GIF. |
