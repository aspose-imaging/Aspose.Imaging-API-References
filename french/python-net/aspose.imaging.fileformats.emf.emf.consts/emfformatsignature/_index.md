L'énumération FormatSignature définit des valeurs utilisées pour identifier le format des données intégrées dans les enregistrements EMF.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfFormatSignature

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| ENHMETA_SIGNATURE | La valeur de ce membre est la séquence de caractères ASCII "FME ",<br/>            qui se révèle être l'inverse de la chaîne "EMF", et elle désigne les données d'enregistrement EMF.<br/>            Remarque : le caractère d'espace dans la chaîne est significatif et DOIT être présent. |
| EPS_SIGNATURE | La valeur de ce membre est la séquence de caractères ASCII "FSPE", qui se révèle <br/>            être l'inverse de la chaîne "EPSF", et elle désigne les données du format PostScript encapsulé (EPS). |
