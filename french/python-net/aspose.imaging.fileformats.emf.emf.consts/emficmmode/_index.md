L'énumération ICMMode définit des valeurs qui spécifient quand activer ou désactiver l'ICM.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfIcmMode

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| ICM_DONE_OUTSIDEDC | Désactive ICM dans le contexte du dispositif de lecture, et désactive la correction des couleurs de type ancien des demi-teintes |
| ICM_OFF | Désactive la gestion des couleurs d'image (ICM) dans le contexte du dispositif de lecture. Active la correction des couleurs de type ancien des demi-teintes |
| ICM_ON | Active ICM dans le contexte du dispositif de lecture. Désactive la correction des couleurs de type ancien des demi-teintes. |
| ICM_QUERY | Interroge l'état actuel de la gestion des couleurs dans le contexte du dispositif de lecture. |
