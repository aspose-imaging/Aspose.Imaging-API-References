L'énumération FloodFill définit des valeurs qui spécifient comment déterminer la zone pour une opération de remplissage.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfFloodFill

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| FLOODFILLBORDER | La zone de remplissage est limitée par une couleur spécifique. |
| FLOODFILLSURFACE | La zone de remplissage est définie par une couleur spécifique. Le remplissage continue vers l'extérieur dans toutes les directions<br/>             tant que la couleur est rencontrée. Ce style est utile pour remplir des zones avec des limites multicolores |
