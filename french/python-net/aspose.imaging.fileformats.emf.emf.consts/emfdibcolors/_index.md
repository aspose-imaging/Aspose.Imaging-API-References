L'énumération DIBColors définit comment interpréter les valeurs dans la table de couleurs d'un DIB.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfDibColors

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| DIB_PAL_COLORS | La table de couleurs se compose d'un tableau d'index 16 bits vers l'objet LogPalette (section 2.2.17) qui est actuellement défini dans le contexte de périphérique de lecture. |
| DIB_PAL_INDICES | Aucune table de couleurs n'existe. Les pixels du DIB sont des indices vers la palette logique actuelle dans le contexte de périphérique de lecture. |
| DIB_RGB_COLORS | La table de couleurs contient des valeurs RGB littérales |
