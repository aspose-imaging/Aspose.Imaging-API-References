Spécifie l'unité de mesure des données fournies.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.GraphicsUnit

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| DISPLAY | Spécifie l'unité de mesure du dispositif d'affichage. Typiquement des pixels pour les écrans vidéo, et 1/100 de pouce pour les imprimantes. |
| DOCUMENT | Spécifie l'unité du document (1/300 pouce) comme unité de mesure. |
| POUCE | Spécifie le pouce comme unité de mesure. |
| MILLIMETER | Spécifie le millimètre comme unité de mesure. |
| PIXEL | Spécifie un pixel d'appareil comme unité de mesure. |
| POINT | Spécifie le point d'imprimante (1/72 pouce) comme unité de mesure. |
| WORLD | Spécifie l'unité du système de coordonnées mondial comme unité de mesure. |
