Spécifie les canaux individuels dans l'espace colorimétrique CMJN (cyan, magenta, jaune, noir). Cette énumération est utilisée par les méthodes SetOutputChannel.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.ColorChannelFlag

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| COLOR_CHANNEL_C | Le canal de couleur cyan. |
| COLOR_CHANNEL_K | Le canal de couleur noir. |
| COLOR_CHANNEL_LAST | Le dernier canal sélectionné doit être utilisé. |
| COLOR_CHANNEL_M | Le canal de couleur magenta. |
| COLOR_CHANNEL_Y | Le canal de couleur jaune. |
