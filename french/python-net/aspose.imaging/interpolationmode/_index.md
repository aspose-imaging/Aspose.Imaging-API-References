L'énumération [InterpolationMode](/imaging/python-net/aspose.imaging/interpolationmode/) spécifie l'algorithme utilisé lorsque les images sont redimensionnées ou pivotées.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.InterpolationMode

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| BICUBIC | Spécifie une interpolation bicubique. Aucun préfiltrage n'est effectué. Ce mode n'est pas adapté à la réduction d'une image en dessous de 25 % de sa taille originale. |
| BILINEAR | Spécifie une interpolation bilinéaire. Aucun préfiltrage n'est effectué. Ce mode n'est pas adapté à la réduction d'une image en dessous de 50 % de sa taille originale. |
| DEFAULT | Spécifie le mode par défaut. |
| HIGH | Spécifie une interpolation de haute qualité. |
| HIGH_QUALITY_BICUBIC | Spécifie une interpolation bicubique de haute qualité. Un préfiltrage est effectué pour garantir une réduction de haute qualité. Ce mode produit les images transformées de la meilleure qualité. |
| HIGH_QUALITY_BILINEAR | Spécifie une interpolation bilinéaire de haute qualité. Un préfiltrage est effectué pour garantir une réduction de haute qualité. |
| INVALID | Mode d'interpolation invalide. |
| LOW | Spécifie une interpolation de basse qualité. |
| NEAREST_NEIGHBOR | Spécifie une interpolation du voisin le plus proche. |
