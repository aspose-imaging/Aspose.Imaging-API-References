Spécifie de combien une image est pivotée et l'axe utilisé pour la retourner.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.RotateFlipType

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |

| ROTATE_180_FLIP_X | Spécifie une rotation de 180 degrés dans le sens des aiguilles d'une montre suivie d'un retournement horizontal. |
| ROTATE_180_FLIP_XY | Spécifie une rotation de 180 degrés dans le sens des aiguilles d'une montre suivie d'un retournement horizontal et vertical. |

| ROTATE_270_FLIP_XY | Spécifie une rotation de 270 degrés dans le sens horaire suivie d'un retournement horizontal et vertical. |
| ROTATE_270_FLIP_Y | Spécifie une rotation de 270 degrés dans le sens horaire suivie d'un retournement vertical. |
| ROTATE_90_FLIP_NONE | Spécifie une rotation de 90 degrés dans le sens horaire sans retournement. |
