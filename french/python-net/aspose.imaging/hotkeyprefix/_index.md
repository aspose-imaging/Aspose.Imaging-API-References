Spécifie le type d'affichage des préfixes de raccourcis clavier liés au texte.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.HotkeyPrefix

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| MASQUER | Ne pas afficher le préfixe du raccourci clavier. |
| NONE | Pas de préfixe de raccourci clavier. |
| AFFICHER | Afficher le préfixe du raccourci clavier. |
