Définit le mode d’entrelacement pour les données de pixels multi-composants (couleur).

**Module:** [aspose.imaging.fileformats.jpeg](/imaging/python-net/aspose.imaging.fileformats.jpeg/)

**Full Name:** aspose.imaging.fileformats.jpeg.JpegLsInterleaveMode

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| LIGNE | Le mode d'entrelacement est par ligne. Une ligne complète de chaque composant est encodée avant de passer à la ligne suivante. |
| NONE | Les données sont encodées et stockées composant par composant : RRRGGGBBB. |
| ÉCHANTILLON | Les données sont encodées et stockées par échantillon. Pour les images couleur, c'est le format comme RGBRGBRGB. |
