L'énumération BrushStyle spécifie les différents types de pinceaux possibles<br/>                qui peuvent être utilisés dans les opérations graphiques. Pour plus d'informations, consultez la<br/>                spécification de l'objet Brush (section 2.2.1.1).

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfBrushStyle

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| DIBPATTERN | Un pinceau à motif spécifié par un DIB. |
| DIBPATTERNPT | Un pinceau à motif spécifié par un DIB. |
| DIBPATTERN_8X8 | Non pris en charge. |
| GRADIENT | Le gradient<br/>            non pris en charge dans wmf, pris en charge dans odg. |
| HATCHED | Un pinceau qui peint un motif simple prédéfini, ou \"hatch\", sur un arrière-plan uni |
| INDEXED | Non pris en charge. |
| MONOPATTERN | Non pris en charge. |
| NULL | Un pinceau qui ne fait rien. Utiliser un pinceau NULL dans une opération graphique<br/>                DOIT avoir le même effet que de ne pas utiliser de pinceau du tout |
| PATTERN | Un pinceau qui peint un motif défini par un bitmap, qui PEUT être un objet Bitmap16<br/>                ou un objet DeviceIndependentBitmap (DIB). |
| PATTERN_8X8 | Non pris en charge. |
| SOLID | Un pinceau qui peint une couleur unique et constante, soit solide, soit tramage. |
