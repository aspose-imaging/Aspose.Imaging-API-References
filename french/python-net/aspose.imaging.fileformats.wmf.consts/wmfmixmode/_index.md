L'énumération MixMode spécifie le mode de mélange d'arrière-plan pour le texte, les pinceaux hachurés,<br/>                et les autres styles de stylo non plein.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfMixMode

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| OPAQUE | L'arrière-plan est rempli avec la<br/>                couleur d'arrière-plan actuellement définie dans le contexte de périphérique de lecture avant que le texte, le pinceau à hachures ou le stylo ne soient<br/>                dessinés. |
| TRANSPARENT | L'arrière-plan reste intact. |
