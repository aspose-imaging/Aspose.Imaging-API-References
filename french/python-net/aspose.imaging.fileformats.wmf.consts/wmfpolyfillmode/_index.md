L'énumération PolyFillMode spécifie la méthode utilisée pour remplir un<br/>                polygone.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfPolyFillMode

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| ALTERNATE | Sélectionne le mode alternatif (remplit la zone entre les côtés impairs et pairs du polygone à chaque ligne de balayage). |
| WINDING | Sélectionne le mode d'enroulement (remplit toute région avec une valeur d'enroulement non nulle) |
