L'énumération FloodFill spécifie le type d'opération de remplissage à<br/>                effectuer.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfFloodFillMode

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| FLOOD_FILL_BORDER | La zone de remplissage est limitée par la couleur spécifiée par le membre Color.<br/>                Ce style est identique au remplissage effectué par le<br/>                enregistrement META_FLOODFILL. |
| FLOOD_FILL_SURFACE | La zone de remplissage est limitée par la couleur spécifiée par le membre Color<br/>                . Le remplissage continue vers l’extérieur dans toutes les directions tant que la<br/>                couleur est rencontrée. Ce style est utile pour remplir des zones avec<br/>                des frontières multicolores. |
