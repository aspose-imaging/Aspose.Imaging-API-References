L'énumération ColorUsage spécifie si une table de couleurs existe dans un bitmap indépendant du dispositif<br/>                (DIB) et comment interpréter ses valeurs.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfColorUsageEnum

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| DIB_PAL_COLORS | La table de couleurs contient des indices de 16 bits dans la palette logique actuelle du contexte de périphérique de lecture. |
| DIB_PAL_INDICES | Aucune table de couleurs n'existe. Les pixels du DIB sont des indices dans la<br/>                palette logique actuelle du contexte de périphérique de lecture. |
| DIB_RGB_COLORS | La table de couleurs contient des valeurs RVB spécifiées par les objets RGBQuad (section 2.2.2.20). |
