L'énumération PostScriptClipping définit les fonctions pouvant être appliquées au chemin de découpage<br/>                utilisé pour la sortie PostScript.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfPostScriptClipping

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| CLIP_INCLUSIVE | Intersecte le chemin de découpage PostScript actuel avec le chemin de découpage actuel<br/>                et enregistre le résultat comme le nouveau chemin de découpage PostScript. |
| CLIP_RESTORE | Restaure le chemin de découpage PostScript au dernier chemin de découpage qui a été enregistré<br/>                par une fonction CLIP_SAVE précédente appliquée par un enregistrement CLIP_TO_PATH (section 2.3.6.6). |
| CLIP_SAVE | Enregistre le chemin de découpage PostScript actuel. |
