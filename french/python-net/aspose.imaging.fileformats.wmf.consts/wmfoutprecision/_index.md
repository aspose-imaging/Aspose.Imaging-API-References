L'énumération OutPrecision définit des valeurs pour la précision de sortie, qui est la contrainte pour que le mappeur de polices corresponde à des paramètres de police spécifiques, y compris la hauteur, la largeur, l'orientation des caractères,<br/>                l'angle d'échappement, le pas et le type de police.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfOutPrecision

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| DEFAULT | Une valeur qui spécifie le comportement par défaut. |
| DEVICE | Une valeur qui spécifie le choix d’une police de périphérique lorsque le système<br/>                contient plusieurs polices portant le même nom. |
| OUTLINE | Une valeur qui spécifie l’exigence pour les polices TrueType et autres polices de contour. |
| PS_ONLY | Une valeur qui spécifie une exigence pour uniquement les polices PostScript. S’il<br/>                n’y a aucune police PostScript installée dans le système, le comportement par défaut est spécifié. |
| RASTER | Une valeur qui spécifie le choix d’une police rasterisée lorsque le système<br/>                contient plusieurs polices portant le même nom. |
| SCREEN_OUTLINE | Une valeur qui spécifie une préférence pour les polices TrueType et autres<br/>                polices de contour. |
| STRING | Une valeur qui est renvoyée lorsque les polices rasterisées sont énumérées. |
| STROKE | Une valeur qui est renvoyée lorsque les polices TrueType et autres polices de contour, ainsi que les polices vectorielles, sont énumérées. |
| TT | Une valeur qui spécifie le choix d’une police TrueType lorsque le système<br/>                contient plusieurs polices portant le même nom. |
| TT_ONLY | Une valeur qui spécifie l’exigence pour uniquement les polices TrueType. S’il<br/>                n’y a aucune police TrueType installée dans le système, le comportement par défaut est spécifié. |
