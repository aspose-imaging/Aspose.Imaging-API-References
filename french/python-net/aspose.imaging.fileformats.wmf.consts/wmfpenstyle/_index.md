L'énumération PenStyle 16 bits est utilisée pour spécifier différents types de stylos pouvant être employés dans les opérations graphiques.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfPenStyle

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| ALTERNATE | Le stylo définit chaque deuxième pixel (ce style n'est applicable qu'aux stylos cosmétiques). |
| COSMETIC | Le cosmétique |
| DASH | Le stylo est en tirets. |
| DASHDOT | Le stylo a des tirets et des points alternés. |
| DASHDOTDOT | Le stylo a des tirets et des points doubles. |
| DOT | Le stylo est pointillé. |
| ENDCAP_FLAT | Les embouts de ligne sont plats. |
| ENDCAP_ROUND | Les extrémités de ligne sont rondes. |
| ENDCAP_SQUARE | Les extrémités de ligne sont carrées. |
| INSIDEFRAME | Le stylo est plein. Lorsqu'il est utilisé dans n'importe quel enregistrement de dessin qui prend un rectangle englobant, les dimensions de<br/>                la figure sont réduites afin qu'elle tienne entièrement dans le rectangle englobant, en tenant compte de la largeur du stylo. |
| JOIN_BEVEL | Les jointures de ligne sont biseautées. |
| JOIN_MITER | Les jointures de ligne sont en onglet lorsqu'elles sont dans la limite actuelle<br/>                définie par l'enregistrement SETMITERLIMIT META_ESCAPE. Une jointure est biseautée lorsqu'elle dépasserait la limite. |
| JOIN_ROUND | Les jointures de ligne sont rondes. |
| NULL | Le stylo est invisible. |
| SOLID | Le stylo est plein. |
| USERSTYLE | Le stylo utilise un tableau de style fourni par l'utilisateur. |
