L'énumération LogicalColorSpace spécifie le type d'espace colorimétrique.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfLogicalColorSpaceEnum

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| LCS_CALIBRATED_RGB | Les valeurs de couleur sont des valeurs calibrées rouge vert bleu (RVB). |
| LCS_S_RGB | La valeur est un encodage des caractères ASCII "sRGB", et indique que les<br/>                valeurs de couleur sont des valeurs sRGB. |
| LCS_WINDOWS_COLOR_SPACE | La valeur est un encodage des caractères ASCII "Win ",<br/>                incluant l'espace final, et indique que les valeurs de couleur sont les valeurs d'espace couleur par défaut de Windows. |
