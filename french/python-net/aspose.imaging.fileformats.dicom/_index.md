Le module gère le traitement du format de fichier Dicom

## **Classes**
| **Classe** | **Description** |
| :- | :- |
| [Compression](/imaging/python-net/aspose.imaging.fileformats.dicom/compression/) | Contient les paramètres de compression d'image. |
| [DicomImage](/imaging/python-net/aspose.imaging.fileformats.dicom/dicomimage/) | Cette classe implémente le support du format d'image matricielle Digital Imaging and Communications in Medicine<br/>            (DICOM) et offre une solution complète pour<br/>            le traitement des images DICOM avec précision et flexibilité. Vous pouvez manipuler sans effort<br/>            les pages d'image, y compris les opérations d'obtention, d'ajout ou de suppression de pages, et<br/>            contrôler les pages par défaut et actives. Avec la capacité de travailler avec des canaux alpha,<br/>            d'intégrer des métadonnées XMP, de redimensionner, faire pivoter, recadrer, binariser, ajuster, appliquer des filtres,<br/>            et de convertir vers d'autres formats matriciels. Cette API permet aux développeurs de gérer<br/>            efficacement les images DICOM tout en répondant aux diverses exigences des applications dans<br/>            les contextes d'imagerie médicale. |
| [DicomImageInfo](/imaging/python-net/aspose.imaging.fileformats.dicom/dicomimageinfo/) | Contient toutes les métadonnées du header du fichier DICOM. |
| [DicomPage](/imaging/python-net/aspose.imaging.fileformats.dicom/dicompage/) | C'est une classe pour travailler avec les fichiers DICOM de type multi-trame. |
