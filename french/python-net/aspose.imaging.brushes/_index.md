Le module fournit des classes d'assistance et des méthodes pour travailler avec différents types de pinceaux.

## **Classes**
| **Classe** | **Description** |
| :- | :- |
| [HatchBrush](/imaging/python-net/aspose.imaging.brushes/hatchbrush/) | Définit un pinceau rectangulaire avec un style hachuré, une couleur de premier plan et une couleur d'arrière-plan. Cette classe ne peut pas être héritée. |
| [LinearGradientBrush](/imaging/python-net/aspose.imaging.brushes/lineargradientbrush/) | Encapsule un [Brush](/imaging/python-net/aspose.imaging/brush/) avec un dégradé linéaire. Cette classe ne peut pas être héritée. |
| [LinearGradientBrushBase](/imaging/python-net/aspose.imaging.brushes/lineargradientbrushbase/) | Représente un [Brush](/imaging/python-net/aspose.imaging/brush/) avec des capacités de dégradé et des propriétés appropriées. |
| [LinearMulticolorGradientBrush](/imaging/python-net/aspose.imaging.brushes/linearmulticolorgradientbrush/) | Représente un [Brush](/imaging/python-net/aspose.imaging/brush/) avec un dégradé linéaire défini par plusieurs couleurs et des positions appropriées. Cette classe ne peut pas être héritée. |
| [PathGradientBrush](/imaging/python-net/aspose.imaging.brushes/pathgradientbrush/) | Encapsule un objet [Brush](/imaging/python-net/aspose.imaging/brush/) avec un dégradé. Cette classe ne peut pas être héritée. |
| [PathGradientBrushBase](/imaging/python-net/aspose.imaging.brushes/pathgradientbrushbase/) | Représente un [Brush](/imaging/python-net/aspose.imaging/brush/) avec une fonctionnalité de dégradé de chemin de base. |
| [PathMulticolorGradientBrush](/imaging/python-net/aspose.imaging.brushes/pathmulticolorgradientbrush/) | Encapsule un objet [Brush](/imaging/python-net/aspose.imaging/brush/) avec un dégradé. Cette classe ne peut pas être héritée. |
| [SolidBrush](/imaging/python-net/aspose.imaging.brushes/solidbrush/) | Le pinceau plein est destiné au dessin continu avec une couleur spécifique. Cette classe ne peut pas être héritée. |
| [TextureBrush](/imaging/python-net/aspose.imaging.brushes/texturebrush/) | Chaque propriété de la classe [TextureBrush](/imaging/python-net/aspose.imaging.brushes/texturebrush/) est un objet [Brush](/imaging/python-net/aspose.imaging/brush/) qui utilise une image pour remplir l'intérieur d'une forme. Cette classe ne peut pas être héritée. |
| [TransformBrush](/imaging/python-net/aspose.imaging.brushes/transformbrush/) | Un [Brush](/imaging/python-net/aspose.imaging/brush/) avec des capacités de transformation. |
