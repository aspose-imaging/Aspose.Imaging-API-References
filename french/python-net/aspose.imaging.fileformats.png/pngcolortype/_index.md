Représente le type de couleur de l'image PNG.

**Module:** [aspose.imaging.fileformats.png](/imaging/python-net/aspose.imaging.fileformats.png/)

**Full Name:** aspose.imaging.fileformats.png.PngColorType

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| GRAYSCALE | Représente le type de couleur où chaque pixel est un échantillon en niveaux de gris. |
| GRAYSCALE_WITH_ALPHA | Représente le type de couleur où chaque pixel est un échantillon en niveaux de gris suivi d'un échantillon alpha. |
| INDEXED_COLOR | Représente le type de couleur où chaque pixel est un indice de palette; un bloc PLTE doit apparaître. |
| TRUECOLOR | Représente le type de couleur où chaque pixel est un triplet R,G,B. |
| TRUECOLOR_WITH_ALPHA | Représente le type de couleur où chaque pixel est un triplet R,G,B suivi d'un échantillon alpha. |
