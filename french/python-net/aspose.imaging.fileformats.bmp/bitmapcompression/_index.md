Spécifie différentes méthodes de compression bitmap.

**Module:** [aspose.imaging.fileformats.bmp](/imaging/python-net/aspose.imaging.fileformats.bmp/)

**Full Name:** aspose.imaging.fileformats.bmp.BitmapCompression

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| ALPHA_BITFIELDS | Champs de bits RGBA. Peut être utilisé uniquement avec des images bitmap de 16 et 32 bits/pixel. |
| CHAMPS DE BITS | Champs de bits RGB. Ne peut être utilisé qu'avec des images bitmap de 16 et 32 bits/pixel. |
| DXT1 | Compression DXT1. Le bitmap contient une texture. |
| JPEG | Compression JPEG. Le bitmap contient une image JPEG. |
| PNG | Compression PNG. Le bitmap contient une image PNG. |
| RGB | Pas de compression. |
| RLE4 | Compression RLE 4 bits/pixel. Ne peut être utilisée qu'avec des images bitmap de 4 bits/pixel. |
| RLE8 | Compression RLE 8 bits/pixel. Ne peut être utilisée qu'avec des images bitmap de 8 bits/pixel. |
