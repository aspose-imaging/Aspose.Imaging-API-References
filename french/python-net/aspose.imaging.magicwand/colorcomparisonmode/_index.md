Spécifie comment les couleurs sont comparées pendant l'algorithme Baguette Magique.

**Module:** [aspose.imaging.magicwand](/imaging/python-net/aspose.imaging.magicwand/)

**Full Name:** aspose.imaging.magicwand.ColorComparisonMode

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |
| CUSTOM | L'algorithme de comparaison des couleurs est défini par l'utilisateur. |
| RGB_DEFAULT | Les couleurs sont comparées dans l'espace colorimétrique RGB.<br/>            Chaque différence de couleur doit respecter le seuil. |
| YUV_DEFAULT | Les couleurs sont comparées dans l'espace colorimétrique YUV.<br/>            Chaque différence de couleur doit respecter le seuil. |
| YUV_LESS_LUMA_SENSITIVE | Les couleurs sont comparées dans l'espace colorimétrique YUV.<br/>            Les différences d'information couleur doivent respecter le seuil, le seuil pour le composant de luminance est doublé. |
