**Full Name:** aspose.imaging.fileformats.core.vectorpaths.PathOperations

## **Members**
| **Nom du membre** | **Description** |
| :- | :- |

| EXCLUDE_OVERLAPPING_SHAPES | Exclure les formes qui se chevauchent (opération XOR). |
