## ExifData.IsBigEndian property

يحصل أو يضبط قيمة تشير إلى ما إذا كانت بيانات EXIF المتدفقة التي تم إنشاؤها منها ذات ترتيب بايت كبير.

```csharp
public bool IsBigEndian { get; set; }
```

### Property Value

`true` إذا كان تدفق بيانات EXIF الذي تم إنشاؤه منه ذو ترتيب كبير النهاية؛ وإلا `false`.
