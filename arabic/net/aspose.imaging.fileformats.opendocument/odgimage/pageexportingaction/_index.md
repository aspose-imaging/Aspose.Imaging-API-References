## OdgImage.PageExportingAction property

تسمح هذه الخاصية باسترجاع أو تعديل الإجراء المرتبط بتصدير الصفحات بسهولة. من خلال التلاعب الدقيق بهذه الخاصية، تكتسب حلول البرمجيات مرونة لتخصيص سلوك تصدير الصفحات وفقًا لمتطلبات التطبيق المحددة، مما يضمن أداءً مثاليًا وتجربة مستخدم محسنة. يرجى ملاحظة أن ضبط هذه الطريقة سيؤدي تلقائيًا إلى تحرير موارد الصفحات بعد تنفيذها. سيتم تنفيذها مباشرةً قبل حفظ كل صفحة.

```csharp
public override PageExportingAction PageExportingAction { get; set; }
```

### Property Value

عملية تصدير الصفحة.
