## Resize(int, int, ImageResizeSettings) {#resize_1}

يضبط أبعاد الصورة وفقًا للعرض والارتفاع وإعدادات إعادة التحجيم المحددة. توفر هذه الطريقة مرونة في تغيير حجم الصور مع الحفاظ على النسب المطلوبة والالتزام بتكوينات إعادة التحجيم المحددة، مما يضمن تعديلًا دقيقًا لأبعاد الصورة لتلبية المتطلبات الخاصة أو معايير العرض.

```csharp
public override void Resize(int newWidth, int newHeight, ImageResizeSettings settings)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| newWidth | Int32 | العرض الجديد. |
| newHeight | Int32 | الارتفاع الجديد. |
| الإعدادات | ImageResizeSettings | إعدادات التحجيم. |

## Resize(int, int, ResizeType) {#resize_2}

تقوم هذه الطريقة بإعادة تحجيم الصورة، مع تعديل كل من العرض والارتفاع بناءً على الأبعاد المحددة ونوع إعادة التحجيم. تقدم نهجًا شاملاً لإعادة التحجيم، مما يسمح بتعديلات دقيقة مع الحفاظ على جودة الصورة وسلامتها. من خلال دمج معامل نوع إعادة التحجيم، يمكن للمستخدمين اختيار خوارزميات أو طرق إعادة تحجيم مختلفة لتحقيق أفضل النتائج لمختلف حالات الاستخدام أو التفضيلات.

```csharp
public override void Resize(int newWidth, int newHeight, ResizeType resizeType)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| newWidth | Int32 | العرض الجديد. |
| newHeight | Int32 | الارتفاع الجديد. |
| resizeType | ResizeType | نوع تغيير الحجم. |
