## OdImage.IsCached property

يحصل على قيمة منطقية تشير إلى ما إذا كانت بيانات الكائن مخزنة مؤقتًا حاليًا، مما يلغي الحاجة إلى قراءة البيانات. تُعد هذه الخاصية مؤشرًا على التحسين، حيث تعزز الأداء من خلال تقليل عمليات الوصول المتكررة للبيانات.

```csharp
public override bool IsCached { get; }
```

### Property Value

`true` إذا كانت بيانات الكائن مخزنة مؤقتًا؛ وإلا `false`.
