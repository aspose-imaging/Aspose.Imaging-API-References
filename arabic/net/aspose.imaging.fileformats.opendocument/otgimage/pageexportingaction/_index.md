## OtgImage.PageExportingAction property

تسمح هذه الخاصية باسترجاع أو تعديل إجراء تصدير الصفحات المرتبط بالصورة. إنها تمثل معلمة حاسمة تُحدد سلوك الصورة عند تصديرها أو معالجتها لاحقًا. يرجى ملاحظة أن ضبط هذه الطريقة سيؤدي تلقائيًا إلى تحرير موارد الصفحات بعد تنفيذها. سيتم تنفيذها مباشرةً قبل حفظ كل صفحة.

```csharp
public override PageExportingAction PageExportingAction { get; set; }
```

عملية تصدير الصفحة.
