## TiffDataType.IsValid property

يحصل على قيمة تشير إلى ما إذا كانت بيانات الوسم صالحة. الوسم الصالح يحتوي على بيانات يمكن حفظها. الوسم غير الصالح لا يمكن تخزينه.

```csharp
public bool IsValid { get; }
```

### Property Value

`true` إذا كانت بيانات العلامة صالحة؛ وإلا `false`.
