## EmfLogPenEx.Width property

يحصل أو يعيّن عدد صحيح غير موقع 32 بت يحدد عرض الخط المرسوم بالقلم. إذا كان نوع القلم في حقل PenStyle هو PS_GEOMETRIC، فإن هذه القيمة هي العرض بوحدات منطقية؛ وإلا يُحدد العرض بوحدات الجهاز. إذا كان نوع القلم في حقل PenStyle هو PS_COSMETIC، يجب أن تكون هذه القيمة 0x00000001.

public int Width { get; set; }
