## EmfPixelFormatDescriptor.DwVisibleMask property

الحصول أو الضبط يحدد اللون الشفاف أو الفهرس لطائرة تحتية. عندما يكون نوع البكسل RGBA، يكون dwVisibleMask قيمة لون RGB شفافة. عندما يكون نوع البكسل فهرس ألوان، يكون قيمة فهرس شفافة.

public int DwVisibleMask { get; set; }
