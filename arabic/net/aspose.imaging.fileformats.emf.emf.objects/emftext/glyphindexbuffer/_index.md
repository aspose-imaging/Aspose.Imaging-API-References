## EmfText.GlyphIndexBuffer property

يحصل أو يعيّن مخزن فهارس القوالب الاختياري. إذا كان للخيارات علم ETO_GLYPH_INDEX فإن رموز الأحرف في سلسلة النص المُخرجة هي في الواقع فهارس لقوالب الأحرف في خط TrueType (تعداد ExtTextOutOptions القسم 2.1.11). فهارس القوالب خاصة بالخط، لذا لعرض الأحرف الصحيحة عند التشغيل، يجب أن يكون الخط المستخدم متماثلًا تمامًا مع الخط المستخدم لإنشاء الفهارس.

```csharp
public int[] GlyphIndexBuffer { get; set; }
```
