## WebPImage.PageExportingAction property

الوصول إلى إجراء تصدير الصفحة أو تعديله، والذي يحدد الإجراء المحدد الذي يتم تنفيذه قبل حفظ كل صفحة. يرجى ملاحظة أن ضبط هذه الخاصية سيؤدي تلقائيًا إلى تحرير موارد الصفحة بعد التنفيذ. استخدم هذه الميزة لأداء إجراءات مخصصة أو مهام تنظيف قبل تصدير كل صفحة، لضمان إدارة موارد مثالية والسلوك المطلوب أثناء عمليات حفظ الصور داخل تطبيقك.

```csharp
public override PageExportingAction PageExportingAction { get; set; }
```

### Property Value

عملية تصدير الصفحة.
