## PngImage.IsInterlaced property

يرجع قيمة منطقية تُظهر ما إذا كان مثيل الصورة متشابكًا. هذه الخاصية حاسمة لتحسين استراتيجيات التحميل وضمان أداء فعّال أثناء مهام معالجة أو عرض الصور.

```csharp
public bool IsInterlaced { get; }
```

### Property Value

`true` إذا كان هذا المثال من الصورة متشابكًا؛ وإلا `false`.
