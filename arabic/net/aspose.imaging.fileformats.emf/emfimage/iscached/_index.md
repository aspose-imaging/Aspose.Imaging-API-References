## EmfImage.IsCached property

الوصول إلى قيمة تشير إلى ما إذا كانت بيانات الكائن مخزنة مؤقتًا حاليًا، مما يلغي الحاجة إلى قراءة بيانات إضافية. عزّز الكفاءة من خلال تحديد سريع ما إذا كانت البيانات المخزنة متاحة للوصول الفوري. حسّن سير عملك بعمليات استرجاع بيانات مبسطة.

```csharp
public override bool IsCached { get; }
```

### Property Value

`true` إذا كانت بيانات الكائن مخزنة مؤقتًا؛ وإلا `false`.
