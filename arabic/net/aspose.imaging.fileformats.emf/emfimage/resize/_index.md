## Resize(int, int, ResizeType) {#resize_2}

عدل حجم صورتك بسهولة باستخدام هذه الدالة، مع تحديد العرض والارتفاع والنوع المطلوب. مثالي لضبط الصور لتناسب الأبعاد المحددة مع الحفاظ على الوضوح والجودة. مثالي لتحسين الصور لمختلف المنصات والتطبيقات.

```csharp
public override void Resize(int newWidth, int newHeight, ResizeType resizeType)
```

| معامل | نوع | الوصف |

| newWidth | Int32 | العرض الجديد. |
| newHeight | Int32 | الارتفاع الجديد. |
| resizeType | ResizeType | نوع تغيير الحجم. |
