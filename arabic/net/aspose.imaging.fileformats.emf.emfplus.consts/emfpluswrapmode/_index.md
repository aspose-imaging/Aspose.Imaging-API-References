## EmfPlusWrapMode enumeration

تحدد تعداد WrapMode كيفية تكرار النمط من القماش أو فرشاة التدرج عبر الشكل أو على حدود الشكل عندما يكون أصغر من المنطقة التي يتم تعبئتها.

```csharp
public enum EmfPlusWrapMode
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| WrapModeTile | `0` | يُكرّر التدرج أو النسيج. |
| WrapModeTileFlipX | `1` | يعكس القوام أو التدرج أفقيًا، ثم يكرر القوام أو التدرج. |
| WrapModeTileFlipY | `2` | يعكس القوام أو التدرج عموديًا، ثم يكرر القوام أو التدرج. |
| WrapModeTileFlipXY | `3` | يعكس القوام أو التدرج أفقيًا وعموديًا، ثم يكرر القوام أو التدرج. |
| WrapModeClamp | `4` | يثبت القوام أو التدرج على حدود الكائن. |
