## EmfPlusFontStyleFlags enumeration

تحدد أعلام FontStyle أنماط خطوط الرسومات. يمكن دمج هذه الأعلام لتحديد خيارات متعددة.

```csharp
[Flags]
public enum EmfPlusFontStyleFlags
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| FontStyleBold | `1` | إذا تم تعيينها، يجب عرض نوع الخط بوزن أو سمك أثقل. إذا لم يتم تعيينها، يجب عرض نوع الخط بسمك عادي. |
| FontStyleItalic | `2` | إذا تم تعيينها، يجب عرض نوع الخط بأعمدة رأسية للأحرف بزاوية أو ميل متزايد مقارنة بالخط الأساسي. إذا لم يتم تعيينها، يجب عرض نوع الخط بأعمدة رأسية للأحرف بزاوية عادية. |
| FontStyleUnderline | `4` | إذا تم تعيينها، يجب عرض نوع الخط بخط تحت الخط الأساسي للأحرف. إذا لم يتم تعيينها، يجب عرض نوع الخط بدون خط تحت الخط الأساسي. |
| FontStyleStrikeout | `8` | إذا تم تعيينها، يجب عرض نوع الخط بخط موازٍ للخط الأساسي مرسوم عبر وسط الأحرف. إذا لم يتم تعيينها، يجب عرض نوع الخط بدون خط عبر الأحرف. |
