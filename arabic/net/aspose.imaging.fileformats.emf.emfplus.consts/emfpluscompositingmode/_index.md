## EmfPlusCompositingMode enumeration

يحدد تعداد CompositingMode أوضاع دمج ألوان المصدر مع ألوان الخلفية. تمثل وضعية التركيب حالة تمكين المزج ألفا.

```csharp
public enum EmfPlusCompositingMode : byte
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| CompositingModeSourceOver | `0` | يفعل المزج ألفا، والذي يحدد أنه عندما يتم عرض لون، يتم دمجه مع لون الخلفية. يتم تحديد مدى الدمج بقيمة المكوّن ألفا للون المعروض. |
| CompositingModeSourceCopy | `1` | يعطل المزج ألفا، مما يعني أنه عندما يتم عرض لون المصدر، يكتب فوق لون الخلفية. |
