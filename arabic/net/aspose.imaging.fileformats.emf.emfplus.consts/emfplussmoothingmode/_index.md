## EmfPlusSmoothingMode enumeration

تحدد تعداد SmoothingMode أوضاع التنعيم التي تُطبق على الخطوط والمنحنيات وحواف المناطق المملوءة لجعلها تبدو أكثر استمرارية أو حادة التعريف.

```csharp
public enum EmfPlusSmoothingMode : byte
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| SmoothingModeDefault | `0` | يحدد التنعيم الافتراضي للمنحنيات بدون مضاد التسنين. |
| SmoothingModeHighSpeed | `1` | يحدد أفضل أداء بدون مضاد التسنين. |
| SmoothingModeHighQuality | `2` | يحدد أفضل جودة مع مضاد التسنين. |
| SmoothingModeNone | `3` | ينفذ بدون تنعيم للمنحنيات وبدون مضاد التسنين. |
| SmoothingModeAntiAlias8x4 | `4` | يحدد جودة جيدة باستخدام مرشح صندوق 8×4. |
