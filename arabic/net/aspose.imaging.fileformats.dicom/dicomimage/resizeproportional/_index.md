## DicomImage.ResizeProportional method

قم بتغيير حجم الصورة مع الحفاظ على نسبة العرض إلى الارتفاع باستخدام هذه الطريقة المريحة. مثالي للمطورين الذين يسعون لضبط أبعاد الصورة بشكل متناسب، مع ضمان التناسق والحفاظ على نسب المحتوى الأصلي. سيقوم تغيير الحجم المتناسب بتغيير حجم كل إطار وفقًا للنسبة بين *newWidth*/العرض و *newHeight*/الارتفاع.

```csharp
public void ResizeProportional(int newWidth, int newHeight, ResizeType resizeType)
```

| newHeight | Int32 | الارتفاع الجديد. |
| resizeType | ResizeType | نوع تغيير الحجم. |
