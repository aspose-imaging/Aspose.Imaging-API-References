## DicomImage.PageExportingAction property

إدارة عملية تصدير الصفحات باستخدام هذه الخاصية البديهية. مثالية للمطورين الذين يرغبون في التحكم بسلوك تصدير صفحات الصورة، وضمان تكامل سلس وتخصيص في مختلف سير عمل معالجة الصور. يرجى ملاحظة أن ضبط هذه الطريقة سيؤدي تلقائيًا إلى تحرير موارد الصفحة بعد تنفيذها. سيتم تنفيذها مباشرة قبل حفظ كل صفحة.

```csharp
public override PageExportingAction PageExportingAction { get; set; }
```
