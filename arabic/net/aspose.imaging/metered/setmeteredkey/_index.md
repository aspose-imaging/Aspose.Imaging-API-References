## Metered.SetMeteredKey method

يضبط المفتاح العام والخاص المحسوب. إذا قمت بشراء ترخيص محسوب، عند بدء التطبيق، يجب استدعاء هذه API، عادةً يكون ذلك كافيًا. ومع ذلك، إذا فشل دائمًا تحميل بيانات الاستهلاك وتجاوزت 24 ساعة، سيتم تعيين الترخيص إلى حالة التقييم؛ لتجنب هذه الحالة، يجب عليك فحص حالة الترخيص بانتظام، إذا كانت في حالة التقييم، استدعِ هذه API مرة أخرى.

```csharp
public void SetMeteredKey(string publicKey, string privateKey)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| publicKey | String | المفتاح العام |
| privateKey | String | المفتاح الخاص |
