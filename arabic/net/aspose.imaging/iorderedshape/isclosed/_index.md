## IOrderedShape.IsClosed property

يحصل أو يعيّن قيمة تشير إلى ما إذا كان الشكل المرتّب مغلقًا. عند معالجة شكل مرتّب مغلق لا يكون لنقطتي البداية والنهاية معنى.

```csharp
public bool IsClosed { get; set; }
```

### Property Value

`True` إذا كان هذا الشكل المرتب مغلقًا؛ وإلا، `false`.
