## StringFormat.DigitSubstitutionLanguage property

يحصل أو يضبط اللغة المستخدمة عندما يتم استبدال الأرقام المحلية بالأرقام الغربية.

```csharp
public int DigitSubstitutionLanguage { get; set; }
```

### Property Value

معرف لغة دعم اللغة الوطنية (NLS) يحدد اللغة التي ستُستخدم عندما يتم استبدال الأرقام المحلية بالأرقام الغربية. يمكنك تمرير خاصية LCID لكائن CultureInfo كمعرف لغة NLS. على سبيل المثال، افترض أنك تنشئ كائن CultureInfo بتمرير السلسلة "ar-EG" إلى مُنشئ CultureInfo. إذا مررت خاصية LCID لذلك الكائن مع طريقة StringDigitSubstitute التقليدية، فستُستبدل الأرقام العربية-الهندية بالأرقام الغربية عند وقت العرض.
