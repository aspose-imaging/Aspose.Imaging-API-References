## Figure.IsClosed property

يحصل أو يضبط قيمة تشير إلى ما إذا كان هذا الشكل مغلقًا. سيُحدث الشكل المغلق فرقًا فقط في الحالة التي تكون فيها أشكال الشكل الأول والأخير أشكالًا متصلة. في هذه الحالة، سيتم ربط النقطة الأولى للشكل الأول بخط مستقيم من النقطة الأخيرة للشكل الأخير.

```csharp
public bool IsClosed { get; set; }
```

### Property Value

`True` إذا كان هذا الشكل مغلقًا؛ وإلا `false`.
