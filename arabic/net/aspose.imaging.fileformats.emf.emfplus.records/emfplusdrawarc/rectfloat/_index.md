## EmfPlusDrawArc.RectFloat property

يحصل أو يعيّن قيمة تشير إلى ما إذا كانت البيانات تحتوي على سجلات EmfPlusRectF أو EmfPlusRect. هذا البت يحدد ما إذا كانت البيانات في حقل RectData مضغوطة. إذا كان مضبوطًا، يحتوي RectData على كائن EmfPlusRect (القسم 2.2.2.38). إذا كان غير مضبوط، يحتوي RectData على كائن EmfPlusRectF (القسم 2.2.2.39).

```csharp
public bool RectFloat { get; set; }
```

### Property Value

`true` إذا كان عائمًا؛ وإلا `false`.
