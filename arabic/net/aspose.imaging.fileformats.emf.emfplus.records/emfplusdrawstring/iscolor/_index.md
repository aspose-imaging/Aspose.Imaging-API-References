## EmfPlusDrawString.IsColor property

يحصل أو يعيّن قيمة تشير إلى ما إذا كانت هذه النسخة لونًا. إذا تم تعيينها، يحدد BrushId لونًا ككائن EmfPlusARGB (القسم 2.2.2.1). إذا لم تُحدد، يحتوي BrushId على فهرس كائن EmfPlusBrush (القسم 2.2.1.1) في جدول كائنات EMF+.

```csharp
public bool IsColor { get; set; }
```

### Property Value

`true` إذا كانت هذه الحالة ملونة؛ وإلا `false`.
