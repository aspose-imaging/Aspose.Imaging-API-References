## EmfPlusDrawBeziers.Compressed property

يحصل أو يعيّن قيمة تشير إلى ما إذا كان PointData مضغوطاً. إذا تم التعيين، يحدد PointData المواقع المطلقة في مساحة الإحداثيات باستخدام إحداثيات صحيحة 16‑بت. إذا لم يتم التعيين، يحدد PointData المواقع المطلقة باستخدام إحداثيات عائمة 32‑بت. ملاحظة: إذا تم تعيين علامة Relative (أدناه)، تكون هذه العلامة غير معرفة ويجب تجاهلها.

```csharp
public bool Compressed { get; set; }
```

### Property Value

`true` إذا كان مضغوطًا؛ وإلا `false`.
