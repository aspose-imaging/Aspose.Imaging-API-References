## EmfPlusDrawBeziers.Relative property

يحصل أو يعيّن قيمة تشير إلى ما إذا كان PointData نسبياً. إذا تم التعيين، كل عنصر في PointData يحدد موقعاً في مساحة الإحداثيات يكون نسبياً إلى الموقع المحدد بالعنصر السابق في المصفوفة. في حالة العنصر الأول في PointData، يُفترض وجود موقع سابق عند الإحداثيات (0,0). إذا لم يتم التعيين، يحدد PointData مواقع مطلقة وفقاً لعلامة C. ملاحظة: إذا تم تعيين هذه العلامة، تكون علامة C (أعلاه) غير معرفة ويجب تجاهلها.

```csharp
public bool Relative { get; set; }
```

### Property Value

`true` إذا كان نسبياً؛ وإلا `false`.
