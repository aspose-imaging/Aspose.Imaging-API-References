## EmfPlusDrawCurve.Compressed property

تحصل أو تعين قيمة تشير إلى ما إذا كان هذا [`EmfPlusDrawClosedCurve`](../../emfplusdrawclosedcurve/) مضغوطًا. هذه البتة تشير إلى ما إذا كان حقل PointData يحدد بيانات مضغوطة. إذا كان مُحددًا، فإن PointData يحدد مواقع مطلقة في مساحة الإحداثيات باستخدام إحداثيات صحيحة 16‑bit. إذا كان غير مُحدد، فإن PointData يحدد مواقع مطلقة في مساحة الإحداثيات باستخدام إحداثيات عائمة 32‑bit. ملاحظة: إذا تم تعيين علم Relative (أدناه)، فإن هذه العلم غير معرف ويجب تجاهله.

```csharp
public bool Compressed { get; set; }
```

### Property Value

`true` إذا كان مضغوطًا؛ وإلا `false`.
