## EmfPlusFillPolygon.IsRelative property

يحصل أو يعيّن قيمة تشير إلى ما إذا كانت هذه المثيلة نسبية. إذا تم الضبط، كل عنصر في PointData يحدد موقعًا في مساحة الإحداثيات يكون نسبياً إلى الموقع المحدد بواسطة العنصر السابق في المصفوفة. في حالة العنصر الأول في PointData، يُفترض وجود موقع سابق عند الإحداثيات (0,0). إذا تم الإلغاء، يحدد PointData مواقع مطلقة وفقًا لعلامة C flag.

```csharp
public bool IsRelative { get; set; }
```

### Property Value

`true` إذا كانت هذه الحالة نسبية؛ وإلا `false`.
