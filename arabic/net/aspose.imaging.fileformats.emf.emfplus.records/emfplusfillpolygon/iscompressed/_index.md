## EmfPlusFillPolygon.IsCompressed property

يحصل أو يعيّن قيمة تشير إلى ما إذا كان هذا المثيل مضغوطًا. إذا تم ضبطه، فإن PointData يحدد المواقع المطلقة في مساحة الإحداثيات باستخدام إحداثيات صحيحة 16‑بت. إذا لم يتم ضبطه، فإن PointData يحدد المواقع المطلقة في مساحة الإحداثيات باستخدام إحداثيات عائمة 32‑بت.

```csharp
public bool IsCompressed { get; set; }
```

### Property Value

`true` إذا كانت هذه المثيلة مضغوطة؛ وإلا `false`.
