## EmfPlusHeader.VideoDisplay property

يحصل أو يعيّن قيمة تشير إلى ما إذا كان عرض فيديو. إذا تم تعيينها، فإن هذه العلامة تشير إلى أن ملف التعريف سُجل باستخدام سياق جهاز مرجعي لشاشة فيديو. إذا لم تُحدد، سُجل ملف التعريف باستخدام سياق جهاز مرجعي لطابعة.

```csharp
public bool VideoDisplay { get; set; }
```

### Property Value

`true` إذا كان [video display]؛ وإلا `false`.
