## EmfPlusDrawClosedCurve.Compressed property

تحصل أو تعيين قيمة تشير إلى ما إذا كان هذا [`EmfPlusDrawClosedCurve`](../) مضغوطًا. هذه البتة تشير إلى ما إذا كان حقل PointData يحدد بيانات مضغوطة. إذا تم ضبطها، يحدد PointData المواقع المطلقة في مساحة الإحداثيات باستخدام إحداثيات صحيحة 16‑bit. إذا لم يتم ضبطها، يحدد PointData المواقع المطلقة في مساحة الإحداثيات باستخدام إحداثيات عائمة 32‑bit. ملاحظة: إذا تم ضبط علم Relative (أدناه)، تكون هذه العلامة غير معرفة ويجب تجاهلها.

```csharp
public bool Compressed { get; set; }
```

### Property Value

`true` إذا كان مضغوطًا؛ وإلا `false`.
