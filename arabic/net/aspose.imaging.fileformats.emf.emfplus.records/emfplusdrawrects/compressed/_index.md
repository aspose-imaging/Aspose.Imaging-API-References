## EmfPlusDrawRects.Compressed property

يحصل أو يعيّن قيمة تشير إلى ما إذا كان PointData مضغوطًا. إذا تم التعيين، يحتوي RectData على كائن EmfPlusRect (القسم 2.2.2.38). إذا تم الإلغاء، يحتوي RectData على كائن EmfPlusRectF (القسم 2.2.2.39).

```csharp
public bool Compressed { get; set; }
```

### Property Value

`true` إذا كان مضغوطًا؛ وإلا `false`.
