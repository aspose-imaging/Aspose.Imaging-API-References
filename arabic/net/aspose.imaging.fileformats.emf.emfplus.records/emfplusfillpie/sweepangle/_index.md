## EmfPlusFillPie.SweepAngle property

يحصل أو يعيّن زاوية المسح. عدد عائم 32 بت يحدد مدى القوس الذي يحدد قطعة الفطيرة المراد رسمها، كزاوية بالدرجات مقاسة من النقطة البداية المحددة بقيمة StartAngle. أي قيمة مقبولة، لكن يجب تقييدها بين -360.0 إلى 360.0 شامل. القيمة الموجبة تشير إلى أن المسح يُعرف باتجاه عقارب الساعة، والقيمة السالبة تشير إلى أن المسح يُعرف باتجاه عكس عقارب الساعة.

```csharp
public float SweepAngle { get; set; }
```
