## WmfLogColorSpaceW.ColorSpaceType property

يحصل أو يعيّن عددًا صحيحًا موقّعًا 32‑بت يحدد نوع مساحة اللون. يجب أن يكون معرفًا في تعداد LogicalColorSpace (القسم 2.1.1.14). إذا كانت هذه القيمة LCS_sRGB أو LCS_WINDOWS_COLOR_SPACE، يجب استخدام مساحة اللون sRGB.

public WmfLogicalColorSpaceEnum ColorSpaceType { get; set; }
