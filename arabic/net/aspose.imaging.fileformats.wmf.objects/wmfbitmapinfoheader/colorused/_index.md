## WmfBitmapInfoHeader.ColorUsed property

يحصل أو يعيّن عددًا صحيحًا غير موقع 32-بت يحدد عدد الفهارس في جدول الألوان الذي يستخدمه DIB، كما يلي: إذا كانت هذه القيمة صفرًا، يستخدم DIB الحد الأقصى لعدد الألوان التي تتطابق مع قيمة BitCount. إذا كانت هذه القيمة غير صفرية وكانت قيمة BitCount أقل من 16، تحدد هذه القيمة عدد الألوان المستخدمة بواسطة DIB. إذا كانت هذه القيمة غير صفرية وكانت قيمة BitCount 16 أو أكثر، تحدد هذه القيمة حجم جدول الألوان المستخدم لتحسين أداء لوحة النظام. ملاحظة: إذا كانت هذه القيمة غير صفرية وأكبر من الحد الأقصى الممكن لحجم جدول الألوان بناءً على قيمة BitCount، يجب افتراض الحد الأقصى لحجم جدول الألوان.

```csharp
public int ColorUsed { get; set; }
```
