## WmfBitmapInfoHeader.Compression property

يحصل أو يعيّن عددًا صحيحًا غير موقع 32-بت يحدد وضع الضغط لـ DIB. يجب أن تكون هذه القيمة ضمن تعداد Compression (القسم 2.1.1.7). يجب ألا تحدد هذه القيمة تنسيقًا مضغوطًا إذا كان DIB صورة bitmap من الأعلى إلى الأسفل، كما يشير إليه قيمة Height.

public WmfCompression Compression { get; set; }
