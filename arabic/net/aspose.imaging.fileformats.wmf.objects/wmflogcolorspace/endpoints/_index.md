## WmfLogColorSpace.Endpoints property

يسترجع أو يعيّن كائن CIEXYZTriple (القسم 2.2.2.7) الذي يحدد إحداثيات اللون CIE للكروماتية x و y و z للثلاثة ألوان التي تتطابق مع نقاط النهاية RGB للمساحة اللونية المنطقية المرتبطة بالصورة النقطية. إذا لم يحدد حقل [`ColorSpaceType`](../colorspacetype/) القيمة LCS_CALIBRATED_RGB، يجب تجاهل هذا الحقل.

```csharp
public WmfCieXyzTriple Endpoints { get; set; }
```
