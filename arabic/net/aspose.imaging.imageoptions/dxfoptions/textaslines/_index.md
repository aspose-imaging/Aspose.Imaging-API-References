## DxfOptions.TextAsLines property

ما إذا كان يجب تصدير النص كحدود تتكون من خطوط متعددة النقاط (افتراضي) أو ككيانات TEXT قابلة للتحرير في AutoCAD. إذا تم ضبط هذا الخيار

```csharp
public bool TextAsLines { get; set; }
```

### Property Value

`true` لتصدير النص كخطوط حدودية (افتراضي)، وإلا، `false` لتصدير النص ككيانات TEXT.
