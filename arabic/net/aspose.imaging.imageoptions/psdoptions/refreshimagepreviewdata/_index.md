## PsdOptions.RefreshImagePreviewData property

يحصل أو يضبط قيمة تشير إلى ما إذا كان [refresh image preview data] - خيار يُستخدم لتعزيز التوافق مع عارضات صور PSD أخرى. يرجى ملاحظة أن رسم طبقات النص إلى التخطيط النهائي غير مدعوم لمنصة Compact Framework.

```csharp
public bool RefreshImagePreviewData { get; set; }
```

### Property Value

`true` إذا كان [refresh image preview data]؛ وإلا `false`.
