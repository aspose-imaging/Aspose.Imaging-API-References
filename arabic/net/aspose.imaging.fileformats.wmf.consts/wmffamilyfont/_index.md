## WmfFamilyFont enumeration

يحدد تعداد FamilyFont عائلة الخط. تصف عائلات الخط مظهر الخط بطريقة عامة. تُستخدم لتحديد الخطوط عندما لا يتوفر النوع الدقيق المطلوب.

```csharp
public enum WmfFamilyFont : byte
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| Dontcare | `0` | يتم تحديد الخط الافتراضي، وهو يعتمد على التنفيذ. |
| Roman | `1` | خطوط ذات عرض ضربة متغير، يتناسب مع العرض الفعلي للرموز، وتحتوي على حواف. "MS Serif" مثال على ذلك. |
| Swiss | `2` | خطوط ذات عرض ضربة متغير، يتناسب مع العرض الفعلي للرموز، ولا تحتوي على حواف. "MS Sans Serif" مثال على ذلك. |
| Modern | `3` | خطوط ذات عرض ضربة ثابت، مع أو بدون حواف. الخطوط ذات العرض الثابت عادةً ما تكون حديثة. "Pica"، "Elite"، و"Courier New" أمثلة. |
| Script | `4` | خطوط مصممة لتبدو كخط اليد. "Script" و"Cursive" أمثلة. |
| Decorative | `5` | خطوط زينة. "Old English" مثال. |
