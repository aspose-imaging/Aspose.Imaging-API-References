## WmfBrushStyle enumeration

يحدد تعداد BrushStyle الأنواع المختلفة الممكنة للفرش التي يمكن استخدامها في عمليات الرسومات. لمزيد من المعلومات، راجع مواصفات كائن الفرش (القسم 2.2.1.1).

```csharp
public enum WmfBrushStyle
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| Solid | `0` | فرشاة تقوم برسم لون ثابت واحد، إما صلب أو متدرج. |
| Null | `1` | فرشاة لا تفعل شيئًا. استخدام فرشاة NULL في عملية رسومية يجب أن يكون له نفس تأثير عدم استخدام أي فرشاة على الإطلاق. |
| Hatched | `2` | فرشاة تقوم برسم نمط بسيط مسبق التعريف، أو \"hatch\"، على خلفية صلبة. |
| Pattern | `3` | فرشاة تقوم برسم نمط معرف بواسطة صورة نقطية، والتي قد تكون كائن Bitmap16 أو كائن DeviceIndependentBitmap (DIB). |
| Indexed | `4` | غير مدعوم. |
| Dibpattern | `5` | فرشاة نمط محددة بواسطة DIB. |
| Dibpatternpt | `6` | فرشاة نمط محددة بواسطة DIB. |
| Pattern8X8 | `7` | غير مدعوم. |
| Dibpattern8X8 | `8` | غير مدعوم. |
| Monopattern | `9` | غير مدعوم. |
| Gradient | `10` | التدرج غير مدعوم في wmf، مدعوم في odg. |
