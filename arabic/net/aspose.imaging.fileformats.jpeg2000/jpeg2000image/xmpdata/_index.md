## Jpeg2000Image.XmpData property

استرجاع أو تعديل بيانات التعريف XMP المرتبطة بالصورة. هذه الخاصية تمنح الوصول إلى معلومات منصة البيانات الوصفية القابلة للتوسيع (XMP) المدمجة داخل ملف الصورة، مما يسمح بالتلاعب أو استخراج سمات البيانات الوصفية مثل تفاصيل المؤلف، معلومات حقوق النشر، والوسوم الوصفية. استخدام هذه الخاصية يمكّنك من إدارة واستفادة من البيانات الوصفية المدمجة داخل الصورة، مما يعزز التوافق وتدفقات العمل المعتمدة على البيانات الوصفية في مهام معالجة الصور.

```csharp
public override XmpPacketWrapper XmpData { get; set; }
```
