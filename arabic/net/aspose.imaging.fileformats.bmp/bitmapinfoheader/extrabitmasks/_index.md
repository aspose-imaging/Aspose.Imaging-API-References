## BitmapInfoHeader.ExtraBitMasks property

يحصل أو يضبط أقنعة البت الإضافية. تظهر فقط في حالة كون رأس DIB هو BITMAPINFOHEADER وتكون قيمة [`BitmapCompression`](../bitmapcompression/) مضبوطة إما على Bitfields (RGB) أو AlphaBitfields (RGBA).

public int[] ExtraBitMasks { get; set; }
