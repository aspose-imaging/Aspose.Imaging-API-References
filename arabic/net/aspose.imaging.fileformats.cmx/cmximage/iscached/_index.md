## CmxImage.IsCached property

حدد ما إذا كانت بيانات الكائن مخزنة مؤقتاً حالياً، مما يلغي الحاجة إلى قراءة البيانات. مثالي للمطورين الذين يسعون إلى تحسين الأداء باستخدام البيانات المخزنة مؤقتاً بفعالية، لضمان وصول أسرع إلى معلومات الكائن.

```csharp
public override bool IsCached { get; }
```

### Property Value

`true` إذا كانت بيانات الكائن مخزنة مؤقتًا؛ وإلا `false`.
