## GifImage.PageExportingAction property

تمكّن هذه الخاصية من تعديل إجراء التصدير للصفحة، مما يسمح بتحديد الإجراء المطلوب عند تصدير بيانات الصفحة. توفر مرونة في اختيار إجراءات التصدير الملائمة لاحتياجات التطبيق أو سير العمل، مما يعزز التخصيص والقدرة على التكيف. يرجى ملاحظة أن ضبط هذه الطريقة سيؤدي تلقائيًا إلى تحرير موارد الصفحة بعد تنفيذها. سيتم تنفيذها مباشرة قبل حفظ كل صفحة.

```csharp
public override PageExportingAction PageExportingAction { get; set; }
```
