## GifImage.IsPaletteSorted property

تحكم في ترتيب لوحة الألوان في صور GIF الخاصة بك باستخدام هذه الخاصية. سواء كنت بحاجة للتحقق مما إذا كانت لوحة الألوان مرتبة أو تعيين سلوك الترتيب، فإن هذه الخاصية توفر طريقة بسيطة لإدارة تنظيم لوحة الألوان في ملفات GIF.

```csharp
public bool IsPaletteSorted { get; set; }
```

### Property Value

`true` إذا كانت لوحة الألوان مرتبة؛ وإلا `false`.
