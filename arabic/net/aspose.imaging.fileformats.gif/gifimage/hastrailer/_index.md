## GifImage.HasTrailer property

تحكم في وجود مقطع نهائي (trailer) في ملفات GIF الخاصة بك باستخدام هذه الخاصية. سواء كنت بحاجة للتحقق مما إذا كان هناك مقطع نهائي أو تعيين وجوده، فإن هذه الخاصية تبسط العملية. حافظ على هيكلة ملفات GIF الخاصة بك والامتثال باستخدام هذه الميزة البديهية.

```csharp
public bool HasTrailer { get; set; }
```

### Property Value

`true` إذا كان GIF يحتوي على مقطع إضافي؛ وإلا `false`.
