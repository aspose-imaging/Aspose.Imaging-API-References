مساحة الأسماء تتعامل مع معالجة تنسيق ملف Gif.

## الفئات

| الفئة | الوصف |
| --- | --- |
| [GifBlock](./gifblock/) | تنفيذ كتلة gif الافتراضي. |
| [GifBlocksRegistry](./gifblocksregistry/) | يمثل سجل مُفتحات كتل gif. |
| [GifImage](./gifimage/) | توفر API لتنسيق تبادل الرسومات (GIF) أدوات متعددة للمطورين لمعالجة الصور النقطية المضغوطة وملفات GIF المتحركة. تشمل الميزات معالجة بيانات التعريف XMP، إعدادات لوحة الألوان، التحكم في لون الخلفية والشفافية، إعدادات الشفافية، تغيير الحجم، القص، تطبيق الفلاتر، تصحيح غاما، تعديل التباين، تحويل إلى تدرج الرمادي، والتحويل إلى صيغ أخرى. تمكّن هذه API المطورين من التلاعب السلس وتحسين صور GIF لمجموعة واسعة من التطبيقات. |
