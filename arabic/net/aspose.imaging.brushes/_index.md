مساحة الاسم توفر فئات مساعدة وطرق للعمل مع أنواع الفرش المختلفة.

## الفئات

| الفئة | الوصف |
| --- | --- |
| [HatchBrush](./hatchbrush/) | يعرف فرشاة مستطيلة مع نمط تظليل، ولون أمامي، ولون خلفية. لا يمكن وراثة هذه الفئة. |
| [LinearGradientBrush](./lineargradientbrush/) | يغلف [`Brush`](../aspose.imaging/brush/) بتدرج خطي. لا يمكن وراثة هذه الفئة. |
| [LinearGradientBrushBase](./lineargradientbrushbase/) | يمثل [`Brush`](../aspose.imaging/brush/) بقدرات التدرج والخصائص المناسبة. |
| [LinearMulticolorGradientBrush](./linearmulticolorgradientbrush/) | يمثل [`Brush`](../aspose.imaging/brush/) بتدرج خطي محدد بألوان متعددة ومواقع مناسبة. لا يمكن وراثة هذه الفئة. |
| [PathGradientBrush](./pathgradientbrush/) | يغلف كائن [`Brush`](../aspose.imaging/brush/) بتدرج. لا يمكن وراثة هذه الفئة. |
| [PathGradientBrushBase](./pathgradientbrushbase/) | يمثل [`Brush`](../aspose.imaging/brush/) بوظيفة تدرج مسار أساسي. |
| [PathMulticolorGradientBrush](./pathmulticolorgradientbrush/) | يغلف كائن [`Brush`](../aspose.imaging/brush/) بتدرج. لا يمكن وراثة هذه الفئة. |
| [SolidBrush](./solidbrush/) | الفرشاة الصلبة مخصصة للرسم المستمر بلون محدد. لا يمكن وراثة هذه الفئة. |
| [TextureBrush](./texturebrush/) | كل خاصية في فئة [`TextureBrush`](../aspose.imaging.brushes/texturebrush/) هي كائن [`Brush`](../aspose.imaging/brush/) يستخدم صورة لملء داخل الشكل. لا يمكن وراثة هذه الفئة. |
| [TransformBrush](./transformbrush/) | فرشاة [`Brush`](../aspose.imaging/brush/) بقدرات التحويل. |
