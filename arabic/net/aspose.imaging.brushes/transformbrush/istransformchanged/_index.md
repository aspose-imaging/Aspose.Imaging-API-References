## TransformBrush.IsTransformChanged property

يحصل على قيمة تشير إلى ما إذا تم تغيير التحويلات بطريقة ما. على سبيل المثال ضبط مصفوفة التحويل أو استدعاء أي من الطرق التي تغير مصفوفة التحويل. تم تقديم الخاصية للتوافقية الخلفية مع GDI+.

```csharp
public bool IsTransformChanged { get; }
```

### Property Value

`True` إذا تم تغيير التحويل؛ وإلا `false`.
