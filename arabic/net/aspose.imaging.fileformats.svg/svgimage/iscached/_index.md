## SvgImage.IsCached property

يسترجع قيمة منطقية تشير إلى ما إذا كانت بيانات الكائن مخزنة مؤقتًا حاليًا، مما يلغي الحاجة إلى عمليات قراءة إضافية للبيانات. توفر هذه الخاصية نظرة على حالة التخزين المؤقت الحالية، مما يُحسّن عمليات استرجاع البيانات وسير عمل المعالجة لأداء وكفاءة أعلى.

```csharp
public override bool IsCached { get; }
```

### Property Value

`true` إذا كانت بيانات الكائن مخزنة مؤقتًا؛ وإلا `false`.
