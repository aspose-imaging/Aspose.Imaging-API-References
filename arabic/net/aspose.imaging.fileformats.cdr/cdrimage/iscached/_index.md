## CdrImage.IsCached property

حدد بسهولة ما إذا كانت بيانات الكائن مخزنة مؤقتاً حالياً، مما يلغي الحاجة لقراءة البيانات. مثالي للمطورين الذين يسعون لتحسين الأداء باستخدام البيانات المخزنة مؤقتاً بفعالية، مما يضمن وصولاً أسرع إلى معلومات الكائن.

```csharp
public override bool IsCached { get; }
```

### Property Value

`true` إذا كانت بيانات الكائن مخزنة مؤقتًا؛ وإلا `false`.
