## CdrImage.PageExportingAction property

استرجاع أو تعديل إجراء تصدير الصفحات المرتبط بالصورة بسهولة باستخدام هذه الخاصية البديهية. مثالية للمطورين الذين يرغبون في تخصيص سلوك تصدير الصفحات داخل الصور متعددة الصفحات، مما يضمن مرونة وكفاءة في تطبيقاتهم. يرجى ملاحظة أن ضبط هذه الخاصية سيؤدي تلقائيًا إلى تحرير موارد الصفحات بعد تنفيذها. سيتم تنفيذها مباشرة قبل حفظ كل صفحة.

```csharp
public override PageExportingAction PageExportingAction { get; set; }
```

عملية تصدير الصفحة.
