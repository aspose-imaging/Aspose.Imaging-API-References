## EmfPlusBrightnessContrastEffect.BrightnessLevel property

يحصل أو يعيّن عددًا صحيحًا موقعًا 32-بت يحدد مستوى السطوع. This value MUST be in the range -255 through 255, with effects as follows: -255 ≤ value &lt; 0 As the value decreases, the brightness of the image SHOULD decrease. 0 A value of 0 specifies that the brightness MUST NOT change. 0 &lt; value ≤ 255 As the value increases, the brightness of the image SHOULD increase.

public int BrightnessLevel { get; set; }
