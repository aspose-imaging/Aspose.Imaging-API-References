سجل EMR\\_SETMAPMODE يحدد وضعية التخطيط لسياق جهاز التشغيل. وضعية التخطيط تحدد وحدة القياس المستخدمة لتحويل وحدات مساحة الصفحة إلى وحدات مساحة الجهاز، وتحدد أيضًا اتجاه محور x ومحور y للجهاز.
