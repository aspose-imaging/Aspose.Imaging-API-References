تعداد FormatSignature يحدد القيم التي تُستخدم لتحديد تنسيق البيانات المضمنة في سجلات EMF.
## الحقول

| حقل | الوصف |
| --- | --- |
| [ENHMETA_SIGNATURE](#ENHMETA-SIGNATURE) | قيمة هذا العضو هي تسلسل أحرف ASCII \"FME \", والذي يصادف أن يكون عكس السلسلة \"EMF\"، ويشير إلى بيانات سجل EMF. |
| [EPS_SIGNATURE](#EPS-SIGNATURE) | قيمة هذا العضو هي تسلسل أحرف ASCII \"FSPE\", والذي يصادف أن يكون عكس السلسلة \"EPSF\"، ويشير إلى بيانات تنسيق PostScript المغلف (EPS). |
### ENHMETA_SIGNATURE {#ENHMETA-SIGNATURE}
```
public static final int ENHMETA_SIGNATURE
```


قيمة هذا العضو هي تسلسل أحرف ASCII \"FME \", والذي يصادف أن يكون عكس السلسلة \"EMF\"، ويشير إلى بيانات سجل EMF. ملاحظة: المسافة في السلسلة ذات أهمية ويجب أن تكون موجودة.

### EPS_SIGNATURE {#EPS-SIGNATURE}
```
public static final int EPS_SIGNATURE
```


قيمة هذا العضو هي تسلسل أحرف ASCII \"FSPE\", والذي يصادف أن يكون عكس السلسلة \"EPSF\"، ويشير إلى بيانات تنسيق PostScript المغلف (EPS).
