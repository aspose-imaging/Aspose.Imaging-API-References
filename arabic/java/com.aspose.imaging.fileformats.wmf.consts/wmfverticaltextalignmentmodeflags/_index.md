تحدد أعلام وضع محاذاة النص العمودي العلاقة بين نقطة مرجعية ومستطيل محيط لتحديد محاذاة النص. يمكن دمج هذه الأعلام لتحديد خيارات متعددة، مع القيد أن يتم اختيار علم واحد فقط يغيّر موضع الرسم في سياق جهاز التشغيل. يتم تنفيذ محاذاة النص العمودي عندما يكون للخط أساس عمودي افتراضي، مثل كانجي.
