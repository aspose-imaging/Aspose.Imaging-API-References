VerticalTextAlignmentMode Flags تحدد العلاقة بين نقطة مرجعية ومستطيل حد، لتنسيق النص. يمكن دمج هذه العلامات لتحديد خيارات متعددة، مع القيد بأنه يمكن اختيار علامة واحدة فقط تُغيّر موضع الرسم في سياق جهاز التشغيل. يتم تنفيذ محاذاة النص العمودي عندما يكون للخط خط أساس عمودي افتراضي، مثل كانجي.
