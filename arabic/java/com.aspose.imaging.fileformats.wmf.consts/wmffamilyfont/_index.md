### Roman {#Roman}
```

```


خطوط ذات عرض ضربة متغير، يتناسب مع العرض الفعلي للرموز، وتحتوي على حواف. \"MS Serif\" مثال على ذلك.

### Swiss {#Swiss}
```

```


خطوط ذات عرض ضربة متغير، يتناسب مع العرض الفعلي للرموز، ولا تحتوي على حواف. \"MS Sans Serif\" مثال على ذلك.

### Modern {#Modern}
```
public static final byte Modern
```


خطوط ذات عرض ضربة ثابت، مع أو بدون حواف. الخطوط ذات العرض الثابت عادةً ما تكون حديثة. \"Pica\" و\"Elite\" و\"Courier New\" أمثلة.

### Script {#Script}

public static final byte Script

### Decorative {#Decorative}
```
public static final byte Decorative
```
