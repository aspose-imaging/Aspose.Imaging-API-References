### Dontcare {#Dontcare}
```
public static final byte Dontcare
```


الخط الافتراضي محدد، وهو يعتمد على التنفيذ.

### Roman {#Roman}
```
public static final byte Roman
```


الخطوط ذات عرض الضربة المتغيّر، والتي تتناسب مع العرض الفعلي للرموز، وتحتوي على حواف. "MS Serif" مثال على ذلك.

### Swiss {#Swiss}
```
public static final byte Swiss
```


خطوط ذات عرض ضربات متغيرة، تكون متناسبة مع العرض الفعلي للرموز، ولا تحتوي على حواف. "MS Sans Serif" مثال على ذلك.

### Modern {#Modern}
```
public static final byte Modern
```


خطوط ذات عرض ضربات ثابت، مع أو بدون حواف. الخطوط ذات العرض الثابت عادةً ما تكون حديثة. "Pica"، "Elite"، و"Courier New" أمثلة.

### Script {#Script}
```
public static final byte Script
```


خطوط مصممة لتبدو كخط اليد. "Script" و"Cursive" أمثلة.

### Decorative {#Decorative}
```
public static final byte Decorative
```


خطوط novelty. "Old English" مثال على ذلك.
