تحدد تعداد FontQuality مدى قرب تطابق خصائص الخط المنطقي مع<br/>                خصائص الخط الفعلي عند عرض النص.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfFontQuality

## **Members**
| **اسم العضو** | **الوصف** |
| :- | :- |
| ANTIALIASED | يحدد أنه يجب استخدام مضاد التنعيم عند عرض النص، إذا<br/>                كان الخط يدعم ذلك. |
| CLEARTYPE | يحدد أنه يجب استخدام مضاد التنعيم ClearType عند<br/>                عرض النص، إذا كان الخط يدعم ذلك. |
| افتراضي | يحدد أن جودة الأحرف للخط لا تهم، لذا<br/>                يمكن استخدام DRAFT. |
| DRAFT | يحدد أن جودة الأحرف للخط أقل أهمية من<br/>                مطابقة السمات المنطقية. بالنسبة للخطوط المرسومة، يجب تمكين التحجيم، مما<br/>                يعني توفر أحجام خطوط أكثر. |
| NONANTIALIASED | يحدد أنه لا يجب استخدام مضاد التنعيم عند<br/>                عرض النص |
| PROOF | يحدد أن جودة الأحرف للخط أكثر أهمية من<br/>                مطابقة السمات المنطقية. بالنسبة للخطوط المرسومة، يجب تعطيل التحجيم، ويجب اختيار الخط<br/>                الأقرب في الحجم. |
