تحدد تعداد FamilyFont عائلة الخط. عائلات الخطوط تصف مظهر الخط بطريقة<br/>                عامة. تُستخدم لتحديد الخطوط عندما لا يكون النوع الدقيق المطلوب متاحًا.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfFamilyFont

## **Members**
| **اسم العضو** | **الوصف** |
| :- | :- |
| DECORATIVE | خطوط novelty. \"Old English\" هو مثال. |
| DONTCARE | الخط الافتراضي محدد، وهو يعتمد على التنفيذ. |
| MODERN | خطوط ذات عرض خط ثابت، مع أو بدون حواف. الخطوط ذات العرض الثابت عادةً ما تكون حديثة.<br/>                \"Pica\", \"Elite\", و \"Courier New\" أمثلة. |
| ROMAN | خطوط ذات عرض خط متغير، تتناسب مع العرض الفعلي للرموز<br/>                ولها حواف. \"MS Serif\" مثال. |
| SCRIPT | خطوط مصممة لتبدو كخط اليد. \"Script\" و \"Cursive\" أمثلة. |
| SWISS | خطوط ذات عرض خط متغير، تتناسب مع العرض الفعلي للرموز<br/>                ولا تحتوي على حواف. \"MS Sans Serif\" مثال. |
