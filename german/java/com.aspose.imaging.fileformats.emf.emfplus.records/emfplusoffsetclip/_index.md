Der EmfPlusOffsetClip‑Datensatz wendet eine Translations‑Transformation auf die aktuelle Beschneidungsregion für den Weltraum an. Die neue aktuelle Beschneidungsregion wird auf das Ergebnis der Translations‑Transformation gesetzt.
