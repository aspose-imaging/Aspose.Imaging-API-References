Die State‑Record‑Typen geben Operationen am Zustand des Wiedergabegerätekontexts an.

Jeder Grafikzustandscontainer MUSS zu einem Array gespeicherter Grafikcontainer hinzugefügt werden. Der Grafikzustandscontainer wird nicht in die EMF+-Metadatei geschrieben, sodass sein Format von der Implementierung bestimmt werden kann.
