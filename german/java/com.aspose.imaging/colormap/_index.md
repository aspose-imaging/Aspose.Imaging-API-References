Definiert eine Zuordnung zum Konvertieren von Farben. Mehrere Methoden der Klasse [ImageAttributes](../../com.aspose.imaging/imageattributes) passen Bildfarben mithilfe einer Farb‑Remap‑Tabelle an, die ein Array von `com.aspose.imaging.ColorMap`‑Strukturen ist. Nicht vererbbar.
