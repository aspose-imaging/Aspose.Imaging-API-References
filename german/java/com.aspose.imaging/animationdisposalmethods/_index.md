### PRESERVE {#PRESERVE}
```
public static final int PRESERVE
```


Nicht freigeben. Die Grafik bleibt an ihrem Platz.

### BACKGROUND {#BACKGROUND}
```
public static final int BACKGROUND
```


Zur Hintergrundfarbe wiederherstellen. Der von der Grafik genutzte Bereich muss zur Hintergrundfarbe zurückgesetzt werden.

### PREVIOUS {#PREVIOUS}
```
public static final int PREVIOUS
```


Zur vorherigen wiederherstellen. Der Decoder muss den von der Grafik überschriebenen Bereich mit dem vorherigen Zustand wiederherstellen.
