Gibt die Ausrichtung eines `Pen`‑Objekts in Bezug auf die theoretische, nullbreite Linie an.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [Center](#Center) | Gibt an, dass das `Pen`-Objekt über der theoretischen Linie zentriert ist. |
| [Inset](#Inset) | Gibt an, dass das `Pen` auf der Innenseite der theoretischen Linie positioniert ist. |
| [Outset](#Outset) | Gibt an, dass das `Pen` auf der Außenseite der theoretischen Linie positioniert ist. |
| [Left](#Left) | Gibt an, dass das `Pen` links von der theoretischen Linie positioniert ist. |
| [Right](#Right) | Gibt an, dass das `Pen` rechts von der theoretischen Linie positioniert ist. |
