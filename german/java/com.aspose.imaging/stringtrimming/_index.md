Gibt an, wie Zeichen aus einer Zeichenfolge abgeschnitten werden, die nicht vollständig in eine Layout‑Form passt.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [None](#None) | Gibt an, dass kein Trimmen erfolgt. |
| [Character](#Character) | Gibt an, dass der Text bis zum nächsten Zeichen getrimmt wird. |
| [Word](#Word) | Gibt an, dass der Text bis zum nächsten Wort getrimmt wird. |
| [EllipsisCharacter](#EllipsisCharacter) | Gibt an, dass der Text bis zum nächsten Zeichen getrimmt wird und am Ende einer getrimmten Zeile ein Auslassungszeichen eingefügt wird. |
| [EllipsisWord](#EllipsisWord) | Gibt an, dass der Text bis zum nächsten Wort getrimmt wird und am Ende einer getrimmten Zeile ein Auslassungszeichen eingefügt wird. |
| [EllipsisPath](#EllipsisPath) | Der Mittelteil wird aus getrimmten Zeilen entfernt und durch ein Auslassungszeichen ersetzt. |
