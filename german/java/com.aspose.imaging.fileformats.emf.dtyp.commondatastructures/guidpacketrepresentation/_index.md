Die Paketversion wird in Blockprotokollen verwendet. Das folgende Diagramm stellt eine GUID als undurchsichtige Byte‑Sequenz dar. Eine GUID, auch als UUID bekannt, ist eine 16‑Byte‑Struktur, die als eindeutiger Bezeichner für ein Objekt dient. Es gibt drei Darstellungen einer GUID, wie in den folgenden Abschnitten beschrieben.
