Mit der Fähigkeit, CDR-Bildrasterisierung durchzuführen und Skalierungsfaktoren für sowohl X- als auch Y-Dimensionen festzulegen, bietet diese API eine präzise Kontrolle über den Transformationsprozess. Ob Skalierung für spezifische Ausgabeanforderungen oder die Konvertierung von Vektorgrafiken in Rasterformate – Sie können diese API für eine effiziente und anpassbare CDR-Vektor‑zu‑Raster‑Bildkonvertierung nutzen.
