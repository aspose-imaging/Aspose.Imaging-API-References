Liest oder setzt den n saved dc.

Wert: Der wiederherzustellende gespeicherte Zustand. Wenn dieses Mitglied positiv ist, stellt nSavedDC eine bestimmte Instanz des wiederherzustellenden Zustands dar. Wenn dieses Mitglied negativ ist, stellt nSavedDC eine Instanz relativ zum aktuellen Zustand dar.
