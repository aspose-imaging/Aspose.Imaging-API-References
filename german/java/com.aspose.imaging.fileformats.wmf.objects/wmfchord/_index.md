Der META\_CHORD-Datensatz zeichnet einen Akkord, der durch einen Bereich definiert ist, der durch die Schnittmenge einer Ellipse mit einem Liniensegment begrenzt wird. Der Akkord wird mit dem im Wiedergabegerätekontext definierten Stift umrissen und mit dem dort definierten Pinsel gefüllt.
