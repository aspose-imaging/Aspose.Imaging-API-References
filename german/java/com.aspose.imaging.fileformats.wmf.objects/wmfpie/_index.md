Der META\_PIE-Datensatz zeichnet einen keilförmigen Kuchenabschnitt, begrenzt durch die Schnittmenge einer Ellipse und zweier Radien. Der Kuchen wird mit dem im Wiedergabegeräte-Kontext definierten Stift umrandet und mit dem dort definierten Pinsel gefüllt.
