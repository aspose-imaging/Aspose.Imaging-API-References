Der META\_PATBLT-Datensatz malt ein angegebenes Rechteck mit dem im Wiedergabegeräte-Kontext definierten Pinsel. Die Pinsel-Farbe und die Oberflächenfarbe bzw. -farben werden mit der angegebenen Rasteroperation kombiniert.
