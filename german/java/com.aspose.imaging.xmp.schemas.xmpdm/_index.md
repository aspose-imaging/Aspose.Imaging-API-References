Das Paket enthält XMP-bezogene Hilfsklassen, Konstanten und Methoden, die von der Adobe Dynamic Media Group verwendet werden.


## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [AudioChannelType](../com.aspose.imaging.xmp.schemas.xmpdm/audiochanneltype) | Stellt den Audiokanaltyp dar. |
| [AudioSampleType](../com.aspose.imaging.xmp.schemas.xmpdm/audiosampletype) | Stellt den Audiosampletyp in `XmpDynamicMediaPackage` dar. |
| [ProjectLink](../com.aspose.imaging.xmp.schemas.xmpdm/projectlink) | Stellt den Pfad des Projekts dar. |
| [ProjectType](../com.aspose.imaging.xmp.schemas.xmpdm/projecttype) | Stellt den Projekttyp in `XmpDynamicMediaPackage` dar. |
| [Time](../com.aspose.imaging.xmp.schemas.xmpdm/time) | Darstellung eines Zeitwerts in Sekunden. |
| [TimeFormat](../com.aspose.imaging.xmp.schemas.xmpdm/timeformat) | Stellt das Zeitformat in `Timecode` dar. |
| [Timecode](../com.aspose.imaging.xmp.schemas.xmpdm/timecode) | Stellt den Timecode-Wert im Video dar. |
| [XmpDynamicMediaPackage](../com.aspose.imaging.xmp.schemas.xmpdm/xmpdynamicmediapackage) | Stellt den XMP Dynamic Media-Namespace dar. |
