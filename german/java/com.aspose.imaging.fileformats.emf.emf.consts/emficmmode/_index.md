Die Aufzählung ICMMode definiert Werte, die angeben, wann ICM ein- und ausgeschaltet wird.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [ICM_OFF](#ICM-OFF) | Schaltet die Bildfarbverwaltung (ICM) im Wiedergabegeräte-Kontext aus. |
| [ICM_ON](#ICM-ON) | Schaltet ICM im Wiedergabegeräte-Kontext ein. |
| [ICM_QUERY](#ICM-QUERY) | Fragt den aktuellen Zustand der Farbverwaltung im Wiedergabegeräte-Kontext ab. |
| [ICM_DONE_OUTSIDEDC](#ICM-DONE-OUTSIDEDC) | Schaltet ICM im Wiedergabegeräte-Kontext aus und schaltet die altmodische Farbkorrektur von Halbtönen aus. |
