Die Aufzählung ColorAdjustment wird verwendet, um anzugeben, wie das Ausgabebild vorbereitet werden soll, wenn der Dehnungsmodus HALFTONE ist.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [CA_NEGATIVE](#CA-NEGATIVE) | Gibt an, dass das Negative des Originalbildes ANGEZEIGT WERDEN SOLLTE. |
| [CA_LOG_FILTER](#CA-LOG-FILTER) | Der gibt an, dass ein logarithmischer Prozess AUF die endgültige Dichte der Ausgabefarben ANGEWENDET WERDEN SOLLTE. |
### CA_NEGATIVE {#CA-NEGATIVE}
```
public static final int CA_NEGATIVE
```


Gibt an, dass das Negative des Originalbildes ANGEZEIGT WERDEN SOLLTE.

### CA_LOG_FILTER {#CA-LOG-FILTER}
```
public static final int CA_LOG_FILTER
```


Der gibt an, dass ein logarithmischer Prozess AUF die endgültige Dichte der Ausgabefarben ANGEWENDET WERDEN SOLLTE. Dies erhöht den Farbkontrast, wenn die Luminanz niedrig ist.
