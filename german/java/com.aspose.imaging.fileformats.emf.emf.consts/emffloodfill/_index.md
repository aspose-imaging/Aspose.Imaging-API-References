### FLOODFILLSURFACE {#FLOODFILLSURFACE}
```
public static final int FLOODFILLSURFACE
```


Der Füllbereich wird durch eine bestimmte Farbe definiert. Das Füllen setzt sich in alle Richtungen nach außen fort, solange die Farbe gefunden wird. Dieser Stil ist nützlich, um Bereiche mit mehrfarbigen Grenzen zu füllen.
