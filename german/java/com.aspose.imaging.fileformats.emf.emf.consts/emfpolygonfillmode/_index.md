Die PolygonFillMode‑Aufzählung definiert Werte, die festlegen, wie die Region eines auszufüllenden Polygons berechnet wird.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [ALTERNATE](#ALTERNATE) | Wählt den alternativen Modus (füllt den Bereich zwischen ungeraden und geraden Polygonseiten in jeder Scan‑Zeile). |
| [WINDING](#WINDING) | Wählt den Windungsmodus (füllt jede Region mit einem von Null verschiedenen Windungswert). |
