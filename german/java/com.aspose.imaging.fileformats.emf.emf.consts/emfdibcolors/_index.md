Die Aufzählung DIBColors definiert, wie die Werte in der Farbpalette einer DIB interpretiert werden.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [DIB_RGB_COLORS](#DIB-RGB-COLORS) | Die Farbpalette enthält wörtliche RGB-Werte. |
| [DIB_PAL_COLORS](#DIB-PAL-COLORS) | Die Farbpalette besteht aus einem Array von 16‑Bit‑Indizes in das LogPalette‑Objekt (Abschnitt 2.2.17), das derzeit im Wiedergabegerätekontext definiert ist. |
| [DIB_PAL_INDICES](#DIB-PAL-INDICES) | Es existiert keine Farbpalette. |
### DIB_RGB_COLORS {#DIB-RGB-COLORS}
```
public static final int DIB_RGB_COLORS
```

Die Farbpalette enthält wörtliche RGB-Werte.

### DIB_PAL_COLORS {#DIB-PAL-COLORS}
```
public static final int DIB_PAL_COLORS
```


Die Farbpalette besteht aus einem Array von 16‑Bit‑Indizes in das LogPalette‑Objekt (Abschnitt 2.2.17), das derzeit im Wiedergabegerätekontext definiert ist.

### DIB_PAL_INDICES {#DIB-PAL-INDICES}
```
public static final int DIB_PAL_INDICES
```


Es existiert keine Farbpalette. Die Pixel im DIB sind Indizes in die aktuelle logische Palette im Wiedergabegerätekontext.
