Die Aufzählung FormatSignature definiert Werte, die verwendet werden, um das Format eingebetteter Daten in EMF-Datensätzen zu identifizieren.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [ENHMETA_SIGNATURE](#ENHMETA-SIGNATURE) | Der Wert dieses Members ist die Sequenz von ASCII‑Zeichen "FME ", die zufällig die umgekehrte Zeichenkette "EMF" ist, und sie bezeichnet EMF‑Aufzeichnungsdaten. |
| [EPS_SIGNATURE](#EPS-SIGNATURE) | Der Wert dieses Members ist die Sequenz von ASCII‑Zeichen "FSPE", die zufällig die umgekehrte Zeichenkette "EPSF" ist, und sie bezeichnet encapsulated PostScript (EPS) Formatdaten. |
### ENHMETA_SIGNATURE {#ENHMETA-SIGNATURE}
```
public static final int ENHMETA_SIGNATURE
```


Der Wert dieses Members ist die Sequenz von ASCII‑Zeichen "FME ", die zufällig die umgekehrte Zeichenkette "EMF" ist, und sie bezeichnet EMF‑Aufzeichnungsdaten. Hinweis: Das Leerzeichen‑Zeichen in der Zeichenkette ist signifikant und MUSS vorhanden sein.

### EPS_SIGNATURE {#EPS-SIGNATURE}
```
public static final int EPS_SIGNATURE
```


Der Wert dieses Members ist die Sequenz von ASCII‑Zeichen "FSPE", die zufällig die umgekehrte Zeichenkette "EPSF" ist, und sie bezeichnet encapsulated PostScript (EPS) Formatdaten.
