Die Aufzählung HatchStyle ist eine Erweiterung der WMF HatchStyle-Aufzählung ([MS-WMF] Abschnitt 2.1.1.12).
## Felder

| Feld | Beschreibung |
| --- | --- |
| [HS_HORIZONTAL](#HS-HORIZONTAL) | Eine horizontale Schraffur. |
| [HS_VERTICAL](#HS-VERTICAL) | Eine vertikale Schraffur. |
| [HS_FDIAGONAL](#HS-FDIAGONAL) | Eine 45-Grad nach unten, von links nach rechts verlaufende Schraffur. |
| [HS_BDIAGONAL](#HS-BDIAGONAL) | Eine 45-Grad nach oben, von links nach rechts verlaufende Schraffur. |
| [HS_CROSS](#HS-CROSS) | Eine horizontale und vertikale Kreuzschraffur. |
| [HS_DIAGCROSS](#HS-DIAGCROSS) | Eine 45-Grad Kreuzschraffur. |
| [HS_SOLIDCLR](#HS-SOLIDCLR) | Die Schraffur ist kein Muster, sondern eine Vollfarbe. |
| [HS_DITHEREDCLR](#HS-DITHEREDCLR) | Die Schraffur ist kein Muster, sondern eine Vollfarbe. |
| [HS_SOLIDTEXTCLR](#HS-SOLIDTEXTCLR) | Die Schraffur ist kein Muster, sondern eine Vollfarbe, definiert durch die aktuelle Textfarbe (Vordergrund). |
| [HS_DITHEREDTEXTCLR](#HS-DITHEREDTEXTCLR) | Die Schraffur ist kein Muster, sondern eine ditherte Farbe, definiert durch die aktuelle Textfarbe (Vordergrund). |
| [HS_SOLIDBKCLR](#HS-SOLIDBKCLR) | Die Schraffur ist kein Muster, sondern eine Vollfarbe, definiert durch die aktuelle Hintergrundfarbe. |
| [HS_DITHEREDBKCLR](#HS-DITHEREDBKCLR) | Die Schraffur ist kein Muster, sondern eine ditherte Farbe, definiert durch die aktuelle Hintergrundfarbe. |
