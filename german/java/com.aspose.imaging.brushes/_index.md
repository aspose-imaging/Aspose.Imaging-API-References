Das Paket stellt Hilfsklassen und -methoden zur Arbeit mit verschiedenen Pinseltypen bereit.


## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [HatchBrush](../com.aspose.imaging.brushes/hatchbrush) | Definiert einen rechteckigen Pinsel mit Schraffurstil, Vordergrundfarbe und Hintergrundfarbe. |
| [LinearGradientBrush](../com.aspose.imaging.brushes/lineargradientbrush) | Kapselt einen `Aspose.Imaging.Brush` mit einem linearen Farbverlauf. |
| [LinearGradientBrushBase](../com.aspose.imaging.brushes/lineargradientbrushbase) | Stellt einen `Brush` mit Gradientfähigkeiten und entsprechenden Eigenschaften dar. |
| [LinearMulticolorGradientBrush](../com.aspose.imaging.brushes/linearmulticolorgradientbrush) | Stellt einen `Brush` mit linearem Farbverlauf dar, definiert durch mehrere Farben und passende Positionen. |
| [PathGradientBrush](../com.aspose.imaging.brushes/pathgradientbrush) | Kapselt ein `Aspose.Imaging.Brush`‑Objekt mit einem Farbverlauf. |
| [PathGradientBrushBase](../com.aspose.imaging.brushes/pathgradientbrushbase) | Stellt einen `Brush` mit Basis-Pfad‑Gradientfunktionalität dar. |
| [PathMulticolorGradientBrush](../com.aspose.imaging.brushes/pathmulticolorgradientbrush) | Kapselt ein `Aspose.Imaging.Brush`‑Objekt mit einem Farbverlauf. |
| [SolidBrush](../com.aspose.imaging.brushes/solidbrush) | Ein Vollpinsel ist zum kontinuierlichen Zeichnen mit einer bestimmten Farbe gedacht. |
| [TextureBrush](../com.aspose.imaging.brushes/texturebrush) | Jede Eigenschaft der Klasse `Aspose.Imaging.Brushes.TextureBrush` ist ein `Aspose.Imaging.Brush`‑Objekt, das ein Bild verwendet, um das Innere einer Form zu füllen. |
| [TransformBrush](../com.aspose.imaging.brushes/transformbrush) | Ein `Brush` mit Transformationsfähigkeiten. |
