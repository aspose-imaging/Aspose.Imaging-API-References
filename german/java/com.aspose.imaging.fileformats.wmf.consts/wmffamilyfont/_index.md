Die FamilyFont‑Aufzählung gibt die Schriftfamilie an. Schriftfamilien beschreiben das Aussehen einer Schriftart allgemein. Sie dienen dazu, Schriftarten anzugeben, wenn die gewünschte genaue Schriftart nicht verfügbar ist.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [Dontcare](#Dontcare) | Die Standardschriftart wird angegeben, wobei sie implementierungsabhängig ist. |
| [Roman](#Roman) | Schriften mit variabler Strichstärke, die proportional zu den tatsächlichen Breiten der Glyphen sind und Serifen besitzen. |
| [Swiss](#Swiss) | Schriften mit variabler Strichstärke, die proportional zu den tatsächlichen Breiten der Glyphen sind und keine Serifen besitzen. |
| [Modern](#Modern) | Schriften mit konstanter Strichstärke, mit oder ohne Serifen. |
| [Script](#Script) | Schriften, die wie Handschrift aussehen. |
| [Decorative](#Decorative) | Sonderfonts. |
### Dontcare {#Dontcare}
```
public static final byte Dontcare
```


Die Standardschriftart wird angegeben, wobei sie implementierungsabhängig ist.

### Roman {#Roman}
```
public static final byte Roman
```


Schriften mit variabler Strichstärke, die proportional zu den tatsächlichen Breiten der Glyphen sind und Serifen besitzen. "MS Serif" ist ein Beispiel.

### Swiss {#Swiss}
```
public static final byte Swiss
```


Schriften mit variabler Strichstärke, die proportional zu den tatsächlichen Breiten der Glyphen sind und keine Serifen haben. "MS Sans Serif" ist ein Beispiel.

### Modern {#Modern}
```
public static final byte Modern
```


Schriften mit konstanter Strichstärke, mit oder ohne Serifen. Festbreitschriften sind normalerweise modern. "Pica", "Elite" und "Courier New" sind Beispiele.

### Script {#Script}
```
public static final byte Script
```


Schriften, die wie Handschrift aussehen. "Script" und "Cursive" sind Beispiele.

### Decorative {#Decorative}
```
public static final byte Decorative
```


Sonderfonts. "Old English" ist ein Beispiel.
