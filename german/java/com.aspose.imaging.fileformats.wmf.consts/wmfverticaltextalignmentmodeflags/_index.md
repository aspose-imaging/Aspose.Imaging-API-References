VerticalTextAlignmentMode Flags geben die Beziehung zwischen einem Referenzpunkt und einem Begrenzungsrechteck für die Textausrichtung an. Diese Flags können kombiniert werden, um mehrere Optionen anzugeben, wobei die Einschränkung gilt, dass nur ein Flag gewählt werden kann, das die Zeichenposition im Wiedergabegeräte-Kontext ändert. Die vertikale Textausrichtung wird durchgeführt, wenn die Schriftart eine vertikale Standard-Grundlinie hat, wie z. B. bei Kanji.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [VTA_TOP](#VTA-TOP) | Der Referenzpunkt MUSS sich an der oberen Kante des Begrenzungsrechtecks befinden. |
| [VTA_RIGHT](#VTA-RIGHT) | Der Referenzpunkt MUSS sich an der rechten Kante des Begrenzungsrechtecks befinden. |
| [VTA_BOTTOM](#VTA-BOTTOM) | Der Referenzpunkt MUSS sich an der unteren Kante des Begrenzungsrechtecks befinden. |
| [VTA_CENTER](#VTA-CENTER) | Der Referenzpunkt MUSS vertikal mit der Mitte des Begrenzungsrechtecks ausgerichtet sein. |
| [VTA_LEFT](#VTA-LEFT) | Der Referenzpunkt MUSS sich an der linken Kante des Begrenzungsrechtecks befinden. |
| [VTA_BASELINE](#VTA-BASELINE) | Der Referenzpunkt MUSS sich auf der Grundlinie des Textes befinden. |
