Die OutPrecision‑Aufzählung definiert Werte für die Ausgabegenauigkeit, die die Anforderung an den Schriftarten‑Mapper beschreibt, bestimmte Schriftparameter zuzuordnen, einschließlich Höhe, Breite, Zeichenorientierung, Eskapement, Schriftweite und Schriftarttyp.
## Felder

| Feld | Beschreibung |

| [String](#String) | Ein Wert, der zurückgegeben wird, wenn rasterisierte Schriften aufgezählt werden. |
| [Stroke](#Stroke) | Ein Wert, der zurückgegeben wird, wenn TrueType- und andere Konturschriften sowie Vektorschriften aufgezählt werden. |
| [Tt](#Tt) | Ein Wert, der die Auswahl einer TrueType‑Schrift angibt, wenn das System mehrere Schriften mit demselben Namen enthält. |
| [Device](#Device) | Ein Wert, der die Auswahl einer Geräteschrift angibt, wenn das System mehrere Schriften mit demselben Namen enthält. |
