Die PitchFont‑Aufzählung definiert Werte, die zur Angabe von Eigenschaften einer Schrift verwendet werden. Die Werte geben an, ob die Zeichen einer Schrift eine feste oder variable Breite bzw. einen festen bzw. variablen Pitch haben.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [DEFAULT_PITCH](#DEFAULT-PITCH) | Der Standard‑Pitch, der implementationsabhängig ist. |
| [FIXED_PITCH](#FIXED-PITCH) | Ein fester Pitch, was bedeutet, dass alle Zeichen der Schrift bei der Ausgabe in einer Zeichenkette dieselbe Breite einnehmen. |
| [VARIABLE_PITCH](#VARIABLE-PITCH) | Ein variabler Pitch, was bedeutet, dass die Zeichen der Schrift bei der Ausgabe in einer Zeichenkette Breiten einnehmen, die proportional zu den tatsächlichen Breiten der Glyphen sind. |

### VARIABLE_PITCH {#VARIABLE-PITCH}
```
public static final byte VARIABLE_PITCH
```


Ein variabler Pitch, was bedeutet, dass die Zeichen der Schrift bei der Ausgabe in einer Zeichenkette Breiten einnehmen, die proportional zu den tatsächlichen Breiten der Glyphen sind. Zum Beispiel haben die Zeichen "i" und das Leerzeichen normalerweise viel kleinere Breiten als ein "W"‑ oder "O"‑Zeichen.
