Die FloodFill‑Aufzählung gibt die Art der auszuführenden Fülloperation an.
## Felder

| Feld | Beschreibung |

| [FloodFillBorder](#FloodFillBorder) | Der Füllbereich ist durch die vom Color‑Member angegebene Farbe begrenzt. |

### FloodFillBorder {#FloodFillBorder}
```
public static final int FloodFillBorder
```


Der Füllbereich ist durch die vom Color‑Member angegebene Farbe begrenzt. Dieser Stil ist identisch mit der von dem META\_FLOODFILL‑Datensatz durchgeführten Füllung.

### FloodFillSurface {#FloodFillSurface}
```
public static final int FloodFillSurface
```


Der Füllbereich ist durch die vom Color‑Member angegebene Farbe begrenzt. Die Füllung setzt sich in alle Richtungen fort, solange die Farbe gefunden wird. Dieser Stil ist nützlich, um Bereiche mit mehrfarbigen Grenzen zu füllen.
