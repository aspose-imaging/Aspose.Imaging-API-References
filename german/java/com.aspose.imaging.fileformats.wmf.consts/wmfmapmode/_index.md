### Text {#Text}
```
public static final short Text
```


Der Text Jede logische Einheit wird einem Geräte-Pixel zugeordnet. Positives x ist nach rechts; positives y ist nach unten.

### Lometric {#Lometric}
```
public static final short Lometric
```

Der lometric Jede logische Einheit wird auf 0,1 Millimeter abgebildet. Positives x ist nach rechts; positives y ist nach oben.

### Himetric {#Himetric}
```
public static final short Himetric
```


Der himetric Jede logische Einheit wird auf 0,01 Millimeter abgebildet. Positives x ist nach rechts; positives y ist nach oben.

### Loenglish {#Loenglish}

```
public static final short Loenglish
```

### Hienglish {#Hienglish}
```
public static final short Hienglish
```


Der hienglish Jede logische Einheit wird auf 0,001 Zoll abgebildet. Positives x ist nach rechts; positives y ist nach oben.

### Twips {#Twips}
```
public static final short Twips
```


Der twips Jede logische Einheit wird auf ein Zwanzigstel (1/20) eines Punktes abgebildet. Beim Drucken ist ein Punkt 1/72 Zoll; daher ist 1/20 eines Punktes 1/1440 Zoll. Diese Einheit ist auch als "twip" bekannt.

### Isotropic {#Isotropic}
```
public static final short Isotropic
```


Der isotropic Logische Einheiten werden auf beliebige Geräteeinheiten mit gleich skalierten Achsen abgebildet; das heißt, eine Einheit entlang der x-Achse ist gleich einer Einheit entlang der y-Achse. Die META\_SETWINDOWEXT- und META\_SETVIEWPORTEXT‑Datensätze geben die Einheiten und die Orientierung der Achsen an.

### Anisotropic {#Anisotropic}
```
public static final short Anisotropic
```


Der anisotrope Logische Einheiten werden beliebigen Einheiten mit beliebig skalierten Achsen zugeordnet.
