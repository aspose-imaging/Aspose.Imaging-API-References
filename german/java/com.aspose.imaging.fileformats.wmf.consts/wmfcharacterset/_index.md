Die CharacterSet‑Aufzählung definiert die möglichen Zeichensatzgruppen, die in Schriftarten für die Grafikausgabe definiert sind.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [Ansi](#Ansi) | Gibt den englischen Zeichensatz an. |
| [Default](#Default) | Gibt einen Zeichensatz basierend auf dem aktuellen System‑Locale an; zum Beispiel, wenn das System‑Locale US‑Englisch ist, ist der Standardzeichensatz ANSI\_CHARSET. |
| [Symbol](#Symbol) | Gibt einen Zeichensatz für Symbole an. |
| [Mac](#Mac) | Gibt den Apple‑Macintosh‑Zeichensatz an. |
| [Shiftjis](#Shiftjis) | Gibt den japanischen Zeichensatz an. |
| [Hangul](#Hangul) | Auch geschrieben "Hangeul". |
| [Johab](#Johab) | Auch geschrieben "Johap". |
| [Gb2312](#Gb2312) | Gibt den "vereinfachten" chinesischen Zeichensatz für die Volksrepublik China an. |
| [Chinesebig5](#Chinesebig5) | Gibt den "traditionellen" chinesischen Zeichensatz an, der hauptsächlich in Taiwan sowie in den Sonderverwaltungszonen Hongkong und Macau verwendet wird. |
| [Greek](#Greek) | Gibt den griechischen Zeichensatz an. |
| [Turkish](#Turkish) | Gibt den türkischen Zeichensatz an. |
| [Vietnamese](#Vietnamese) | Gibt den vietnamesischen Zeichensatz an. |
| [Hebrew](#Hebrew) | Gibt den vietnamesischen Zeichensatz an. |
| [Arabic](#Arabic) | Gibt den arabischen Zeichensatz an |
| [Baltic](#Baltic) | Gibt den baltischen (nordosteuropäischen) Zeichensatz an |
| [Russian](#Russian) | Gibt den russischen kyrillischen Zeichensatz an. |
| [Thai](#Thai) | Gibt den thailändischen Zeichensatz an. |
| [Easteurope](#Easteurope) | Gibt einen osteuropäischen Zeichensatz an. |
| [Oem](#Oem) | Gibt eine Zuordnung zu einer der OEM‑Codepages an, basierend auf der aktuellen System‑Locale‑Einstellung. |
