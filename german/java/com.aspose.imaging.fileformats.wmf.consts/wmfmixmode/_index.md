Die MixMode‑Aufzählung gibt den Hintergrund‑Mischmodus für Text, schraffierte Pinsel und andere nicht‑solide Stiftstile an.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [Transparent](#Transparent) | Der Hintergrund bleibt unverändert. |
| [Opaque](#Opaque) | Der Hintergrund wird mit der Hintergrundfarbe gefüllt, die derzeit im Wiedergabe-Geräte-Kontext definiert ist, bevor der Text, der gepunktete Pinsel oder der Stift gezeichnet wird. |
### Transparent {#Transparent}
```
public static final short Transparent
```


Der Hintergrund bleibt unverändert.

### Opaque {#Opaque}
```
public static final short Opaque
```


Der Hintergrund wird mit der Hintergrundfarbe gefüllt, die derzeit im Wiedergabe-Geräte-Kontext definiert ist, bevor der Text, der gepunktete Pinsel oder der Stift gezeichnet wird.
