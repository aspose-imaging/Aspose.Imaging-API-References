Die Aufzählung BrushStyle gibt die verschiedenen möglichen Pinseltypen an, die in Grafikoperationen verwendet werden können. Weitere Informationen finden Sie in der Spezifikation des Brush-Objekts (Abschnitt 2.2.1.1).
## Felder

| Feld | Beschreibung |
| --- | --- |
| [Solid](#Solid) | Ein Pinsel, der eine einzelne, konstante Farbe malt, entweder einfarbig oder dithered. |
| [Null](#Null) | Ein Pinsel, der nichts tut. |
| [Hatched](#Hatched) | Ein Pinsel, der ein vordefiniertes einfaches Muster, oder "hatch", auf einen einfarbigen Hintergrund malt |
| [Pattern](#Pattern) | Ein Pinsel, der ein Muster malt, das durch ein Bitmap definiert ist, das ein Bitmap16-Objekt oder ein DeviceIndependentBitmap (DIB)-Objekt sein KANN. |
| [Indexed](#Indexed) | Nicht unterstützt. |
| [Dibpattern](#Dibpattern) | Ein Musterpinsel, der durch ein DIB angegeben wird. |
| [Dibpatternpt](#Dibpatternpt) | Ein Musterpinsel, der durch ein DIB angegeben wird. |
| [Pattern8X8](#Pattern8X8) | Nicht unterstützt. |
| [Dibpattern8X8](#Dibpattern8X8) | Nicht unterstützt. |
| [Monopattern](#Monopattern) | Nicht unterstützt. |
| [Gradient](#Gradient) | Der Farbverlauf wird in WMF nicht unterstützt, aber in ODG. |
