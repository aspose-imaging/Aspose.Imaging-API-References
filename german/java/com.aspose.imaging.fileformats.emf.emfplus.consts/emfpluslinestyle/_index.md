Die LineStyle-Aufzählung definiert Stilarten von Linien, die mit Grafikstiften gezeichnet werden.

--------------------

Grafiklinien werden durch [EmfPlusPen](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspen) Objekte (Abschnitt 2.2.1.7) angegeben.
