Die Aufzählung CurveChannel definiert Farbkanäle, die durch eine Farbkurven‑Effektanpassung eines Bildes beeinflusst werden können.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [CurveChannelAll](#CurveChannelAll) | Gibt an, dass eine Farbkurvenanpassung auf alle Farbkanäle angewendet wird. |
| [CurveChannelRed](#CurveChannelRed) | Gibt an, dass eine Farbkurvenanpassung nur auf den roten Farbkanal angewendet wird. |
| [CurveChannelGreen](#CurveChannelGreen) | Gibt an, dass eine Farbkurvenanpassung nur auf den grünen Farbkanal angewendet wird. |
| [CurveChannelBlue](#CurveChannelBlue) | Gibt an, dass eine Farbkurvenanpassung nur auf den blauen Farbkanal angewendet wird. |
