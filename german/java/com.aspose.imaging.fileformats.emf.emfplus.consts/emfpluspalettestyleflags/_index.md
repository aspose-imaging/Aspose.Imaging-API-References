Die PaletteStyle-Flags geben Eigenschaften von Grafikpaletten an. Diese Flags können kombiniert werden, um mehrere Optionen anzugeben.

--------------------

Grafikpaletten werden durch [EmfPlusPalette](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspalette)-Objekte angegeben.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [PaletteStyleHasAlpha](#PaletteStyleHasAlpha) | Falls gesetzt, muss einer oder mehrere Paletteneinträge Alpha-Transparenzinformationen enthalten. |
| [PaletteStyleGrayScale](#PaletteStyleGrayScale) | Falls gesetzt, muss die Palette ausschließlich Graustufeneinträge enthalten. |
| [PaletteStyleHalftone](#PaletteStyleHalftone) | Falls gesetzt, muss die Palette diskrete Farbwerte enthalten, die für die Halbtonerzeugung verwendet werden können. |
