## Felder

| Feld | Beschreibung |
| --- | --- |
| [BrushTypeSolidColor](#BrushTypeSolidColor) | Gibt einen einfarbigen Pinsel an, der durch einen EmfPlusArgb-Wert charakterisiert wird. |
| [BrushTypeHatchFill](#BrushTypeHatchFill) | Gibt einen Schraffurpinsel an, der durch ein vordefiniertes Muster charakterisiert wird. |
| [BrushTypeTextureFill](#BrushTypeTextureFill) | Gibt einen Texturpinsel an, der durch ein Bild charakterisiert wird. |
| [BrushTypePathGradient](#BrushTypePathGradient) | Gibt einen Pfadverlaufpinsel an, der durch Farbverlauf‑Pfadverlauf‑Pinsel‑Daten charakterisiert wird. |
