Die PenAlignment-Aufzählung definiert die Verteilung der Stiftbreite in Bezug auf die zu zeichnende Linie.

--------------------

Grafikstifte werden durch [EmfPlusPen](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspen) Objekte (Abschnitt 2.2.1.7) angegeben. Die Stiftausrichtung kann visualisiert werden, indem man eine theoretische eindimensionale Linie betrachtet, die zwischen zwei angegebenen Punkten gezogen wird. Die Stiftausrichtung bestimmt den Anteil der Stiftbreite, der orthogonal zur theoretischen Linie verläuft.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [PenAlignmentCenter](#PenAlignmentCenter) | Gibt an, dass das EmfPlusPen-Objekt zentriert über der theoretischen Linie liegt. |
| [PenAlignmentInset](#PenAlignmentInset) | Gibt an, dass der Stift auf der Innenseite der theoretischen Linie positioniert ist. |
| [PenAlignmentLeft](#PenAlignmentLeft) | Gibt an, dass der Stift links von der theoretischen Linie positioniert ist. |
| [PenAlignmentOutset](#PenAlignmentOutset) | Gibt an, dass der Stift auf der Außenseite der theoretischen Linie positioniert ist. |
| [PenAlignmentRight](#PenAlignmentRight) | Gibt an, dass der Stift rechts von der theoretischen Linie positioniert ist. |
