Die Aufzählung CompositingMode definiert Modi zum Kombinieren von Quellfarben mit Hintergrundfarben. Der Compositing‑Modus stellt den Aktivierungszustand des Alpha‑Blending dar.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [CompositingModeSourceOver](#CompositingModeSourceOver) | Aktiviert Alpha-Blending, das festlegt, dass wenn eine Farbe gerendert wird, sie mit der Hintergrundfarbe gemischt wird. |
| [CompositingModeSourceCopy](#CompositingModeSourceCopy) | Deaktiviert Alpha-Blending, was bedeutet, dass wenn eine Quellfarbe gerendert wird, sie die Hintergrundfarbe überschreibt. |
### CompositingModeSourceOver {#CompositingModeSourceOver}
```
public static final byte CompositingModeSourceOver
```


Aktiviert Alpha-Blending, das festlegt, dass wenn eine Farbe gerendert wird, sie mit der Hintergrundfarbe gemischt wird. Das Ausmaß des Mischens wird durch den Wert der Alpha-Komponente der gerenderten Farbe bestimmt.

### CompositingModeSourceCopy {#CompositingModeSourceCopy}
```
public static final byte CompositingModeSourceCopy
```


Deaktiviert Alpha-Blending, was bedeutet, dass wenn eine Quellfarbe gerendert wird, sie die Hintergrundfarbe überschreibt.
