Die UnitType-Aufzählung definiert Maßeinheiten in verschiedenen Koordinatensystemen.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [UnitTypeWorld](#UnitTypeWorld) | Gibt eine Einheit für logische Distanz im Weltraum an. |
| [UnitTypeDisplay](#UnitTypeDisplay) | Gibt eine Einheit für Distanz basierend auf den Eigenschaften des physischen Displays an. |
| [UnitTypePixel](#UnitTypePixel) | Gibt eine Einheit von 1 Pixel an. |
| [UnitTypePoint](#UnitTypePoint) | Gibt eine Einheit von 1 Druckerpunkt bzw. 1/72 Zoll an. |
| [UnitTypeInch](#UnitTypeInch) | Gibt eine Einheit von 1 Zoll an. |
| [UnitTypeDocument](#UnitTypeDocument) | Gibt eine Einheit von 1/300 Zoll an. |
| [UnitTypeMillimeter](#UnitTypeMillimeter) | Gibt eine Einheit von 1 Millimeter an. |
