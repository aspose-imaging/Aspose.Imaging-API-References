Die PathPointType-Flags geben Typ-Eigenschaften von Punkten auf Grafikpfaden an. Diese Flags können kombiniert werden, um mehrere Optionen anzugeben.

--------------------

Grafikpfade werden durch [EmfPlusPath](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspath)-Objekte angegeben.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [PathPointTypeDashMode](#PathPointTypeDashMode) | Gibt an, dass ein Liniensegment, das durch den Punkt verläuft, gestrichelt ist. |
| [PathPointTypePathMarker](#PathPointTypePathMarker) | Gibt an, dass der Punkt ein Positionsmarker ist. |
| [PathPointTypeCloseSubpath](#PathPointTypeCloseSubpath) | Gibt an, dass der Punkt das Endpunkt eines Unterpfads ist. |
