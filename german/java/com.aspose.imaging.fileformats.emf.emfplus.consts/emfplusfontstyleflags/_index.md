Die FontStyle‑Flags geben die Stile von Grafik‑Schriftarten an. Diese Flags können kombiniert werden, um mehrere Optionen anzugeben.

--------------------

Grafik‑Schriftarten werden durch die Objekte [EmfPlusFont](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfplusfont) spezifiziert.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [FontStyleBold](#FontStyleBold) | Wenn gesetzt, muss die Schriftart mit einem stärkeren Gewicht oder einer dickeren Strichstärke dargestellt werden. |
| [FontStyleItalic](#FontStyleItalic) | Wenn gesetzt, muss die Schriftart mit den vertikalen Stämmen der Zeichen in einem erhöhten Winkel bzw. einer Schräglage relativ zur Grundlinie dargestellt werden. |
| [FontStyleUnderline](#FontStyleUnderline) | Wenn gesetzt, muss die Schriftart mit einer Linie unterhalb der Grundlinie der Zeichen dargestellt werden. |
| [FontStyleStrikeout](#FontStyleStrikeout) | Wenn gesetzt, muss die Schriftart mit einer Linie, die parallel zur Grundlinie durch die Mitte der Zeichen verläuft, dargestellt werden. |
### FontStyleBold {#FontStyleBold}
```
public static final int FontStyleBold
```


Wenn gesetzt, muss die Schriftart mit einem stärkeren Gewicht oder einer dickeren Strichstärke dargestellt werden. Wenn nicht gesetzt, muss die Schriftart mit einer normalen Strichstärke dargestellt werden.

### FontStyleItalic {#FontStyleItalic}
```
public static final int FontStyleItalic
```


Wenn gesetzt, muss die Schriftart mit den vertikalen Stämmen der Zeichen in einem erhöhten Winkel bzw. einer Schräglage relativ zur Grundlinie dargestellt werden. Wenn nicht gesetzt, muss die Schriftart mit den vertikalen Stämmen der Zeichen in einem normalen Winkel dargestellt werden.

### FontStyleUnderline {#FontStyleUnderline}
```
public static final int FontStyleUnderline
```


Wenn gesetzt, muss die Schriftart mit einer Linie unterhalb der Grundlinie der Zeichen dargestellt werden. Wenn nicht gesetzt, muss die Schriftart ohne eine Linie unterhalb der Grundlinie dargestellt werden.

### FontStyleStrikeout {#FontStyleStrikeout}
```
public static final int FontStyleStrikeout
```


Wenn gesetzt, muss die Schriftart mit einer Linie, die parallel zur Grundlinie verläuft und durch die Mitte der Zeichen gezogen wird, gerendert werden. Wenn nicht gesetzt, muss die Schriftart ohne eine Linie durch die Zeichen gerendert werden.
