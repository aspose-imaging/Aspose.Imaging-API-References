Die MetafileDataType-Aufzählung definiert Typen von Metadateien, die in einer EMF+-Metadatei eingebettet werden können.

--------------------

Eingebettete Metadatei‑Daten werden durch EmfPlusMetafileData‑Objekte (Abschnitt 2.2.2.27) angegeben.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [MetafileDataTypeWmf](#MetafileDataTypeWmf) | Gibt an, dass die Metadatei eine WMF‑Metadatei ist, die Grafikoperationen mit WMF‑Datensätzen spezifiziert, wie in [MS-WMF] angegeben. |
| [MetafileDataTypeWmfPlaceable](#MetafileDataTypeWmfPlaceable) | Gibt an, dass die Metadatei eine WMF‑Metadatei ist, die Grafikoperationen mit WMF‑Datensätzen spezifiziert und zusätzliche Header‑Informationen enthält, die die WMF‑Metadatei geräteunabhängig machen, wie in [MS-WMF] angegeben. |
| [MetafileDataTypeEmf](#MetafileDataTypeEmf) | Gibt an, dass die Metadatei eine EMF‑Metadatei ist, die Grafikoperationen mit EMF‑Datensätzen spezifiziert, wie in [MS-EMF] angegeben. |
| [MetafileDataTypeEmfPlusOnly](#MetafileDataTypeEmfPlusOnly) | Gibt an, dass die Metadatei eine EMF+‑Metadatei ist, die Grafikoperationen ausschließlich mit EMF+‑Datensätzen spezifiziert. |
| [MetafileDataTypeEmfPlusDual](#MetafileDataTypeEmfPlusDual) | Gibt an, dass die Metadatei eine EMF+‑Metadatei ist, die Grafikoperationen sowohl mit EMF‑ als auch mit EMF+‑Datensätzen spezifiziert. |
