Die PathPointType-Aufzählung definiert Typen von Punkten auf einem Grafikpfad.

--------------------

Grafik-Pfad-Punktetypen werden durch [EmfPlusPathPointType](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspathpointtype)-Objekte angegeben (Abschnitt 2.2.2.31).
## Felder

| Feld | Beschreibung |
| --- | --- |
| [PathPointTypeStart](#PathPointTypeStart) | Gibt an, dass der Punkt der Startpunkt eines Pfades ist. |
| [PathPointTypeLine](#PathPointTypeLine) | Gibt an, dass der Punkt einer der beiden Endpunkte einer Linie ist. |
| [PathPointTypeBezier](#PathPointTypeBezier) | Gibt an, dass der Punkt ein Endpunkt oder Kontrollpunkt einer kubischen Bézier-Kurve ist. |
