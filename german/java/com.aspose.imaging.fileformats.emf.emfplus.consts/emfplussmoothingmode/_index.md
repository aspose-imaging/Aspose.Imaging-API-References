Die SmoothingMode-Aufzählung definiert Glättungsmodi, die auf Linien, Kurven und die Kanten gefüllter Flächen angewendet werden, um sie kontinuierlicher oder schärfer definiert erscheinen zu lassen.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [SmoothingModeDefault](#SmoothingModeDefault) | Gibt die standardmäßige Kurvenglättung ohne Antialiasing an. |
| [SmoothingModeHighSpeed](#SmoothingModeHighSpeed) | Gibt die beste Leistung ohne Antialiasing an. |
| [SmoothingModeHighQuality](#SmoothingModeHighQuality) | Gibt die beste Qualität mit Antialiasing an. |
| [SmoothingModeNone](#SmoothingModeNone) | Führt keine Kurvenglättung und kein Antialiasing durch. |
| [SmoothingModeAntiAlias8x4](#SmoothingModeAntiAlias8x4) | Gibt eine gute Qualität unter Verwendung eines 8x4-Boxfilters an. |
| [SmoothingModeAntiAlias8x8](#SmoothingModeAntiAlias8x8) | Gibt eine bessere Qualität unter Verwendung eines 8x8-Boxfilters an. |
