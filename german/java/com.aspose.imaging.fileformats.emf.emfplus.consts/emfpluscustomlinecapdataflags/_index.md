Die CustomLineCapData-Flags geben Daten für benutzerdefinierte Linienenden an. Diese Flags können kombiniert werden, um mehrere Optionen anzugeben.

--------------------

Benutzerdefinierte Grafik-Linienenden werden durch [EmfPlusCustomLineCap](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecap)-Objekte angegeben.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [CustomLineCapDataFillPath](#CustomLineCapDataFillPath) | Falls gesetzt, muss ein [EmfPlusFillPath](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfplusfillpath)-Objekt im OptionalData‑Feld des [EmfPlusCustomLineCapData](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecapdata)-Objekts angegeben werden, um das benutzerdefinierte Linienende zu füllen. |
| [CustomLineCapDataLinePath](#CustomLineCapDataLinePath) | Falls gesetzt, muss ein [EmfPlusLinePath](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluslinepath)-Objekt im OptionalData‑Feld des EmfPlusCustomLineCapData‑Objekts angegeben werden, um das benutzerdefinierte Linienende zu umreißen. |
