Die StringAlignment-Aufzählung definiert Möglichkeiten, Zeichenketten in Bezug auf ein Textlayout-Rechteck auszurichten.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [StringAlignmentNear](#StringAlignmentNear) | Gibt an, dass die Zeichenkettenausrichtung zum Ursprung des Layout-Rechtecks zeigt. |
| [StringAlignmentCenter](#StringAlignmentCenter) | Gibt an, dass die Ausrichtung zwischen Ursprung und Ausdehnung des Layout-Rechtecks zentriert ist. |
| [StringAlignmentFar](#StringAlignmentFar) | Gibt an, dass die Ausrichtung an der rechten Seite des Layout-Rechtecks liegt. |
### StringAlignmentNear {#StringAlignmentNear}
```
public static final int StringAlignmentNear
```


Gibt an, dass die Zeichenkettenausrichtung zum Ursprung des Layout-Rechtecks zeigt. Dies kann verwendet werden, um Zeichen entlang einer Linie auszurichten oder Text innerhalb eines Rechtecks zu positionieren. Für ein von rechts nach links gerichtetes Layout-Rechteck, der Ursprung SHOULD oben rechts liegen.

### StringAlignmentCenter {#StringAlignmentCenter}

public static final int StringAlignmentCenter

Gibt an, dass die Ausrichtung zwischen Ursprung und Ausdehnung des Layout-Rechtecks zentriert ist.

### StringAlignmentFar {#StringAlignmentFar}
```
public static final int StringAlignmentFar
```


Gibt an, dass die Ausrichtung an der rechten Seite des Layout-Rechtecks liegt.
