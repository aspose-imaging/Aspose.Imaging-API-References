Die StringTrimming-Aufzählung definiert, wie Zeichen aus einer Zeichenkette, die zu groß für das Textlayout-Rechteck ist, abgeschnitten werden.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [StringTrimmingNone](#StringTrimmingNone) | Gibt an, dass kein Trimmen durchgeführt wird. |
| [StringTrimmingCharacter](#StringTrimmingCharacter) | Gibt an, dass die Zeichenkette an der Grenze des letzten Zeichens, das innerhalb des Layoutrechtecks liegt, umgebrochen wird. |
| [StringTrimmingWord](#StringTrimmingWord) | Gibt an, dass die Zeichenkette an der Grenze des letzten Wortes, das innerhalb des Layoutrechtecks liegt, umgebrochen wird. |
| [StringTrimmingEllipsisCharacter](#StringTrimmingEllipsisCharacter) | Gibt an, dass die Zeichenkette an der Grenze des letzten Zeichens, das innerhalb des Layoutrechtecks liegt, umgebrochen wird und ein Auslassungszeichen (...) nach dem Zeichen eingefügt wird. |
| [StringTrimmingEllipsisWord](#StringTrimmingEllipsisWord) | Gibt an, dass die Zeichenkette an der Grenze des letzten Wortes, das innerhalb des Layoutrechtecks liegt, umgebrochen wird und ein Auslassungszeichen (...) nach dem Wort eingefügt wird. |
| [StringTrimmingEllipsisPath](#StringTrimmingEllipsisPath) | Gibt an, dass die Mitte der Zeichenkette entfernt und durch ein Auslassungszeichen ersetzt wird. |
