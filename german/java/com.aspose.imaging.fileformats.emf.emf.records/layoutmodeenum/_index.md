## Felder

| Feld | Beschreibung |
| --- | --- |
| [LAYOUT_LTR](#LAYOUT-LTR) | Legt das Standard‑Horizontal‑Layout von links nach rechts fest. |
| [LAYOUT_RTL](#LAYOUT-RTL) | Legt das Standard‑Horizontal‑Layout von rechts nach links fest. |

### LAYOUT_LTR {#LAYOUT-LTR}
```
public static final int LAYOUT_LTR
```


Legt das Standard‑Horizontal‑Layout von links nach rechts fest. Dies ist der Standardmodus für englische und europäische Gebietsschemas.

### LAYOUT_RTL {#LAYOUT-RTL}
```
public static final int LAYOUT_RTL
```


Legt das Standard‑Horizontal‑Layout von rechts nach links fest. Dieser Modus ist für einige Sprachen erforderlich, darunter Arabisch und Hebräisch.

### LAYOUT_BITMAPORIENTATIONPRESERVED {#LAYOUT-BITMAPORIENTATIONPRESERVED}
```
public static final int LAYOUT_BITMAPORIENTATIONPRESERVED
```


Deaktiviert das Spiegeln von Bitmaps, die von Bitmap‑Record‑Typen (Abschnitt 2.3.1) gezeichnet werden, wenn der Layout‑Modus von rechts nach links ist.
