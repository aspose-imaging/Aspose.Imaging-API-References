Der EMR\\_POLYPOLYLINE-Datensatz spezifiziert mehrere Reihen verbundener Liniensegmente.

Die Liniensegmente SOLLTEN mit dem aktuellen Stift gezeichnet werden. Die durch die Segmente gebildeten Figuren SOLLTEN NICHT gefüllt werden. Die aktuelle Position SOLLTE von diesem Datensatz weder verwendet noch aktualisiert werden.
