Der EMR\\_POLYGON-Datensatz spezifiziert ein Polygon, das aus zwei oder mehr Eckpunkten besteht, die durch gerade Linien verbunden sind.

Das Polygon SOLLTE mit dem aktuellen Stift umrissen und mit dem aktuellen Pinsel sowie dem Polygonfüllmodus gefüllt werden. Das Polygon SOLLTE automatisch geschlossen werden, indem eine Linie vom letzten Scheitelpunkt zum ersten gezeichnet wird.
