Der EMR\_POLYGON16‑Datensatz definiert ein Polygon, das aus zwei oder mehr Eckpunkten besteht, die durch gerade Linien verbunden sind. Das Polygon wird mit dem aktuellen Stift umrissen und mit dem aktuellen Pinsel sowie dem Polygon‑Füllmodus gefüllt. Das Polygon wird automatisch geschlossen, indem eine Linie vom letzten Eckpunkt zum ersten gezeichnet wird.

Das Polygon SOLLTE mit dem aktuellen Stift umrissen und mit dem aktuellen Pinsel sowie dem Polygonfüllmodus gefüllt werden. Das Polygon SOLLTE automatisch geschlossen werden, indem eine Linie vom letzten Scheitelpunkt zum ersten gezeichnet wird.
