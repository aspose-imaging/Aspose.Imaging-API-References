Der EMR\_POLYLINETO16-Datensatz gibt eine oder mehrere gerade Linien an, die auf der aktuellen Position basieren. Eine Linie wird von der aktuellen Position zum ersten Punkt, der durch das Feld aPoints angegeben ist, mit dem aktuellen Stift gezeichnet. Für jede weitere Linie wird vom Endpunkt der vorherigen Linie zum nächsten durch aPoints angegebenen Punkt gezeichnet.
