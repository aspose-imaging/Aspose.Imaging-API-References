Der EMR\_POLYPOLYGON16-Datensatz gibt eine Reihe geschlossener Polygone an. Jedes Polygon wird mit dem aktuellen Stift konturiert und mit dem aktuellen Pinsel sowie dem Polygon-Füllmodus gefüllt. Die von diesem Datensatz gezeichneten Polygone können sich überschneiden.

Jedes Polygon SOLLTE mit dem aktuellen Stift konturiert und mit dem aktuellen Pinsel sowie dem Polygon‑Füllmodus, die im Wiedergabe‑Geräte‑Kontext definiert sind, gefüllt werden. Die durch diesen Datensatz definierten Polygone können sich überschneiden.
