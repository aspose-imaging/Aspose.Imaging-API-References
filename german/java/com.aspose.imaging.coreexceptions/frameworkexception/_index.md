Die Imaging‑Framework‑Ausnahme. Diese Klasse ist eine Kernklasse für alle Aspose.Imaging‑Ausnahmen. Sie wurde eingeführt, um zwischen den vom Aspose.Imaging‑Engine ausgelösten Ausnahmen und allen anderen Ausnahmetypen zu unterscheiden.
