public int getHueLevel()

Liest oder legt fest die Anpassung des Farbtons. -180 \u2264 Wert < 0 Negative Werte geben eine Drehung im Uhrzeigersinn auf dem Farbkreis an. 0 Ein Wert von 0 gibt an, dass der Farbton NICHT geändert werden darf. 0 < Wert \u2264 180 Positive Werte geben eine Drehung gegen den Uhrzeigersinn auf dem Farbkreis an.

Wert: Der Farbtonwert.
