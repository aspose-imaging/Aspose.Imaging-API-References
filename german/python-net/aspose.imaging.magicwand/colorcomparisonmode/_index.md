Gibt an, wie Farben während des Magic Wand‑Algorithmus verglichen werden.

**Module:** [aspose.imaging.magicwand](/imaging/python-net/aspose.imaging.magicwand/)

**Full Name:** aspose.imaging.magicwand.ColorComparisonMode

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| CUSTOM | Der Farbvergleichsalgorithmus wird vom Benutzer definiert. |
| RGB_DEFAULT | Farben werden im RGB-Farbraum verglichen.<br/>            Jede Farbabweichung muss den Schwellenwert erfüllen. |
| YUV_DEFAULT | Farben werden im YUV-Farbraum verglichen.<br/>            Jede Farbabweichung muss den Schwellenwert erfüllen. |
| YUV_LESS_LUMA_SENSITIVE | Farben werden im YUV-Farbraum verglichen.<br/>            Farb‑informations‑Unterschiede müssen den Schwellenwert erfüllen, der Schwellenwert für die Luminanzkomponente wird verdoppelt. |
