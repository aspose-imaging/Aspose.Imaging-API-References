Die Aufzählung gibt an, wie Ziffern in einer Zeichenfolge gemäß der Gebietsschema‑ oder Spracheinstellung eines Benutzers ersetzt werden.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.StringDigitSubstitute

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| NATIONAL | Gibt Ersetzungsziffern an, die der offiziellen Landessprache der Benutzereinstellung entsprechen. |
| NONE | Gibt an, dass Ersetzungen deaktiviert werden sollen. |
| TRADITIONAL | Gibt Ersetzungsziffern an, die dem nativen Schriftsystem oder der Sprache des Benutzers entsprechen, die von der offiziellen Landessprache der Benutzereinstellung abweichen können. |
| USER | Gibt ein benutzerdefiniertes Ersetzungsschema an. |
