Gibt die verfügbaren Endstilarten an, mit denen ein [Pen](/imaging/python-net/aspose.imaging/pen/) Objekt eine Linie beenden kann.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.LineCap

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| ANCHOR_MASK | Gibt einen benutzerdefinierten Linienabschluss an. |
| ARROW_ANCHOR | Gibt einen pfeilförmigen Ankerabschluss an. |
| CUSTOM | Gibt eine Maske an, die verwendet wird, um zu prüfen, ob ein Linienabschluss ein Ankerabschluss ist. |
| DIAMOND_ANCHOR | Gibt einen diamantförmigen Ankerabschluss an. |
| FLAT | Gibt einen flachen Linienabschluss an. |
| NO_ANCHOR | Gibt keinen Anker an. |
| ROUND | Gibt eine runde Linienabschlussform an. |
| ROUND_ANCHOR | Gibt einen runden Ankerabschluss an. |
| SQUARE | Gibt eine quadratische Linienabschlussform an. |
| SQUARE_ANCHOR | Gibt einen quadratischen Ankerlinienabschluss an. |
| TRIANGLE | Gibt einen dreieckigen Linienabschluss an. |
