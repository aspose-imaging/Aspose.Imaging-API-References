Die Aufzählung [InterpolationMode](/imaging/python-net/aspose.imaging/interpolationmode/) gibt den Algorithmus an, der verwendet wird, wenn Bilder skaliert oder rotiert werden.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.InterpolationMode

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| BICUBIC | Gibt bikubische Interpolation an. Es wird keine Vorfilterung durchgeführt. Dieser Modus ist nicht geeignet, ein Bild unter 25% seiner Originalgröße zu verkleinern. |
| BILINEAR | Gibt bilineare Interpolation an. Es wird keine Vorfilterung durchgeführt. Dieser Modus ist nicht geeignet, ein Bild unter 50% seiner Originalgröße zu verkleinern. |
| STANDARD | Gibt den Standardmodus an. |
| HIGH | Gibt hochqualitative Interpolation an. |
| HIGH_QUALITY_BICUBIC | Gibt hochqualitative, bikubische Interpolation an. Vorfilterung wird durchgeführt, um ein hochwertiges Verkleinern zu gewährleisten. Dieser Modus erzeugt die qualitativ besten transformierten Bilder. |
| HIGH_QUALITY_BILINEAR | Gibt hochqualitative, bilineare Interpolation an. Vorfilterung wird durchgeführt, um ein hochwertiges Verkleinern zu gewährleisten. |
| INVALID | Ungültiger Interpolationsmodus. |
| LOW | Gibt eine Interpolation von niedriger Qualität an. |
| NEAREST_NEIGHBOR | Gibt eine Interpolation nach dem nächsten Nachbarn an. |
