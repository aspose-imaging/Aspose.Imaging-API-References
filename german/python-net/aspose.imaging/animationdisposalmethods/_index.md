Gibt an, wie die Grafik nach der Anzeige behandelt werden soll.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.AnimationDisposalMethods

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| HINTERGRUND | Zurücksetzen auf Hintergrundfarbe. Der von der Grafik belegte Bereich muss auf die Hintergrundfarbe zurückgesetzt werden. |
| BEWAHREN | Nicht freigeben. Die Grafik bleibt an ihrer Stelle. |
| VORHERIGE | Zurücksetzen auf vorherige. Der Decoder muss den von der Grafik überschriebenen Bereich mit dem wiederherstellen, was vor dem Rendern der Grafik dort war. |
