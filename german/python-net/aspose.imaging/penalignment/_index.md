Gibt die Ausrichtung eines [Pen](/imaging/python-net/aspose.imaging/pen/) Objekts in Bezug auf die theoretische, nullbreite Linie an.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.PenAlignment

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| CENTER | Gibt an, dass das [Pen](/imaging/python-net/aspose.imaging/pen/) Objekt zentriert über der theoretischen Linie liegt. |
| INSET | Gibt an, dass das [Pen](/imaging/python-net/aspose.imaging/pen/) auf der Innenseite der theoretischen Linie positioniert ist. |
| LEFT | Gibt an, dass das [Pen](/imaging/python-net/aspose.imaging/pen/) links von der theoretischen Linie positioniert ist. |
| OUTSET | Gibt an, dass das [Pen](/imaging/python-net/aspose.imaging/pen/) auf der Außenseite der theoretischen Linie positioniert ist. |
| RIGHT | Gibt an, dass das [Pen](/imaging/python-net/aspose.imaging/pen/) rechts von der theoretischen Linie positioniert ist. |
