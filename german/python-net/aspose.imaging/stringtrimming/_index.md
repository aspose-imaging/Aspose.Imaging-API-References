Gibt an, wie Zeichen aus einer Zeichenfolge entfernt werden, die nicht vollständig in eine Layout‑Form passt.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.StringTrimming

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| CHARACTER | Gibt an, dass der Text bis zum nächsten Zeichen gekürzt wird. |
| ELLIPSIS_CHARACTER | Gibt an, dass der Text bis zum nächsten Zeichen gekürzt wird und am Ende einer gekürzten Zeile ein Auslassungszeichen eingefügt wird. |
| ELLIPSIS_PATH | Der Mittelteil wird aus gekürzten Zeilen entfernt und durch ein Auslassungszeichen ersetzt. Der Algorithmus behält so viel wie möglich vom letzten durch Schrägstriche getrennten Segment der Zeile bei. |
| ELLIPSIS_WORD | Gibt an, dass der Text bis zum nächsten Wort gekürzt wird und am Ende einer gekürzten Zeile ein Auslassungszeichen eingefügt wird. |
| NONE | Gibt an, dass nicht gekürzt wird. |
| WORD | Gibt an, dass Text auf das nächste Wort gekürzt wird. |
