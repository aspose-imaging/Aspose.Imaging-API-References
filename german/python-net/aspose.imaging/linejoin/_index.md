Gibt an, wie aufeinanderfolgende Linien- oder Kurvensegmente in einer Figur (Unterpfad), die in einem [GraphicsPath](/imaging/python-net/aspose.imaging/graphicspath/) Objekt enthalten ist, verbunden werden.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.LineJoin

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| BEVEL | Gibt eine abgeschrägte Verbindung an. Dies erzeugt eine diagonale Ecke. |
| MITER | Gibt eine Gehrungsverbindung an. Dies erzeugt eine scharfe Ecke oder eine abgeschnittene Ecke, abhängig davon, ob die Länge des Gehrungswinkels das Gehrungslimit überschreitet. |
| MITER_CLIPPED | Gibt eine Gehrungsverbindung an. Dies erzeugt eine scharfe Ecke oder eine abgeschrägte Ecke, abhängig davon, ob die Länge des Gehrungswinkels das Gehrungslimit überschreitet. |
| ROUND | Gibt eine kreisförmige Verbindung an. Dies erzeugt einen glatten, kreisförmigen Bogen zwischen den Linien. |
