Gibt den Stil der mit einem [Pen](/imaging/python-net/aspose.imaging/pen/) Objekt gezeichneten gestrichelten Linien an.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.DashStyle

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| CUSTOM | Gibt einen benutzerdefinierten Strichstil an. |
| DASH | Gibt eine Linie an, die aus Strichen besteht. |
| DASH_DOT | Gibt eine Linie an, die aus einem wiederholenden Muster von Strich-Punkt besteht. |
| DASH_DOT_DOT | Gibt eine Linie an, die aus einem wiederholenden Muster von Strich-Punkt-Punkt besteht. |
| DOT | Gibt eine Linie an, die aus Punkten besteht. |
| SOLID | Gibt eine durchgezogene Linie an. |
