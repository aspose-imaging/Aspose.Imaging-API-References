Gibt die Qualität der Textdarstellung an.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.TextRenderingHint

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| ANTI_ALIAS | Jedes Zeichen wird mit seiner antialiasierten Glyphen-Bitmap ohne Hinting gezeichnet. Bessere Qualität durch Antialiasing. Unterschiede in der Stängelbreite können bemerkbar sein, weil Hinting deaktiviert ist. |
| ANTI_ALIAS_GRID_FIT | Jedes Zeichen wird mit seinem antialiasierten Glyphen-Bitmap unter Verwendung von Hinting gezeichnet. Viel bessere Qualität dank Antialiasing, jedoch zu höheren Leistungskosten. |
| CLEAR_TYPE_GRID_FIT | Jedes Zeichen wird mit seinem Glyphen‑ClearType‑Bitmap unter Verwendung von Hinting gezeichnet. Die höchste Qualitätseinstellung. Wird verwendet, um die ClearType‑Schriftmerkmale zu nutzen. |
| SINGLE_BIT_PER_PIXEL | Jedes Zeichen wird mit seinem Glyphen‑Bitmap gezeichnet. Hinting wird nicht verwendet. |
| SINGLE_BIT_PER_PIXEL_GRID_FIT | Jedes Zeichen wird mit seinem Glyphen‑Bitmap gezeichnet. Hinting wird verwendet, um das Erscheinungsbild von Zeichen an Stämmen und Kurven zu verbessern. |
| SYSTEM_DEFAULT | Jedes Zeichen wird mit seinem Glyphen‑Bitmap gezeichnet, wobei der systemstandardmäßige Rendering‑Hinweis verwendet wird. Der Text wird mit den vom Benutzer für das System ausgewählten Schriftglättungseinstellungen gezeichnet. |
