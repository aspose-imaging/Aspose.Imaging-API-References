Gibt an, ob Glättung (Antialiasing) auf Linien und Kurven sowie die Kanten von gefüllten Bereichen angewendet wird.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.SmoothingMode

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| ANTI_ALIAS | Gibt antialiasiertes Rendering an. |
| STANDARD | Gibt kein Antialiasing an. |
| HIGH_QUALITY | Gibt antialiasiertes Rendering an. |
| HIGH_SPEED | Gibt kein Antialiasing an. |
| INVALID | Gibt einen ungültigen Modus an. |
| NONE | Gibt kein Antialiasing an. |
