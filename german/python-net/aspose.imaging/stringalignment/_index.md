Gibt die Ausrichtung einer Textzeichenfolge relativ zu ihrem Layout‑Rechteck an.

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.StringAlignment

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| CENTER | Gibt an, dass der Text in der Mitte des Layout-Rechtecks ausgerichtet ist. |
| FAR | Gibt an, dass der Text weit von der Ursprungposition des Layout-Rechtecks ausgerichtet ist. In einem links-nach-rechts Layout ist die ferne Position rechts. In einem rechts-nach-links Layout ist die ferne Position links. |
| NEAR | Gibt an, dass der Text nahe am Layout ausgerichtet wird. In einem links-nach-rechts Layout ist die nahe Position links. In einem rechts-nach-links Layout ist die nahe Position rechts. |
