Das Modul enthält verschiedene Formsegmente, die Formen kombinieren.

| :- | :- |
| [BezierSegment](/imaging/python-net/aspose.imaging.shapesegments/beziersegment/) | Das Bézier‑Segment, das von einem Punkt zum nächsten Punkt verläuft und zwei Kontrollpunkte verwendet. |
| [LineSegment](/imaging/python-net/aspose.imaging.shapesegments/linesegment/) | Stellt ein Segment dar, das direkt von einem bestimmten Punkt zum nächsten Punkt führt. |
