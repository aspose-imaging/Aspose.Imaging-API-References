Die FontQuality‑Enumeration gibt an, wie genau die Attribute der logischen Schrift mit denen der physischen Schrift übereinstimmen sollten<br/>                beim Rendern von Text.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfFontQuality

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| ANTIALIASED | Gibt an, dass Antialiasing SOLLTE verwendet werden, wenn Text gerendert wird, falls<br/>                die Schriftart dies unterstützt. |
| CLEARTYPE | Gibt an, dass ClearType-Antialiasing SOLLTE verwendet werden, wenn<br/>                Text gerendert wird, falls die Schriftart dies unterstützt. |
| STANDARD | Gibt an, dass die Zeichenqualität der Schriftart keine Rolle spielt, sodass<br/>                DRAFT verwendet werden kann. |
| DRAFT | Gibt an, dass die Zeichenqualität der Schriftart weniger wichtig ist als die<br/>                Übereinstimmung logischer Attribute. Für gerasterte Schriften SOLLTE das Skalieren aktiviert werden, was<br/>                bedeutet, dass mehr Schriftgrößen verfügbar sind. |
| NONANTIALIASED | Gibt an, dass Antialiasing SOLLTE NICHT verwendet werden, wenn<br/>                Text gerendert wird |
| PROOF | Gibt an, dass die Zeichenqualität der Schriftart wichtiger ist als die<br/>                Übereinstimmung logischer Attribute. Für gerasterte Schriften SOLLTE das Skalieren deaktiviert werden, und die Schriftart<br/>                die der Größe am nächsten kommt, SOLLTE ausgewählt werden. |
