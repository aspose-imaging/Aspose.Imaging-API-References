Die CharacterSet‑Enumeration definiert die möglichen Satz von Zeichen‑Glyphen, die in<br/>                Schriftarten für die Grafikdarstellung definiert sind.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfCharacterSet

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| ANSI | Gibt den englischen Zeichensatz an. |
| ARABIC | Gibt den arabischen Zeichensatz an |
| BALTIC | Gibt den baltischen (nordosteuropäischen) Zeichensatz an |
| CHINESEBIG5 | Gibt den "traditionellen" chinesischen Zeichensatz an, der hauptsächlich in<br/>                Taiwan und in den Sonderverwaltungszonen Hongkong und Macau verwendet wird. |
| STANDARD | Gibt einen Zeichensatz basierend auf der aktuellen System-Locale an; zum<br/>                Beispiel, wenn die System-Locale US-Englisch ist, ist der Standardzeichensatz<br/>                ANSI_CHARSET. |
| EASTEUROPE | Gibt einen osteuropäischen Zeichensatz an. |
| GB2312 | Gibt den "vereinfachten" chinesischen Zeichensatz für die Volksrepublik China an. |
| GREEK | Gibt den griechischen Zeichensatz an. |
| HANGUL | Auch geschrieben als "Hangeul". Gibt den Hangul‑koreanischen Zeichensatz an. |
| HEBREW | Gibt den vietnamesischen Zeichensatz an. |
| JOHAB | Auch geschrieben als "Johap". Gibt den Johab‑koreanischen Zeichensatz an. |
| MAC | Gibt den Apple Macintosh‑Zeichensatz an. |
| OEM | Gibt eine Zuordnung zu einer der OEM-Codepages an, gemäß der aktuellen<br/>                Systemeinstellung für das Gebietsschema. |
| RUSSISCH | Gibt den russischen kyrillischen Zeichensatz an. |
| SHIFTJIS | Gibt den japanischen Zeichensatz an. |
| SYMBOL | Gibt einen Zeichensatz von Symbolen an. |
| THAI | Gibt den thailändischen Zeichensatz an. |
| TÜRKISCH | Gibt den türkischen Zeichensatz an. |
| VIETNAMESISCH | Gibt den vietnamesischen Zeichensatz an. |
