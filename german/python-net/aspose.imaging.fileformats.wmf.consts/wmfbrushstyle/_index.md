Die BrushStyle‑Enumeration gibt die verschiedenen möglichen Pinseltypen an<br/>                , die in Grafikoperationen verwendet werden können. Weitere Informationen finden Sie in der<br/>                Spezifikation des Brush‑Objekts (Abschnitt 2.2.1.1).

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfBrushStyle

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| DIBPATTERN | Ein Musterpinsel, der durch ein DIB angegeben wird. |
| DIBPATTERNPT | Ein Musterpinsel, der durch ein DIB angegeben wird. |
| DIBPATTERN_8X8 | Nicht unterstützt. |
| GRADIENT | Der Gradient<br/>            Nicht unterstützt in wmf, unterstützt in odg. |
| HATCHED | Ein Pinsel, der ein vordefiniertes einfaches Muster, oder "Schraffur", auf einen festen Hintergrund malt. |
| INDEXED | Nicht unterstützt. |
| MONOPATTERN | Nicht unterstützt. |
| NULL | Ein Pinsel, der nichts tut. Die Verwendung eines NULL-Pinsels in einer Grafikoperation<br/>                MUSS die gleiche Wirkung haben wie die Verwendung überhaupt keines Pinsels. |
| PATTERN | Ein Pinsel, der ein Muster malt, das durch ein Bitmap definiert ist, das ein Bitmap16-Objekt<br/>                oder ein DeviceIndependentBitmap (DIB)-Objekt sein kann. |
| PATTERN_8X8 | Nicht unterstützt. |
| SOLID | Ein Pinsel, der eine einzelne, konstante Farbe malt, entweder einfarbig oder dithered. |
