Die PostScriptClipping-Aufzählung definiert Funktionen, die auf den Clipping‑Pfad angewendet werden können,<br/>                der für PostScript‑Ausgaben verwendet wird.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfPostScriptClipping

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| CLIP_INCLUSIVE | Schneidet den aktuellen PostScript‑Clipping‑Pfad mit dem aktuellen Clipping‑Pfad<br/>
                und speichert das Ergebnis als neuen PostScript‑Clipping‑Pfad. |
| CLIP_RESTORE | Stellt den PostScript‑Clipping‑Pfad auf den letzten Clipping‑Pfad wieder her, der<br/>
                durch eine vorherige CLIP_SAVE‑Funktion gespeichert wurde, die von einem CLIP_TO_PATH‑Datensatz (Abschnitt 2.3.6.6) angewendet wurde. |
| CLIP_SAVE | Speichert den aktuellen PostScript‑Clipping‑Pfad. |
