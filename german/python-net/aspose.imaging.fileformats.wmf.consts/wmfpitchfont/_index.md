Die PitchFont-Aufzählung definiert Werte, die zur Angabe von Eigenschaften einer Schrift verwendet werden.<br/>                Die Werte geben an, ob die Zeichen einer Schrift eine feste oder variable Breite bzw. einen Pitch haben.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfPitchFont

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| DEFAULT_PITCH | Der Standard‑Pitch, der implementationsabhängig ist. |
| FIXED_PITCH | Ein fester Pitch, was bedeutet, dass alle Zeichen in der Schriftart dieselbe<br/>                Breite belegen, wenn sie in einer Zeichenkette ausgegeben werden. |
| VARIABLE_PITCH | Eine variable Laufweite, was bedeutet, dass die Zeichen in der Schrift Breiten einnehmen<br/>                die proportional zu den tatsächlichen Breiten der Glyphen sind, wenn sie in einer Zeichenkette ausgegeben werden. Zum Beispiel,<br/>                haben die Zeichen "i" und das Leerzeichen normalerweise viel kleinere Breiten als ein "W"- oder "O"-Zeichen. |
