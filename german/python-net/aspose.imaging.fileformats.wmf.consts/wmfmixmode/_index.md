Die MixMode-Aufzählung gibt den Hintergrund-Mischmodus für Text, schraffierte Pinsel,<br/>                und andere nicht‑solide Stiftstile an.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfMixMode

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| OPAQUE | Der Hintergrund wird mit der<br/>                Hintergrundfarbe gefüllt, die derzeit im Wiedergabegeräte-Kontext definiert ist, bevor der Text, der schraffierte Pinsel oder der Stift<br/>                gezeichnet wird. |
| TRANSPARENT | Der Hintergrund bleibt unverändert. |
