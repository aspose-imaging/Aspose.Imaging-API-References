VerticalTextAlignmentMode Flags geben die Beziehung zwischen einem Referenzpunkt und einem<br/>                begrenzenden Rechteck für die Textausrichtung an. Diese Flags können kombiniert werden, um mehrere Optionen anzugeben,<br/>                mit der Einschränkung, dass nur ein Flag ausgewählt werden kann, das die Zeichenposition im Wiedergabegerät<br/>                Kontext ändert.<br/>                Die vertikale Textausrichtung wird durchgeführt, wenn die Schrift eine vertikale Standard‑Grundlinie hat, z. B. Kanji.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfVerticalTextAlignmentModeFlags

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| VTA_BASELINE | Der Referenzpunkt MUSS auf der Grundlinie des Textes liegen. |
| VTA_BOTTOM | Der Referenzpunkt MUSS an der unteren Kante des Begrenzungsrechtecks liegen. |
| VTA_CENTER | Der Referenzpunkt MUSS vertikal mit der Mitte des Begrenzungsrechtecks ausgerichtet sein. |
| VTA_LEFT | Der Referenzpunkt MUSS an der linken Kante des Begrenzungsrechtecks liegen. |
| VTA_RIGHT | Der Referenzpunkt MUSS an der rechten Kante des Begrenzungsrechtecks liegen. |
| VTA_TOP | Der Referenzpunkt MUSS an der oberen Kante des Begrenzungsrechtecks liegen. |
