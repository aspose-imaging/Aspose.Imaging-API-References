Die OutPrecision-Aufzählung definiert Werte für die Ausgabegenauigkeit, die die Anforderung für<br/>                den Font‑Mapper darstellen, bestimmte Schriftparameter abzugleichen, einschließlich Höhe, Breite, Zeichenorientierung,<br/>                Fluchtwinkel, Pitch und Schriftart.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfOutPrecision

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| STANDARD | Ein Wert, der das Standardverhalten festlegt. |
| GERÄT | Ein Wert, der die Auswahl einer Geräte-Schriftart festlegt, wenn das System<br/>                mehrere Schriftarten mit demselben Namen enthält. |
| UMRISS | Ein Wert, der die Anforderung für TrueType- und andere Umriss-Schriftarten festlegt. |
| PS_NUR | Ein Wert, der eine Anforderung ausschließlich für PostScript-Schriftarten festlegt. Wenn es<br/>                keine PostScript-Schriftarten im System gibt, wird das Standardverhalten verwendet. |
| RASTER | Ein Wert, der die Auswahl einer gerasterten Schriftart festlegt, wenn das System<br/>                mehrere Schriftarten mit demselben Namen enthält. |
| BILDSCHIRM_UMRISS | Ein Wert, der eine Präferenz für TrueType- und andere<br/>                Umriss-Schriftarten festlegt. |
| ZEICHENKETTE | Ein Wert, der zurückgegeben wird, wenn gerasterte Schriftarten aufgelistet werden. |
| STRICH | Ein Wert, der zurückgegeben wird, wenn TrueType- und andere Umriss-Schriftarten sowie<br/>                Vektor-Schriftarten aufgelistet werden. |
| TT | Ein Wert, der die Auswahl einer TrueType-Schriftart festlegt, wenn das System<br/>                mehrere Schriftarten mit demselben Namen enthält. |
| TT_NUR | Ein Wert, der die Anforderung ausschließlich für TrueType-Schriftarten festlegt. Wenn<br/>                keine TrueType-Schriftarten im System installiert sind, wird das Standardverhalten verwendet. |
