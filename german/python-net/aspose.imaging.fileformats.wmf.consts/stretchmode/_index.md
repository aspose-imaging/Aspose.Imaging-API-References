Die [StretchMode](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/stretchmode/)‑Enumeration gibt den Bitmap‑Stretch‑Modus an, der definiert, wie das System Zeilen oder Spalten einer Bitmap mit vorhandenen Pixeln kombiniert.

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.StretchMode

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| BLACK_ON_WHITE | Führt eine boolesche UND-Operation unter Verwendung der Farbwerte für die<br/>                eliminierten und vorhandenen Pixel aus. Wenn das Bitmap ein monochromes<br/>                Bitmap ist, bewahrt dieser Modus schwarze Pixel auf Kosten weißer<br/>                Pixel. |
| COLOR_ON_COLOR | Löscht die Pixel. Dieser Modus löscht alle eliminierten Pixelzeilen<br/>                ohne zu versuchen, deren Informationen zu erhalten. |
| HALF_TONE | Mappt Pixel aus dem Quellrechteck in Pixelblöcke im<br/>                Zielrechteck. Die durchschnittliche Farbe über den Zielblock<br/>                der Pixel approximiert die Farbe der Quellpixel. |
| WHITE_ON_BLACK | Führt eine boolesche ODER-Operation unter Verwendung der Farbwerte für die<br/>                eliminierten und vorhandenen Pixel aus. Wenn das Bitmap ein monochromes<br/>                Bitmap ist, bewahrt dieser Modus weiße Pixel auf Kosten schwarzer<br/>                Pixel. |
