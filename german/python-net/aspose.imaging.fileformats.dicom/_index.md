Das Modul verarbeitet das Dicom-Dateiformat.

## **Classes**
| **Klasse** | **Beschreibung** |
| :- | :- |
| [Compression](/imaging/python-net/aspose.imaging.fileformats.dicom/compression/) | Enthält die Bildkomprimierungseinstellungen. |
| [DicomImage](/imaging/python-net/aspose.imaging.fileformats.dicom/dicomimage/) | Diese Klasse implementiert die Unterstützung des Rasterbildformats Digital Imaging and Communications in Medicine<br/> (DICOM) und bietet eine umfassende Lösung für<br/> die Verarbeitung von DICOM‑Bildern mit Präzision und Flexibilität. Sie können nahtlos<br/> Bildseiten manipulieren, einschließlich Vorgängen zum Abrufen, Hinzufügen oder Entfernen von Seiten, und<br/> die Standard‑ und aktive Seite steuern. Mit Fähigkeiten zur Arbeit mit Alphakanälen,<br/> zum Einbetten von XMP‑Metadaten, zum Ändern der Größe, Drehen, Zuschneiden, Binärisieren, Anpassen, Anwenden von Filtern,<br/> und zum Konvertieren in andere Rasterformate. Diese API ermöglicht Entwicklern, DICOM‑Bilder effektiv zu handhaben<br/> und gleichzeitig vielfältige Anwendungsanforderungen im Kontext der medizinischen Bildgebung zu erfüllen. |
| [DicomImageInfo](/imaging/python-net/aspose.imaging.fileformats.dicom/dicomimageinfo/) | Enthält alle Metainformationen aus dem DICOM‑Dateikopf. |
| [DicomPage](/imaging/python-net/aspose.imaging.fileformats.dicom/dicompage/) | Es ist eine Klasse zur Arbeit mit DICOM‑Dateien des Typs Mehrfachrahmen. |
