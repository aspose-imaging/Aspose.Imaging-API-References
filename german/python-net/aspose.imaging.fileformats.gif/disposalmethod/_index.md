Gibt an, wie die Grafik nach der Anzeige behandelt werden soll.

**Module:** [aspose.imaging.fileformats.gif](/imaging/python-net/aspose.imaging.fileformats.gif/)

**Full Name:** aspose.imaging.fileformats.gif.DisposalMethod

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| NONE | Keine Entsorgung angegeben. |
| BEWAHREN | Nicht freigeben. Die Grafik bleibt an ihrer Stelle. |
| PREVIUOS | Zurücksetzen auf vorherige. Der Decoder muss den von der Grafik überschriebenen Bereich mit dem wiederherstellen, was vor dem Rendern der Grafik dort war. |
| RESTORE | Zurücksetzen auf Hintergrundfarbe. Der von der Grafik belegte Bereich muss auf die Hintergrundfarbe zurückgesetzt werden. |
| UNDEFINED | Undefinierter Wert. |
