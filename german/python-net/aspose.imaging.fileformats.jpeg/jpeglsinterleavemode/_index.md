Definiert den Interleav‑Modus für mehrkomponentige (Farb‑)Pixel‑Daten.

**Module:** [aspose.imaging.fileformats.jpeg](/imaging/python-net/aspose.imaging.fileformats.jpeg/)

**Full Name:** aspose.imaging.fileformats.jpeg.JpegLsInterleaveMode

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| LINE | Der Interleaving-Modus ist zeilenweise. Eine komplette Zeile jeder Komponente wird kodiert, bevor zur nächsten Zeile gewechselt wird. |
| NONE | Die Daten werden komponentenweise kodiert und gespeichert: RRRGGGBBB. |
| SAMPLE | Die Daten werden pro Sample kodiert und gespeichert. Bei Farbbildern ist dies das Format wie RGBRGBRGB. |
