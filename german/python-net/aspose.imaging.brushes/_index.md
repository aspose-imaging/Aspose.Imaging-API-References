Das Modul stellt Hilfsklassen und Methoden bereit, um mit verschiedenen Pinseltypen zu arbeiten.

## **Classes**
| **Klasse** | **Beschreibung** |
| :- | :- |
| [HatchBrush](/imaging/python-net/aspose.imaging.brushes/hatchbrush/) | Definiert einen rechteckigen Pinsel mit einem Schraffurstil, einer Vordergrundfarbe und einer Hintergrundfarbe. Diese Klasse kann nicht abgeleitet werden. |
| [LinearGradientBrush](/imaging/python-net/aspose.imaging.brushes/lineargradientbrush/) | Kapselt einen [Brush](/imaging/python-net/aspose.imaging/brush/) mit einem linearen Farbverlauf. Diese Klasse kann nicht abgeleitet werden. |
| [LinearGradientBrushBase](/imaging/python-net/aspose.imaging.brushes/lineargradientbrushbase/) | Stellt einen [Brush](/imaging/python-net/aspose.imaging/brush/) mit Farbverlaufsfähigkeiten und entsprechenden Eigenschaften dar. |
| [LinearMulticolorGradientBrush](/imaging/python-net/aspose.imaging.brushes/linearmulticolorgradientbrush/) | Stellt einen [Brush](/imaging/python-net/aspose.imaging/brush/) mit linearem Farbverlauf dar, der durch mehrere Farben und passende Positionen definiert ist. Diese Klasse kann nicht abgeleitet werden. |
| [PathGradientBrush](/imaging/python-net/aspose.imaging.brushes/pathgradientbrush/) | Kapselt ein [Brush](/imaging/python-net/aspose.imaging/brush/) Objekt mit einem Farbverlauf. Diese Klasse kann nicht abgeleitet werden. |
| [PathGradientBrushBase](/imaging/python-net/aspose.imaging.brushes/pathgradientbrushbase/) | Stellt einen [Brush](/imaging/python-net/aspose.imaging/brush/) mit Basis-Pfad-Farbverlaufsfunktionalität dar. |
| [PathMulticolorGradientBrush](/imaging/python-net/aspose.imaging.brushes/pathmulticolorgradientbrush/) | Kapselt ein [Brush](/imaging/python-net/aspose.imaging/brush/) Objekt mit einem Farbverlauf. Diese Klasse kann nicht abgeleitet werden. |
| [SolidBrush](/imaging/python-net/aspose.imaging.brushes/solidbrush/) | Der Solid-Pinsel ist für das kontinuierliche Zeichnen mit einer bestimmten Farbe vorgesehen. Diese Klasse kann nicht abgeleitet werden. |
| [TextureBrush](/imaging/python-net/aspose.imaging.brushes/texturebrush/) | Jede Eigenschaft der [TextureBrush](/imaging/python-net/aspose.imaging.brushes/texturebrush/) Klasse ist ein [Brush](/imaging/python-net/aspose.imaging/brush/) Objekt, das ein Bild verwendet, um das Innere einer Form zu füllen. Diese Klasse kann nicht abgeleitet werden. |
| [TransformBrush](/imaging/python-net/aspose.imaging.brushes/transformbrush/) | Ein [Brush](/imaging/python-net/aspose.imaging/brush/) mit Transformationsfähigkeiten. |
