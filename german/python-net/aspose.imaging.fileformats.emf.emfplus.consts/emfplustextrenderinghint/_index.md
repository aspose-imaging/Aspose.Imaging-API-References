Die TextRenderingHint-Aufzählung definiert Arten von Text-Hinting und Antialiasing, die die Qualität der Textdarstellung beeinflussen.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusTextRenderingHint

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| TEXT_RENDERING_HINT_ANTIALIAS | Gibt an, dass jedes Textzeichen mit seiner antialiasierten Glyphen-Bitmap ohne Hinting gezeichnet wird. Antialiasing liefert eine bessere Qualität, aber Unterschiede in der Strichbreite KÖNNTEN sichtbar sein, da Hinting deaktiviert ist. |
| TEXT_RENDERING_HINT_ANTIALIAS_GRID_FIT | Gibt an, dass jedes Textzeichen MIT antialiasierter Glyphen-Bitmap und Glättung gezeichnet werden SOLLTE. Das Rendering ist dank Antialiasing von hoher Qualität, verursacht jedoch höhere Leistungskosten. |
| TEXT_RENDERING_HINT_CLEAR_TYPE_GRID_FIT | Gibt an, dass jedes Textzeichen MIT ClearType-Glyphen-Bitmap und Glättung gezeichnet werden SOLLTE. Dies ist die höchstqualitative Text-Hinting-Einstellung, die genutzt wird, um die ClearType-Schriftmerkmale zu nutzen. |
| TEXT_RENDERING_HINT_SINGLE_BIT_PER_PIXEL | Gibt an, dass jedes Textzeichen MIT seiner Glyphen-Bitmap gezeichnet werden SOLLTE. Glättung wird nicht verwendet. |
| TEXT_RENDERING_HINT_SINGLE_BIT_PER_PIXEL_GRID_FIT | Gibt an, dass jedes Textzeichen MIT seiner Glyphen‑Bitmap gezeichnet werden SOLLTE. Glättung KANN verwendet werden, um das Aussehen von Glyphenstämmen und -krümmungen zu verbessern. |
| TEXT_RENDERING_HINT_SYSTEM_DEFAULT | Gibt an, dass jedes Textzeichen SOLL mit den auf dem Betriebssystem konfigurierten Schriftglättungseinstellungen gezeichnet werden. |
