Die PixelFormat-Aufzählung definiert Pixelformate, die in EMF+-Bitmaps unterstützt werden.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusPixelFormat

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| PIXEL_FORMAT_16BPP_ARGB1555 | Das Format hat 16 Bit pro Pixel; 1 Bit wird für die Alpha-Komponente verwendet und jeweils 5 Bits für die Rot-, Grün- und Blau-Komponenten. |
| PIXEL_FORMAT_16BPP_GRAY_SCALE | Das Format hat 16 Bit pro Pixel, Graustufen. |

| PIXEL_FORMAT_1BPP_INDEXED | Das Format ist monochrom und es wird eine Farbtabelle zur Palette verwendet. |

| PIXEL_FORMAT_8BPP_INDEXED | Das Format ist 256-farbig, und es wird eine Lookup-Tabelle für die Farbpalette verwendet. |
