Die CompositingQuality‑Aufzählung definiert Qualitätsstufen für die Erstellung zusammengesetzter Bilder.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusCompositingQuality

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| COMPOSITING_QUALITY_ASSUME_LINEAR | Es wird keine Gammakorrektur durchgeführt; jedoch führt die Verwendung linearer Werte zu einer besseren Qualität als die Standardeinstellung bei leicht geringerer Geschwindigkeit. |
| COMPOSITING_QUALITY_DEFAULT | Es wird keine Gammakorrektur durchgeführt. Die Gammakorrektur steuert die Gesamthelligkeit und den Kontrast eines Bildes. Ohne Gammakorrektur können zusammengesetzte Bilder zu hell oder zu dunkel erscheinen. |
| COMPOSITING_QUALITY_GAMMA_CORRECTED | Aktivieren Sie die Gammakorrektur für eine qualitativ hochwertigere Zusammensetzung bei geringerer Geschwindigkeit. Was das Ergebnis betrifft, gibt es keinen Unterschied zwischen diesem Wert und CompositingQualityHighQuality. |
| COMPOSITING_QUALITY_HIGH_QUALITY | Gammakorrektur wird durchgeführt. Die Qualität der Zusammensetzung wird zugunsten der Geschwindigkeit bevorzugt. |
| COMPOSITING_QUALITY_HIGH_SPEED | Es wird keine Gammakorrektur durchgeführt. Die Geschwindigkeit der Zusammensetzung wird zugunsten der Qualität bevorzugt. Was das Ergebnis betrifft, gibt es keinen Unterschied zwischen diesem Wert und CompositingQualityDefault. |
