Die MetafileDataType-Aufzählung definiert Arten von Metadateien, die in einer EMF+-Metadatei eingebettet werden können.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusMetafileDataType

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| METAFILE_DATA_TYPE_EMF | Gibt an, dass die Metadatei eine EMF-Metadatei ist, die Grafikoperationen mit EMF‑Datensätzen spezifiziert, wie in [MS-EMF] angegeben. |
| METAFILE_DATA_TYPE_EMF_PLUS_DUAL | Gibt an, dass die Metadatei eine EMF+-Metadatei ist, die Grafikoperationen mit sowohl EMF- als auch EMF+-Datensätzen spezifiziert. |
| METAFILE_DATA_TYPE_EMF_PLUS_ONLY | Gibt an, dass die Metadatei eine EMF+-Metadatei ist, die Grafikoperationen ausschließlich mit EMF+-Datensätzen spezifiziert. |
| METAFILE_DATA_TYPE_WMF | Gibt an, dass die Metadatei eine WMF-Metadatei ist, die Grafikoperationen mit WMF-Datensätzen spezifiziert, wie in [MS-WMF] angegeben. |
| METAFILE_DATA_TYPE_WMF_PLACEABLE | Gibt an, dass die Metadatei eine WMF-Metadatei ist, die Grafikoperationen mit WMF-Datensätzen spezifiziert und zusätzliche Header-Informationen enthält, die die WMF-Metadatei geräteunabhängig machen, wie in [MS-WMF] angegeben. |
