Die PaletteStyle-Flags geben Eigenschaften von Grafikpaletten an. Diese Flags können kombiniert werden, um mehrere Optionen anzugeben.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusPaletteStyleFlags

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| PALETTE_STYLE_GRAY_SCALE | Wenn gesetzt, muss die Palette nur Graustufen‑Einträge enthalten. |
| PALETTE_STYLE_HALFTONE | Wenn gesetzt, muss die Palette diskrete Farbwerte enthalten, die für die Halbtonerzeugung verwendet werden können. |
| PALETTE_STYLE_HAS_ALPHA | Wenn gesetzt, muss einer oder mehrere Paletteneinträge Alphatransparenz‑Informationen enthalten. |
