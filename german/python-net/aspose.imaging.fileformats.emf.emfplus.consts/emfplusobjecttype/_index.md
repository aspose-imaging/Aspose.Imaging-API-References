Die ObjectType-Aufzählung definiert Arten von Grafikobjekten, die erstellt und in Grafikoperationen verwendet werden können.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusObjectType

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| OBJECT_TYPE_BRUSH | Gibt ein [EmfPlusBrush](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusbrush/) Objekt (Abschnitt 2.2.1.1) an. Pinselobjekte füllen Grafikbereiche. |
| OBJECT_TYPE_CUSTOM_LINE_CAP | Gibt ein [EmfPlusCustomLineCap](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecap/) Objekt (Abschnitt 2.2.1.2) an. Benutzerdefinierte Linienenden-Objekte definieren Formen, die an den Enden einer Grafiklinie gezeichnet werden, einschließlich Quadraten, Kreisen und Rauten. |
| OBJECT_TYPE_FONT | Gibt ein [EmfPlusFont](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusfont/) Objekt (Abschnitt 2.2.1.3) an. Schriftobjekte definieren Schriftarteigenschaften, einschließlich Schriftstil, EM-Größe und Schriftfamilie. |
| OBJECT_TYPE_IMAGE | Gibt ein [EmfPlusImage](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusimage/) Objekt (Abschnitt 2.2.1.4) an. Bildobjekte kapseln Bitmaps und Metadateien. |
| OBJECT_TYPE_IMAGE_ATTRIBUTES | Gibt ein [EmfPlusImageAttributes](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusimageattributes/) Objekt (Abschnitt 2.2.1.5) an. Bildattribut-Objekte definieren Vorgänge an Pixeln während der Bilddarstellung, einschließlich Farbkorrektur, Graustufenanpassung, Gamma-Korrektur und Farbabstimmung. |
| OBJECT_TYPE_INVALID | Das Objekt ist kein gültiges Objekt. |
| OBJECT_TYPE_PATH | Gibt ein [EmfPlusPath](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfpluspath/) Objekt (Abschnitt 2.2.1.6) an. Pfadobjekte definieren Sequenzen von Linien, Kurven und Formen. |
| OBJECT_TYPE_PEN | Gibt ein [EmfPlusPen](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfpluspen/) Objekt (Abschnitt 2.2.1.7) an. Stiftobjekte zeichnen Grafiklinien. |
| OBJECT_TYPE_REGION | Gibt ein [EmfPlusRegion](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusregion/) Objekt (Abschnitt 2.2.1.8) an. Regionsobjekte definieren Bereiche der Ausgabefläche. |
| OBJECT_TYPE_STRING_FORMAT | Gibt ein [EmfPlusStringFormat](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusstringformat/) Objekt (Abschnitt 2.2.1.9) an. Stringformat-Objekte definieren Textlayout, einschließlich Ausrichtung, Orientierung, Tabulatoren, Beschneidung und Ziffernersetzung für Sprachen, die keine westeuropäischen Ziffern verwenden. |
