Die PenData-Flags geben Eigenschaften von Grafikstiften an, einschließlich des Vorhandenseins optionaler Datenfelder. Diese Flags können kombiniert werden, um mehrere Optionen anzugeben.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)
