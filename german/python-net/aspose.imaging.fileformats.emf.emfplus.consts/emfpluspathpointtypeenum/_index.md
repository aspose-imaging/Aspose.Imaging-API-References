Die PathPointType-Aufzählung definiert Arten von Punkten auf einem Grafikpfad.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusPathPointTypeEnum

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| PATH_POINT_TYPE_BEZIER | Gibt an, dass der Punkt ein Endpunkt oder ein Kontrollpunkt einer kubischen Bezier-Kurve ist. |
| PATH_POINT_TYPE_LINE | Gibt an, dass der Punkt einer der beiden Endpunkte einer Linie ist. |
| PATH_POINT_TYPE_START | Gibt an, dass der Punkt der Startpunkt eines Pfads ist. |
