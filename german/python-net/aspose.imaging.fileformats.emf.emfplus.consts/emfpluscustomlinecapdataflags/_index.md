Die CustomLineCapData‑Flags geben Daten für benutzerdefinierte Linienenden an. Diese Flags können kombiniert werden, um mehrere Optionen anzugeben.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusCustomLineCapDataFlags

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| CUSTOM_LINE_CAP_DATA_FILL_PATH | Wenn gesetzt, MUSS ein [EmfPlusFillPath](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfplusfillpath/) Objekt im OptionalData-Feld des [EmfPlusCustomLineCapData](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfpluscustomlinecapdata/) Objekts angegeben werden, um die benutzerdefinierte Linienkappe zu füllen. |
| CUSTOM_LINE_CAP_DATA_LINE_PATH | Wenn gesetzt, MUSS ein [EmfPlusLinePath](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.objects/emfpluslinepath/) Objekt im OptionalData-Feld des EmfPlusCustomLineCapData-Objekts angegeben werden, um die benutzerdefinierte Linienkappe zu umreißen. |
