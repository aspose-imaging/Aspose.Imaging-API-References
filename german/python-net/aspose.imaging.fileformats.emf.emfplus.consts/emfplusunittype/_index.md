Die UnitType-Aufzählung definiert Maßeinheiten in verschiedenen Koordinatensystemen.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusUnitType

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| UNIT_TYPE_DISPLAY | Gibt eine Einheit für die Entfernung basierend auf den Eigenschaften des physischen Displays an.<br/>            Zum Beispiel, wenn das Anzeigegerät ein Monitor ist, dann ist die Einheit 1 Pixel. |
| UNIT_TYPE_DOCUMENT | Gibt eine Einheit von 1/300 Zoll an. |
| UNIT_TYPE_INCH | Gibt eine Einheit von 1 Zoll an. |
| UNIT_TYPE_MILLIMETER | Gibt eine Einheit von 1 Millimeter an. |
| UNIT_TYPE_PIXEL | Gibt eine Einheit von 1 Pixel an. |
| UNIT_TYPE_POINT | Gibt eine Einheit von 1 Druckerpunkt oder 1/72 Zoll an. |
| UNIT_TYPE_WORLD | Gibt eine Einheit für logische Entfernung im Weltraum an. |
