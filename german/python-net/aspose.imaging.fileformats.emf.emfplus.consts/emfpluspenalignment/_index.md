Die PenAlignment-Aufzählung definiert die Verteilung der Stiftdicke in Bezug auf die zu zeichnende Linie.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusPenAlignment

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| PEN_ALIGNMENT_CENTER | Gibt an, dass das EmfPlusPen-Objekt über der theoretischen Linie zentriert ist. |
| PEN_ALIGNMENT_INSET | Gibt an, dass der Stift auf der Innenseite der theoretischen Linie positioniert ist. |
| PEN_ALIGNMENT_LEFT | Gibt an, dass der Stift links von der theoretischen Linie positioniert ist. |
| PEN_ALIGNMENT_OUTSET | Gibt an, dass der Stift auf der Außenseite der theoretischen Linie positioniert ist. |
| PEN_ALIGNMENT_RIGHT | Gibt an, dass der Stift rechts von der theoretischen Linie positioniert ist. |
