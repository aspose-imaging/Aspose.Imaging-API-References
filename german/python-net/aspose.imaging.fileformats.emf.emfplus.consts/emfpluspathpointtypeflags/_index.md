Die PathPointType-Flags geben Typeneigenschaften von Punkten auf Grafikpfaden an. Diese Flags können kombiniert werden, um mehrere Optionen anzugeben.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusPathPointTypeFlags

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| PATH_POINT_TYPE_CLOSE_SUBPATH | Gibt an, dass der Punkt das Endpunkt eines Teilpfads ist. |
| PATH_POINT_TYPE_DASH_MODE | Gibt an, dass ein Liniensegment, das durch den Punkt verläuft, gestrichelt ist. |
| PATH_POINT_TYPE_PATH_MARKER | Gibt an, dass der Punkt ein Positionsmarker ist. |
