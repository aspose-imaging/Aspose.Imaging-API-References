Die HatchStyle-Aufzählung definiert Schraffurmuster, die von Grafikpinseln verwendet werden. Ein Schraffurmuster besteht aus einer einfarbigen Hintergrundfarbe und darüber gezeichneten Linien.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)
