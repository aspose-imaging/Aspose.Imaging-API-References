Die CurveChannel‑Aufzählung definiert Farbkanäle, die durch eine Farbkurveneffektanpassung eines Bildes beeinflusst werden können.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusCurveChannel

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| CURVE_CHANNEL_ALL | Gibt an, dass eine Farbkurvenanpassung auf alle Farbkanäle angewendet wird. |
| CURVE_CHANNEL_BLUE | Gibt an, dass eine Farbkurvenanpassung nur auf den blauen Farbkanal angewendet wird. |
| CURVE_CHANNEL_GREEN | Gibt an, dass eine Farbkurvenanpassung nur auf den grünen Farbkanal angewendet wird. |
| CURVE_CHANNEL_RED | Gibt an, dass eine Farbkurvenanpassung nur auf den roten Farbkanal angewendet wird. |
