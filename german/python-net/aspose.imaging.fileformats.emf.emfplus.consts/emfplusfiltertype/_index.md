Die FilterType-Aufzählung definiert Arten von Filteralgorithmen, die für die Verbesserung der Text- und Grafikqualität sowie für die Bilddarstellung verwendet werden können.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusFilterType

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| FILTER_TYPE_BOX | Gibt einen Box-Filter-Algorithmus an, bei dem jedes Zielpixel durch Mittelung eines Rechtecks von Quellpixeln berechnet wird. Dieser Algorithmus ist nur beim Verkleinern eines Bildes nützlich. |
| FILTER_TYPE_GAUSSIAN_QUAD | Gibt an, dass ein 4‑Stichproben‑Gauß‑Filter verwendet wird, der einen Unschärfeeffekt auf ein Bild erzeugt. |
| FILTER_TYPE_LINEAR | Gibt an, dass lineare Interpolation mittels gewichteter Mittelung eines 2×2‑Pixel‑Bereichs um das Quellpixel herum durchgeführt wird. |
| FILTER_TYPE_NONE | Gibt an, dass keine Filterung durchgeführt wird. |
| FILTER_TYPE_POINT | Gibt an, dass jedes Zielpixel durch Abtasten des nächstgelegenen Pixels aus dem Quellbild berechnet wird. |
| FILTER_TYPE_PYRAMIDAL_QUAD | Gibt an, dass ein 4‑Stichproben‑Zelt‑Filter verwendet wird. |
| FILTER_TYPE_TRIANGLE | Gibt an, dass jedes Pixel im Quellbild gleichmäßig zum Zielbild beiträgt. Dies ist der langsamste der Filteralgorithmen. |
