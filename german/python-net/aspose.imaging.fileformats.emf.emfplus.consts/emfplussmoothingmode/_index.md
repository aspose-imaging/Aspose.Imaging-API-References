Die SmoothingMode-Aufzählung definiert Glättungsmodi, die auf Linien, Kurven und die Kanten gefüllter Flächen angewendet werden, um sie kontinuierlicher oder schärfer definiert erscheinen zu lassen.

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusSmoothingMode

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| SMOOTHING_MODE_ANTI_ALIAS_8X4 | Gibt eine gute Qualität unter Verwendung eines 8x4-Boxfilters an. |
| SMOOTHING_MODE_ANTI_ALIAS_8X8 | Gibt eine bessere Qualität unter Verwendung eines 8x8-Boxfilters an. |
| SMOOTHING_MODE_DEFAULT | Gibt die standardmäßige Kurvenglättung ohne Kantenglättung an. |
| SMOOTHING_MODE_HIGH_QUALITY | Gibt die beste Qualität mit Kantenglättung an. |
| SMOOTHING_MODE_HIGH_SPEED | Gibt die beste Leistung ohne Kantenglättung an. |
| SMOOTHING_MODE_NONE | Führt keine Kurvenglättung und keine Kantenglättung durch. |
