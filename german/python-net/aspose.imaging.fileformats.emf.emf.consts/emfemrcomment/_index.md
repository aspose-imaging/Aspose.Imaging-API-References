Die EmrComment-Aufzählung definiert die Datentypen, die ein öffentlicher Kommentar‑Datensatz enthalten kann<br/>            wie in Abschnitt 2.3.3.4 angegeben.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfEmrComment

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| EMR_COMMENT_BEGINGROUP | Dieser Kommentardatensatz identifiziert den Beginn einer Gruppe von Zeichenaufzeichnungen. Er identifiziert ein Objekt innerhalb einer EMF-Metadatei. |
| EMR_COMMENT_ENDGROUP | Dieser Kommentardatensatz identifiziert das Ende einer Gruppe von Zeichenaufzeichnungen. Für jeden EMR_COMMENT_BEGINGROUP<br/>            Datensatz muss ein EMR_COMMENT_ENDGROUP-Datensatz in der Metadatei enthalten sein, und sie dürfen verschachtelt sein. |
| EMR_COMMENT_MULTIFORMATS | Dieser Kommentardatensatz ermöglicht das Einbinden mehrerer Definitionen eines Bildes in die Metadatei. <br/>            Durch diesen Kommentar kann eine Anwendung beispielsweise einkapsulierten PostScript-Text sowie eine EMF-Definition eines Bildes einbinden. |
| EMR_COMMENT_UNICODE_END | Dieser Kommentardatensatz ist reserviert und DARF NICHT in einer EMF-Metadatei verwendet werden. |
| EMR_COMMENT_UNICODE_STRING | Dieser Kommentardatensatz ist reserviert und DARF NICHT in einer EMF-Metadatei verwendet werden. |
| EMR_COMMENT_WINDOWS_METAFILE | Dieser Kommentardatensatz enthält eine Spezifikation eines Bildes im WMF. Siehe [MS-WMF] für weitere Informationen. |
