Die ColorSpace-Aufzählung wird verwendet, um anzugeben, wann die Farbprüfung ein- und ausgeschaltet wird und wann Transformationen gelöscht werden sollen.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfColorSpace

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| CS_DELETE_TRANSFORM | Wenn die Farbverwaltung für das Zielprofil aktiviert ist, wird sie deaktiviert und die zusammengefügte Transformation gelöscht. |
| CS_DISABLE | Deaktiviert die Farbprüfung. |
| CS_ENABLE | Ordnet Farben dem Farbraum des Zielgeräts zu. Dies aktiviert die Farbprüfung. <br/>            Alle nachfolgenden Zeichenbefehle im Wiedergabegeräte-Kontext rendern Farben, wie sie auf dem Zielgerät erscheinen würden. |
