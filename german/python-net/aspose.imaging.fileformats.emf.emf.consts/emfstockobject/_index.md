Die StockObject‑Aufzählung gibt die Indizes vordefinierter logischer Grafikobjekte an <br/>            die in Grafikoperationen verwendet werden können. Die spezifischen Strukturen von Stock‑Objekten sind <br/>            implementationsabhängig; jedoch sollten die Eigenschaften von Stock‑Objekten den Eigenschaften von explizit erstellten Objekten desselben Typs entsprechen. <br/>            Diese Eigenschaften werden, wo möglich, für die in dieser Aufzählung definierten Stock‑Objekte angegeben.
