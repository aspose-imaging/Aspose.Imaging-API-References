Die ModifyWorldTransformMode-Aufzählung definiert Modi zur Verwendung der angegebenen Transformationsdaten<br/>            um die Welt‑zu‑Seiten‑Transformation, die derzeit im Wiedergabegeräte‑Kontext definiert ist, zu ändern.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfModifyWorldTransformMode

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| MWT_IDENTITY | Setzt die aktuelle Transformation mithilfe der Identitätsmatrix zurück. In diesem Modus werden die angegebenen Transformationsdaten ignoriert |
| MWT_LEFTMULTIPLY | Multipliziert die aktuelle Transformation. In diesem Modus ist das angegebene Transformationsdaten das linke Multiplikand, und <br/>            die Transformation, die derzeit im Wiedergabegeräte-Kontext definiert ist, das rechte Multiplikand |
| MWT_RIGHTMULTIPLY | Multiplizieren Sie die aktuelle Transformation. In diesem Modus ist das angegebene Transformationsdaten das rechte Multiplikand, <br/>            und die Transformation, die derzeit im Wiedergabegeräte-Kontext definiert ist, das linke Multiplikand. |
| MWT_SET | Führen Sie die Funktion eines EMR_SETWORLDTRANSFORM‑Datensatzes aus (Abschnitt 2.3.12.2). |
