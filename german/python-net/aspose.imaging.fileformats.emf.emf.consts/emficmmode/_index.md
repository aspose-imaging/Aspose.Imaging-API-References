Die ICMMode-Aufzählung definiert Werte, die angeben, wann ICM ein- und ausgeschaltet wird.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfIcmMode

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| ICM_DONE_OUTSIDEDC | Schaltet ICM im Wiedergabegeräte-Kontext aus und deaktiviert die alte Farbkorrektur von Halbtönen |
| ICM_OFF | Schaltet die Bildfarbverwaltung (ICM) im Wiedergabegeräte-Kontext aus. Schaltet die alte Farbkorrektur von Halbtönen ein |
| ICM_ON | Schaltet ICM im Wiedergabegeräte-Kontext ein. Deaktiviert die alte Farbkorrektur von Halbtönen. |
| ICM_QUERY | Fragt den aktuellen Zustand der Farbverwaltung im Wiedergabegeräte-Kontext ab. |
