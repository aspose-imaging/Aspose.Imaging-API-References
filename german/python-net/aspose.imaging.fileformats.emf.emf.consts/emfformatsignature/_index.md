Die FormatSignature-Aufzählung definiert Werte, die verwendet werden, um das Format eingebetteter Daten in EMF‑Datensätzen zu identifizieren.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfFormatSignature

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| ENHMETA_SIGNATURE | Der Wert dieses Elements ist die Sequenz der ASCII‑Zeichen "FME ",<br/>            die zufällig die Umkehrung des Strings "EMF" ist und EMF‑Aufzeichnungsdaten bezeichnet.<br/>            Hinweis: Das Leerzeichen im String ist signifikant und MUSS vorhanden sein. |
| EPS_SIGNATURE | Der Wert dieses Elements ist die Sequenz der ASCII‑Zeichen "FSPE", die zufällig<br/>            die Umkehrung des Strings "EPSF" ist und kapsulierte PostScript‑(EPS‑)Formulardaten bezeichnet. |
