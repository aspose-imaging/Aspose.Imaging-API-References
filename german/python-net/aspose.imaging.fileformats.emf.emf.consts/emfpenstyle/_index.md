Die PenStyle-Aufzählung definiert die Attribute von Stiften, die in Grafikoperationen verwendet werden können.<br/>             Ein Stiftstil ist eine Kombination aus Stifttyp, Linienstil, Linienende und Linienverbindung.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfPenStyle

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| END_CAP_MASK | Die Endkappenmaske |
| JOIN_MASK | Die Verbindungsmaske |
| PS_ALTERNATE | Ein Linienstil, bei dem jedes zweite Pixel gesetzt ist. Dieser Stil ist nur für einen Stifttyp von PS_COSMETIC anwendbar. |
| PS_COSMETIC | Ein Stifttyp, der eine Linie mit einer Breite von einer logischen Einheit und einem Stil, der eine einfarbige Farbe ist, spezifiziert. |
| PS_DASH | Ein Linienstil, der gestrichelt ist. |
| PS_DASHDOT | Ein Linienstil, der aus abwechselnden Strichen und Punkten besteht. |
| PS_DASHDOTDOT | Ein Linienstil, der aus Strichen und doppelten Punkten besteht. |
| PS_DOT | Ein Linienstil, der gepunktet ist. |
| PS_ENDCAP_FLAT | Eine Linienendkappe, die flache Enden angibt. |
| PS_ENDCAP_ROUND | Eine Linienendkappe, die runde Enden angibt. |
| PS_ENDCAP_SQUARE | Eine Linienendkappe, die quadratische Enden angibt. |
| PS_GEOMETRIC | Ein Stifttyp, der eine Linie mit einer Breite angibt, die in logischen Einheiten gemessen wird <br/>            und einen Stil, der beliebige Attribute eines Pinsels enthalten kann. |
| PS_INSIDEFRAME | Ein Linienstil, der eine Vollfarbe ist. Wenn dieser Stil in einem Zeichendatensatz <br/>            angegeben wird, der ein Begrenzungsrechteck verwendet, werden die Abmessungen der Figur verkleinert, sodass <br/>            sie vollständig in das Begrenzungsrechteck passt, wobei die Breite des Stifts berücksichtigt wird. |
| PS_JOIN_BEVEL | Eine Linienverbindung, die abgeschrägte Verbindungen angibt. |
| PS_JOIN_MITER | Eine Linienverbindung, die miterförmige Verbindungen angibt, wenn die Längen der Verbindungen innerhalb des aktuellen Miter-Längenlimits liegen, das im Wiedergabegeräte-Kontext festgelegt ist. <br/>            Überschreiten die Längen der Verbindungen das Miter-Limit, werden abgeschrägte Verbindungen angegeben. |
| PS_JOIN_ROUND | Eine Linienverbindung, die runde Verbindungen angibt. |
| PS_NULL | Ein Linienstil, der unsichtbar ist. |
| PS_SOLID | Ein Linienstil, der eine Vollfarbe ist |
| PS_USERSTYLE | Ein Linienstil, der durch ein Stil-Array definiert ist, das die Längen von Strichen und Lücken in der Linie angibt. |
| STYLE_MASK | Die Stilmaske |
| TYPE_MASK | Die Typmaske |
