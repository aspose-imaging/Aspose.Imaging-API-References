Die StretchMode‑Aufzählung wird verwendet, um anzugeben, wie Farbdaten zu gestreckten oder komprimierten Bitmaps hinzugefügt oder von ihnen entfernt werden.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfStretchMode

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| STRETCH_ANDSCANS | Führt eine boolesche UND-Operation unter Verwendung der Farbwerte für die eliminierten und vorhandenen Pixel aus.<br/>            Wenn das Bitmap ein monochromes Bitmap ist, bewahrt dieser Modus schwarze Pixel auf Kosten weißer Pixel. |
| STRETCH_DELETESCANS | Löscht die Pixel. Dieser Modus löscht alle eliminierten Pixelzeilen, ohne zu versuchen, deren Informationen zu erhalten. |
| STRETCH_HALFTONE | Mappt Pixel vom Quellrechteck in Pixelblöcke im Zielrechteck. <br/>            Die durchschnittliche Farbe über den Zielpixelblock approximiert die Farbe der Quellpixel. |
| STRETCH_ORSCANS | Führt eine boolesche ODER-Operation unter Verwendung der Farbwerte für die eliminierten und vorhandenen Pixel aus. <br/>            Wenn das Bitmap ein monochromes Bitmap ist, bewahrt dieser Modus weiße Pixel auf Kosten schwarzer Pixel. |
