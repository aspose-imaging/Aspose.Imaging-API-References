Die GradientFill-Aufzählung definiert die Modi für Farbverlauf‑Fülloperationen.

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfGradientFill

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| GRADIENT_FILL_RECT_H | Ein Modus, bei dem die Farbübergabe entlang eines Farbverlaufs von der linken zur rechten Kante eines Rechtecks durchgeführt wird. |
| GRADIENT_FILL_RECT_V | Ein Modus, bei dem die Farbübergabe entlang eines Farbverlaufs von der oberen zur unteren Kante eines Rechtecks durchgeführt wird. |
| GRADIENT_FILL_TRIANGLE | Ein Modus, bei dem die Farbübergabe zwischen den Scheitelpunkten eines Dreiecks durchgeführt wird. |
