**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfColorAdjustmentEnum

## **Members**
| **Member name** | **Beschreibung** |
| :- | :- |
| CA_LOG_FILTER | Der gibt an, dass ein logarithmischer Prozess SOLL auf die endgültige <br/>            Dichte der Ausgabefarben angewendet werden. Dies erhöht den Farbkontrast, wenn die Luminanz niedrig ist |
| CA_NEGATIVE | Gibt an, dass das Negative des Originalbildes SOLL angezeigt werden. |
