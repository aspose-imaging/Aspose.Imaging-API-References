RegionMode 枚举定义了与 EMR_SELECTCLIPPATH 和 EMR_EXTSELECTCLIPRGN 一起使用的值，<br/>            用于指定当前路径或与当前剪裁区域合并的新区域。

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfRegionMode

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| RGN_AND | 新的裁剪区域包括当前裁剪区域与当前路径（或新区域）的交集（重叠区域）。 |
| RGN_COPY | 新的裁剪区域是当前路径（或新区域）。 |
| RGN_DIFF | 新的裁剪区域包括当前裁剪区域的区域，但排除当前路径（或新区域）的部分。 |
| RGN_OR | 新的裁剪区域包括当前裁剪区域与当前路径（或新区域）的并集（组合区域）。 |
| RGN_XOR | 新的裁剪区域包括当前裁剪区域与当前路径（或新区域）的并集，但不包括重叠区域。 |
