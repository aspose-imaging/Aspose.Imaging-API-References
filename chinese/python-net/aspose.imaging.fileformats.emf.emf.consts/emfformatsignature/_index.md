FormatSignature 枚举定义了用于识别 EMF 记录中嵌入数据格式的取值。

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfFormatSignature

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| ENHMETA_SIGNATURE | 此成员的值是 ASCII 字符序列 "FME ",<br/>            它恰好是字符串 "EMF" 的反序，并且表示 EMF 记录数据。<br/>            注意：字符串中的空格字符是重要的，且必须存在。 |
| EPS_SIGNATURE | 此成员的值是 ASCII 字符序列 "FSPE", <br/>            它恰好是字符串 "EPSF" 的反序，并且表示封装的 PostScript (EPS) 格式数据。 |
