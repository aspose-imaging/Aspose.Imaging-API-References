ICMMode 枚举定义了指定何时开启或关闭 ICM 的取值。

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfIcmMode

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| ICM_DONE_OUTSIDEDC | 在播放设备上下文中关闭 ICM，并关闭旧式半色调颜色校正 |
| ICM_OFF | 在播放设备上下文中关闭图像颜色管理 (ICM)。打开旧式半色调颜色校正 |
| ICM_ON | 在播放设备上下文中打开 ICM。关闭旧式半色调颜色校正。 |
| ICM_QUERY | 查询播放设备上下文中颜色管理的当前状态。 |
