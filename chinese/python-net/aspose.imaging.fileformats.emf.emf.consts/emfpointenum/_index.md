Point 枚举用于指定在绘图调用中点的使用方式。

**Module:** [aspose.imaging.fileformats.emf.emf.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emf.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emf.consts.EmfPointEnum

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| BEZIERTO | 指定此点是贝塞尔曲线的控制点或结束点。 |
| CLOSEFIGURE | 可以使用位运算符 OR 将 PT_LINETO 或 PT_BEZIERTO 类型与此值组合，以指示对应的点是图形中的最后一点 <br/>            并且图形已闭合 |
| LINETO | 指定从当前坐标绘制一条线到此点，<br/>            然后此点成为新的当前坐标 |
| MOVETO | 指定此点开始一个不连续的图形。此点将成为新的当前坐标。 |
