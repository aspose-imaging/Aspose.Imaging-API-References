该 16 位 PenStyle 枚举用于指定可在图形操作中使用的不同类型的笔。

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfPenStyle

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| ALTERNATE | 笔每隔一个像素设置一次（此样式仅适用于化妆笔）。 |
| COSMETIC | 该化妆 |
| DASH | 笔为虚线。 |
| DASHDOT | 笔具有交替的短划线和点。 |
| DASHDOTDOT | 笔具有短划线和双点。 |
| DOT | 笔为点线。 |
| ENDCAP_FLAT | 线端帽为平坦。 |
| ENDCAP_ROUND | 线段端帽是圆形的。 |
| ENDCAP_SQUARE | 线段端帽是方形的。 |
| INSIDEFRAME | 画笔是实线。当此画笔用于任何需要边界矩形的绘图记录时，图形的尺寸会在<br/>                考虑画笔宽度后缩小，以便完全适应边界矩形。 |
| JOIN_BEVEL | 线段连接为斜角。 |
| JOIN_MITER | 当线段连接在当前<br/>                由 SETMITERLIMIT META_ESCAPE 记录设置的限制范围内时，采用斜接。若超出该限制，则使用斜角连接。 |
| JOIN_ROUND | 线段连接为圆形。 |
| NULL | 画笔是不可见的。 |
| SOLID | 画笔是实线。 |
| USERSTYLE | 画笔使用用户提供的样式数组。 |
