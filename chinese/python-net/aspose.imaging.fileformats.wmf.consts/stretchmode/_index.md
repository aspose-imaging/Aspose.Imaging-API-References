[StretchMode](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/stretchmode/) 枚举指定位图<br/>                拉伸模式，定义系统如何将位图的行或列与现有像素合并。

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.StretchMode

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| BLACK_ON_WHITE | 使用已消除像素和现有像素的颜色值执行布尔 AND 操作。<br/>                如果位图是单色位图，<br/>                此模式会以牺牲白色像素为代价保留黑色像素。 |
| COLOR_ON_COLOR | 删除像素。此模式会删除所有已消除的像素行<br/>                而不尝试保留其信息。 |
| HALF_TONE | 将像素从源矩形映射到目标矩形中的像素块。<br/>                目标块像素的平均颜色近似于源像素的颜色。 |
| WHITE_ON_BLACK | 使用已消除和现有像素的颜色值执行布尔 OR 操作。<br/>                如果位图是单色位图，则此模式会以牺牲黑色像素为代价保留白色像素 |
