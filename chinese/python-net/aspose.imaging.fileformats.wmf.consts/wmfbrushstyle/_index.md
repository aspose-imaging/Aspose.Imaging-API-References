BrushStyle 枚举指定可用于图形操作的不同可能的画刷类型<br/>                。欲了解更多信息，请参阅<br/>                Brush 对象的规范（第 2.2.1.1 节）。

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfBrushStyle

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| DIBPATTERN | 由 DIB 指定的图案画刷。 |
| DIBPATTERNPT | 由 DIB 指定的图案画刷。 |
| DIBPATTERN_8X8 | 不受支持。 |
| GRADIENT | 渐变<br/>            在 wmf 中不受支持，在 odg 中受支持。 |
| HATCHED | 在实心背景上绘制预定义的简单图案，或 "hatch" 的画刷 |
| INDEXED | 不受支持。 |
| MONOPATTERN | 不受支持。 |
| NULL | 不执行任何操作的画刷。在图形操作中使用 NULL 画刷<br/>                必须产生与根本不使用画刷相同的效果 |
| PATTERN | 使用位图定义的图案进行绘制的画刷，该位图可能是 Bitmap16 对象<br/>                或 DeviceIndependentBitmap (DIB) 对象。 |
| PATTERN_8X8 | 不受支持。 |
| SOLID | 绘制单一、固定颜色的画刷，可为实色或抖动色。 |
