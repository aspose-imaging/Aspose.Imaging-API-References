FamilyFont 枚举指定字体族。字体族以一般方式描述字体的外观<br/>                。当所需的确切字体不可用时，它们用于指定字体。

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfFamilyFont

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| DECORATIVE | 新颖字体。"Old English" 是一个例子。 |
| DONTCARE | 指定了默认字体，该字体取决于实现。 |
| MODERN | 具有恒定笔画宽度的字体，可带或不带衬线。等宽字体通常是现代的。<br/>                "Pica"、"Elite" 和 "Courier New" 是例子。 |
| ROMAN | 具有可变笔画宽度的字体，其宽度与字形的实际宽度成比例，并且带有衬线。<br/>                "MS Serif" 是一个例子。 |
| SCRIPT | 旨在模仿手写的字体。"Script" 和 "Cursive" 是例子。 |
| SWISS | 具有可变笔画宽度的字体，其宽度与字形的实际宽度成比例，并且不带衬线。<br/>                "MS Sans Serif" 是一个例子。 |
