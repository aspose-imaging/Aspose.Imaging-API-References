CharacterSet 枚举定义在用于图形输出的字体中定义的字符字形的可能集合<br/>                。

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfCharacterSet

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| ANSI | 指定英文字符集。 |
| ARABIC | 指定阿拉伯字符集 |
| BALTIC | 指定波罗的海（东北欧）字符集 |
| CHINESEBIG5 | 指定 "传统" 中文字符集，主要用于<br/>                台湾以及香港和澳门特别行政区。 |
| 默认 | 指定基于当前系统区域设置的字符集；<br/>                例如，当系统区域设置为美国英语时，默认字符集为<br/>                ANSI_CHARSET。 |
| EASTEUROPE | 指定东欧字符集。 |
| GB2312 | 指定 "简体" 中文字符集，适用于中华人民共和国。 |
| GREEK | 指定希腊字符集。 |
| HANGUL | 也拼写为 "Hangeul"。指定 Hangul 韩国字符集。 |
| HEBREW | 指定越南字符集。 |
| JOHAB | 也拼写为 "Johap"。指定 Johab 韩国字符集。 |
| MAC | 指定 Apple Macintosh 字符集。 |
| OEM | 指定根据当前<br/>                系统区域设置映射到 OEM 代码页之一。 |
| 俄语 | 指定俄语西里尔字符集。 |
| SHIFTJIS | 指定日语字符集。 |
| SYMBOL | 指定符号字符集。 |
| THAI | 指定泰语字符集。 |
| TURKISH | 指定土耳其语字符集。 |
| VIETNAMESE | 指定越南字符集。 |
