该 OutPrecision 枚举定义了输出精度的值，这些值是字体映射器匹配特定字体参数的要求，包括高度、宽度、字符方向、<br/>                文字倾斜、字距以及字体类型。

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfOutPrecision

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| 默认 | 指定默认行为的值。 |
| 设备 | 指定在系统<br/>                包含多个同名字体时选择设备字体的值。 |
| 轮廓 | 指定对 TrueType 和其他轮廓字体的需求的值。 |
| PS_ONLY | 指定仅对 PostScript 字体的需求的值。如果系统中<br/>                未安装 PostScript 字体，则指定默认行为。 |
| 光栅 | 指定在系统<br/>                包含多个同名字体时选择光栅化字体的值。 |
| 屏幕轮廓 | 指定对 TrueType 和其他<br/>                轮廓字体的偏好的值。 |
| 字符串 | 枚举光栅化字体时返回的值。 |
| 笔画 | 枚举 TrueType 和其他轮廓字体，以及<br/>                矢量字体时返回的值。 |
| TT | 指定在系统<br/>                包含多个同名字体时选择 TrueType 字体的值。 |
| TT_ONLY | 指定仅对 TrueType 字体的需求的值。如果系统中<br/>                未安装 TrueType 字体，则指定默认行为。 |
