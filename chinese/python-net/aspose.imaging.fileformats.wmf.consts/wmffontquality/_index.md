FontQuality 枚举指定在渲染文本时，逻辑字体的属性应与物理字体的属性匹配的程度<br/>                。

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfFontQuality

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| ANTIALIASED | 指定在渲染文本时应使用抗锯齿，如果<br/>                字体支持的话。 |
| CLEARTYPE | 指定在渲染文本时应使用 ClearType 抗锯齿，如果<br/>                字体支持的话。 |
| 默认 | 指定字体的字符质量不重要，因此<br/>                可以使用 DRAFT。 |
| DRAFT | 指定字体的字符质量不如<br/>                逻辑属性的匹配重要。对于光栅化字体，缩放应被启用，<br/>                这意味着可以使用更多的字体大小。 |
| NONANTIALIASED | 指定在渲染文本时不应使用抗锯齿，<br/>                渲染文本。 |
| PROOF | 指定字体的字符质量比<br/>                逻辑属性的匹配更重要。对于光栅化字体，缩放应被禁用，<br/>                并应选择最接近尺寸的字体。 |
