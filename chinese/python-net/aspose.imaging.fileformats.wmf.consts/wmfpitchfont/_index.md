该 PitchFont 枚举定义了用于指定字体特性的值。<br/>                这些值用于指示字体中的字符是固定宽度、可变宽度，还是字距。

**Module:** [aspose.imaging.fileformats.wmf.consts](/imaging/python-net/aspose.imaging.fileformats.wmf.consts/)

**Full Name:** aspose.imaging.fileformats.wmf.consts.WmfPitchFont

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| DEFAULT_PITCH | 默认间距，取决于实现。 |
| FIXED_PITCH | 固定间距，意味着字体中的所有字符在字符串输出时占用相同的<br/>                宽度。 |
| VARIABLE_PITCH | 可变间距，这意味着字体中的字符占用的宽度<br/>                与在字符串中输出时字形的实际宽度成比例。例如，<br/>                "i"和空格字符的宽度通常远小于"W"或"O"字符的宽度。 |
