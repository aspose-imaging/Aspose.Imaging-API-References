该模块提供帮助类和方法，以处理不同的画笔类型。

## **Classes**
| **Class** | **描述** |
| :- | :- |
| [HatchBrush](/imaging/python-net/aspose.imaging.brushes/hatchbrush/) | 定义具有网格样式、前景色和背景色的矩形画刷。此类不能被继承。 |
| [LinearGradientBrush](/imaging/python-net/aspose.imaging.brushes/lineargradientbrush/) | 封装一个带有线性渐变的 [Brush](/imaging/python-net/aspose.imaging/brush/)。此类不能被继承。 |
| [LinearGradientBrushBase](/imaging/python-net/aspose.imaging.brushes/lineargradientbrushbase/) | 表示具有渐变功能和相应属性的 [Brush](/imaging/python-net/aspose.imaging/brush/)。 |
| [LinearMulticolorGradientBrush](/imaging/python-net/aspose.imaging.brushes/linearmulticolorgradientbrush/) | 表示具有由多种颜色和相应位置定义的线性渐变的 [Brush](/imaging/python-net/aspose.imaging/brush/)。此类不能被继承。 |
| [PathGradientBrush](/imaging/python-net/aspose.imaging.brushes/pathgradientbrush/) | 封装一个带有渐变的 [Brush](/imaging/python-net/aspose.imaging/brush/) 对象。此类不能被继承。 |
| [PathGradientBrushBase](/imaging/python-net/aspose.imaging.brushes/pathgradientbrushbase/) | 表示具有基础路径渐变功能的 [Brush](/imaging/python-net/aspose.imaging/brush/)。 |
| [PathMulticolorGradientBrush](/imaging/python-net/aspose.imaging.brushes/pathmulticolorgradientbrush/) | 封装一个带有渐变的 [Brush](/imaging/python-net/aspose.imaging/brush/) 对象。此类不能被继承。 |
| [SolidBrush](/imaging/python-net/aspose.imaging.brushes/solidbrush/) | 实心画刷用于使用特定颜色连续绘制。此类不能被继承。 |
| [TextureBrush](/imaging/python-net/aspose.imaging.brushes/texturebrush/) | 每个 [TextureBrush](/imaging/python-net/aspose.imaging.brushes/texturebrush/) 类的属性都是使用图像填充形状内部的 [Brush](/imaging/python-net/aspose.imaging/brush/) 对象。此类不能被继承。 |
| [TransformBrush](/imaging/python-net/aspose.imaging.brushes/transformbrush/) | 具有变换功能的 [Brush](/imaging/python-net/aspose.imaging/brush/)。 |
