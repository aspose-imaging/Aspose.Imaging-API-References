指定如何在 [GraphicsPath](/imaging/python-net/aspose.imaging/graphicspath/) 对象中包含的图形（子路径）中连接连续的直线或曲线段。

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.LineJoin

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| BEVEL | 指定斜角连接。这会产生对角角落。 |
| MITER | 指定斜接连接。这会产生锐角或被裁剪的角，取决于斜接长度是否超过斜接限制。 |
| MITER_CLIPPED | 指定斜接连接。这会产生锐角或斜角，取决于斜接长度是否超过斜接限制。 |
| ROUND | 指定圆形连接。这会在直线之间产生平滑的圆弧。 |
