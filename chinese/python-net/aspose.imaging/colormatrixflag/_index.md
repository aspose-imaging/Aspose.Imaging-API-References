指定将受到 [ImageAttributes](/imaging/python-net/aspose.imaging/imageattributes/) 的颜色和灰度调整设置影响的图像和颜色类型。

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.ColorMatrixFlag

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| ALT_GRAYS | 仅调整灰色阴影。 |
| 默认 | 所有颜色值，包括灰色阴影，均通过相同的颜色调整矩阵进行调整。 |
| SKIP_GRAYS | 所有颜色都会被调整，但灰色阴影不会被调整。灰色阴影是指红、绿、蓝分量值相同的任何颜色。 |
