指定文本字符串相对于其布局矩形的对齐方式。

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.StringAlignment

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| CENTER | 指定文本在布局矩形的中心对齐。 |
| FAR | 指定文本在布局矩形的原点位置之外对齐。在从左到右的布局中，远端位置在右侧。在从右到左的布局中，远端位置在左侧。 |
| NEAR | 指定文本在布局附近对齐。在从左到右的布局中，近端位置在左侧。在从右到左的布局中，近端位置在右侧。 |
