枚举 [InterpolationMode](/imaging/python-net/aspose.imaging/interpolationmode/) 指定在对图像进行缩放或旋转时使用的算法。

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.InterpolationMode

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| BICUBIC | 指定双三次插值。未进行预过滤。此模式不适用于将图像缩小至原始大小的 25% 以下。 |
| BILINEAR | 指定双线性插值。未进行预过滤。此模式不适用于将图像缩小至原始大小的 50% 以下。 |
| 默认 | 指定默认模式。 |
| HIGH | 指定高质量插值。 |
| HIGH_QUALITY_BICUBIC | 指定高质量的双三次插值。进行预过滤以确保高质量的缩小。此模式产生最高质量的变换图像。 |
| HIGH_QUALITY_BILINEAR | 指定高质量的双线性插值。进行预过滤以确保高质量的缩小。 |
| INVALID | 无效的插值模式。 |
| LOW | 指定低质量插值。 |
| NEAREST_NEIGHBOR | 指定最近邻插值。 |
