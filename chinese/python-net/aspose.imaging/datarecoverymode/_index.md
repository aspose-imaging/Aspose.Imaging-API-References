数据恢复模式。

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.DataRecoveryMode

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| CONSISTENT_RECOVER | 一致恢复模式尝试在腐败未破坏文件格式的情况下恢复所有数据，并允许正确的后续处理。 |
| MAXIMAL_RECOVER | 最大恢复模式即使在文件格式结构已损坏的情况下也会恢复所有数据，后续处理可能会产生不可预料的效果。 |
| NONE | 不暗示任何数据恢复。每当文件格式出现损坏数据时，都会抛出相应的异常。 |
