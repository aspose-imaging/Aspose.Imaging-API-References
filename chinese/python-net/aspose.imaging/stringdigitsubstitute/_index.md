枚举指定如何根据用户的区域设置或语言在字符串中替换数字。

**Module:** [aspose.imaging](/imaging/python-net/aspose.imaging/)

**Full Name:** aspose.imaging.StringDigitSubstitute

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| NATIONAL | 指定与用户区域设置的官方国家语言对应的替代数字。 |
| NONE | 指定禁用替代。 |
| TRADITIONAL | 指定与用户本土文字或语言对应的替代数字，这可能与用户区域设置的官方国家语言不同。 |
| USER | 指定用户自定义的替代方案。 |
