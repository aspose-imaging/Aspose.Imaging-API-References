指示图形在显示后应如何处理。

**Module:** [aspose.imaging.fileformats.gif](/imaging/python-net/aspose.imaging.fileformats.gif/)

**Full Name:** aspose.imaging.fileformats.gif.DisposalMethod

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| NONE | 未指定释放方式。 |
| PRESERVE | 不处理。图形保持原位。 |
| PREVIUOS | 恢复到之前的状态。解码器需要将图形覆盖的区域恢复为渲染图形之前的内容。 |
| RESTORE | 恢复为背景颜色。图形使用的区域必须恢复为背景颜色。 |
| UNDEFINED | 未定义的值。 |
