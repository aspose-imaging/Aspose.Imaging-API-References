FontStyle 标志指定图形字体字形的样式。这些标志可以组合以指定多个选项。

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusFontStyleFlags

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| FONT_STYLE_BOLD | 如果设置，则字体字形必须以更粗的粗细或厚度渲染。<br/>            如果未设置，则字体字形必须以正常的粗细渲染。 |
| FONT_STYLE_ITALIC | 如果设置，则字体必须以相对于基线增加角度或倾斜的方式渲染字符的垂直笔画。<br/>            如果未设置，则字体必须以正常角度渲染字符的垂直笔画。 |
| FONT_STYLE_STRIKEOUT | 如果设置，则字体必须在基线平行的线上，穿过字符中部绘制一条线。<br/>            如果未设置，则字体必须不在字符上绘制线。 |
| FONT_STYLE_UNDERLINE | 如果设置，则字体必须在字符的基线下方绘制一条线。<br/>            如果未设置，则字体必须不在基线下方绘制线。 |
