BrushType 枚举定义了用于填充图形区域的图形画刷类型。

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusBrushType

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| BRUSH_TYPE_HATCH_FILL | 指定一种交叉刷，其特征是预定义的图案。 |
| BRUSH_TYPE_LINEAR_GRADIENT | 包含线性渐变刷数据。 |
| BRUSH_TYPE_PATH_GRADIENT | 指定一种路径渐变刷，其特征是颜色渐变路径渐变刷数据。 |
| BRUSH_TYPE_SOLID_COLOR | 指定一种纯色刷，其特征是 EmfPlusArgb 值。 |
| BRUSH_TYPE_TEXTURE_FILL | 指定一种纹理刷，其特征是图像。 |
