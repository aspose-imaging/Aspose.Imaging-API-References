该 WrapMode 枚举定义了当纹理或渐变画笔的图案小于填充区域时，如何在形状或形状边界上平铺该图案。

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusWrapMode

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| WRAP_MODE_CLAMP | 将纹理或渐变固定在对象边界上。 |
| WRAP_MODE_TILE | 平铺渐变或纹理。 |
| WRAP_MODE_TILE_FLIP_X | 水平翻转纹理或渐变，然后对纹理或渐变进行平铺。 |
| WRAP_MODE_TILE_FLIP_XY | 水平和垂直翻转纹理或渐变，然后对纹理或渐变进行平铺。 |
| WRAP_MODE_TILE_FLIP_Y | 垂直翻转纹理或渐变，然后对纹理或渐变进行平铺。 |
