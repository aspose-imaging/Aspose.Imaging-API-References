CompositingMode 枚举定义了将源颜色与背景颜色合并的模式。合成模式表示 alpha 混合的启用状态。

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusCompositingMode

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| COMPOSITING_MODE_SOURCE_COPY | 禁用 alpha 混合，这意味着当渲染源颜色时，它会覆盖背景颜色。 |
| COMPOSITING_MODE_SOURCE_OVER | 启用 alpha 混合，这指定当渲染颜色时，它会与背景颜色混合。混合程度由被渲染颜色的 alpha 分量值决定。 |
