CurveAdjustments 枚举定义了可应用于图像颜色曲线的调整。

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusCurveAdjustments

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| ADJUST_BLACK_SATURATION | 指定对图像的黑色饱和度进行调整，该饱和度是给定颜色通道强度范围的最小值，通常为 0 到 255。 |
| ADJUST_CONTRAST | 指定对图像对比度的提升或降低。 |
| ADJUST_DENSITY | 指定对图像密度进行增减的模拟。 |
| ADJUST_EXPOSURE | 指定对图像曝光度进行增减的模拟。 |
| ADJUST_HIGHLIGHT | 指定在图像的颜色通道值已高于一半强度时，对该通道值进行提升或降低。此调整可用于在不影响暗部的情况下，提高图像亮区的细节定义。 |
| ADJUST_MIDTONE | 指定对图像进行提亮或加暗的调整。位于强度范围中部的颜色通道值会比接近最小或最大极限的通道值变化更大。此调整可在不失去图像最暗和最亮部分之间对比度的前提下，对图像进行提亮或加暗。 |
| ADJUST_SHADOW | 指定在图像的颜色通道值已低于一半强度时，对该通道值进行提升或降低。此调整可用于在不影响亮区的情况下，提高图像暗部的细节定义。 |
| ADJUST_WHITE_SATURATION | 指定对图像的白色饱和度进行调整，白色饱和度定义为给定颜色通道强度范围的最大值，通常为 0 到 255。 |
