SmoothingMode 枚举定义了用于对线条、曲线以及填充区域边缘进行平滑处理的模式，使其看起来更连续或更清晰。

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusSmoothingMode

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| SMOOTHING_MODE_ANTI_ALIAS_8X4 | 指定使用 8x4 箱形滤波器的良好质量。 |
| SMOOTHING_MODE_ANTI_ALIAS_8X8 | 指定使用 8x8 箱形滤波器的更佳质量。 |
| SMOOTHING_MODE_DEFAULT | 指定默认的曲线平滑（无抗锯齿）。 |
| SMOOTHING_MODE_HIGH_QUALITY | 指定带抗锯齿的最佳质量。 |
| SMOOTHING_MODE_HIGH_SPEED | 指定在无抗锯齿情况下的最佳性能。 |
| SMOOTHING_MODE_NONE | 不执行曲线平滑和抗锯齿。 |
