PaletteStyle 标志指定图形调色板的属性。这些标志可以组合以指定多个选项。

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusPaletteStyleFlags

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| PALETTE_STYLE_GRAY_SCALE | 如果设置，则调色板必须仅包含灰度条目。 |
| PALETTE_STYLE_HALFTONE | 如果设置，则调色板必须包含可用于半色调的离散颜色值。 |
| PALETTE_STYLE_HAS_ALPHA | 如果设置，则调色板的一个或多个条目必须包含 alpha 透明度信息。 |
