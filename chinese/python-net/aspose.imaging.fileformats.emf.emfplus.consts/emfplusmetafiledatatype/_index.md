MetafileDataType 枚举定义了可以嵌入 EMF+ 元文件的元文件数据类型。

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusMetafileDataType

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| METAFILE_DATA_TYPE_EMF | 指定该元文件是 EMF 元文件，使用 EMF 记录指定图形操作，如 [MS-EMF] 中所述。 |
| METAFILE_DATA_TYPE_EMF_PLUS_DUAL | 指定该元文件是一个 EMF+ 元文件，使用 EMF 和 EMF+ 记录来指定图形操作。 |
| METAFILE_DATA_TYPE_EMF_PLUS_ONLY | 指定该元文件是一个 EMF+ 元文件，仅使用 EMF+ 记录来指定图形操作。 |
| METAFILE_DATA_TYPE_WMF | 指定该元文件是一个 WMF 元文件，使用 WMF 记录来指定图形操作，详见 [MS-WMF]。 |
| METAFILE_DATA_TYPE_WMF_PLACEABLE | 指定该元文件是一个 WMF 元文件，使用 WMF 记录来指定图形操作，并包含额外的头部信息，使 WMF 元文件与设备无关，详见 [MS-WMF]。 |
