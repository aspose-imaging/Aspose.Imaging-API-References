DriverStringOptions 标志指定图形文本定位和渲染的属性。这些标志可以组合以指定多个选项。

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusDriverStringOptionsFlags

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| DRIVER_STRING_OPTIONS_CMAP_LOOKUP | 如果设置，则字符字形的位置应在字符映射查找表中指定。<br/>            如果未设置，则字形位置应从坐标数组中获取。 |
| DRIVER_STRING_OPTIONS_LIMIT_SUBPIXEL | 如果设置，则应使用更少的内存来缓存抗锯齿字形，这会导致较低质量的文本渲染。<br/>            如果未设置，则应使用更多的内存，这会产生更高质量的文本渲染。 |
| DRIVER_STRING_OPTIONS_REALIZED_ADVANCE | 如果设置，则字符字形位置应相对于第一个字形的位置进行计算。<br/>            如果未设置，则字形位置应从坐标数组中获取。 |
| DRIVER_STRING_OPTIONS_VERTICAL | 如果设置，则字符串应垂直渲染。<br/>            如果未设置，则字符串应水平渲染。 |
