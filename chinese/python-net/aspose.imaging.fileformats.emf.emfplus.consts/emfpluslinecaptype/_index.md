LineCapType 枚举定义了使用图形笔绘制的线条末端的线帽类型。

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusLineCapType

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| LINE_CAP_TYPE_ANCHOR_MASK | 用于检查线帽是否为锚点线帽的掩码。 |
| LINE_CAP_TYPE_ARROW_ANCHOR | 指定线段末端使用箭头形状锚定。箭头尖端必须位于线段的最后一点。箭头的宽度应大于线段宽度。 |
| LINE_CAP_TYPE_CUSTOM | 指定自定义线帽。 |
| LINE_CAP_TYPE_DIAMOND_ANCHOR | 指定线段末端使用菱形线帽锚定，该线帽是旋转 45 度的正方形。菱形的中心必须位于线段的最后一点。菱形的宽度应大于线段宽度。 |
| LINE_CAP_TYPE_FLAT | 指定方形线帽。线段的末端必须是线段的最后一点。 |
| LINE_CAP_TYPE_NO_ANCHOR | 指定线段末端未锚定。 |
| LINE_CAP_TYPE_ROUND | 指定圆形线帽。圆心必须位于线段的最后一点。圆的直径等于线宽。 |
| LINE_CAP_TYPE_ROUND_ANCHOR | 指定线段末端使用圆形线帽锚定。圆心必须位于线段的最后一点。圆的宽度应大于线段宽度。 |
| LINE_CAP_TYPE_SQUARE | 指定方形线帽。方形的中心必须位于线段的最后一点。方形的宽度即为线宽。 |
| LINE_CAP_TYPE_SQUARE_ANCHOR | 指定线段末端使用方形线帽锚定。方形的中心必须位于线段的最后一点。方形的高度和宽度均为线宽。 |
| LINE_CAP_TYPE_TRIANGLE | 指定三角形线帽。三角形的底部必须位于线段的最后一点。三角形的底部宽度即为线宽。 |
