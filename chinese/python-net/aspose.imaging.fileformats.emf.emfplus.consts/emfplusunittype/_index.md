该 UnitType 枚举定义了不同坐标系中的测量单位。

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusUnitType

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| UNIT_TYPE_DISPLAY | 指定基于物理显示特性的距离单位。<br/>            例如，如果显示设备是监视器，则该单位为 1 像素。 |
| UNIT_TYPE_DOCUMENT | 指定 1/300 英寸的单位。 |
| UNIT_TYPE_INCH | 指定 1 英寸的单位。 |
| UNIT_TYPE_MILLIMETER | 指定 1 毫米的单位。 |
| UNIT_TYPE_PIXEL | 指定 1 像素的单位。 |
| UNIT_TYPE_POINT | 指定 1 打印机点（或 1/72 英寸）的单位。 |
| UNIT_TYPE_WORLD | 指定世界空间内的逻辑距离单位。 |
