该 StringAlignment 枚举定义了相对于文本布局矩形对齐字符串的方式。

**Module:** [aspose.imaging.fileformats.emf.emfplus.consts](/imaging/python-net/aspose.imaging.fileformats.emf.emfplus.consts/)

**Full Name:** aspose.imaging.fileformats.emf.emfplus.consts.EmfPlusStringAlignment

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| STRING_ALIGNMENT_CENTER | 指定对齐方式在布局矩形的原点和范围之间居中。 |
| STRING_ALIGNMENT_FAR | 指定对齐方式位于布局矩形的右侧。 |
| STRING_ALIGNMENT_NEAR | 指定字符串对齐朝向布局矩形的原点。这可用于沿直线对齐字符或在矩形内对齐文本。对于从右到左的布局矩形，原点应位于右上角。 |
