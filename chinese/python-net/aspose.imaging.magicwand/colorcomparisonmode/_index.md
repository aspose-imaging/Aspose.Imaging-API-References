指定在 Magic Wand 算法期间颜色的比较方式。

**Module:** [aspose.imaging.magicwand](/imaging/python-net/aspose.imaging.magicwand/)

**Full Name:** aspose.imaging.magicwand.ColorComparisonMode

## **Members**
| **成员名称** | **描述** |
| :- | :- |
| 自定义 | 颜色比较算法由用户定义。 |
| RGB_DEFAULT | 颜色在 RGB 色彩空间中进行比较。<br/>            每个颜色差异必须满足阈值。 |
| YUV_DEFAULT | 颜色在 YUV 色彩空间中进行比较。<br/>            每个颜色差异必须满足阈值。 |
| YUV_LESS_LUMA_SENSITIVE | 颜色在 YUV 色彩空间中进行比较。<br/>            颜色信息差异必须满足阈值，亮度分量的阈值加倍。 |
