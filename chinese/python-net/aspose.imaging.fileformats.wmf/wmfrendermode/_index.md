## **Members**
| **成员名称** | **描述** |
| :- | :- |
| AUTO | 自动渲染。如果存在嵌入的 emf，则渲染 emf，否则渲染 wmf。 |
| BOTH | 按顺序渲染两者。 |
| EMBEDDED_EMF_ONLY | 仅渲染嵌入的 emf。 |
