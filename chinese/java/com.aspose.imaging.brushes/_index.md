| [PathMulticolorGradientBrush](../com.aspose.imaging.brushes/pathmulticolorgradientbrush) | 封装一个带有渐变的 `Aspose.Imaging.Brush` 对象。 |
| [SolidBrush](../com.aspose.imaging.brushes/solidbrush) | 实心画刷用于使用特定颜色连续绘制。 |
| [TextureBrush](../com.aspose.imaging.brushes/texturebrush) | `Aspose.Imaging.Brushes.TextureBrush` 类的每个属性都是使用图像填充形状内部的 `Aspose.Imaging.Brush` 对象。 |
| [TransformBrush](../com.aspose.imaging.brushes/transformbrush) | 具有变换功能的 `Brush`。 |
