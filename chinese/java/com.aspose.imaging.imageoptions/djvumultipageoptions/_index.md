DjVu 图形文件格式的 API 为开发人员提供对 DjVu 文档的无缝访问，适用于扫描文档和书籍。借助图像加载选项，开发人员可以轻松地将 DjVu 文件集成到其应用程序中，释放处理多页内容的潜力，包括文本、图形和图像，从而实现多功能的文档处理解决方案。
