通过能够执行 CDR 图像光栅化并为 X 和 Y 维度设置比例因子，此 API 提供对转换过程的精确控制。无论是针对特定输出需求进行缩放，还是将矢量图形转换为光栅格式，您都可以利用此 API 实现高效且可定制的 CDR 矢量到光栅图像转换。
