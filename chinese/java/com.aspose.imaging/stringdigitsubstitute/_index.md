该枚举指定如何根据用户的地区设置或语言在字符串中替换数字。
## 字段

| 字段 | 描述 |
| --- | --- |
| [User](#User) | 指定用户定义的替换方案。 |
| [None](#None) | 指定禁用替换。 |
| [National](#National) | 指定与用户区域设置的官方国家语言对应的替换数字。 |
| [Traditional](#Traditional) | 指定与用户本土文字或语言对应的替换数字，这可能与用户区域设置的官方国家语言不同。 |
