指定输出文件的 PDF 合规级别。有效值为：

 *  \#Pdf15.Pdf15 - The output file will be PDF 1.5 compliant.
 *  \#PdfA1a.PdfA1a - The output file will be PDF/A-1a compliant.
 *  \#PdfA1b.PdfA1b - The output file will be PDF/A-1b compliant.
