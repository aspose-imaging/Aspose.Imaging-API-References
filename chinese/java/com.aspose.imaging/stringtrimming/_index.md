| [EllipsisCharacter](#EllipsisCharacter) | 指定将文本修剪到最近的字符，并在修剪行的末尾插入省略号。 |
| [EllipsisWord](#EllipsisWord) | 指定将文本修剪到最近的单词，并在修剪行的末尾插入省略号。 |
