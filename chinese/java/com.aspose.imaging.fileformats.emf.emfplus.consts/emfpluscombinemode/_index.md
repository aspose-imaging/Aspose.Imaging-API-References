CombineMode 枚举定义了合并两个图形区域的模式。在以下描述中，要合并的区域称为“existing”（现有）和“new”（新）区域。
## 字段

| 字段 | 描述 |
| --- | --- |
| [CombineModeReplace](#CombineModeReplace) | 用新区域替换现有区域。 |
| [CombineModeIntersect](#CombineModeIntersect) | 用现有区域与新区域的交集替换现有区域。 |
| [CombineModeUnion](#CombineModeUnion) | 用现有区域和新区域的并集替换现有区域。 |
| [CombineModeXor](#CombineModeXor) | 用现有区域和新区域的异或（XOR）替换现有区域。 |
| [CombineModeExclude](#CombineModeExclude) | 用不在新区域中的现有区域自身的部分替换现有区域。 |
| [CombineModeComplement](#CombineModeComplement) | 用不在现有区域中的新区域的部分替换现有区域。 |
