LanguageIdentifier 枚举定义了地区中自然语言的标识符，包括国家、地理区域和行政区划。

--------------------

语言标识符由 [EmfPlusLanguageIdentifierType](../../com.aspose.imaging.fileformats.emf.emfplus.consts/emfpluslanguageidentifiertype) 对象指定（第 2.2.2.23 节）。每个值都是主语言标识符和子语言标识符的编码。有关语言标识符的更多信息（包括 Windows 版本支持），请参阅 `[MS-LCID]`。
