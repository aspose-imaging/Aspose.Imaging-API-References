StringAlignment 枚举定义相对于文本布局矩形对齐字符串的方式。
## 字段

| 字段 | 描述 |
| --- | --- |
| [StringAlignmentNear](#StringAlignmentNear) | 指定字符串对齐方向为布局矩形的原点。 |
| [StringAlignmentCenter](#StringAlignmentCenter) | 指定对齐方式在布局矩形的原点和范围之间居中。 |
| [StringAlignmentFar](#StringAlignmentFar) | 指定对齐方式位于布局矩形的右侧。 |
### StringAlignmentNear {#StringAlignmentNear}
```
public static final int StringAlignmentNear
```


指定字符串对齐方向为布局矩形的原点。这可用于沿直线对齐字符或在矩形内对齐文本。对于从右到左的布局矩形，原点SHOULD应位于右上角。

### StringAlignmentCenter {#StringAlignmentCenter}
```
public static final int StringAlignmentCenter
```


指定对齐方式在布局矩形的原点和范围之间居中。

### StringAlignmentFar {#StringAlignmentFar}
```
public static final int StringAlignmentFar
```


指定对齐方式位于布局矩形的右侧。
