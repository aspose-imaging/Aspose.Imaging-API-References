BrushType 枚举定义图形画刷的类型，这些画刷用于填充图形区域。
## 字段

| 字段 | 描述 |
| --- | --- |
| [BrushTypeSolidColor](#BrushTypeSolidColor) | 指定一种实色画刷，其特征是 EmfPlusArgb 值。 |
| [BrushTypeHatchFill](#BrushTypeHatchFill) | 指定一种交叉线画刷，其特征是预定义的图案。 |
| [BrushTypeTextureFill](#BrushTypeTextureFill) | 指定一种纹理画刷，其特征是图像。 |
| [BrushTypePathGradient](#BrushTypePathGradient) | 指定一种路径渐变画刷，其特征是颜色渐变路径渐变画刷数据。 |
| [BrushTypeLinearGradient](#BrushTypeLinearGradient) | 包含线性渐变画刷数据。 |
