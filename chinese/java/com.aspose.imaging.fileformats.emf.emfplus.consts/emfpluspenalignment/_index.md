PenAlignment 枚举定义了笔宽相对于所绘制线的分布方式。

--------------------

图形笔由 [EmfPlusPen](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspen) 对象指定（第 2.2.1.7 节）。笔对齐可以通过考虑在两个指定点之间绘制的理论一维线来可视化。笔对齐决定笔宽在垂直于理论线的方向上的比例。
## 字段

| 字段 | 描述 |
| --- | --- |
| [PenAlignmentCenter](#PenAlignmentCenter) | 指定 EmfPlusPen 对象居中于理论线之上。 |
| [PenAlignmentInset](#PenAlignmentInset) | 指定笔位于理论线的内部。 |
| [PenAlignmentLeft](#PenAlignmentLeft) | 指定笔位于理论线的左侧。 |
| [PenAlignmentOutset](#PenAlignmentOutset) | 指定笔位于理论线的外部。 |
| [PenAlignmentRight](#PenAlignmentRight) | 指定笔位于理论线的右侧。 |
