PaletteStyle 标志指定图形调色板的属性。这些标志可以组合以指定多个选项。

--------------------

图形调色板由 [EmfPlusPalette](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspalette) 对象指定。
## 字段

| 字段 | 描述 |
| --- | --- |
| [PaletteStyleHasAlpha](#PaletteStyleHasAlpha) | 如果设置，则调色板条目中必须包含一个或多个 alpha 透明度信息。 |
| [PaletteStyleGrayScale](#PaletteStyleGrayScale) | 如果设置，则调色板必须仅包含灰度条目。 |
| [PaletteStyleHalftone](#PaletteStyleHalftone) | 如果设置，则调色板必须包含可用于半色调的离散颜色值。 |
