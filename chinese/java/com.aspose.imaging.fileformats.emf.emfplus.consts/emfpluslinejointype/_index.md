LineJoinType 枚举定义了由同一图形笔绘制且端点相接的两条线的连接方式。

--------------------

Graphics 线由 [EmfPlusPen](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfpluspen) 对象（第 2.2.1.7 节）指定。线段连接使两条线端的交叉看起来更连续。
