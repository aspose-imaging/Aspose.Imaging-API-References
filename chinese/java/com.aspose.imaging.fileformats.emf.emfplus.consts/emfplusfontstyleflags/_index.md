FontStyle 标志指定图形字体字形的样式。这些标志可以组合以指定多个选项。

--------------------

Graphics 字体字形由 [EmfPlusFont](../../com.aspose.imaging.fileformats.emf.emfplus.objects/emfplusfont) 对象指定
## 字段

| 字段 | 描述 |
| --- | --- |
| [FontStyleBold](#FontStyleBold) | 如果设置，则必须以更粗的粗细或厚度呈现字体字形。 |
| [FontStyleItalic](#FontStyleItalic) | 如果设置，则必须以相对于基线更大的角度或倾斜度渲染字符的垂直笔画。 |
| [FontStyleUnderline](#FontStyleUnderline) | 如果设置，则必须在字符基线下方绘制一条线来呈现字体字形。 |
| [FontStyleStrikeout](#FontStyleStrikeout) | 如果设置，则必须在字符中部绘制一条与基线平行的线来呈现字体字形。 |
### FontStyleBold {#FontStyleBold}
```
public static final int FontStyleBold
```


如果设置，则必须以更粗的粗细或厚度呈现字体字形。如果未设置，则必须以正常粗细呈现字体字形。

### FontStyleItalic {#FontStyleItalic}
```
public static final int FontStyleItalic
```


如果设置，则必须以相对于基线更大的角度或倾斜度渲染字符的垂直笔画。如果未设置，则必须以正常角度渲染字符的垂直笔画。

### FontStyleUnderline {#FontStyleUnderline}
```
public static final int FontStyleUnderline
```


如果设置，则必须在字符基线下方绘制一条线来呈现字体字形。如果未设置，则必须在基线下方不绘制线条。

### FontStyleStrikeout {#FontStyleStrikeout}
```
public static final int FontStyleStrikeout
```


如果设置，则必须在字符中部绘制一条与基线平行的线来呈现字体字形。如果未设置，则必须不在字符中绘制任何线条。
