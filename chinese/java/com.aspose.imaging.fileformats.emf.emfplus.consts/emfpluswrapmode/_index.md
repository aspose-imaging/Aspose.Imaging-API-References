WrapMode 枚举定义当纹理或渐变画笔的图案小于填充区域时，如何在形状或形状边界上平铺该图案。
## 字段

| 字段 | 描述 |
| --- | --- |
| [WrapModeTile](#WrapModeTile) | 平铺渐变或纹理。 |
| [WrapModeTileFlipX](#WrapModeTileFlipX) | 水平翻转纹理或渐变，然后平铺纹理或渐变。 |
| [WrapModeTileFlipY](#WrapModeTileFlipY) | 垂直翻转纹理或渐变，然后平铺纹理或渐变。 |
| [WrapModeTileFlipXY](#WrapModeTileFlipXY) | 水平和垂直翻转纹理或渐变，然后平铺纹理或渐变。 |
| [WrapModeClamp](#WrapModeClamp) | 将纹理或渐变固定在对象边界上。 |
