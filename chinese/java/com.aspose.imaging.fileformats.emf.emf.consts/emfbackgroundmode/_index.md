BackgroundMode 枚举用于指定文本、带纹理的画刷以及非实线笔样式使用的背景模式。背景模式决定如何将背景与前景文本、带纹理的画刷以及非实线笔样式组合在一起。
## 字段

| 字段 | 描述 |
| --- | --- |
| [TRANSPARENT](#TRANSPARENT) | 透明 - 背景保持不变。 |
| [OPAQUE](#OPAQUE) | 不透明 - 背景在绘制文本、填充刷或笔之前，以当前背景颜色填充。 |
