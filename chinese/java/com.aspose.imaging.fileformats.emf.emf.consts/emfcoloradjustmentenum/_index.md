ColorAdjustment 枚举用于指定在拉伸模式为 HALFTONE 时应如何准备输出图像。
## 字段

| 字段 | 描述 |
| --- | --- |
| [CA_NEGATIVE](#CA-NEGATIVE) | 指定应显示原始图像的负片。 |
| [CA_LOG_FILTER](#CA-LOG-FILTER) | 该说明指定应对输出颜色的最终密度应用对数处理。 |
### CA_NEGATIVE {#CA-NEGATIVE}
```
public static final int CA_NEGATIVE
```


指定应显示原始图像的负片。

### CA_LOG_FILTER {#CA-LOG-FILTER}
```
public static final int CA_LOG_FILTER
```


该说明指定应对输出颜色的最终密度应用对数处理。这将在亮度低时增加颜色对比度。
