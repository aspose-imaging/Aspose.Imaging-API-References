ICMMode 枚举定义了指定何时开启或关闭 ICM 的取值。
## 字段

| 字段 | 描述 |
| --- | --- |
| [ICM_OFF](#ICM-OFF) | 在播放设备上下文中关闭图像颜色管理（ICM）。 |
| [ICM_ON](#ICM-ON) | 在播放设备上下文中打开 ICM。 |
| [ICM_QUERY](#ICM-QUERY) | 查询播放设备上下文中颜色管理的当前状态。 |
| [ICM_DONE_OUTSIDEDC](#ICM-DONE-OUTSIDEDC) | 在播放设备上下文中关闭 ICM，并关闭旧式半色调颜色校正 |
