PolygonFillMode 枚举定义了用于指定如何计算要填充的多边形区域的取值。
## 字段

| 字段 | 描述 |
| --- | --- |
| [ALTERNATE](#ALTERNATE) | 选择交替模式（在每条扫描线上填充奇数边和偶数边之间的区域）。 |
| [WINDING](#WINDING) | 选择环绕模式（填充任何非零环绕值的区域）。 |
### ALTERNATE {#ALTERNATE}

public static final int ALTERNATE
