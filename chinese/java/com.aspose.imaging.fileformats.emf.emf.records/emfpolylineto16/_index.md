EMR\_POLYLINETO16 记录基于当前坐标指定一条或多条直线。使用当前画笔，从当前坐标绘制到 aPoints 字段指定的第一个点。对于每条后续直线，绘制从前一条线的结束点到 aPoints 指定的下一个点。
