该 EMR\_SETWORLDTRANSFORM 记录指定回放设备上下文中当前世界坐标到页面坐标的变换。

有关变换和坐标空间的更多信息，请参阅 [MSDN-WRLDPGSPC]。有关其他变换记录类型的规范，请参见第 2.3.12 节。
