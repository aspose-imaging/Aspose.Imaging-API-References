public final class EmfSetMapMode extends EmfRecord

EMR\_SETMAPMODE 记录指定回放设备上下文的映射模式。映射模式指定用于将页面空间单位转换为设备空间单位的计量单位，并且指定设备的 x 轴和 y 轴的方向。
