EMR\_POLYPOLYGON16 记录指定一系列闭合多边形。每个多边形使用当前笔进行描边，使用当前画刷和多边形填充模式进行填充。该记录绘制的多边形可以重叠。

每个多边形 SHOULD 使用当前笔进行描边，并使用在回放设备上下文中定义的当前画刷和多边形填充模式进行填充。此记录定义的多边形可以重叠。
