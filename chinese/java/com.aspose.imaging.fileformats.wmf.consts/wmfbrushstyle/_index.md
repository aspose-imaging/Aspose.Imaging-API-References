BrushStyle 枚举指定了在图形操作中可使用的不同刷子类型。欲了解更多信息，请参阅 Brush 对象的规范（第 2.2.1.1 节）。
## 字段

| 字段 | 描述 |
| --- | --- |
| [Solid](#Solid) | 一种刷子，可绘制单一、恒定的颜色，可为纯色或抖动色。 |
| [Null](#Null) | 一种不执行任何操作的刷子。 |
| [Hatched](#Hatched) | 一种刷子，在纯色背景上绘制预定义的简单图案或 "hatch"。 |
| [Pattern](#Pattern) | 一种刷子，绘制由位图定义的图案，该位图可能是 Bitmap16 对象或 DeviceIndependentBitmap（DIB）对象。 |
| [Indexed](#Indexed) | 不支持。 |
| [Dibpattern](#Dibpattern) | 由 DIB 指定的图案刷子。 |
| [Dibpatternpt](#Dibpatternpt) | 由 DIB 指定的图案刷子。 |
| [Pattern8X8](#Pattern8X8) | 不支持。 |
| [Dibpattern8X8](#Dibpattern8X8) | 不支持。 |
| [Monopattern](#Monopattern) | 不支持。 |
| [Gradient](#Gradient) | wmf 不支持渐变，odg 中支持。 |
