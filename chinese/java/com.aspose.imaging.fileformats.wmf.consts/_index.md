该软件包包含类型 [MS-WMF]：Windows Metafile Format 2.1 WMF 常量。


## 类

| 类 | 描述 |
| --- | --- |
| [StretchMode](../com.aspose.imaging.fileformats.wmf.consts/stretchmode) | 该 [StretchMode](../com.aspose.imaging.fileformats.wmf.consts/stretchmode) 枚举指定位图拉伸模式，该模式定义系统如何将位图的行或列与现有像素合并。 |
| [WmfBinaryRasterOperation](../com.aspose.imaging.fileformats.wmf.consts/wmfbinaryrasteroperation) | 该 BinaryRasterOperation 枚举部分列出了二进制光栅操作代码。 |
| [WmfBrushStyle](../com.aspose.imaging.fileformats.wmf.consts/wmfbrushstyle) | 该 BrushStyle 枚举指定可在图形操作中使用的不同可能的画笔类型。 |
| [WmfCharacterSet](../com.aspose.imaging.fileformats.wmf.consts/wmfcharacterset) | 该 CharacterSet 枚举定义了在字体中为图形输出定义的字符字形的可能集合。 |
| [WmfClipPrecisionFlags](../com.aspose.imaging.fileformats.wmf.consts/wmfclipprecisionflags) | ClipPrecision 标志指定剪裁精度，该精度定义如何剪裁部分位于剪裁区域外的字符。 |
| [WmfColorUsageEnum](../com.aspose.imaging.fileformats.wmf.consts/wmfcolorusageenum) | 该 ColorUsage 枚举指定设备无关位图（DIB）中是否存在颜色表以及如何解释其值。 |
| [WmfCompression](../com.aspose.imaging.fileformats.wmf.consts/wmfcompression) | 该 Compression 枚举指定位图图像的压缩类型 |
| [WmfFamilyFont](../com.aspose.imaging.fileformats.wmf.consts/wmffamilyfont) | 该 FamilyFont 枚举指定字体族。 |
| [WmfFloodFillMode](../com.aspose.imaging.fileformats.wmf.consts/wmffloodfillmode) | 该 FloodFill 枚举指定要执行的填充操作类型。 |
| [WmfFontQuality](../com.aspose.imaging.fileformats.wmf.consts/wmffontquality) | 该 FontQuality 枚举指定在渲染文本时，逻辑字体的属性应与物理字体的属性匹配的程度。 |
| [WmfGamutMappingIntent](../com.aspose.imaging.fileformats.wmf.consts/wmfgamutmappingintent) | 该 GamutMappingIntent 枚举指定逻辑颜色与物理颜色之间的关系。 |
| [WmfHatchStyle](../com.aspose.imaging.fileformats.wmf.consts/wmfhatchstyle) | 该 HatchStyle 枚举指定填充图案。 |
| [WmfLogicalColorSpaceEnum](../com.aspose.imaging.fileformats.wmf.consts/wmflogicalcolorspaceenum) | 该 LogicalColorSpace 枚举指定颜色空间的类型。 |
| [WmfMapMode](../com.aspose.imaging.fileformats.wmf.consts/wmfmapmode) | 映射模式 |
| [WmfMetafileEscapes](../com.aspose.imaging.fileformats.wmf.consts/wmfmetafileescapes) | MetafileEscapes 枚举指定可能无法通过 RecordType 枚举（第 2.1.1.1 节）中定义的 WMF 记录直接访问的打印机驱动程序功能。 |
| [WmfMetafileVersion](../com.aspose.imaging.fileformats.wmf.consts/wmfmetafileversion) | MetafileVersion 枚举定义指定在元文件中对设备无关位图（DIB）支持的值。 |
| [WmfMixMode](../com.aspose.imaging.fileformats.wmf.consts/wmfmixmode) | MixMode 枚举指定文本、交叉刷和其他非实心笔样式的背景混合模式。 |
| [WmfOutPrecision](../com.aspose.imaging.fileformats.wmf.consts/wmfoutprecision) | OutPrecision 枚举定义输出精度的值，这是字体映射器匹配特定字体参数（包括高度、宽度、字符方向、倾斜角度、字距和字体类型）的要求。 |
| [WmfPenStyle](../com.aspose.imaging.fileformats.wmf.consts/wmfpenstyle) | 16 位 PenStyle 枚举用于指定可在图形操作中使用的不同笔类型。 |
| [WmfPitchFont](../com.aspose.imaging.fileformats.wmf.consts/wmfpitchfont) | PitchFont 枚举定义用于指定字体特性的值。 |
| [WmfPolyFillMode](../com.aspose.imaging.fileformats.wmf.consts/wmfpolyfillmode) | PolyFillMode 枚举指定用于填充多边形的方法。 |
| [WmfPostScriptCap](../com.aspose.imaging.fileformats.wmf.consts/wmfpostscriptcap) | PostScriptCap 枚举定义用于 PostScript 打印机驱动程序的线端类型。 |
| [WmfPostScriptClipping](../com.aspose.imaging.fileformats.wmf.consts/wmfpostscriptclipping) | PostScriptClipping 枚举定义可应用于 PostScript 输出使用的裁剪路径的函数。 |
| [WmfRecordType](../com.aspose.imaging.fileformats.wmf.consts/wmfrecordtype) | wmf 记录类型 |
| [WmfTernaryRasterOperation](../com.aspose.imaging.fileformats.wmf.consts/wmfternaryrasteroperation) | 枚举指定三元光栅操作码，这些码定义了如何将源位图中的位与目标位图中的位组合。 |
| [WmfTernaryRasterOperationOperand](../com.aspose.imaging.fileformats.wmf.consts/wmfternaryrasteroperationoperand) | 每个三元光栅操作码表示一种布尔运算，其中源像素、选定刷子和目标像素的值被组合。 |
| [WmfTextAlignmentModeFlags](../com.aspose.imaging.fileformats.wmf.consts/wmftextalignmentmodeflags) | TextAlignmentMode 标志指定参考点与边界矩形之间的关系，用于文本对齐。 |
| [WmfVerticalTextAlignmentModeFlags](../com.aspose.imaging.fileformats.wmf.consts/wmfverticaltextalignmentmodeflags) | VerticalTextAlignmentMode 标志指定参考点与边界矩形之间的关系，用于文本对齐。 |
