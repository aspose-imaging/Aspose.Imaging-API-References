VerticalTextAlignmentMode 标志指定参考点与用于文本对齐的边界矩形之间的关系。这些标志可以组合以指定多个选项，但限制只能选择一个会改变回放设备上下文中绘制位置的标志。当字体具有垂直默认基线（如汉字）时，会执行垂直文本对齐。
## 字段

| 字段 | 描述 |
| --- | --- |
| [VTA_TOP](#VTA-TOP) | 参考点必须位于边界矩形的顶部边缘。 |
| [VTA_RIGHT](#VTA-RIGHT) | 参考点必须位于边界矩形的右侧边缘。 |
| [VTA_BOTTOM](#VTA-BOTTOM) | 参考点必须位于边界矩形的底部边缘。 |
| [VTA_CENTER](#VTA-CENTER) | 参考点必须在垂直方向上与边界矩形的中心对齐。 |
| [VTA_LEFT](#VTA-LEFT) | 参考点必须位于边界矩形的左侧边缘。 |
| [VTA_BASELINE](#VTA-BASELINE) | 参考点必须位于文本的基线位置。 |
