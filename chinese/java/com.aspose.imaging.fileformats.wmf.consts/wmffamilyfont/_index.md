FamilyFont 枚举指定字体族。字体族以一般方式描述字体的外观。当所需的确切字体不可用时，它们用于指定字体。
## 字段

| 字段 | 描述 |
| --- | --- |
| [Dontcare](#Dontcare) | 默认字体已指定，取决于实现。 |
| [Roman](#Roman) | 具有可变笔画宽度的字体，其宽度与字形的实际宽度成比例，并且带有衬线。 |
| [Swiss](#Swiss) | 具有可变笔画宽度的字体，其宽度与字形的实际宽度成比例，但不带衬线。 |
| [Modern](#Modern) | 笔画宽度固定的字体，可带衬线也可不带衬线。 |
| [Script](#Script) | 设计成手写体外观的字体。 |
| [Decorative](#Decorative) | 新奇字体。 |
### Dontcare {#Dontcare}
```
public static final byte Dontcare
```


默认字体已指定，取决于实现。

### Roman {#Roman}
```
public static final byte Roman
```


具有可变笔画宽度的字体，其宽度与字形的实际宽度成比例，并且带有衬线。"MS Serif"是一个例子。

### Swiss {#Swiss}
```
public static final byte Swiss
```


字体具有可变笔画宽度，宽度与字形的实际宽度成比例，并且没有衬线。"MS Sans Serif" 是一个例子。

### Modern {#Modern}
```
public static final byte Modern
```


字体具有固定笔画宽度，可能有衬线也可能没有。等宽字体通常是现代的。"Pica"、"Elite" 和 "Courier New" 是例子。

### Script {#Script}
```
public static final byte Script
```


字体设计成手写体的外观。"Script" 和 "Cursive" 是例子。

### Decorative {#Decorative}
```
public static final byte Decorative
```


新奇字体。"Old English" 是一个例子。
