## EmfIcmMode enumeration

该 ICMMode 枚举定义了指定何时开启和关闭 ICM 的取值。

```csharp
public enum EmfIcmMode
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| ICM_OFF | `1` | 在回放设备上下文中关闭图像颜色管理 (ICM)。打开旧式半色调颜色校正。 |
| ICM_ON | `2` | 在回放设备上下文中打开 ICM。关闭旧式半色调颜色校正。 |
| ICM_QUERY | `3` | 查询回放设备上下文中颜色管理的当前状态。 |
| ICM_DONE_OUTSIDEDC | `4` | 在回放设备上下文中关闭 ICM，并关闭旧式半色调颜色校正。 |
