该命名空间包含类型 [MS-EMF]：增强型图元文件格式。2.1 EMF 枚举

## 枚举

| 枚举 | 描述 |
| --- | --- |
| [EmfArcDirection](./emfarcdirection/) | ArcDirection 枚举用于设置弧线和矩形输出的绘制方向。 |
| [EmfArmStyle](./emfarmstyle/) | ArmStyle 枚举定义了 PANOSE 系统中用于分类字体的特征之一的取值。 |
| [EmfBackgroundMode](./emfbackgroundmode/) | BackgroundMode 枚举用于指定文本、交叉线画刷以及非实线笔样式使用的背景模式。背景模式决定如何将背景与前景文本、交叉线画刷以及非实线笔样式组合。 |
| [EmfColorAdjustmentEnum](./emfcoloradjustmentenum/) | ColorAdjustment 枚举用于指定在拉伸模式为 HALFTONE 时应如何准备输出图像。 |
| [EmfColorMatchToTarget](./emfcolormatchtotarget/) | ColorMatchToTarget 枚举用于确定是否已在元文件中嵌入颜色配置文件。 |
| [EmfColorSpace](./emfcolorspace/) | ColorSpace 枚举用于指定何时开启或关闭颜色校样，以及何时删除变换。 |
| [EmfContrast](./emfcontrast/) | Contrast 枚举定义了 PANOSE 系统中用于分类字体的特征之一的取值。 |
| [EmfDibColors](./emfdibcolors/) | 该 DIBColors 枚举定义了如何解释 DIB 的颜色表中的值。 |
| [EmfEmrComment](./emfemrcomment/) | 该 EmrComment 枚举定义了公共注释记录可以包含的数据类型，详见第 2.3.3.4 节。 |
| [EmfExtTextOutOptions](./emfexttextoutoptions/) | 该 ExtTextOutOptions 枚举指定了控制 EMR_SMALLTEXTOUT（第 2.3.5.37 节）记录和 EmrText 对象中文本输出各方面的参数。 |
| [EmfFamilyType](./emffamilytype/) | 该 FamilyType 枚举为 PANOSE 系统中用于分类字体的特征之一定义了取值。 |
| [EmfFloodFill](./emffloodfill/) | 该 FloodFill 枚举定义了用于确定洪水填充操作区域的取值。 |
| [EmfFormatSignature](./emfformatsignature/) | 该 FormatSignature 枚举定义了用于识别 EMF 记录中嵌入数据格式的取值。 |
| [EmfGradientFill](./emfgradientfill/) | 该 GradientFill 枚举定义了渐变填充操作的模式。 |
| [EmfGraphicsMode](./emfgraphicsmode/) | 该 GraphicsMode 枚举用于指定如何解释形状数据，例如矩形坐标。 |
| [EmfHatchStyle](./emfhatchstyle/) | 该 HatchStyle 枚举是对 WMF HatchStyle 枚举的扩展（[MS-WMF] 第 2.1.1.12 节）。 |
| [EmfIcmMode](./emficmmode/) | 该 ICMMode 枚举定义了指定何时开启和关闭 ICM 的取值。 |
| [EmfIlluminant](./emfilluminant/) | 该 Illuminant 枚举定义了图像的光源值，该值决定了观看图像时的标准光源，以便相应地调整颜色。 |
| [EmfLetterform](./emfletterform/) | 该 Letterform 枚举为 PANOSE 系统中用于分类字体的特征之一定义了取值。 |
| [EmfLogFontWeight](./emflogfontweight/) | 该 [`EmfLogFont`](../aspose.imaging.fileformats.emf.emf.objects/emflogfont/) 权重。 |
| [EmfMapMode](./emfmapmode/) | 该 MapMode 枚举用于定义将页面空间单位转换为设备空间单位的度量单位，并定义绘图轴的方向。 |
| [EmfMetafileVersion](./emfmetafileversion/) | 该 MetafileVersion 枚举定义了 EMF 元文件的互操作版本。 |
| [EmfMidLine](./emfmidline/) | 该 MidLine 枚举为 PANOSE 系统中用于分类字体的特征之一定义了取值。 |
| [EmfModifyWorldTransformMode](./emfmodifyworldtransformmode/) | 该 ModifyWorldTransformMode 枚举定义了使用指定的变换数据来修改当前在回放设备上下文中定义的世界空间到页面空间变换的模式。 |
| [EmfPenStyle](./emfpenstyle/) | 该 PenStyle 枚举定义了可用于图形操作的笔的属性。笔样式是笔类型、线型、线帽和线接的组合。 |
| [EmfPointEnum](./emfpointenum/) | 该 Point 枚举用于指定在绘图调用中如何使用点。 |
| [EmfPolygonFillMode](./emfpolygonfillmode/) | 该 PolygonFillMode 枚举定义了指定如何计算要填充的多边形区域的取值。 |
| [EmfProportion](./emfproportion/) | 该 Proportion 枚举为 PANOSE 系统中用于分类字体的特征之一定义了取值。 |
| [EmfRecordType](./emfrecordtype/) | 该 RecordType 枚举定义了唯一标识 EMF 记录的取值。这些取值在每个记录的 Type 字段中提供。 |
| [EmfRegionMode](./emfregionmode/) | 该 RegionMode 枚举定义了与 EMR_SELECTCLIPPATH 和 EMR_EXTSELECTCLIPRGN 一起使用的取值，用于指定当前路径或与当前剪裁区域合并的新区域。 |
| [EmfSerifStyle](./emfserifstyle/) | 该 SerifType 枚举为 PANOSE 系统中用于分类字体的特征之一定义了取值。 |
| [EmfSerifType](./emfseriftype/) | 该 SerifType 枚举为 PANOSE 系统中用于分类字体的特征之一定义了取值。 |
| [EmfStockObject](./emfstockobject/) | StockObject 枚举指定了可在图形操作中使用的预定义逻辑图形对象的索引。StockObject 的具体结构取决于实现；然而，StockObject 的属性应等同于同类型显式创建对象的属性。对于此枚举中定义的 StockObject，尽可能指定了这些属性。 |
| [EmfStretchMode](./emfstretchmode/) | StretchMode 枚举用于指定在拉伸或压缩位图时，如何添加或移除颜色数据。 |
| [EmfStrokeVariation](./emfstrokevariation/) | StrokeVariation 枚举定义了 PANOSE 系统中用于分类字体的特征之一的取值。 |
| [EmfWeight](./emfweight/) | Weight 枚举定义了 PANOSE 系统中用于分类字体的特征之一的取值。 |
| [EmfXHeight](./emfxheight/) | XHeight 枚举定义了 PANOSE 系统中用于分类字体的特征之一的取值。 |
