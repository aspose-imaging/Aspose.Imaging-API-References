该命名空间处理 WebP 文件格式。

## 类

| 类 | 描述 |
| --- | --- |
| [WebPFrameBlock](./webpframeblock/) | 表示 WebP 块打开器注册表。 |
| [WebPImage](./webpimage/) | 使用我们的 API 操作 WebP 栅格图像，利用其现代特性实现无损和有损压缩，确保在减小文件尺寸的同时获得最佳图像质量。无缝处理扩展文件格式、动画和 Alpha 通道，同时轻松更新尺寸、等比例缩放、裁剪、旋转、应用滤镜、调整图像参数，并转换为其他图像格式，以实现多功能的网页图像优化。 |
