## PngFilterType enumeration

png 滤镜类型。

```csharp
public enum PngFilterType
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| None | `0` | null-filter，表示对图像数据行不进行过滤。 |
| Sub | `1` | sub filter，表示将对图像数据应用减法过滤。 |
| Up | `2` | up filter，表示将应用逐行减法过滤。 |
| Avg | `3` | avg filter，表示将对图像数据应用平均过滤。 |
| Paeth | `4` | paeth 预测过滤器。 |
| Adaptive | `5` | 自适应过滤，表示保存过程将为每个数据行选择最合适的过滤器。压缩率最高，执行时间最慢。 |
