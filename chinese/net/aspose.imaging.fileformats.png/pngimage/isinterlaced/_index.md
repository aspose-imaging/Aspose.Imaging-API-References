## PngImage.IsInterlaced property

返回一个布尔值，指示图像实例是否为隔行扫描。此属性对优化加载策略并确保图像处理或显示任务期间的高效性能至关重要。

```csharp
public bool IsInterlaced { get; }
```

### Property Value

`true` 表示此图像实例为交错；否则为 `false`。
