## PngImage.Interlaced property

检索一个布尔值，指示 [`PngImage`](../) 是否为隔行扫描，这决定图像数据是否以渐进方式存储以实现更快的加载或传输。

```csharp
public bool Interlaced { get; }
```

### Property Value

`true` 如果是隔行扫描；否则为 `false`。
