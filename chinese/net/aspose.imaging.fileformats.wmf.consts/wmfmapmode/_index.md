## WmfMapMode enumeration

映射模式

```csharp
public enum WmfMapMode : short
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Text | `1` | 文本：每个逻辑单位映射为一个设备像素。正向 x 向右；正向 y 向下。 |
| Lometric | `2` | 洛米制：每个逻辑单位映射为 0.1 毫米。正向 x 向右；正向 y 向上。 |
| Himetric | `3` | 海米制：每个逻辑单位映射为 0.01 毫米。正向 x 向右；正向 y 向上。 |
| Loenglish | `4` | 低英制：每个逻辑单位映射为 0.01 英寸。正向 x 向右；正向 y 向上。 |
| Hienglish | `5` | 高英制：每个逻辑单位映射为 0.001 英寸。正向 x 向右；正向 y 向上。 |
| Twips | `6` | twip：每个逻辑单位映射为一点的二十分之一（1/20）。在印刷中，一点等于 1/72 英寸；因此，1/20 点等于 1/1440 英寸。此单位也称为 "twip"。 |
| Isotropic | `7` | 等向性：逻辑单位映射到任意设备单位，且轴的比例相等；即 x 轴上的一个单位等于 y 轴上的一个单位。META_SETWINDOWEXT 和 META_SETVIEWPORTEXT 记录指定单位和轴的方向。 |
| Anisotropic | `8` | 各向异性：逻辑单位映射到任意单位，轴的比例任意缩放。 |
