## WmfVerticalTextAlignmentModeFlags enumeration

VerticalTextAlignmentMode 标志指定参考点与边界矩形之间的关系，用于文本对齐。这些标志可以组合以指定多个选项，但限制只能选择一个会更改回放设备上下文中绘制位置的标志。当字体具有垂直默认基线（例如汉字）时，执行垂直文本对齐。

```csharp
public enum WmfVerticalTextAlignmentModeFlags
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| VTA_TOP | `0` | 参考点必须位于边界矩形的顶部边缘。 |
| VTA_RIGHT | `0` | 参考点必须位于边界矩形的右侧边缘。 |
| VTA_BOTTOM | `2` | 参考点必须位于边界矩形的底部边缘。 |
| VTA_CENTER | `6` | 参考点必须在垂直方向上与边界矩形的中心对齐。 |
| VTA_LEFT | `8` | 参考点必须位于边界矩形的左侧边缘。 |
| VTA_BASELINE | `24` | 参考点必须位于文本的基线位置。 |
