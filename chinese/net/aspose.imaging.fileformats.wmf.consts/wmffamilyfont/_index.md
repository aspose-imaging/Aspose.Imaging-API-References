## WmfFamilyFont enumeration

此 FamilyFont 枚举指定字体族。字体族以通用方式描述字体的外观。当所需的精确字体不可用时，旨在用于指定字体。

```csharp
public enum WmfFamilyFont : byte
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Dontcare | `0` | 默认字体已指定，取决于实现。 |
| Roman | `1` | 字体具有可变笔画宽度，宽度与字形的实际宽度成比例，并且带有衬线。"MS Serif" 是一个例子。 |
| Swiss | `2` | 字体具有可变笔画宽度，宽度与字形的实际宽度成比例，但不带衬线。"MS Sans Serif" 是一个例子。 |
| Modern | `3` | 字体具有固定笔画宽度，可带或不带衬线。等宽字体通常是现代的。"Pica"、"Elite" 和 "Courier New" 是例子。 |
| Script | `4` | 字体设计成手写体外观。"Script" 和 "Cursive" 是例子。 |
| Decorative | `5` | 新颖字体。"Old English" 是一个例子。 |
