该命名空间包含类型 [MS-WMF]：Windows Metafile Format 2.1 WMF 常量

## 枚举

| 枚举 | 描述 |
| --- | --- |
| [StretchMode](./stretchmode/) | 此 [`StretchMode`](../aspose.imaging.fileformats.wmf.consts/stretchmode/) 枚举指定位图拉伸模式，该模式定义系统如何将位图的行或列与现有像素合并。 |
| [WmfBinaryRasterOperation](./wmfbinaryrasteroperation/) | 此 BinaryRasterOperation 枚举部分列出了二进制光栅操作代码。光栅操作代码定义元文件处理如何将选定笔的位与目标位图中的位合并。 |
| [WmfBrushStyle](./wmfbrushstyle/) | 此 BrushStyle 枚举指定可在图形操作中使用的不同可能的画刷类型。欲了解更多信息，请参阅画刷对象的规范（第 2.2.1.1 节）。 |
| [WmfCharacterSet](./wmfcharacterset/) | 此 CharacterSet 枚举定义了在字体中为图形输出定义的字符字形的可能集合。 |
| [WmfClipPrecisionFlags](./wmfclipprecisionflags/) | ClipPrecision 标志指定剪裁精度，该精度定义如何剪裁部分位于剪裁区域外的字符。这些标志可以组合以指定多个选项。 |
| [WmfColorUsageEnum](./wmfcolorusageenum/) | 此 ColorUsage 枚举指定设备无关位图（DIB）中是否存在颜色表以及如何解释其值。 |
| [WmfCompression](./wmfcompression/) | 此 Compression 枚举指定位图图像的压缩类型 |
| [WmfFamilyFont](./wmffamilyfont/) | 此 FamilyFont 枚举指定字体族。字体族以通用方式描述字体的外观。当所需的精确字体不可用时，旨在用于指定字体。 |
| [WmfFloodFillMode](./wmffloodfillmode/) | 此 FloodFill 枚举指定要执行的填充操作类型。 |
| [WmfFontQuality](./wmffontquality/) | 此 FontQuality 枚举指定在渲染文本时，逻辑字体的属性应与物理字体的属性匹配的程度。 |
| [WmfGamutMappingIntent](./wmfgamutmappingintent/) | 此 GamutMappingIntent 枚举指定逻辑颜色与物理颜色之间的关系。 |
| [WmfHatchStyle](./wmfhatchstyle/) | 此 HatchStyle 枚举指定交叉线图案。 |
| [WmfLogicalColorSpaceEnum](./wmflogicalcolorspaceenum/) | 此 LogicalColorSpace 枚举指定颜色空间的类型。 |
| [WmfMapMode](./wmfmapmode/) | 映射模式 |
| [WmfMetafileEscapes](./wmfmetafileescapes/) | 此 MetafileEscapes 枚举指定可能无法通过 RecordType 枚举（第 2.1.1.1 节）中定义的 WMF 记录直接访问的打印机驱动程序功能。 |
| [WmfMetafileVersion](./wmfmetafileversion/) | 此 MetafileVersion 枚举定义了指定元文件中对设备无关位图（DIB）支持的值。 |
| [WmfMixMode](./wmfmixmode/) | 此 MixMode 枚举指定文本、交叉线画刷和其他非实心笔样式的背景混合模式。 |
| [WmfOutPrecision](./wmfoutprecision/) | 此 OutPrecision 枚举定义了输出精度的值，即字体映射器匹配特定字体参数（包括高度、宽度、字符方向、倾斜、字距和字体类型）的要求。 |
| [WmfPenStyle](./wmfpenstyle/) | 此 16 位 PenStyle 枚举用于指定可在图形操作中使用的不同类型的笔。 |
| [WmfPitchFont](./wmfpitchfont/) | 此 PitchFont 枚举定义了用于指定字体特性的值。这些值用于指示字体中的字符是固定宽度、可变宽度还是字距。 |
| [WmfPolyFillMode](./wmfpolyfillmode/) | 此 PolyFillMode 枚举指定用于填充多边形的方法。 |
| [WmfPostScriptCap](./wmfpostscriptcap/) | 此 PostScriptCap 枚举定义了用于 PostScript 打印机驱动程序的线端类型。 |
| [WmfPostScriptClipping](./wmfpostscriptclipping/) | 此 PostScriptClipping 枚举定义了可应用于 PostScript 输出所使用的剪裁路径的功能。 |
| [WmfRecordType](./wmfrecordtype/) | wmf 记录类型 |
| [WmfTernaryRasterOperation](./wmfternaryrasteroperation/) | 枚举指定三元光栅操作码，这些码定义了如何将源位图中的位与目标位图中的位组合。 |
| [WmfTernaryRasterOperationOperand](./wmfternaryrasteroperationoperand/) | 每个三元光栅操作码表示一种布尔运算，其中源像素、所选画刷和目标像素的值被组合。以下是这些运算中使用的三个操作数。 |
| [WmfTextAlignmentModeFlags](./wmftextalignmentmodeflags/) | TextAlignmentMode 标志指定参考点与边界矩形之间的关系，用于文本对齐。这些标志可以组合以指定多个选项，但限制只能选择一个会更改回放设备上下文中绘制位置的标志。当字体具有水平默认基线时，执行水平文本对齐。 |
| [WmfVerticalTextAlignmentModeFlags](./wmfverticaltextalignmentmodeflags/) | VerticalTextAlignmentMode 标志指定参考点与边界矩形之间的关系，用于文本对齐。这些标志可以组合以指定多个选项，但限制只能选择一个会更改回放设备上下文中绘制位置的标志。当字体具有垂直默认基线（例如汉字）时，执行垂直文本对齐。 |
