## WmfPenStyle enumeration

此 16 位 PenStyle 枚举用于指定可在图形操作中使用的不同类型的笔。

```csharp
public enum WmfPenStyle : short
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Cosmetic | `0` | 化妆笔 |
| EndcapRound | `0` | 线段端帽为圆形。 |
| JoinRound | `0` | 线段连接为圆形。 |
| Solid | `0` | 笔为实线。 |
| Dash | `1` | 笔是虚线的。 |
| Dot | `2` | 笔是点线的。 |
| Dashdot | `3` | 笔交替使用短划线和点。 |
| Dashdotdot | `4` | 笔有短划线和双点。 |
| Null | `5` | 笔是不可见的。 |
| Insideframe | `6` | 笔是实线的。当此笔在任何接受边界矩形的绘图记录中使用时，图形的尺寸会被缩小，以便完全适应边界矩形，并考虑笔的宽度。 |
| Userstyle | `7` | 笔使用用户提供的样式数组。 |
| Alternate | `8` | 笔设置每隔一个像素（此样式仅适用于装饰性笔）。 |
| EndcapSquare | `256` | 线端帽是方形的。 |
| EndcapFlat | `512` | 线端帽是平的。 |
| JoinBevel | `4096` | 线段连接是斜角的。 |
| JoinMiter | `8192` | 当线段连接在 SETMITERLIMIT META_ESCAPE 记录设置的当前限制范围内时，连接为斜接。若超出该限制，连接则为斜角。 |
