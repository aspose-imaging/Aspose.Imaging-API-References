## WmfBrushStyle enumeration

此 BrushStyle 枚举指定可在图形操作中使用的不同可能的画刷类型。欲了解更多信息，请参阅画刷对象的规范（第 2.2.1.1 节）。

```csharp
public enum WmfBrushStyle
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Solid | `0` | 一种绘制单一、固定颜色的画刷，可以是实色或抖动的。 |
| Null | `1` | 一种不执行任何操作的画刷。在图形操作中使用 NULL 画刷必须产生与根本不使用画刷相同的效果。 |
| Hatched | `2` | 一种在实色背景上绘制预定义的简单图案（或称为“网格”）的画刷。 |
| Pattern | `3` | 一种使用位图定义的图案进行绘制的画刷，该位图可以是 Bitmap16 对象或设备无关位图（DIB）对象。 |
| Indexed | `4` | 不支持。 |
| Dibpattern | `5` | 由 DIB 指定的图案画刷。 |
| Dibpatternpt | `6` | 由 DIB 指定的图案画刷。 |
| Pattern8X8 | `7` | 不支持。 |
| Dibpattern8X8 | `8` | 不支持。 |
| Monopattern | `9` | 不支持。 |
| Gradient | `10` | 在 wmf 中不支持渐变，odg 中支持。 |
