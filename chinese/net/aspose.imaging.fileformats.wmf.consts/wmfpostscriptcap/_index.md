## WmfPostScriptCap enumeration

此 PostScriptCap 枚举定义了用于 PostScript 打印机驱动程序的线端类型。

```csharp
public enum WmfPostScriptCap
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| PostScriptNotSet | `-2` | 指定未设置换行样式，并且可能使用默认样式 [24]。 |
| PostScriptFlatCap | `0` | 指定线在最后一点结束。端点为方形。 |
| PostScriptRoundCap | `1` | 指定圆形端帽。圆心是线的最后一点。圆的直径与线宽相同，即线的粗细。 |
| PostScriptSquareCap | `2` | 指定方形端帽。方形的中心是线的最后一点。方形的高宽与线宽相同，即线的粗细。 |
