## ImageMetadata.TrySetMetadata method

如果此 [`Image`](../../../aspose.imaging/image/) 实例支持并实现 [`IImageMetadataFormat`](../../iimagemetadataformat/) 实例，则尝试设置 *metadata* 实例。

```csharp
public bool TrySetMetadata(IImageMetadataFormat metadata)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 元数据 | IImageMetadataFormat | 元数据。 |

### 返回值

*metadata* 不为 null 且 [`IMetadataContainer`](../../../aspose.imaging/imetadatacontainer/) 实例支持和/或实现 [`IImageMetadataFormat`](../../iimagemetadataformat/) 实例时为 True；否则为 false。
