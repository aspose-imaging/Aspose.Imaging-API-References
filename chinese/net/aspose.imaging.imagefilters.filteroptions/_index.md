该命名空间处理过滤器选项。

## 类

| 类 | 描述 |
| --- | --- |
| [AdaptiveWhiteStretchFilterOptions](./adaptivewhitestretchfilteroptions/) | 提供配置自适应白色拉伸滤镜的选项。允许自定义直方图拉伸参数，以提升白色水平并改善淡文字或低对比度文档图像的可读性。 |
| [AutoWhiteBalanceFilterOptions](./autowhitebalancefilteroptions/) | 提供自动白平衡滤镜的配置选项。允许调节对比度拉伸参数和通道缩放，以提升数字图像的外观。 |
| [BigRectangularFilterOptions](./bigrectangularfilteroptions/) | 大矩形滤镜选项 |
| [BilateralSmoothingFilterOptions](./bilateralsmoothingfilteroptions/) | 双边平滑滤镜选项。 |
| [ClaheFilterOptions](./clahefilteroptions/) | 提供配置对比度受限自适应直方图均衡（CLAHE）滤镜的选项。 |
| [ConvolutionFilterOptions](./convolutionfilteroptions/) | 卷积滤镜选项。 |
| [DeconvolutionFilterOptions](./deconvolutionfilteroptions/) | 去卷积滤镜选项，抽象类 |
| [FilterOptionsBase](./filteroptionsbase/) | 基础滤镜选项类。 |
| [GaussianBlurFilterOptions](./gaussianblurfilteroptions/) | 高斯模糊滤镜选项。 |
| [GaussianDeconvolutionFilterOptions](./gaussiandeconvolutionfilteroptions/) | 使用高斯模糊的去卷积滤镜选项。 |
| [GaussWienerFilterOptions](./gausswienerfilteroptions/) | 用于图像去模糊的高斯维纳滤镜选项。 |
| [ImageBlendingFilterOptions](./imageblendingfilteroptions/) | 图像混合滤镜选项 |
| [MedianFilterOptions](./medianfilteroptions/) | 中值滤镜 |
| [MotionWienerFilterOptions](./motionwienerfilteroptions/) | 运动去模糊滤镜选项。 |
| [ShadowFilterOptions](./shadowfilteroptions/) | 阴影滤镜选项 |
| [SharpenFilterOptions](./sharpenfilteroptions/) | 锐化滤镜选项。 |
| [SmallRectangularFilterOptions](./smallrectangularfilteroptions/) | 小矩形滤镜选项 |
