## IcoImage.HasAlpha property

使用此属性确定此实例是否存在 alpha 通道。它提供了一种快速检查图像或文档是否包含 alpha 通道的方法，这对各种图像处理和渲染任务至关重要。非常适合确保兼容性并处理图像或文档中的透明效果。

```csharp
public override bool HasAlpha { get; }
```

### Property Value

`true` 如果此实例具有 alpha；否则为 `false`。
