该命名空间包含由形状段组合而成的不同形状。

## 类

| 类 | 描述 |
| --- | --- |
| [ArcShape](./arcshape/) | 表示弧形。 |
| [BezierShape](./beziershape/) | 表示贝塞尔样条。 |
| [CurveShape](./curveshape/) | 表示曲线样条形状。 |
| [EllipseShape](./ellipseshape/) | 表示椭圆形。 |
| [PieShape](./pieshape/) | 表示饼形。 |
| [PolygonShape](./polygonshape/) | 表示多边形形状。 |
| [RectangleProjectedShape](./rectangleprojectedshape/) | 表示一种形状，该形状投影到矩形上并旋转到特定方向。由四个点指定，这些点可以在空间中旋转，保持相同的边长且相邻边之间为90度。 |
| [RectangleShape](./rectangleshape/) | 表示矩形形状。 |
| [TextShape](./textshape/) | 表示文本形状。 |
