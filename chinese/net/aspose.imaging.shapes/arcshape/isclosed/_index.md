## ArcShape.IsClosed property

获取或设置指示有序形状是否闭合的值。处理闭合有序形状时，起始点和结束点没有意义。

```csharp
public bool IsClosed { get; set; }
```

### Property Value

如果此有序形状闭合，则为 `True`；否则为 `false`。
