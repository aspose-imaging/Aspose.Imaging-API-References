## JpegImage.Width property

此属性检索图像的宽度，单位为像素。它提供有关图像尺寸的关键信息，使得图像数据的准确渲染、操作或显示成为可能。

```csharp
public override int Width { get; }
```

### Property Value

图像宽度。
