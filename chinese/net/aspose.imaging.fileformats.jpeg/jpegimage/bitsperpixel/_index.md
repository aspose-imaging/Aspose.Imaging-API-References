## JpegImage.BitsPerPixel property

使用此属性轻松获取图像的像素深度，提供对颜色或灰度表现丰富度的洞察。无论是鲜艳的照片还是单色插图，此属性都提供了关于图像视觉复杂性的关键信息。

```csharp
public override int BitsPerPixel { get; }
```

### Property Value

图像每像素位数。
