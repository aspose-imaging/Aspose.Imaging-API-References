## JpegImage.Jfif property

此属性允许您访问或修改与 JPEG 图像关联的 JFIF（JPEG 文件交换格式）数据。JFIF 是在计算机和其他设备之间交换 JPEG 压缩图像的标准格式。通过获取或设置此属性，您可以与 JFIF 数据交互，其中可能包括图像的分辨率、宽高比和缩略图等信息。

```csharp
public JFIFData Jfif { get; set; }
```
