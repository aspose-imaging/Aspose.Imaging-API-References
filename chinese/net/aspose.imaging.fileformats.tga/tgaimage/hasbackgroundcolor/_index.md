## TgaImage.HasBackgroundColor property

获取或设置一个值，指示图像是否包含背景颜色。此属性用于确定图像是否具有与前景内容分离的明确背景颜色。它使您能够根据是否存在背景颜色来自定义图像处理或渲染。

```csharp
public override bool HasBackgroundColor { get; set; }
```
