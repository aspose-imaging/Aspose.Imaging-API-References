该命名空间处理 Tga 文件格式。

## 类

| 类 | 描述 |
| --- | --- |
| [TgaImage](./tgaimage/) | 使用我们的 API 操作 TGA 栅格图像文件，该 API 针对 TARGA（Truevision Advanced Raster Adapter）格式进行定制，实现无缝加载和自定义。可以轻松更新作者、时间戳、图像 ID 和软件版本等公共属性，同时使用不同的每像素位数设置、Alpha 通道和颜色透明度。此外，您还可以将 TGA 图像导出为其他流行的栅格格式，确保项目的兼容性。 |
