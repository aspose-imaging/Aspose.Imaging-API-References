## EmfLogBrushEx.BrushStyle property

获取或设置一个指定画刷样式的 32 位无符号整数。该值必须是 WMF BrushStyle 枚举中的一个成员（[MS-WMF] 第 2.1.1.4 节）。本结构支持的样式值在本节后面列出。应使用 BS_NULL 样式来指定没有效果的画刷。

```csharp
public WmfBrushStyle BrushStyle { get; set; }
```
