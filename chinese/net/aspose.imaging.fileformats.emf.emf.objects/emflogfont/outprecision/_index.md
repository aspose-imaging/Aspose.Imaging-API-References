## EmfLogFont.OutPrecision property

获取或设置一个 8 位无符号整数，指定输出精度。输出精度定义字体需要多接近匹配请求的高度、宽度、字符方向、倾斜角度、字距和字体类型。它必须是 WMF OutPrecision 枚举中的一个值。

```csharp
public WmfOutPrecision OutPrecision { get; set; }
```
