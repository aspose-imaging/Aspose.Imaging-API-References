## EmfLogFont.Quality property

获取或设置一个 8 位无符号整数，指定输出质量。输出质量定义尝试将逻辑字体属性与实际物理字体属性匹配的精确程度。它必须是 WMF FontQuality 枚举（[MS-WMF] 第 2.1.1.10 节）中的一个值。

```csharp
public WmfFontQuality Quality { get; set; }
```
