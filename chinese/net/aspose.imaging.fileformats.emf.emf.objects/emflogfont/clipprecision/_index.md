## EmfLogFont.ClipPrecision property

获取或设置一个 8 位无符号整数，指定剪裁精度。剪裁精度定义如何剪裁部分位于剪裁区域之外的字符。它可以是一个或多个 WMF ClipPrecision 标志。

public WmfClipPrecisionFlags ClipPrecision { get; set; }
