## EmfLogFont.Facename property

获取或设置一个 Facename（64 字节）：一个不超过 32 个 Unicode 字符的字符串，指定字体的字形名称。如果该字符串长度少于 32 个字符，必须包含一个终止的 NULL，之后的字段内容必须被忽略。

public string Facename { get; set; }
