## EmfColorAdjustment.Colorfullness property

获取或设置一个 16 位有符号整数，指定要应用于源对象的色彩饱和度量。该值应在 –100 到 100 之间。值为零表示不得执行色彩饱和度调整

```csharp
public short Colorfullness { get; set; }
```
