## EmfColorAdjustment.ReferenceWhite property

获取或设置一个 16 位无符号整数，指定源颜色的白色参考值。任何比此更亮的颜色都视为白色。该值应在 6,000 到 10,000 之间。

public short ReferenceWhite { get; set; }
