## EmfColorAdjustment.RedGreenTint property

获取或设置 16 位有符号整数，指定要应用于源对象的红色或绿色色调调整量。该值应在 –100 到 100 之间。正数向红色调整，负数向绿色调整。值为零表示不得执行色调调整

public short RedGreenTint { get; set; }
