该命名空间包含类型 [MS-EMF]：增强型图元文件格式。2.2 EMF 对象

## 类

| 类 | 描述 |
| --- | --- |
| [EmfBasePen](./emfbasepen/) | 基础笔对象 |
| [EmfBitFix28To4](./emfbitfix28to4/) | BitFIX28_4 对象定义了 28.4 位 FIX 表示法中的数值。 |
| [EmfColorAdjustment](./emfcoloradjustment/) | ColorAdjustment 对象定义了在位块传输中调整源位图颜色的值。 |
| [EmfDesignVector](./emfdesignvector/) | DesignVector（第 2.2.3 节）对象定义了设计向量，用于指定多主字体的字体轴值。 |
| [EmfEpsData](./emfepsdata/) | EpsData 对象是 EPS 数据的容器。 |
| [EmfFormat](./emfformat/) | EmrFormat 对象包含用于识别 EMR_COMMENT_MULTIFORMATS 记录（第 2.3.3.4.3 节）中图像数据格式的信息。 |
| [EmfGradientRectangle](./emfgradientrectangle/) | GradientRectangle 对象使用 TriVertex 对象（第 2.2.26 节）在 EMR_GRADIENTFILL 记录（第 2.3.5.12 节）中定义矩形。 |
| [EmfGradientTriangle](./emfgradienttriangle/) | GradientTriangle 对象使用 TriVertex 对象（第 2.2.26 节）在 EMR_GRADIENTFILL 记录（第 2.3.5.12 节）中定义三角形。 |
| [EmfHeaderExtension1](./emfheaderextension1/) | HeaderExtension1 对象定义了 EMF 元文件头的第一个扩展。它添加了对 PixelFormatDescriptor 对象（第 2.2.22 节）和 OpenGL [OPENGL] 记录（第 2.3.9 节）的支持。 |
| [EmfHeaderExtension2](./emfheaderextension2/) | HeaderExtension2 对象定义了 EMF 元文件头的第二个扩展。它增加了以微米为单位测量设备表面的能力，从而提升了 EMF 元文件的分辨率和可伸缩性。 |
| [EmfHeaderObject](./emfheaderobject/) | Header 对象定义了 EMF 元文件头。它指定了创建元文件中图像的设备属性。 |
| [EmfLogBrushEx](./emflogbrushex/) | LogBrushEx 对象定义了设备无关画刷的样式、颜色和图案。 |
| [EmfLogFont](./emflogfont/) | LogFont 对象指定了逻辑字体的基本属性。 |
| [EmfLogFontEx](./emflogfontex/) | LogFontEx 对象指定了逻辑字体的扩展属性。 |
| [EmfLogFontExDv](./emflogfontexdv/) | LogFontExDv 对象指定了扩展逻辑字体的设计向量。 |
| [EmfLogFontPanose](./emflogfontpanose/) | LogFontPanose 对象指定了逻辑字体的 PANOSE 特征。 |
| [EmfLogPalette](./emflogpalette/) | LogPalette 对象指定了包含设备无关颜色定义的 logical_palette。 |
| [EmfLogPen](./emflogpen/) | LogPen 对象定义了逻辑笔的样式、宽度和颜色。 |
| [EmfLogPenEx](./emflogpenex/) | LogPenEx 对象指定了扩展逻辑笔的样式、宽度和颜色。 |
| [EmfObject](./emfobject/) | Emf 对象的基类 |
| [EmfPanose](./emfpanose/) | Panose 对象描述了 TrueType 字体的 PANOSE 字体分类值。这些特征用于将该字体与外观相似但名称不同的其他字体关联。 |
| [EmfPixelFormatDescriptor](./emfpixelformatdescriptor/) | PixelFormatDescriptor 对象可在 EMR_HEADER 记录（第 2.3.4.2 节）中使用，以指定回放设备上下文的输出表面的像素格式。 |
| [EmfPoint28To4](./emfpoint28to4/) | Point28_4 对象表示设备表面上点的位置，其坐标采用 28.4 位 FIX 表示法。 |
| [EmfRegionData](./emfregiondata/) | RegionData 对象指定定义区域的数据，该区域由不重叠的矩形组成。 |
| [EmfRegionDataHeader](./emfregiondataheader/) | RegionDataHeader 对象描述 RegionData 对象的属性。 |
| [EmfText](./emftext/) | EmrText 对象包含文本输出的值。 |
| [EmfTriVertex](./emftrivertex/) | TriVertex 对象指定用于定义矩形或三角形顶点的颜色和位置信息。 |
| [EmfUniversalFontId](./emfuniversalfontid/) | UniversalFontId 对象定义了一种在 EMF 元文件中识别字体的机制。 |
