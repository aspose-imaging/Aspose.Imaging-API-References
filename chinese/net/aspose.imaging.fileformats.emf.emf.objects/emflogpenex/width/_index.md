## EmfLogPenEx.Width property

获取或设置一个 32 位无符号整数，指定笔绘制的线宽。如果 PenStyle 字段中的笔类型为 PS_GEOMETRIC，则该值为逻辑单位的宽度；否则，宽度以设备单位指定。如果 PenStyle 字段中的笔类型为 PS_COSMETIC，则此值必须为 0x00000001。

```csharp
public int Width { get; set; }
```
