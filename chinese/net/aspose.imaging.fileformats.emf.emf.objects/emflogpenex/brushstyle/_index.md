## EmfLogPenEx.BrushStyle property

获取或设置一个 32 位无符号整数，指定来自 WMF BrushStyle 枚举（[MS-WMF] 第 2.1.1.4 节）的笔刷样式。如果 PenStyle 字段中的笔类型为 PS_GEOMETRIC，则此值必须是 BS_SOLID 或 BS_HATCHED。此字段的值可以是 BS_NULL，但仅当 PenStyle 中指定的线样式为 PS_NULL 时。应使用 BS_NULL 样式来指定没有效果的画刷。

```csharp
public WmfBrushStyle BrushStyle { get; set; }
```
