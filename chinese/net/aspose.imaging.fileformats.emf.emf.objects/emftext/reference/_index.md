## EmfText.Reference property

获取或设置一个 WMF PointL 对象（[MS-WMF] 第 2.2.2.15 节），该对象指定用于定位字符串的参考点坐标。参考点由最近的 EMR_SETTEXTALIGN 记录（第 2.3.11.25 节）定义。如果未设置此记录，默认对齐方式为 TA_LEFT、TA_TOP。

public Point Reference { get; set; }
