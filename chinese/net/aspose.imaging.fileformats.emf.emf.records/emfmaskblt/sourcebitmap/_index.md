## EmfMaskBlt.SourceBitmap property

获取或设置一个包含源位图的缓冲区，这些位图不需要与 EMR_MASKBLT 记录的固定部分或彼此连续。因此，此缓冲区中标记为 "UndefinedSpace" 的字段是可选的，必须被忽略。

```csharp
public WmfDeviceIndependentBitmap SourceBitmap { get; set; }
```
