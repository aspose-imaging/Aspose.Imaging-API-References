## EmfVertexData.VertexPadding property

获取或设置一个可选的可变长度数组，其长度为 nTri × 4 字节；如果 ulMode 字段的值指示 GradientRectangle 对象（第 2.2.7 节），则此数组必须存在。如果 ulMode 字段的值指示 GradientTriangle 对象（第 2.2.8 节），则不存在 VertexPadding。此字段必须被忽略。

```csharp
public byte[] VertexPadding { get; set; }
```
