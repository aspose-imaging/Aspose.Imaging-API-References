## EmfEof.SizeLast property

获取或设置一个 32 位无符号整数，该整数必须与 Size 相同，并且必须是记录（因此也是元文件）的最后一个字段。如果存在 LogPaletteEntry 对象，则它们必须位于此字段之前。

```csharp
public int SizeLast { get; set; }
```
