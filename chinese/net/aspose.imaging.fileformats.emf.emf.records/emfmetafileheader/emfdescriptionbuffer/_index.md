## EmfMetafileHeader.EmfDescriptionBuffer property

获取或设置 EMF 描述缓冲区。一个可选的字节数组，包含 EMF 描述字符串，该数组不需要与 EmfMetafileHeader 记录的固定部分连续。因此，此缓冲区中标记为 "UndefinedSpace" 的字段是可选的，必须被忽略。

```csharp
public byte[] EmfDescriptionBuffer { get; set; }
```
