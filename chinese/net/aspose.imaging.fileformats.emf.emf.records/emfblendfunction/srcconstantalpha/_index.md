## EmfBlendFunction.SrcConstantAlpha property

获取一个 8 位无符号整数，指定 alpha 透明度，该透明度决定源位图和目标位图的混合方式。此值必须用于整个源位图。最小的 alpha 透明度值 0 表示完全透明，最大值 0xFF 表示完全不透明。实际上，0xFF 表示逐像素的 alpha 值决定源位图和目标位图的混合。详情请参见本节后面的公式。

```csharp
public byte SrcConstantAlpha { get; }
```
