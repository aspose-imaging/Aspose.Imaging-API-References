## EmfMetafileHeaderExtension1.EmfPixelFormatBuffer property

获取或设置一个可选的字节数组，包含 EMF 像素格式描述符，该数组不需要与 EmfMetafileHeaderExtension1 记录的固定部分或 EMF 描述字符串连续。因此，此缓冲区中标记为 "UndefinedSpace" 的字段是可选的，必须被忽略。

public byte[] EmfPixelFormatBuffer { get; set; }
