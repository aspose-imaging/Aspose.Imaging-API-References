## EmfRestoreDc.SavedDc property

获取或设置一个 32 位有符号整数，指定相对于当前状态要恢复的已保存状态。此值必须为负；–1 表示最近一次保存在堆栈上的状态，–2 表示其之前的状态，依此类推。

public int SavedDc { get; set; }
