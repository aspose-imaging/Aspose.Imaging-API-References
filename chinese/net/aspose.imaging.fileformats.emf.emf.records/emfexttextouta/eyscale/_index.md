## EmfExtTextOutA.EyScale property

获取或设置一个 32 位浮点值，指定沿 Y 轴的比例因子，用于将页面空间单位转换为 0.01mm 单位。仅当 iGraphicsMode 指定的图形模式为 GM_COMPATIBLE 时才应使用此值。

```csharp
public float EyScale { get; set; }
```
