## EmfRop4.BackgroundRop3 property

获取背景 ROP3。来自 WMF 三元光栅操作枚举的 24 位三元光栅操作值的无符号最高 8 位（[MS-WMF] 第 2.1.1.31 节）。此代码定义了如何合并源和目标位图以及画刷图案的背景颜色数据。

```csharp
public byte BackgroundRop3 { get; }
```

### Property Value

背景 ROP3。
