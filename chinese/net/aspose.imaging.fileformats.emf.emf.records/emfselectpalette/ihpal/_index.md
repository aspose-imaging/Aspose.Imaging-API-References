## EmfSelectPalette.IhPal property

获取或设置一个 32 位无符号整数，指定 EMF 对象表中 LogPalette 对象（第 2.2.17 节）的索引，或值 DEFAULT_PALETTE，该值是 StockObject 枚举（第 2.1.31 节）中库存对象调色板的索引。

```csharp
public int IhPal { get; set; }
```

## 备注

此值不得为零或任何其他库存对象的索引。
