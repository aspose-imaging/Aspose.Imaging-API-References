## EmfSetTextAlign.TextAlignmentMode property

获取或设置一个 32 位无符号整数，使用文本对齐标志掩码指定文本对齐方式。这些标志可以是用于水平基线文本的 [`WmfTextAlignmentModeFlags`](../../../aspose.imaging.fileformats.wmf.consts/wmftextalignmentmodeflags/)（[MS-WMF] 第 2.1.2.3 节），或用于垂直基线文本的 [`WmfVerticalTextAlignmentModeFlags`](../../../aspose.imaging.fileformats.wmf.consts/wmfverticaltextalignmentmodeflags/)（[MS-WMF] 第 2.1.2.4 节）。只能从影响水平和垂直对齐的选项中选择一个值。

```csharp
public int TextAlignmentMode { get; set; }
```
