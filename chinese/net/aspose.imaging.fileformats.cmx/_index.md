该命名空间处理 Tiff 文件格式。

## 类

| 类 | 描述 |
| --- | --- |
| [CmxImage](./cmximage/) | 针对 Corel Metafile Exchange (CMX) 矢量图像格式并支持元数据描述的 API 是面向处理 CMX 文件的开发者的综合解决方案。该 API 允许无缝加载 CMX 图像，提取诸如每像素位数、对象尺寸等元数据。通过额外的功能，如调整大小、旋转、设置调色板以及转换为其他格式，该 API 使开发者能够高效地操作和定制 CMX 矢量图像，以满足其特定的应用需求。 |
| [CmxImagePage](./cmximagepage/) | CMX 页面图像 |
