## CmxImage.WidthF property

使用此直观属性即可获取对象的宽度（以英寸为单位）。对于希望在应用中获得对象精确测量、确保准确布局和展示的开发者而言，这是理想选择。

```csharp
public override float WidthF { get; }
```

### Property Value

对象宽度，单位为英寸。
