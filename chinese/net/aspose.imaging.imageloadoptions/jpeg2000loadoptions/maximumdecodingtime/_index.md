## Jpeg2000LoadOptions.MaximumDecodingTime property

获取或设置以秒为单位的最大解码时间（此选项可用于内存非常慢的机器，以防在处理非常大的图像（分辨率超过 5500x6500 像素）时挂起）。

```csharp
public int MaximumDecodingTime { get; set; }
```

### Property Value

最大解码时间。
