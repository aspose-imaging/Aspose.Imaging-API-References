## EpsImage.HasRasterPreview property

使用此属性可轻松发现光栅预览的存在。获取布尔值以指示[`EpsImage`](../)实例是否包含光栅预览，为您的图像处理任务提供清晰高效的支持。非常适合基于 EPS 图像中光栅预览的有无来简化工作流决策。

```csharp
public bool HasRasterPreview { get; }
```
