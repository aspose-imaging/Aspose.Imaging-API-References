## EpsImage.Title property

此属性检索从 EPS 文档结构约定（DSC）注释中提取的标题，这些注释嵌入在 EPS 文件中。它提供有关 EPS 文件内容的有价值元数据，有助于在兼容软件应用中进行文档组织和识别。

```csharp
public string Title { get; }
```
