## EpsImage.GetPreviewImage method

```csharp
public Image GetPreviewImage(EpsPreviewFormat format = EpsPreviewFormat.Default)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 格式 | EpsPreviewFormat | EPS 预览图像的格式。 |

### 返回值
