该命名空间包含 EPS 格式类型

## 类

| 类 | 描述 |
| --- | --- |
| [EpsImage](./epsimage/) | 用于 Encapsulated PostScript (EPS) 图像文件格式支持的 API 提供了强大的功能，可对包含文本、图形和图像的组合进行操作。具备位图预览图像处理、方向翻转、获取插图边界的边界框、调整大小、旋转图像以及添加预览图像等特性，此 API 确保在各种应用中以精确且多功能的方式无缝处理和集成 EPS 文件。 |
| [EpsLoadOptions](./epsloadoptions/) | [`EpsImage`](../aspose.imaging.fileformats.eps/epsimage/) 加载选项。 |
