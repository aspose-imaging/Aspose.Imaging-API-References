## EmfPlusSetTsClip.Compressed property

获取一个值，指示此 [`EmfPlusSetTsClip`](../) 是否已压缩。此位指定 rects 字段中矩形数据的格式。如果设置，每个矩形占用 4 字节；如果未设置，每个矩形占用 8 字节。

```csharp
public bool Compressed { get; }
```

### Property Value

`true` 表示已压缩；否则为 `false`。
