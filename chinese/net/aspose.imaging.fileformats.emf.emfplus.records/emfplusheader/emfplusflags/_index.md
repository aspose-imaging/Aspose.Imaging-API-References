## EmfPlusHeader.EmfPlusFlags property

获取或设置 EMF plus 标志。一个 32 位无符号整数，包含有关此元文件记录方式的信息。如果字段的第 31 位被设置，则此标志表示该元文件使用视频显示的参考设备上下文进行记录。如果未设置，则该元文件使用打印机的参考设备上下文进行记录。

```csharp
public int EmfPlusFlags { get; set; }
```

### Property Value

EMF plus 标志。
