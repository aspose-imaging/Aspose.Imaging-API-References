## EmfPlusHeader.VideoDisplay property

获取或设置一个值，指示是否视频显示。如果设置，此标志表示该元文件使用视频显示的参考设备上下文进行记录。如果未设置，则该元文件使用打印机的参考设备上下文进行记录。

```csharp
public bool VideoDisplay { get; set; }
```

### Property Value

`true` 表示 [video display]；否则为 `false`。
