## EmfPlusDrawArc.StartAngle property

获取或设置起始角度。一个 32 位非负浮点值，指定 x 轴与弧线起始点之间的角度。任何值均可接受，但必须对 360 取模，使用的结果应在 0.0（含）到 360.0（不含）之间。

```csharp
public float StartAngle { get; set; }
```
