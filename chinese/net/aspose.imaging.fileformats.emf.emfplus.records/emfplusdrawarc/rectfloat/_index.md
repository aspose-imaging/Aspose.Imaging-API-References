## EmfPlusDrawArc.RectFloat property

获取或设置一个值，指示数据是包含 EmfPlusRectF 还是 EmfPlusRect 记录。此位指示 RectData 字段中的数据是否已压缩。如果设置，则 RectData 包含 EmfPlusRect 对象（章节 2.2.2.38）。如果清除，则 RectData 包含 EmfPlusRectF 对象（章节 2.2.2.39）。

```csharp
public bool RectFloat { get; set; }
```

### Property Value

`true` 表示为 float；否则为 `false`。
