## EmfPlusDrawArc.SweepAngle property

获取或设置扫掠角度。一个 32 位浮点值，指定要绘制的弧线范围，以度数表示，从 StartAngle 值定义的起始点测量。任何值均可接受，但必须限制在 -360.0 到 360.0（含）之间。正值表示扫掠方向为顺时针，负值表示为逆时针。

```csharp
public float SweepAngle { get; set; }
```
