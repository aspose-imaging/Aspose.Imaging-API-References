## EmfPlusDrawBeziers.Relative property

获取或设置一个值，指示 PointData 是否为相对的。如果设置，则 PointData 中的每个元素指定相对于数组中前一个元素位置的坐标空间位置。对于 PointData 的第一个元素，假定前一个位置为坐标 (0,0)。如果未设置，则 PointData 根据 C 标志指定绝对位置。注意：如果此标志被设置，则上面的 C 标志未定义，必须被忽略。

```csharp
public bool Relative { get; set; }
```

### Property Value

`true` 表示相对；否则为 `false`。
