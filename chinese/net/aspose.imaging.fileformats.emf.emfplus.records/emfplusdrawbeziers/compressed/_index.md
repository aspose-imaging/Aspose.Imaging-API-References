## EmfPlusDrawBeziers.Compressed property

获取或设置一个值，指示 PointData 是否已压缩。如果设置，则 PointData 使用 16 位整数坐标指定坐标空间中的绝对位置。如果未设置，则 PointData 使用 32 位浮点坐标指定坐标空间中的绝对位置。注意：如果下面的 Relative 标志被设置，则此标志未定义，必须被忽略。

```csharp
public bool Compressed { get; set; }
```

### Property Value

`true` 表示已压缩；否则为 `false`。
