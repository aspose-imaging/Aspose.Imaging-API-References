## EmfPlusTranslateWorldTransform.PostMultipliedMatrix property

获取一个值，指示是否 [post multiplied matrix]。如果设置，则应后乘变换矩阵；如果未设置，则应前乘。

```csharp
public bool PostMultipliedMatrix { get; }
```

### Property Value

`true` 表示 [post multiplied matrix]；否则为 `false`。
