## EmfPlusFillRects.Compressed property

获取或设置一个值，指示此 [`EmfPlusFillRects`](../) 是否已压缩。如果设置，RectData 包含 EmfPlusRect 对象（章节 2.2.2.38）。如果清除，RectData 包含 EmfPlusRectF 对象（章节 2.2.2.39）对象。

```csharp
public bool Compressed { get; set; }
```

### Property Value

`true` 表示已压缩；否则为 `false`。
