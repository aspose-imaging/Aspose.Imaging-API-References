## EmfPlusFillRects.IsColor property

获取或设置一个值，指示此实例是否为颜色。如果设置，BrushId 指定为 EmfPlusARGB 对象（第 2.2.2.1 节）中的颜色。如果未设置，BrushId 包含 EMF+ 对象表中 EmfPlusBrush 对象（第 2.2.1.1 节）的索引。

```csharp
public bool IsColor { get; set; }
```

### Property Value

`true` 如果此实例是颜色；否则为 `false`.
