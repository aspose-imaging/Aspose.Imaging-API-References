## EmfPlusSetAntiAliasMode.AntiAliasing property

获取或设置一个值，指示是否 [anti aliasing]。如果设置，则应执行抗锯齿；如果未设置，则不应执行抗锯齿。

```csharp
public bool AntiAliasing { get; set; }
```

### Property Value

`true` 表示 [anti aliasing]；否则为 `false`。
