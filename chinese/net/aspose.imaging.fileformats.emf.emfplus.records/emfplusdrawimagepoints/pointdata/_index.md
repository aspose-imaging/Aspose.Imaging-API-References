## EmfPlusDrawImagePoints.PointData property

获取或设置一个 Count 点数组，指定平行四边形的三个点。三个点分别代表平行四边形的左上、右上和左下角。第四个点由前三个点外推得到。SrcRect 字段指定的图像部分如果需要，应当应用缩放和剪切变换以适应平行四边形。

```csharp
public PointF[] PointData { get; set; }
```

### Property Value

点数据。
