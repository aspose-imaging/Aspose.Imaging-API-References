## EmfPlusDrawImagePoints.ApplyingAnEffect property

获取或设置一个值，以指示是否 [applying an effect]。此位指示图像的渲染是否包括应用效果。如果设置，则必须在之前的 EmfPlusSerializableObject 记录（第 2.3.5.2 节）中指定 Effect 类的对象。

```csharp
public bool ApplyingAnEffect { get; set; }
```

### Property Value

`true` 如果 [applying an effect]；否则为 `false`。
