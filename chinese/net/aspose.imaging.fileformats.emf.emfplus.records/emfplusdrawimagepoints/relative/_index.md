## EmfPlusDrawImagePoints.Relative property

获取或设置一个值，指示此 [`EmfPlusDrawImagePoints`](../) 是否为相对坐标。此位指示 PointData 字段是指定相对位置还是绝对位置。如果设置，则 PointData 中的每个元素指定相对于数组中前一个元素位置的坐标空间位置。对于 PointData 的第一个元素，假定前一个位置的坐标为 (0,0)。如果未设置，PointData 根据 C 标志指定绝对位置。注意：如果设置了此标志，上述 C 标志未定义，必须被忽略。

```csharp
public bool Relative { get; set; }
```

### Property Value

`true` 表示相对；否则为 `false`。
