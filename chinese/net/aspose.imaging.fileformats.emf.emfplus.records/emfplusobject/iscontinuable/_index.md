## EmfPlusObject.IsContinuable property

获取或设置一个值，指示此实例是否可继续。表示对象定义在下一个 EmfPlusObject 记录中继续。此标志在定义对象的最终记录中永不设置。

```csharp
public bool IsContinuable { get; set; }
```

### Property Value

`true` 表示此实例已压缩；否则为 `false`。
