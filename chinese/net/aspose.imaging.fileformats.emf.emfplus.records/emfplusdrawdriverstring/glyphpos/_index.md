## EmfPlusDrawDriverString.GlyphPos property

获取或设置字形位置数组，一个 EmfPlusPointF 对象数组（第 2.2.2.36 节），用于指定每个字符字形的输出位置。必须有 GlyphCount 个元素，这些元素与 Glyphs 数组中的元素一一对应。如果在 DriverStringOptions 标志中设置了 DriverStringOptionsRealizedAdvance 标志，则字形位置从第一个字形的位置计算。在这种情况下，GlyphPos 仅指定第一个字形的位置。

```csharp
public PointF[] GlyphPos { get; set; }
```
