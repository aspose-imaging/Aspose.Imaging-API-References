## EmfPlusDrawDriverString.Glyphs property

获取或设置字形数组，一个 16 位值的数组，定义要绘制的文本字符串。如果在 DriverStringOptionsFlags 字段中设置了 DriverStringOptionsCmapLookup 标志，则数组中的每个值表示一个 Unicode 字符。否则，每个值表示在 Flags 字段的 ObjectId 值指定的 EmfPlusFont 对象中的字符字形索引。

public short[] Glyphs { get; set; }
