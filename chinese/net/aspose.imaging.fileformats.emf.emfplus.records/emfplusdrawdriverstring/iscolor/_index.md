## EmfPlusDrawDriverString.IsColor property

获取或设置一个值，指示此实例是否为颜色。此位指示 BrushId 字段中数据的类型。如果设置，则 BrushId 指定 EmfPlusARGB 对象（第 2.2.2.1 节）中的颜色值。如果未设置，则 BrushId 包含 EmfPlusBrush 对象（第 2.2.1.1 节）的 EMF+ 对象表索引。

```csharp
public bool IsColor { get; set; }
```

### Property Value

`true` 如果此实例是颜色；否则为 `false`.
