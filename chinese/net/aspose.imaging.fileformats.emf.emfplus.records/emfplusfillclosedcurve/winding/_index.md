## EmfPlusFillClosedCurve.Winding property

获取或设置一个值，指示此 [`EmfPlusFillClosedCurve`](../) 是否为 winding。此位指示如何执行填充操作。如果设置，填充为 \"winding\" 填充；如果清除，填充为 \"alternate\" 填充。

```csharp
public bool Winding { get; set; }
```

### Property Value

`true` 如果为 winding；否则为 `false`。
