## EmfPlusFillPolygon.IsCompressed property

获取或设置指示此实例是否压缩的值。如果设置，PointData 使用 16 位整数坐标指定坐标空间中的绝对位置。如果未设置，PointData 使用 32 位浮点坐标指定坐标空间中的绝对位置。

```csharp
public bool IsCompressed { get; set; }
```

### Property Value

`true` 表示此实例已压缩；否则为 `false`。
