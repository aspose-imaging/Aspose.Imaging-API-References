## EmfPlusFillPolygon.IsRelative property

获取或设置一个值，指示此实例是否为相对的。如果设置，则 PointData 中的每个元素指定相对于数组中前一个元素指定的位置的坐标空间位置。对于 PointData 的第一个元素，假定前一个位置坐标为 (0,0)。如果未设置，则 PointData 根据 C 标志指定绝对位置。

```csharp
public bool IsRelative { get; set; }
```

### Property Value

`true` 如果此实例是相对的；否则为 `false`。
