## EmfPlusDrawEllipse.Compressed property

获取或设置一个值，指示 PointData 是否已压缩。如果设置，则 RectData 包含 EmfPlusRect 对象（第 2.2.2.38 节）。如果清除，则 RectData 包含 EmfPlusRectF 对象（第 2.2.2.39 节）。

```csharp
public bool Compressed { get; set; }
```

### Property Value

`true` 表示已压缩；否则为 `false`。
