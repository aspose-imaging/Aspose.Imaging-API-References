## TiffDataType.IsValid property

获取一个值，指示标签数据是否有效。有效的标签包含可保留的数据。无效的标签无法存储。

```csharp
public bool IsValid { get; }
```

### Property Value

`true` 如果标签数据有效；否则为 `false`。
