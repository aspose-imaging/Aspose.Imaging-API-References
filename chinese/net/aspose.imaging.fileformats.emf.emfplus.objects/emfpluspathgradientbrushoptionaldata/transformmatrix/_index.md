## EmfPlusPathGradientBrushOptionalData.TransformMatrix property

获取或设置一个可选的 EmfPlusTransformMatrix 对象（第 2.2.2.47 节），该对象指定路径渐变画笔的世界坐标到设备坐标的变换。如果 EmfPlusPathGradientBrushData 对象的 BrushDataFlags 字段中设置了 BrushDataTransform 标志，则此字段必须存在。

public Matrix TransformMatrix { get; set; }
