## EmfPlusTextureBrushData.BrushDataFlags property

获取或设置一个 32 位无符号整数，用于指定 OptionalData 字段中的数据。此值必须由 BrushData 标志（第 2.1.2.1 节）组成。以下标志与纹理画刷相关：BrushDataTransform、BrushDataIsGammaCorrected、BrushDataDoNotTransform。

public EmfPlusBrushDataFlags BrushDataFlags { get; set; }
