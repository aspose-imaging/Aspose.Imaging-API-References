## EmfPlusTextureBrushOptionalData.ImageObject property

获取或设置可选的 EmfPlusImage 对象（第 2.2.1.4 节），指定画笔纹理。如果定义此纹理画笔的 EmfPlusObject 记录（第 2.3.5.1 节）的大小足以容纳除 EmfPlusTextureBrushData 对象的必需字段外的 EmfPlusImage 对象（以及可选的 EmfPlusTransformMatrix 对象），则此字段必须存在。

```csharp
public EmfPlusImage ImageObject { get; set; }
```
