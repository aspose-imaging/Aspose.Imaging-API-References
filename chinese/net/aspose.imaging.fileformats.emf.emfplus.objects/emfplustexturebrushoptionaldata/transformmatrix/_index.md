## EmfPlusTextureBrushOptionalData.TransformMatrix property

获取或设置可选的 EmfPlusTransformMatrix 对象（第 2.2.2.47 节），指定纹理画笔的世界空间到设备空间的变换。如果在 EmfPlusTextureBrushData 对象的 BrushDataFlags 字段中设置了 BrushDataTransform 标志，则此字段必须存在。

```csharp
public Matrix TransformMatrix { get; set; }
```
