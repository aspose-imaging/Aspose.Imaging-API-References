## EmfPlusTintEffect.Amount property

获取或设置 一个 32 位有符号整数，指定色相的增强或削弱程度。-100 ≤ value < 0 负值指定色相被削弱的程度，相当于添加黑色。0 值为 0 表示 tint 不应改变。0 < value ≤ 100 正值指定色相被增强的程度，相当于添加白色。
