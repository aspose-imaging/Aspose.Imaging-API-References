## EmfPlusLevelsEffect.Shadow property

获取或设置，指定对图像阴影的加暗程度。强度范围低端的颜色通道值比中间或高端的值变化更大，这意味着可以在不失去图像亮部对比度的情况下加暗图像。0 指定阴影 MUST NOT 改变。0 < value ≤ 100 指定强度百分比低于此阈值的阴影被加暗。

```csharp
public int Shadow { get; set; }
```

### Property Value

The shadow.
