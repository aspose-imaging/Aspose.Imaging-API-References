## EmfPlusColorBalanceEffect.MagentaGreen property

获取或设置一个 32 位有符号整数，指定图像中绿色量的变化。此值必须在 -100 到 100 的范围内，效果如下：-100 ≤ value &lt; 0 时，随着数值减小，图像中的绿色量应减小，品红量应增加。0 时，绿色和品红的量必须保持不变。0 &lt; value ≤ 100 时，随着数值增大，图像中的绿色量应增大，品红量应减小。

public int MagentaGreen { get; set; }
