## EmfPlusColorBalanceEffect.YellowBlue property

获取或设置一个 32 位有符号整数，指定图像中蓝色量的变化。此值必须在 -100 到 100 的范围内，效果如下：-100 ≤ value &lt; 0 时，随着数值减小，图像中的蓝色量应减小，黄色量应增加。0 时，蓝色和黄色的量必须保持不变。0 &lt; value ≤ 100 时，随着数值增大，图像中的蓝色量应增大，黄色量应减小。

public int YellowBlue { get; set; }
