## EmfPlusBrightnessContrastEffect.ContrastLevel property

获取或设置一个 32 位有符号整数，指定对比度级别。该值必须在 -100 到 100 的范围内，效果如下：-100 ≤ value &lt; 0 当值减小时，图像的对比度应降低。0 值为 0 表示对比度不得改变。0 &lt; value ≤ 100 当值增大时，图像的对比度应增加。

```csharp
public int ContrastLevel { get; set; }
```
