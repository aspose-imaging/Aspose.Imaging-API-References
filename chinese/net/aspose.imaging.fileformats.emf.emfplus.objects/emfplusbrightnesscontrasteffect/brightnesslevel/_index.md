## EmfPlusBrightnessContrastEffect.BrightnessLevel property

获取或设置一个 32 位有符号整数，指定亮度级别。该值必须在 -255 到 255 的范围内，效果如下：-255 ≤ value &lt; 0 当值减小时，图像的亮度应降低。0 值为 0 表示亮度不得改变。0 &lt; value ≤ 255 当值增大时，图像的亮度应增加。

```csharp
public int BrightnessLevel { get; set; }
```
