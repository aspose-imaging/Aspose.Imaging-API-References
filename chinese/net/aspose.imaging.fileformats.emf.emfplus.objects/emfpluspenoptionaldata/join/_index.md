## EmfPlusPenOptionalData.Join property

获取或设置可选的 32 位有符号整数，指定使用同一支笔绘制且端点相接的两条线的连接方式。如果在 EmfPlusPenData 对象的 PenDataFlags 字段中设置了 PenDataJoin 标志，则此字段必须存在，且该值必须在 LineJoinType 枚举（第 2.1.1.19 节）中定义。

```csharp
public EmfPlusLineJoinType Join { get; set; }
```
