## EmfPlusPenOptionalData.DashOffset property

获取或设置可选的 32 位浮点值，指定从直线起点到虚线模式中第一个空格起点的距离。如果在 EmfPlusPenData 对象的 PenDataFlags 字段中设置了 PenDataDashedLineOffset 标志，则此字段必须存在。

```csharp
public float DashOffset { get; set; }
```
