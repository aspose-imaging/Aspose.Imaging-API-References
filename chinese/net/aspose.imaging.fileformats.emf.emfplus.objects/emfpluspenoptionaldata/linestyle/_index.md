## EmfPlusPenOptionalData.LineStyle property

获取或设置可选的 32 位有符号整数，指定使用此笔对象绘制的线条样式。如果在 EmfPlusPenData 对象的 PenDataFlags 字段中设置了 PenDataLineStyle 标志，则此字段必须存在，且该值必须在 LineStyle 枚举（第 2.1.1.20 节）中定义。

```csharp
public EmfPlusLineStyle LineStyle { get; set; }
```
