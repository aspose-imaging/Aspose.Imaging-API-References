## EmfPlusPenOptionalData.CustomEndCapData property

获取或设置可选的 EmfPlusCustomEndCapData 对象（第 2.2.2.11 节），该对象定义自定义结束帽形状，即使用此笔绘制的线段末端的形状。它可以是各种形状，如方形、圆形或菱形。如果在 EmfPlusPenData 对象的 PenDataFlags 字段中设置了 PenDataCustomEndCap 标志，则此字段必须存在。

```csharp
public EmfPlusCustomEndCapData CustomEndCapData { get; set; }
```
