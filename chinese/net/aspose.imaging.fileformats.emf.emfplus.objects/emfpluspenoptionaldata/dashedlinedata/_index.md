## EmfPlusPenOptionalData.DashedLineData property

获取或设置可选的 EmfPlusDashedLineData 对象（第 2.2.2.16 节），该对象指定自定义虚线中短划线和间隔的长度。如果在 EmfPlusPenData 对象的 PenDataFlags 字段中设置了 PenDataDashedLine 标志，则此字段必须存在。

public EmfPlusDashedLineData DashedLineData { get; set; }
