## EmfPlusLinearGradientBrushData.WrapMode property

获取或设置 wrap 模式。

```csharp
public EmfPlusWrapMode WrapMode { get; set; }
```

### Property Value

一个来自 WrapMode 枚举（第 2.1.1.34 节）的 32 位有符号整数，指定是否绘制画笔边界之外的区域。绘制边界之外时，包装模式指定颜色渐变的重复方式。
