## EmfPlusBitmap.Width property

获取或设置图像宽度 Width（4 字节）：一个 32 位有符号整数，指定位图占用区域的像素宽度。如果图像已压缩（根据 Type 字段），此值未定义，必须被忽略。

```csharp
public int Width { get; set; }
```

### Property Value

宽度。
