## EmfPlusBitmap.PixelFormat property

获取或设置像素格式 PixelFormat（4 字节）：一个 32 位无符号整数，指定构成位图图像的像素格式。支持的像素格式在 [`EmfPlusPixelFormat`](../../../aspose.imaging.fileformats.emf.emfplus.consts/emfpluspixelformat/) 枚举（第 2.1.1.25 节）中指定。如果图像根据 Type 字段被压缩，则此值未定义，必须被忽略。

```csharp
public EmfPlusPixelFormat PixelFormat { get; set; }
```

### Property Value

像素格式。
