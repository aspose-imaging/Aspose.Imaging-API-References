## EmfPlusStringFormat.Tracking property

获取或设置一个 32 位浮点值，用于指定指定字符串中每个字符分配的水平空间与字符字体定义宽度的比例。该属性的较大值表示字符之间有充足的间距；小于 1 的值可能导致字符重叠。默认值为 1.03；对于排版字体，默认值为 1.00。

```csharp
public float Tracking { get; set; }
```
