## EmfPlusStringFormat.HotkeyPrefix property

获取或设置一个 32 位有符号整数，指定在遇到键盘快捷键前缀（即 & 符号）时对字符串执行的处理类型。基本上，此字段指定是否显示与文本相关的键盘快捷键前缀。该值必须在 HotkeyPrefix 枚举中定义 (section 2.1.1.14)。

```csharp
public EmfPlusHotkeyPrefix HotkeyPrefix { get; set; }
```
