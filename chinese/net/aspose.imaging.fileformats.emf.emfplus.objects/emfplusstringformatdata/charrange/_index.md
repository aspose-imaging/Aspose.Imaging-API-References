## EmfPlusStringFormatData.CharRange property

获取或设置 一个可选的 RangeCount EmfPlusCharacterRange 对象数组，指定文本字符串中字符位置的范围。边界区域由显示区域中被该字符范围指定的一组字符占据的区域定义。如果 EmfPlusStringFormat 对象中的 RangeCount 字段值大于 0，则此字段必须存在。

```csharp
public EmfPlusCharacterRange[] CharRange { get; set; }
```
