## EmfPlusStringFormatData.TabStops property

获取或设置 一个可选的浮点值数组，指定此对象的可选制表位位置。每个制表位值表示制表位之间的空格数，或者对于第一个制表位，表示行首与第一个制表位之间的空格数。如果 EmfPlusStringFormat 对象中的 TabStopCount 字段值大于 0，则此字段必须存在。

```csharp
public float[] TabStops { get; set; }
```
