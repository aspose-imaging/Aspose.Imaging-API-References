## EmfPlusPathPointTypeRle.Bezier property

获取或设置一个值，指示此 [`EmfPlusPathPointTypeRle`](../) 是否为贝塞尔。如果设置，则路径点位于贝塞尔曲线上。如果清除，则路径点位于普通直线。

```csharp
public bool Bezier { get; set; }
```

### Property Value

`true` 表示贝塞尔；否则为 `false`。
