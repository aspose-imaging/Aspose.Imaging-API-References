## EmfPlusPathGradientBrushData.BoundaryData property

获取或设置路径渐变画笔的边界，该边界可以由路径或闭合的基数样条曲线指定。如果在 BrushDataFlags 字段中设置了 BrushDataPath 标志，则此字段必须包含一个 EmfPlusBoundaryPathData 对象（第 2.2.2.6 节）；否则，此字段必须包含一个 EmfPlusBoundaryPointData 对象（第 2.2.2.7 节）。

```csharp
public EmfPlusBoundaryBase BoundaryData { get; set; }
```
