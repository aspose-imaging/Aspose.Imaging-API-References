## Jpeg2000Image.RawLineSize property

此属性检索原始图像数据单行的字节大小。它表示图像原始数据格式中单行像素占用的内存量。了解原始行大小对于内存分配、数据操作以及对单行图像进行处理的图像算法等任务至关重要。

```csharp
public override int RawLineSize { get; }
```

### Property Value

原始行大小（字节）。
