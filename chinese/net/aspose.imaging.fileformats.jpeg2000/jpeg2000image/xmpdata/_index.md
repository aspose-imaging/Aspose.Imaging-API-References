## Jpeg2000Image.XmpData property

检索或修改与图像关联的 XMP 元数据。此属性授予对图像文件中嵌入的可扩展元数据平台 (XMP) 信息的访问，允许对元数据属性（如作者详情、版权信息和描述性标签）进行操作或提取。利用此属性可帮助您管理和利用嵌入图像的元数据，增强互操作性和基于元数据的工作流在图像处理任务中的效果。

```csharp
public override XmpPacketWrapper XmpData { get; set; }
```

### Property Value

XMP 元数据。
