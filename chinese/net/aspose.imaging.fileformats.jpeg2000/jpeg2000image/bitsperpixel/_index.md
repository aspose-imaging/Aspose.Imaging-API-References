## Jpeg2000Image.BitsPerPixel property

此属性返回图像的深度，以每像素位数 (bpp) 为单位。它表示图像每个像素存储的颜色信息量。了解图像深度对于确定颜色保真度和图像质量至关重要。有了此信息，用户可以评估图像中细节和颜色丰富度的水平。

```csharp
public override int BitsPerPixel { get; }
```
