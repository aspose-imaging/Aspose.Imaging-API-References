## PixelDataFormat.RgbIndexed1Bpp property

获取已定义为每种颜色 1 位的 [`PixelDataFormat`](../)。索引像素数据存储旨在在使用调色板的所有地方允许数据存储和检索。请谨慎使用，因为可能需要从一个调色板转换到另一个调色板，或从 RGBA 转换为索引颜色模型。

```csharp
public static PixelDataFormat RgbIndexed1Bpp { get; }
```
