## PixelDataFormat.RgbIndexed4Bpp property

获取 [`PixelDataFormat`](../) ，其定义为每种颜色 4 位索引。索引像素数据存储旨在在使用调色板的所有地方实现数据的存储和检索。使用时需谨慎，因为可能需要将一个调色板转换为另一个调色板，或将 RGBA 转换为索引颜色模型。

```csharp
public static PixelDataFormat RgbIndexed4Bpp { get; }
```

### Property Value

该 [`PixelDataFormat`](../) 定义为每种颜色 4 位索引。
