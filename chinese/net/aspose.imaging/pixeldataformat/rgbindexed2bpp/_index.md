## PixelDataFormat.RgbIndexed2Bpp property

获取在每种颜色 2 位索引下定义的 [`PixelDataFormat`](../)。索引像素数据存储旨在在使用调色板的所有地方实现数据的存储和检索。使用时需谨慎，因为可能需要将一个调色板转换为另一个调色板，或将 RGBA 转换为索引颜色模型。

```csharp
public static PixelDataFormat RgbIndexed2Bpp { get; }
```
