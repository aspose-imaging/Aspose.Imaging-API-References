## PixelDataFormat.RgbIndexed8Bpp property

获取为每种颜色 8 位索引的 [`PixelDataFormat`](../) 定义。索引像素数据存储旨在在使用调色板的所有地方实现数据的存储和检索。使用时请谨慎，因为可能需要将一个调色板转换为另一个调色板，或将 RGBA 转换为索引颜色模型。

```csharp
public static PixelDataFormat RgbIndexed8Bpp { get; }
```

### Property Value

此 [`PixelDataFormat`](../) 为每种颜色 8 位索引的定义。
