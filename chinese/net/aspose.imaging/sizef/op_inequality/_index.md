## SizeF Inequality operator

测试两个 [`SizeF`](../) 结构是否不同。

```csharp
public static bool operator !=(SizeF size1, SizeF size2)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| size1 | SizeF | 不等式运算符左侧的 [`SizeF`](../) 结构。 |
| size2 | SizeF | 不等式运算符右侧的 [`SizeF`](../) 结构。 |

### 返回值

如果 *size1* 和 *size2* 在宽度或高度上任一不同，此运算符返回 true；如果 *size1* 和 *size2* 相等，则返回 false。
