## SizeF Equality operator

测试两个 [`SizeF`](../) 结构是否相等。

```csharp
public static bool operator ==(SizeF size1, SizeF size2)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| size1 | SizeF | 相等运算符左侧的 [`SizeF`](../) 结构。 |
| size2 | SizeF | 相等运算符右侧的 [`SizeF`](../) 结构。 |

### 返回值

如果 *size1* 和 *size2* 的宽度和高度相等，则此运算符返回 true；否则返回 false。
