## Inflate(RectangleF, float, float)

创建并返回指定 [`RectangleF`](../) 结构的膨胀副本。副本按指定量膨胀。原始矩形保持不变。

```csharp
public static RectangleF Inflate(RectangleF rect, float x, float y)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| rect | RectangleF | 要复制的 [`RectangleF`](../)。此矩形未被修改。 |
| x | 单精度 | 水平膨胀矩形副本的量。 |
| y | 单精度 | 垂直膨胀矩形副本的量。 |

### 返回值

已膨胀的 [`RectangleF`](../)。
