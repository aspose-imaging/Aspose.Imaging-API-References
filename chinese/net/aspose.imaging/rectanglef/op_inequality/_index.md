## RectangleF Inequality operator

测试两个 [`RectangleF`](../) 结构在位置或大小上是否不同。

```csharp
public static bool operator !=(RectangleF left, RectangleF right)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| left | RectangleF | 位于不等式运算符左侧的 [`RectangleF`](../) 结构。 |
| right | RectangleF | 位于不等式运算符右侧的 [`RectangleF`](../) 结构。 |

### 返回值

如果两个 [`RectangleF`](../) 结构的 [`X`](../x/) 、[`Y`](../y/)、[`Width`](../width/) 或 [`Height`](../height/) 属性中有任意不相等，则此运算符返回 true；否则返回 false。
