## Point Equality operator

比较两个[`Point`](../)对象。结果指示两个[`Point`](../)对象的[`X`](../x/)和[`Y`](../y/)属性值是否相等。

```csharp
public static bool operator ==(Point point1, Point point2)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| point1 | Point | 要比较的第一个 [`Point`](../)。 |
| point2 | Point | 要比较的第二个 [`Point`](../)。 |

### 返回值

如果 *point1* 和 *point2* 的 [`X`](../x/) 与 [`Y`](../y/) 值相等，则为 True；否则为 false。
