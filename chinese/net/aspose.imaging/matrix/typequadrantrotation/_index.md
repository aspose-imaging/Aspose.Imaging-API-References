## Matrix.TypeQuadrantRotation field

此标志位表示此对象定义的变换在执行其他标志位指示的转换之外，还会进行以 90 度的整数倍为单位的象限旋转。旋转会以相同的角度改变向量的方向，而不改变向量的长度。此标志位与 TypeGeneralRotation 标志互斥。

```csharp
public const int TypeQuadrantRotation;
```
