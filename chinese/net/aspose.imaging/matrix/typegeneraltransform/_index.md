## Matrix.TypeGeneralTransform field

此常量指示此对象定义的变换执行对输入坐标的任意转换。如果此变换可以由上述任意常量分类，则类型将是常量 TypeIdentity，或是针对该变换执行的各种坐标转换的相应标志位的组合。

```csharp
public const int TypeGeneralTransform;
```
