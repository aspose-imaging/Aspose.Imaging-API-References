## Matrix.TypeGeneralScale field

一般缩放会在 x 和 y 方向上以不同的量乘以向量的长度，而不改变垂直向量之间的角度。此标志位与 TypeUniformScale 标志互斥。

```csharp
public const int TypeGeneralScale;
```
