## Color Inequality operator

测试两个指定的[`Color`](../)结构是否不同。

```csharp
public static bool operator !=(Color left, Color right)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| left | Color | 位于不等式运算符左侧的[`Color`](../)。 |
| right | Color | 位于不等式运算符右侧的[`Color`](../)。 |

### 返回值

如果两个[`Color`](../)结构不同则为 true；否则为 false。
