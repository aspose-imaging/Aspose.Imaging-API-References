## PointF Inequality operator

确定指定点的坐标是否不相等。

```csharp
public static bool operator !=(PointF point1, PointF point2)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| point1 | PointF | 要比较的第一个 [`PointF`](../)。 |
| point2 | PointF | 要比较的第二个 [`PointF`](../)。 |

### 返回值

若 *point1* 和 *point2* 的 [`X`](../x/) 与 [`Y`](../y/) 值不相等则为 True；否则为 false。
