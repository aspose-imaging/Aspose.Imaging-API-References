## RasterImage.HasTransparentColor property

获取或设置一个值，指示此 [`RasterImage`](../) 实例是否具有透明颜色。

```csharp
public virtual bool HasTransparentColor { get; set; }
```

## 备注

如果在支持此功能的特定实现中未被覆盖，基类实现实际上会返回 `false`。此属性主要由 Apng、Png、Gif、Tga 使用，以在图像不通过 alpha 通道支持透明度时设置透明颜色。
