## Graphics.BeginUpdate method

开始缓存以下图形操作。随后应用的图形效果不会立即生效，而是等到 EndUpdate 时一次性应用所有效果。

```csharp
public void BeginUpdate()
```

## 备注

注意，如果在调用 BeginUpdate 后未调用 EndUpdate，则这些效果将不会被应用。
