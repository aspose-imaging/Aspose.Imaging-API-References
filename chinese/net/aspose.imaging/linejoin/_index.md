## LineJoin enumeration

指定如何在包含于 [`GraphicsPath`](../graphicspath/) 对象的图形（子路径）中连接连续的直线或曲线段。

```csharp
public enum LineJoin
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Miter | `0` | 指定斜接连接。这会产生锐角或被裁剪的角，取决于斜接长度是否超过斜接限制。 |
| Bevel | `1` | 指定斜面连接。这会产生对角角。 |
| Round | `2` | 指定圆形连接。这会在直线之间产生平滑的圆弧。 |
| MiterClipped | `3` | 指定斜接连接。这会产生锐角或斜面角，取决于斜接长度是否超过斜接限制。 |
