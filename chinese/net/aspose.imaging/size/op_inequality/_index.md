## Size Inequality operator

测试两个 [`Size`](../) 结构是否不同。

```csharp
public static bool operator !=(Size size1, Size size2)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| size1 | Size | 不等运算符左侧的 [`Size`](../) 结构。 |
| size2 | Size | 不等运算符右侧的 [`Size`](../) 结构。 |

### 返回值

如果 *size1* 和 *size2* 在宽度或高度上任一不同则为 true；如果 *size1* 和 *size2* 相等则为 false。
