## Figure.IsClosed property

获取或设置一个值，以指示此图形是否闭合。闭合图形仅在首个和最后一个图形的形状是连续形状的情况下才会产生差异。在这种情况下，首个形状的起点将通过一条直线与最后一个形状的终点相连。

```csharp
public bool IsClosed { get; set; }
```

### Property Value

`True` 如果此图形是闭合的；否则为 `false`。
