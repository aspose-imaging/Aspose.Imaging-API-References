## WrapMode enumeration

指定当纹理或渐变小于填充区域时的平铺方式。

```csharp
public enum WrapMode
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Tile | `0` | 平铺渐变或纹理。 |
| TileFlipX | `1` | 水平翻转纹理或渐变，然后平铺纹理或渐变。 |
| TileFlipY | `2` | 垂直翻转纹理或渐变，然后平铺纹理或渐变。 |
| TileFlipXY | `3` | 水平和垂直翻转纹理或渐变，然后平铺纹理或渐变。 |
| Clamp | `4` | 纹理或渐变不进行平铺。 |
