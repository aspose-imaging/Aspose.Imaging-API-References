## Intersect(Rectangle, Rectangle)

返回一个第三个[`Rectangle`](../)结构，表示两个其他[`Rectangle`](../)结构的交集。如果没有交集，则返回一个空的[`Rectangle`](../)。

```csharp
public static Rectangle Intersect(Rectangle a, Rectangle b)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 一个 | Rectangle | 第一个用于相交的矩形。 |
| b | Rectangle | 第二个用于相交的矩形。 |

### 返回值

一个[`Rectangle`](../)，表示 *a* 与 *b* 的交集。
