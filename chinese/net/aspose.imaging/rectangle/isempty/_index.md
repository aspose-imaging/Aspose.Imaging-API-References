## Rectangle.IsEmpty property

获取一个值，指示此 [`Rectangle`](../) 的所有数值属性是否为零。

```csharp
public bool IsEmpty { get; }
```

### Property Value

如果此 [`Rectangle`](../) 的 [`Width`](../width/)、[`Height`](../height/)、[`X`](../x/) 和 [`Y`](../y/) 属性全部为零，则此属性返回 true；否则返回 false。
