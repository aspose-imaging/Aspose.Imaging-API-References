该命名空间处理 Dicom 文件格式

## 类

| 类 | 描述 |
| --- | --- |
| [Compression](./compression/) | 包含图像压缩设置。 |
| [DicomImage](./dicomimage/) | 此类实现了医学数字成像与通信 (DICOM) 栅格图像格式的支持，并提供了一个全面的解决方案，用于精确且灵活地处理 DICOM 图像。您可以无缝操作图像页，包括获取、添加或删除页面，以及控制默认页和活动页。它具备处理 alpha 通道、嵌入 XMP 元数据、调整大小、旋转、裁剪、二值化、调节、应用过滤器以及转换为其他栅格格式的能力。此 API 使开发者能够有效地处理 DICOM 图像，同时满足医学影像领域中多样化的应用需求。 |
| [DicomImageInfo](./dicomimageinfo/) | 包含来自 Dicom 文件头的所有元信息。 |
| [DicomPage](./dicompage/) | 这是用于处理多帧类型 DICOM 文件的类。 |
