## DicomImage.HasAlpha property

使用此直观属性轻松获取图像是否具有 alpha 通道。非常适合希望确定图像是否包含透明度信息、在图像处理任务中精确处理 alpha 通道数据的开发者。

```csharp
public override bool HasAlpha { get; }
```

### Property Value
