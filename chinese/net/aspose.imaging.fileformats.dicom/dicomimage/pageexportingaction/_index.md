## DicomImage.PageExportingAction property

使用此直观属性管理页面导出操作。适用于希望控制图像页面导出行为的开发者，确保在各种图像处理工作流中实现无缝集成和自定义。请注意，设置此方法后将在执行后自动释放页面资源。该操作将在每个页面保存之前执行。

```csharp
public override PageExportingAction PageExportingAction { get; set; }
```

### Property Value

页面导出操作。
