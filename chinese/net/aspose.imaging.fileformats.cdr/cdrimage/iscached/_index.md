## CdrImage.IsCached property

轻松判断对象的数据是否已缓存，消除读取数据的需求。对于希望通过高效利用缓存数据来优化性能、确保更快访问信息的开发者而言，这是理想的选择。

```csharp
public override bool IsCached { get; }
```

### Property Value

`true` 如果对象的数据已缓存；否则为 `false`。
