## CdrImage.PageExportingAction property

使用此直观属性轻松检索或修改与图像关联的页面导出操作。非常适合希望自定义多页图像中页面导出行为、在应用程序中实现灵活高效的开发者。请注意，设置此方法后将在执行后自动释放页面资源，并将在每个页面保存之前执行。

```csharp
public override PageExportingAction PageExportingAction { get; set; }
```

页面导出操作。
