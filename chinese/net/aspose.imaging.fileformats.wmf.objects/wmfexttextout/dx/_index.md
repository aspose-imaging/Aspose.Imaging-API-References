## WmfExtTextOut.Dx property

获取或设置 dx。

```csharp
public short[] Dx { get; set; }
```

### Property Value

dx。指示相邻字符单元原点之间的距离。例如，Dx[i] 逻辑单位分隔字符单元 i 和字符单元 i + 1 的原点。如果此字段存在，则其值的数量必须与字符串中的字符数相同。
