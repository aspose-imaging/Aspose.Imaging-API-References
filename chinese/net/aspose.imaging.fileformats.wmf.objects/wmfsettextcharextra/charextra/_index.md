## WmfSetTextCharExtra.CharExtra property

获取或设置字符额外间距。

```csharp
public int CharExtra { get; set; }
```

### Property Value

每个字符要添加的额外空间量（以逻辑单位表示）。如果当前映射模式不是 MM_TEXT，则该值会被转换并四舍五入到最近的像素。有关设置映射模式的详细信息，请参阅 META_SETMAPMODE（第 2.3.5.17 节）。
