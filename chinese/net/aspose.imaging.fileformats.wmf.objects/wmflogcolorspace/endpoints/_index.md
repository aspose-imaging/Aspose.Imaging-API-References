## WmfLogColorSpace.Endpoints property

获取或设置一个 CIEXYZTriple 对象（第 2.2.2.7 节），定义与位图关联的逻辑颜色空间的 RGB 端点对应的三种颜色的 CIE 色度 x、y、z 坐标。如果 [`ColorSpaceType`](../colorspacetype/) 字段未指定 LCS_CALRIBRATED_RGB，则必须忽略此字段。

```csharp
public WmfCieXyzTriple Endpoints { get; set; }
```
