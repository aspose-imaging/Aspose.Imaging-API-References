## WmfLogColorSpace.ColorSpaceType property

获取或设置一个 32 位有符号整数，指定颜色空间类型。它必须在 LogicalColorSpace 枚举（第 2.1.1.14 节）中定义。如果该值为 LCS_sRGB 或 LCS_WINDOWS_COLOR_SPACE，则必须使用 sRGB 颜色空间。

public WmfLogicalColorSpaceEnum ColorSpaceType { get; set; }
