## WmfBitmapInfoHeader.Compression property

获取或设置一个 32 位无符号整数，定义 DIB 的压缩模式。此值必须位于 Compression 枚举（第 2.1.1.7 节）中。如果 DIB 是自上而下的位图（由 Height 值指示），此值不得指定压缩格式。

```csharp
public WmfCompression Compression { get; set; }
```
