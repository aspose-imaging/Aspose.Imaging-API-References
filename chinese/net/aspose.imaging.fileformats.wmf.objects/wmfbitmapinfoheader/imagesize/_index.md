## WmfBitmapInfoHeader.ImageSize property

获取或设置一个 32 位无符号整数，定义图像的大小（字节）。如果 Compression 值为 BI_RGB，则此值应为零并必须被忽略。如果 Compression 值为 BI_JPEG 或 BI_PNG，则此值必须分别指定 JPEG 或 PNG 图像缓冲区的大小。

```csharp
public int ImageSize { get; set; }
```
