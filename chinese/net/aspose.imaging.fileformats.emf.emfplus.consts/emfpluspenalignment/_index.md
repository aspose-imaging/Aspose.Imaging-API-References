## EmfPlusPenAlignment enumeration

PenAlignment 枚举定义了相对于所绘线条的笔宽分布。

```csharp
public enum EmfPlusPenAlignment
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| PenAlignmentCenter | `0` | 指定 EmfPlusPen 对象在理论线的中心位置。 |
| PenAlignmentInset | `1` | 指定笔位于理论线的内部。 |
| PenAlignmentLeft | `2` | 指定笔位于理论线的左侧。 |
| PenAlignmentOutset | `3` | 指定笔位于理论线的外部。 |
| PenAlignmentRight | `4` | 指定笔位于理论线的右侧。 |

## 备注

图形笔由 [`EmfPlusPen`](../../aspose.imaging.fileformats.emf.emfplus.objects/emfpluspen/) 对象指定（第 2.2.1.7 节）。通过考虑在两个指定点之间绘制的理论一维线，可以直观地了解笔对齐方式。笔对齐决定了笔宽相对于理论线的正交比例。
