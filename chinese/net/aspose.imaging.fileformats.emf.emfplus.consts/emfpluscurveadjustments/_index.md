## EmfPlusCurveAdjustments enumeration

CurveAdjustments 枚举定义可应用于图像颜色曲线的调整。

```csharp
public enum EmfPlusCurveAdjustments
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| AdjustExposure | `0` | 指定对图像曝光度进行增加或减少的模拟。 |
| AdjustDensity | `1` | 指定对图像密度进行增加或减少的模拟。 |
| AdjustContrast | `2` | 指定对图像对比度的增加或减少。 |
| AdjustHighlight | `3` | 指定在图像的某个颜色通道值已高于一半强度时，对该通道值进行增加或减少。此调整可用于在不影响暗部的情况下提升图像亮区的细节。 |
| AdjustShadow | `4` | 指定在图像的某个颜色通道值已低于一半强度时，对该通道值进行增加或减少。此调整可用于在不影响亮区的情况下提升图像暗部的细节。 |
| AdjustMidtone | `5` | 指定对图像进行亮化或暗化的调整。强度范围中部的颜色通道值会比接近最小或最大极值的通道值变化更大。此调整可在不失去图像最暗和最亮部分之间对比度的前提下，对图像进行亮化或暗化。 |
| AdjustWhiteSaturation | `6` | 指定对图像白色饱和度的调整，白色饱和度定义为给定颜色通道在强度范围内的最大值，通常范围为 0 到 255。 |
| AdjustBlackSaturation | `7` | 指定对图像黑色饱和度的调整，黑色饱和度是给定颜色通道在强度范围内的最小值，通常范围为 0 到 255。 |
