## EmfPlusWrapMode enumeration

WrapMode 枚举定义了当纹理或渐变画笔的图案小于填充区域时，如何在形状或形状边界上平铺该图案。

```csharp
public enum EmfPlusWrapMode
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| WrapModeTile | `0` | 平铺渐变或纹理。 |
| WrapModeTileFlipX | `1` | 水平翻转纹理或渐变，然后平铺该纹理或渐变。 |
| WrapModeTileFlipY | `2` | 垂直翻转纹理或渐变，然后平铺该纹理或渐变。 |
| WrapModeTileFlipXY | `3` | 水平和垂直翻转纹理或渐变，然后平铺该纹理或渐变。 |
| WrapModeClamp | `4` | 将纹理或渐变固定在对象边界上。 |
