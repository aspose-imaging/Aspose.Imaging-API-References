## EmfPlusBrushType enumeration

BrushType 枚举定义图形画刷的类型，这些画刷用于填充图形区域。

```csharp
public enum EmfPlusBrushType
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| BrushTypeSolidColor | `0` | 指定一种实色画笔，其特征是 EmfPlusArgb 值。 |
| BrushTypeHatchFill | `1` | 指定一种交叉线画笔，其特征是预定义的图案。 |
| BrushTypeTextureFill | `2` | 指定一种纹理画笔，其特征是一幅图像。 |
| BrushTypePathGradient | `3` | 指定一种路径渐变画笔，其特征是颜色渐变路径渐变画笔数据。 |
