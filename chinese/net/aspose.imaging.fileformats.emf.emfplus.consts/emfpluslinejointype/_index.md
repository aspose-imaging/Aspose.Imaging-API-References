## EmfPlusLineJoinType enumeration

LineJoinType 枚举定义了由同一图形笔绘制且端点相接的两条线的连接方式。

```csharp
public enum EmfPlusLineJoinType
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| LineJoinTypeMiter | `0` | 指定斜接线段连接方式。 |
| LineJoinTypeBevel | `1` | 指定斜角线段连接方式。 |
| LineJoinTypeRound | `2` | 指定圆角线段连接方式。 |
| LineJoinTypeMiterClipped | `3` | 指定裁剪的斜接线段连接方式。 |

## 备注

图形线由[`EmfPlusPen`](../../aspose.imaging.fileformats.emf.emfplus.objects/emfpluspen/)对象（第 2.2.1.7 节）指定。线段连接使两个线端的交叉看起来更连续。
