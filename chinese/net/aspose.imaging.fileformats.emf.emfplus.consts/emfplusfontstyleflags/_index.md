## EmfPlusFontStyleFlags enumeration

FontStyle 标志指定图形字体字形的样式。这些标志可以组合以指定多个选项。

```csharp
[Flags]
public enum EmfPlusFontStyleFlags
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| FontStyleBold | `1` | 如果设置，则必须以更粗的粗细或重量渲染字体字形。如果清除，则必须以正常粗细渲染字体字形。 |
| FontStyleItalic | `2` | 如果设置，则必须以相对于基线增加的角度或倾斜渲染字符的垂直笔画。如果清除，则必须以正常角度渲染字符的垂直笔画。 |
| FontStyleUnderline | `4` | 如果设置，则必须在字符基线下方绘制一条线来渲染字体字形。如果清除，则必须在字符基线下方不绘制线来渲染字体字形。 |
| FontStyleStrikeout | `8` | 如果设置，则必须在字符基线平行并穿过字符中部绘制一条线来渲染字体字形。如果清除，则必须不在字符中绘制线来渲染字体字形。 |

## 备注

图形字体字形由 [`EmfPlusFont`](../../aspose.imaging.fileformats.emf.emfplus.objects/emfplusfont/) 对象指定。
