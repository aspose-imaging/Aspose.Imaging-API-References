## EmfPlusObjectType enumeration

ObjectType 枚举定义了可以在图形操作中创建和使用的图形对象类型。

```csharp
public enum EmfPlusObjectType : byte
```

| ObjectTypePen | `2` | 指定一个[`EmfPlusPen`](../../aspose.imaging.fileformats.emf.emfplus.objects/emfpluspen/)对象（第 2.2.1.7 节）。Pen 对象绘制图形线条。 |
| ObjectTypePath | `3` | 指定一个[`EmfPlusPath`](../../aspose.imaging.fileformats.emf.emfplus.objects/emfpluspath/)对象（第 2.2.1.6 节）。Path 对象指定线条、曲线和形状的序列。 |
| ObjectTypeRegion | `4` | 指定一个[`EmfPlusRegion`](../../aspose.imaging.fileformats.emf.emfplus.objects/emfplusregion/)对象（第 2.2.1.8 节）。Region 对象指定输出表面的区域。 |
| ObjectTypeImage | `5` | 指定一个[`EmfPlusImage`](../../aspose.imaging.fileformats.emf.emfplus.objects/emfplusimage/)对象（第 2.2.1.4 节）。Image 对象封装位图和元文件。 |

| ObjectTypeImageAttributes | `8` | 指定一个[`EmfPlusImageAttributes`](../../aspose.imaging.fileformats.emf.emfplus.objects/emfplusimageattributes/)对象（第 2.2.1.5 节）。Image attribute 对象指定图像渲染期间对像素的操作，包括颜色调整、灰度调整、伽马校正和颜色映射。 |
