## EmfPlusCompositingMode enumeration

CompositingMode 枚举定义将源颜色与背景颜色合并的模式。合成模式表示 alpha 混合的启用状态。

```csharp
public enum EmfPlusCompositingMode : byte
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| CompositingModeSourceOver | `0` | 启用 alpha 混合，这表示在渲染颜色时，它会与背景颜色混合。混合程度由被渲染颜色的 alpha 分量值决定。 |
| CompositingModeSourceCopy | `1` | 禁用 alpha 混合，这意味着在渲染源颜色时，它会覆盖背景颜色。 |
