## EmfPlusSmoothingMode enumeration

SmoothingMode 枚举定义了用于线条、曲线以及填充区域边缘的平滑模式，使其呈现出更连续或更清晰的效果。

```csharp
public enum EmfPlusSmoothingMode : byte
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| SmoothingModeDefault | `0` | 指定默认的曲线平滑且不进行抗锯齿。 |
| SmoothingModeHighSpeed | `1` | 指定在不进行抗锯齿的情况下实现最佳性能。 |
| SmoothingModeHighQuality | `2` | 指定在使用抗锯齿时实现最佳质量。 |
| SmoothingModeNone | `3` | 不执行曲线平滑，也不进行抗锯齿。 |
| SmoothingModeAntiAlias8x4 | `4` | 指定使用 8x4 盒式滤波器以获得良好质量。 |
| SmoothingModeAntiAlias8x8 | `5` | 指定使用 8x8 盒式滤波器以获得更好质量。 |
