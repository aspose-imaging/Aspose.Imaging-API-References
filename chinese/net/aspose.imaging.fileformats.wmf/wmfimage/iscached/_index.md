## WmfImage.IsCached property

检索一个布尔值，指示对象的数据是否已缓存，从而消除额外的数据读取操作。利用此属性通过判断对象的数据是否已随时可用来优化性能，避免在您的应用程序中进行昂贵的数据检索过程。

```csharp
public override bool IsCached { get; }
```

### Property Value

`true` 如果对象的数据已缓存；否则为 `false`。
