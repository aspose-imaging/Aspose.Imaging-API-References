## 类

| 类 | 描述 |
| --- | --- |
| [WmfImage](./wmfimage/) | 使用我们的 API 操作 Microsoft Windows Metafile (WMF) 图像，能够无缝处理存储在可变长度记录中的矢量和位图数据。轻松调整大小、旋转和翻转图像，同时设置自定义图像调色板。将 WMF 文件转换为压缩的 WMZ 格式或保存为栅格图像格式，以实现跨平台和应用的多用途使用。 |
