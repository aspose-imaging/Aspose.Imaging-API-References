## TransformBrush.IsTransformChanged property

获取一个值，指示变换是否以某种方式被更改。例如设置变换矩阵或调用任何修改变换矩阵的方法。此属性为向后兼容 GDI+ 而引入。

```csharp
public bool IsTransformChanged { get; }
```

### Property Value

如果变换已更改则为 `True`；否则为 `false`。
