该命名空间提供帮助类和方法，以处理不同的画刷类型。

## 类

| 类 | 描述 |
| --- | --- |
| [HatchBrush](./hatchbrush/) | 定义具有交叉线样式、前景色和背景色的矩形画笔。此类不可被继承。 |
| [LinearGradientBrush](./lineargradientbrush/) | 封装具有线性渐变的 [`Brush`](../aspose.imaging/brush/)。此类不可被继承。 |
| [LinearGradientBrushBase](./lineargradientbrushbase/) | 表示具有渐变功能和相应属性的 [`Brush`](../aspose.imaging/brush/)。 |
| [LinearMulticolorGradientBrush](./linearmulticolorgradientbrush/) | 表示由多种颜色和相应位置定义的线性渐变 [`Brush`](../aspose.imaging/brush/)。此类不可被继承。 |
| [PathGradientBrush](./pathgradientbrush/) | 封装带有渐变的 [`Brush`](../aspose.imaging/brush/) 对象。此类不可被继承。 |
| [PathGradientBrushBase](./pathgradientbrushbase/) | 表示具有基础路径渐变功能的 [`Brush`](../aspose.imaging/brush/)。 |
| [PathMulticolorGradientBrush](./pathmulticolorgradientbrush/) | 封装带有渐变的 [`Brush`](../aspose.imaging/brush/) 对象。此类不可被继承。 |
| [SolidBrush](./solidbrush/) | 实心画笔用于使用特定颜色连续绘制。此类不可被继承。 |
| [TextureBrush](./texturebrush/) | [`TextureBrush`](../aspose.imaging.brushes/texturebrush/) 类的每个属性都是使用图像填充形状内部的 [`Brush`](../aspose.imaging/brush/) 对象。此类不可被继承。 |
| [TransformBrush](./transformbrush/) | 具有变换功能的 [`Brush`](../aspose.imaging/brush/)。 |
