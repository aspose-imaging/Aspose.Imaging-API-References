## TiffStreamReader.ThrowExceptions property

获取或设置一个值，指示在不正确的数据处理（读取或写入流）时是否抛出异常。

```csharp
public bool ThrowExceptions { get; set; }
```

### Property Value

`true` 表示在数据处理错误时抛出异常；否则，错误情况将被静默忽略。
