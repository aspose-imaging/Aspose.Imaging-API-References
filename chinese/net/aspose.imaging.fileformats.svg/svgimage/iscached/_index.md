## SvgImage.IsCached property

检索一个布尔值，指示对象的数据当前是否已缓存，从而消除额外的数据读取操作的需求。此属性提供对当前缓存状态的洞察，优化数据检索和处理工作流，以提升性能和效率。

```csharp
public override bool IsCached { get; }
```

### Property Value

`true` 如果对象的数据已缓存；否则为 `false`。
