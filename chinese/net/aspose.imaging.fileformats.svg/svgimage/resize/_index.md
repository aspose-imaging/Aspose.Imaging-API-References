## SvgImage.Resize method

调整图像大小以适应指定的尺寸，同时保持其纵横比。此方法提供了一种方便的方式来在不失真比例的情况下调整图像大小，确保根据所需尺寸实现最佳显示或存储。

```csharp
public override void Resize(int newWidth, int newHeight, ResizeType resizeType)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| newWidth | Int32 | 新的宽度。 |
| newHeight | Int32 | 新的高度。 |
| resizeType | ResizeType | 缩放类型。 |
