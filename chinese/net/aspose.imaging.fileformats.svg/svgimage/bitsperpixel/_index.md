## SvgImage.BitsPerPixel property

检索图像的每像素位数。需要注意的是，此参数不适用于矢量图像，因为它们不是以像素为单位测量的。此属性提供有关图像颜色深度的关键信息，有助于处理和操作任务。

```csharp
public override int BitsPerPixel { get; }
```

### Property Value

图像每像素位数。

### 异常

| 异常 | 条件 |
| --- | --- |
| NotImplementedException | 对矢量图像无效 |
