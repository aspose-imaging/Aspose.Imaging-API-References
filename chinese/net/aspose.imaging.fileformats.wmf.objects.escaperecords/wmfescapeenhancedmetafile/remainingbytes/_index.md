## WmfEscapeEnhancedMetafile.RemainingBytes property

获取或设置剩余字节。

```csharp
public int RemainingBytes { get; set; }
```

### Property Value

一个 32 位无符号整数，指定在此记录之后仍需处理的 EMF 流中字节数。这些额外的 EMF 字节必须在后续 META_ESCAPE_ENHANDED_METAFILE 转义记录的 EnhancedMetafileData 字段中出现。
