## CdrRasterizationOptions class

此 API 具备对 CDR 图像进行栅格化并设置 X、Y 方向比例因子的能力，提供对转换过程的精确控制。无论是针对特定输出需求进行缩放，还是将矢量图形转换为栅格格式，您都可以利用此 API 实现高效且可定制的 CDR 矢量到栅格图像转换。

```csharp
public class CdrRasterizationOptions : VectorRasterizationOptions
```
