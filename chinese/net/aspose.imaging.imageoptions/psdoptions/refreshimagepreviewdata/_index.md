## PsdOptions.RefreshImagePreviewData property

获取或设置一个值，指示是否 [refresh image preview data] - 该选项用于最大化与其他 PSD 图像查看器的兼容性。请注意，紧凑框架平台不支持将文本图层绘制到最终布局。

```csharp
public bool RefreshImagePreviewData { get; set; }
```

### Property Value

`true` 如果 [refresh image preview data]；否则，`false`。
