## DjvuMultiPageOptions class

DjVu 图形文件格式的 API 为开发者提供了对 DjVu 文档的无缝访问，适用于扫描文档和书籍。通过图像加载选项，开发者可以轻松将 DjVu 文件集成到其应用程序中，释放处理多页内容（包括文本、图形和图像）的潜力，从而实现多功能的文档处理解决方案。

```csharp
public class DjvuMultiPageOptions : MultiPageOptions
```
