## DxfOptions.ConvertTextBeziers property

当  被设置为 `true` 时生效。是否将文本轮廓中的贝塞尔曲线转换为多点多段线。

```csharp
public bool ConvertTextBeziers { get; set; }
```

### Property Value

`true` 导出为多点折线，点数由 . 控制。`false` 将文本轮廓中的每个贝塞尔导出为仅 4 点 /// 折线。
