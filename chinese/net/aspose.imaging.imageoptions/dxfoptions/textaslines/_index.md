## DxfOptions.TextAsLines property

文本是应导出为由多段线组成的轮廓（默认）还是可编辑的 Autocad TEXT 实体。如果设置了此选项

```csharp
public bool TextAsLines { get; set; }
```

### Property Value

`true` 导出文本为轮廓（默认），否则 `false` 导出文本为 TEXT 实体。
