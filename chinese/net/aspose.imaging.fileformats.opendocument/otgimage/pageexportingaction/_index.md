## OtgImage.PageExportingAction property

此属性允许检索或修改与图像关联的页面导出操作。它作为关键参数，决定图像在导出或进一步处理时的行为。请注意，设置此方法后将在执行后自动释放页面资源，并在每个页面保存之前执行。

```csharp
public override PageExportingAction PageExportingAction { get; set; }
```

### Property Value

页面导出操作。
