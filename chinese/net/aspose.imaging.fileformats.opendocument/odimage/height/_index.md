## OdImage.Height property

返回图像的高度，以像素为单位表示垂直尺寸。此属性对于了解图像的整体尺寸和比例至关重要，有助于图像内容的准确显示和处理。

```csharp
public override int Height { get; }
```

### Property Value

图像高度。
