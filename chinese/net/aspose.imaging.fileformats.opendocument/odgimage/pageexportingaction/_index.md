## OdgImage.PageExportingAction property

此属性允许轻松检索或修改与页面导出相关的操作。通过精确操作此属性，软件解决方案能够灵活地根据特定应用需求定制页面导出行为，确保最佳性能和提升用户体验。请注意，设置此方法后将在执行后自动释放页面资源，并在每个页面保存之前执行。

```csharp
public override PageExportingAction PageExportingAction { get; set; }
```

页面导出操作。
