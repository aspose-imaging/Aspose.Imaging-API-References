## ColorComparisonMode enumeration

指定在 Magic Wand 算法期间颜色的比较方式。

```csharp
public enum ColorComparisonMode
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| RgbDefault | `0` | 颜色在 RGB 颜色空间中进行比较。每个颜色差异必须满足阈值。 |
| YuvDefault | `1` | 颜色在 YUV 颜色空间中进行比较。每个颜色差异必须满足阈值。 |
| YuvLessLumaSensitive | `2` | 颜色在 YUV 颜色空间中进行比较。颜色信息差异必须满足阈值，亮度分量的阈值加倍。 |
| Custom | `3` | 颜色比较算法由用户定义。 |
