### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Axial | `0` | 轴向定义了一种双线性渐变，也称为反射渐变或镜像线性渐变。它被创建为沿其轴线镜像（或反射）的线性渐变。 |
| Ellipsoid | `1` | 椭圆体定义了一种渐变，颜色沿由 draw:cx 和 draw:cy 属性定义的椭圆中心的半径混合。半长轴的长度是填充区域的宽度，半短轴的长度是 |
| Linear | `2` | 线性定义了一种渐变，颜色沿渐变的线性轴混合。渐变的轴线使用 draw:angle 属性指定，顺时针相对于垂直轴。 |
| Radial | `3` | 径向定义了一种渐变，颜色沿由 draw:cx 和 draw:cy 属性定义的圆心半径混合。圆的外部填充终止颜色。 |
| Rectangle | `4` | 矩形定义了一种渐变，从矩形中心向四条边中最短的方向产生矩形混合。矩形的中心由 draw:cx 和 draw:cy 属性定义。矩形的宽度是填充区域的宽度，矩形的高度是填充区域的高度。正方形的外部填充终止颜色。 |
| Square | `5` | 正方形定义了一种渐变，产生方形混合，模拟走廊中的视觉透视或金字塔的鸟瞰图。也称为“盒子渐变”和“金字塔渐变”。正方形的中心由 draw:cx 和 draw:cy 属性定义。正方形的宽度和高度取填充区域的宽度或高度的最小值。正方形的外部填充终止颜色。 |
| None | `6` | 渐变样式为无 |
