## GifImage.IsInterlaced property

确定图像是否为交错显示，这会影响加载时的呈现。此属性提供对图像渲染行为的洞察，对优化加载策略和提升整体观看体验至关重要。

```csharp
public bool IsInterlaced { get; }
```

### Property Value

`true` 表示此图像实例为交错；否则为 `false`。
