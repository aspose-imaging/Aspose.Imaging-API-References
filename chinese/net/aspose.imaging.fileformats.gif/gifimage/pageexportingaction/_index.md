## GifImage.PageExportingAction property

此属性允许对页面的导出操作进行控制，以在导出页面数据时指定所需的操作。它提供了根据应用或工作流需求选择导出操作的灵活性，提升了定制化和适应性。请注意，设置此方法后将在执行后自动释放页面资源，并在每个页面保存之前执行。

```csharp
public override PageExportingAction PageExportingAction { get; set; }
```

### Property Value

页面导出操作。
