## GifImage.LoopsCount property

使用此属性轻松获取循环计数。如果您的 GIF 图像包含循环信息，此属性可快速获取循环计数，使您能够无缝管理 GIF 文件中的循环行为。

```csharp
public int LoopsCount { get; set; }
```

### Property Value

循环计数或 1（默认值）
