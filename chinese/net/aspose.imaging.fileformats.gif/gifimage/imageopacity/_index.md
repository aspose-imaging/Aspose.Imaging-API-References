## GifImage.ImageOpacity property

获取图像中活动帧的不透明度，了解其透明程度。此属性对于理解活动帧的透明或不透明程度特别有用。

```csharp
public override float ImageOpacity { get; }
```

### Property Value

透明度值介于 0.0（完全透明）和 1.0（完全不透明）之间。
