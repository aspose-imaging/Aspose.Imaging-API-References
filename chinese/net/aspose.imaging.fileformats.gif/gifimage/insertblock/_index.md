## GifImage.InsertBlock method

插入新的 GIF 块允许您在图像的特定位置添加自定义数据。此方法使您能够在 GIF 图像中将自定义块放置在所需位置，提供组织和结构化图像数据的灵活性。

```csharp
public void InsertBlock(int index, IGifBlock block)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 索引 | Int32 | 零基索引的元素，即块将被插入的位置。 |
| 块 | IGifBlock | 要添加的 GIF 块。 |
