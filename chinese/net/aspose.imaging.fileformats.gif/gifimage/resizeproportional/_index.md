## GifImage.ResizeProportional method

比例缩放在调整图像大小的同时保持图像的宽高比，确保图像不会出现拉伸或失真。此方法按比例调整图像大小，宽度和高度以相同的比例进行缩放。比例缩放将根据 *newWidth*/width 和 *newHeight*/height 的比例来调整每帧的大小。

```csharp
public void ResizeProportional(int newWidth, int newHeight, ResizeType resizeType)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| newWidth | Int32 | 新的宽度。 |
| newHeight | Int32 | 新的高度。 |
| resizeType | ResizeType | 缩放类型。 |
