## DisposalMethod enumeration

指示图形显示后应如何处理。

```csharp
public enum DisposalMethod
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| None | `0` | 未指定处理方式。 |
| Preserve | `1` | 不处理。图形保持原位。 |
| Restore | `2` | 恢复为背景颜色。图形占用的区域必须恢复为背景颜色。 |
| Previuos | `3` | 恢复为先前状态。解码器需要将图形覆盖的区域恢复为渲染图形之前的内容。 |
| Undefined | `4` | 未定义的值。 |
